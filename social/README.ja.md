# 社交型 SOCIAL（social/）

[中文](README.md) | [English](README.en.md) | 日本語
中文版（2026-10-29 時点）からの翻訳。

注意力アドオンシリーズ · 番号 SO01–SO05、全5件。場面上の注意力を分担する。

- SO01 [chat-catchup](chat-catchup/) — 会話に置いていかれたら首を振って助けを求め、直近15秒の要点を目の前に要約表示
- SO02 [guest-watch](guest-watch/) — 来客を一人ずつ見て座席を登録、定時にお茶の残量確認を促す
- SO03 [elder-ear](elder-ear/) — 高齢者の会話を聞き守り、言いつけの文をリストに保存して会話の後に復唱
- SO04 [standup-echo](standup-echo/) — スタンドアップ会議を聞き守り関連する文だけを光らせ、外れた分は黙って記録・要約して後で検索
- SO05 [gift-clue](gift-clue/) — 日常会話の「欲しい」の文を黙って手がかりカードにし、人ごとに再生

全リストは[リポジトリ ルート README](../README.md) 末尾の Agent リストを参照。
