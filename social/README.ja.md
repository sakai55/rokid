# 社交型 SOCIAL（social/）

[中文](README.md) | [English](README.en.md) | 日本語
中国語版（2026-10-29 時点）の翻訳。

注意力アドオンシリーズ。SO01–SO05、全5件。場の注意力はこちらで分担する。

- SO01 [chat-catchup](chat-catchup/) — 会話に置いていかれたら首を振って合図。直近15秒の要点を目の前に要約表示する
- SO02 [guest-watch](guest-watch/) — 来客を1人ずつ見て座席を登録。定期的に、お茶の減り具合の確認を促す
- SO03 [elder-ear](elder-ear/) — 高齢者の話を聞き張り、言いつけの文をリストに保存。話の後に復唱する
- SO04 [standup-echo](standup-echo/) — スタンドアップを聞き張り、自分に関係する文だけを光らせる。外れた分は黙って記録し、要約を後で引ける
- SO05 [gift-clue](gift-clue/) — 日常会話の「欲しい」の一文を黙って手がかりカードにする。人ごとに再生する

全リストはルートの [README](../README.md) 末尾にある Agent リストを参照。
