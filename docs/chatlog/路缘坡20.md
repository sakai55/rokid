维基的定义是：无障碍设施被远大于原设计人群的人使用和欢迎，路缘坡本为轮椅而修，后来推婴儿车、拉行李的人也受益；它与通用设计的区别在于溢出常常是无意的。原文还有一条警告我写进了宪法：当无障碍被从属于「对所有人有好处」时，针对残障者的个体化设计反而会被拒绝。

所以每个 Agent 强制过**立项三问**：① 坡道本体——哪类人、哪条通道断了，拿掉这类人它必须立刻不成立；② 通道改造——视障零屏幕、听障零语音、单手零手部操作、失语靠看选+TTS 代说，断掉的通道整条换掉；③ 溢出地图——只许写「普通人在什么情境性障碍下会用」：抱娃=暂时单手，嘈杂菜场=暂时听障，异国语言不通=暂时失语。不许为溢出人群把坡修陡。
