## Muse — 2026-10-28 20:07
结论：**一半在界内、一半超界**。拆开看：

**界内（能真接线）**
- 逐帧拍摄：`grabFrame` 抓帧 → Canvas 缩到 480×352 → JPEG 存帧序列，或者低频用 `takePhoto`。没问题。
- 定格动画的核心体验全在界内：洋葱皮（上一帧半透明叠在取景上，Canvas 的透明度+drawImage 都有）、语音报数/倒计时、按设定帧率在眼镜内逐帧播放合成预览。参数三件套（播放帧率、总张数、拍摄时长）就是普通设置页。

**超界（官方档案里不存在）**
- **「AI 合成出视频文件」没有编码器**：我刚把 aiui-dev 全部 API 参考 grep 过了 — 没有 `captureStream`、没有 WebCodecs/VideoEncoder、没有 GIF/MP4 帧编码器。Canvas 只能输出 PNG/JPEG 单张图；`MediaRecorder` 只能录**实时流**（摄像头/麦克风），不能把一串静帧喂进去编码。网页上经典的「canvas.captureStream + MediaRecorder 合成」路线，在 Ink 里未文档化，不能当它存在。
- **基座 LLM 也帮不上合成**：`LanguageModel` 只收图、只出文字，没有图像/视频生成输出。所谓 AI 合成如果指生成式补帧或云端 AI 成片，那就得走 HTTPS 上传外部服务 + 域名白名单报备，是外挂依赖，不是基座能力。

**还有一个参数口径要先钉死**
「最长 3 分钟」只能是**拍摄时长**上限，不能是成片时长。成片 3 分钟 × 12fps = 2160 帧，逐帧拍不出来也存不下。可行量级：拍摄 ≤3 分钟、每 1–2 秒或手动一帧、总张数封顶约 120 帧（480 宽 JPEG 约 20–50KB/帧，整批约 3–6MB 只放内存，不承诺跨会话存全部帧），成片 = 张数 ÷ 帧率，即 10–30 秒量级。

**可行的建法（顺带再顶一条新边界）**
做成 AV11「定格工场」：设置页（帧率 4/6/8/12、张数、拍摄时长 ≤3 分钟）→ 拍摄页（洋葱皮+语音报数+手动/定时快门）→ 合成页（眼镜内按帧率播放，即「合成」）→ 作品页（只存参数与计数）。外加一页**编码探针**：真机实测 `canvas.captureStream` 到底存不存在、能不能喂给 MediaRecorder — 存在就是意外之喜可真导出 MP4，不存在导出按钮就如实标 placeholder，绝不假装导出了。
