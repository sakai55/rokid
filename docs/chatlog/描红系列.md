开一个新系列：描红系列（Rokid AIUI Agent）。

系列的壳是固定的，就四件事：眼镜画面中央显示一个范本，边上是步骤，
用户照着范本用自己的手（或手里的笔）做到位，主动触发拍照，眼镜拍照给
LLM 看，判定过了才进下一步。一句话：中央范本 + 边上步骤 + 做一步验一步。

立这个壳的原因：眼镜没有手部追踪，做不了实时纠正；但范本浮在眼前，
用户自己把手伸过去对齐，对齐的过程就是学习——跟小孩描红一个道理。
系统不盯过程，只在每一步结束时验收。

平台铁律（不许突破、不许在文案里暗示能做到）：
- 看手只能靠拍照→data URL→LLM 图片输入这条路，是定格判定，不是连续追踪；
  手语动态词、手的轨迹、实时纠偏一律不做，要切成一段一段验。
- LLM 看图会认错：判定结果必须允许用户纠正/跳过，认不准要老实说认不准。
- 识别只是闭环里的一步，单独做「认出这是什么」与慧眼默认能力冲突，出局；
  每个 Agent 必须有完整场景：学/练→验收→进度存下来下次接着练。

   专业书法评分：有没有少笔多笔、结构重心偏没偏、跟范字差最明显的一
   两处在哪。查完给一句人话点评，用户可自己确认「这字算过」覆盖判定。

内容集先做 20 个常用字，每个字要有笔顺和分笔数据——笔顺数据必须有
可靠来源，来源说不清的字不收进字库，宁可少。

注意：判定只对着用户自己写的字，不拍他人正脸，不做医疗/康复类声明。
