# my-agent — AIUI 脚手架示例智能体

官方脚手架（`npm create @yodaos-pkg/aiui-agent`）生成的示例 Agent：单页 `pages/index/index.ink`，点击后问候语在 “Hello AIUI!” 与 “你好，世界！” 之间切换。用于验证开发 → 打包 → GitHub → Studio 导入 → 真机测试全流程。

在 AIUI Studio 中导入本仓库时，子目录选 `my-agent`。
