描紅シリーズの日本語版（TR01 毛筆字描紅の姉妹台）。日本語初学者のための平仮名 46 字のなぞり練習です。範字は筆形——KanjiVG の筆順・中心線に、教科書体フォント Klee One の輪郭で実測した太さを持たせた字形で、一画ずつ学びます。中央の範字（低輝度）＋書き始めの位置にある筆順の弧と番号（高輝度）を見ながら、本物の紙に筆やペンで書き、下を向いて写真を撮ると粗い三点だけをチェックします。判定は本人の「できた」が優先し、進捗は次回に続きます。

## 機能（7 ページの閉ループ）

| ページ | 内容 |
|---|---|
| 今日 | 今日のかな（日付で回す）＋前回の続き＋進捗の要約、六つの行き先 |
| 一覧 | 46 字の総表（字／ローマ字／画数／練習回数）、フォーカスで選択 |
| 学ぶ | **範字全面**：キャンバスがページを占め、筆形ポリゴンを一画ずつ描く（本体は全画・全状態で統一の低輝度、高輝度は筆順注釈だけ）；範字の本体は約 190px（机上描紅の距離の目安：目から机まで約 40cm、練習帳の一字約 9cm）；各画に**書き始めの位置の筆順の弧**（中心線の開始区間に平行、字身との間に黒い隙間を空け、標本点ごとに輪郭への侵入を硬く検証、置けなければ離れた短い弧で受ける）と実心の矢印（最明るい緑、向きは運筆方向）、**筆順の番号**は弧の尾（＝書き始め）に固定して常に外側（同じ側に二つ寄らない）；下の細い欄に「何画目／全何画（画の種類）＋その画の要点」を出し、TTS が要点を読み上げる；画の位置はそのつど保存し、再入で復元（下記「プラットフォームの境界」参照） |
| 読み方と書き方 | ローマ字、用例、重心の目安（輪郭の面積重心から算出）、画の流れ、データ出典、要点の全画読み上げ |
| 写真チェック | 下を向いて自分の書いた字を撮影。LLM が範字と比べて粗い三点だけ：①画の過不足 ②重心 ③最も目立つ違い 1〜2 か所。見えなければ正直に「見えない」と返し、撮り直しを促す |
| 講評 | 三点＋一言講評の提示。**本人の「できた」判定が機械判定より優先**し、記録に残る（上書き回数を別に記録）。チェックしていない字は「できた」にできない |
| 進捗 | 練習済みの字／字ごとの回数／練習日数の総覧＋復習テスト（字をランダムに引き、チェックページではローマ字だけ・範字なしで書いてから撮る） |

## 字書とデータ出典（二源、欠ければ収録しない）

- 46 字（清音、五十音順）：あ い う え お か き く け こ さ し す せ そ た ち つ て と な に ぬ ね の は ひ ふ へ ほ ま み む め も や ゆ よ ら り る れ ろ わ を ん。全 104 画。
- 筆順・中心線：KanjiVG（CC BY-SA 3.0）の SVG を変換。字形の太さ：Klee One（教科書体、SIL OFL 1.1）の輪郭幅を中心線に沿って実測し、筆形ポリゴンとして再構成。フォント自体は同梱しない（数値データのみ）。ライセンスは `LICENSE-data.txt`。
- 画数は全字照合済み（あ3 い2 う2 え2 お3／か3 き4 く1 け3 こ2／さ3 し1 す2 せ3 そ1／た4 ち2 つ1 て1 と2／な4 に3 ぬ2 ね2 の1／は3 ひ1 ふ4 へ1 ほ4／ま3 み2 む3 め2 も3／や3 ゆ2 よ2／ら2 り2 る1 れ2 ろ1／わ2 を3 ん1）。**「そ」は KanjiVG 準拠で 1 画**（現代の教科書体で一般的な一画書き。一覧ページにも明示）。
- 各画の要点は本シリーズ自作の粗い練習ヒント（入筆／運筆／収筆）で、書道の専門的な評価基準ではありません。

## 方向性 / インタラクション

- 手勢が主、画面のボタンは最小：うなずき＝フォーカスの実行（チェックページでは撮影）、タップ＝確定（Enter）、上下スワイプ＝フォーカス移動／字の選択、二本指タップ相当の戻る（Backspace、一覧ページで接続済み）。
- 音声：各画の要点を TTS が読み上げ（学ぶページは画を進めるたび、読み方ページは全画まとめて）。音声入力は使わない。

## プラットフォームの境界

- **描紅中の画面消灯**：公式ドキュメント全量を確認しても、常時点灯／wake lock の API はありません。Agent 側では消灯を防げないため、学ぶページは画の位置をそのつど保存し（キー `trace.kana.learn`）、同じ字に再入したとき現在画へ戻ります。
- **判定の境界**：写真チェックは粗い三点だけの目安です。LLM は間違えることも見えないこともあり、見えないときは正直に返します。最終の「できた」は本人が決めます。
- **フォントの境界**：実行環境にフォント読み込みの仕組みがないため、教科書体の字形は実行時に読み込むのではなく、変換時に数値データ（筆形ポリゴン）として焼き込んでいます。

## 権限

`CAMERA`（チェック撮影）のみ。TTS に独立した権限はありません。
