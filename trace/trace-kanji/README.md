描紅シリーズの日本語版（TR01 毛筆字描紅の姉妹台）。日本語初学者のための常用漢字 30 字のなぞり練習です。範字は TR01 と同じ真輪郭——hanzi-writer-data の分筆輪郭を空心で描き、筆順は KanjiVG と全字照合して日本式に整えてあります。中央の範字（低輝度）＋書き始めの位置にある筆順の弧と番号（高輝度）を見ながら、本物の紙に筆やペンで書き、下を向いて写真を撮ると粗い三点だけをチェックします。判定は本人の「できた」が優先し、進捗は次回に続きます。

## 機能（7 ページの閉ループ）

| ページ | 内容 |
|---|---|
| 今日 | 今日の漢字（日付で回す）＋前回の続き＋進捗の要約、六つの行き先 |
| 一覧 | 30 字の総表（字／読み／画数／練習回数）、フォーカスで選択 |
| 学ぶ | **範字全面**：キャンバスがページを占め、分筆の輪郭を空心で一画ずつ描く（TR01 と同一方式。本体は全画・全状態で統一の低輝度、高輝度は筆順注釈だけ）；範字の本体は約 205px（机上描紅の距離の目安：目から机まで約 40cm、練習帳の一字約 9cm）；各画に**書き始めの位置の筆順の弧**（中心線の開始区間に平行、字身との間に黒い隙間、標本点ごとに輪郭への侵入を硬く検証、置けなければ離れた短い弧で受ける）と実心の矢印（最明るい緑、向きは運筆方向）、**筆順の番号**は弧の尾（＝書き始め）に固定して常に外側（同じ側に二つ寄らない）；下の細い欄に「何画目／全何画（画の種類）＋その画の要点」を出し、TTS が要点を読み上げる；画の位置はそのつど保存し、再入で復元（下記「プラットフォームの境界」参照）。注釈幾何の QC ゲート（`qc/check-geometry.js`、TR01 v2 の継承）は **v1.0.0 基線で PASS**（弧 105＝平行 94／受け 11、最小隙間 6.51px） |
| 読み方と書き方 | 読み（音・訓）、意味、構成、重心の目安、画の流れ、データ出典、要点の全画読み上げ |
| 写真チェック | 下を向いて自分の書いた字を撮影。LLM が範字と比べて粗い三点だけ：①画の過不足 ②重心 ③最も目立つ違い 1〜2 か所。見えなければ正直に「見えない」と返し、撮り直しを促す |
| 講評 | 三点＋一言講評の提示。**本人の「できた」判定が機械判定より優先**し、記録に残る（上書き回数を別に記録）。チェックしていない字は「できた」にできない |
| 進捗 | 練習済みの字／字ごとの回数／練習日数の総覧＋復習テスト（字をランダムに引き、チェックページでは読みだけ・範字なしで書いてから撮る） |

## 字書とデータ出典

- 30 字（常用の小セット）：一 二 三 四 五 六 七 八 九 十 人 山 川 田 日 月 火 水 木 生 土 大 小 中 上 下 左 右 本 年。全 105 画。
- 分筆の輪郭・中心線：hanzi-writer-data（Make Me a Hanzi プロジェクト、Arphic 字体由来、Arphic Public License）。ライセンスは `LICENSE-data.txt`。
- 筆順は KanjiVG（CC BY-SA 3.0）と全字照合（画数一致＋各画の開始位置）。日中の筆順が違う三字は画ごと入れ替えて日本式にした：**右（1・2画）、田（3・4画）、生（3・4画）**。
- **「金」は収録を見送り**：8 画の密集字で、凍結仕様の注釈幾何では第 5 画に弧が置けず QC ゲート（画の被覆）が不合格になったため、代わりに「生」を収録。注釈方式を変えない限り金は戻さない。
- 読み・意味・各画の要点は本シリーズ自作の粗い練習ヒント（入筆／運筆／収筆）で、書道の専門的な評価基準ではありません。
- 仮名版 trace-kana の筆形方式（中心線＋実測幅の塗りポリゴン）は輪郭の滑らかさが基準に達せず中止となり、本台は真輪郭方式に戻した。kana 版は v1.0.1 のまま保存されている。

## 方向性 / インタラクション

- 手勢が主、画面のボタンは最小：うなずき＝フォーカスの実行（チェックページでは撮影）、タップ＝確定（Enter）、上下スワイプ＝フォーカス移動／字の選択、二本指タップ相当の戻る（Backspace、一覧ページで接続済み）。
- 音声：各画の要点を TTS が読み上げ（学ぶページは画を進めるたび、読み方ページは全画まとめて）。音声入力は使わない。

## プラットフォームの境界

- **描紅中の画面消灯**：公式ドキュメント全量を確認しても、常時点灯／wake lock の API はありません。Agent 側では消灯を防げないため、学ぶページは画の位置をそのつど保存し（キー `trace.kanji.learn`）、同じ字に再入したとき現在画へ戻ります。
- **判定の境界**：写真チェックは粗い三点だけの目安です。LLM は間違えることも見えないこともあり、見えないときは正直に返します。最終の「できた」は本人が決めます。

## 権限

`CAMERA`（チェック撮影）のみ。TTS に独立した権限はありません。
