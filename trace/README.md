# trace — 描红系列

中央范本 + 边上步骤 + 做一步验一步：范本浮在眼前，用户用自己的手（或手里的笔）对齐做到位，主动触发拍照，LLM 定格验收过了才进下一步。系列全案见 [PLAN-Trace-Series.md](PLAN-Trace-Series.md)。

编号 TR01–TR08（建设中，建成一台登记一台）：

- TR01 trace-brush — 毛笔字描红练习（20 字逐笔范字 + 拍照验字）
- TR02 trace-seals — 结印描红（十二基本印，连续多图范本，探针先行）
- TR03 trace-sign — 手语描红（日本手语 JSL 静态手势，探针先行）
- TR04 trace-origami — 折纸描红
- TR05 trace-knots — 绳结描红
- TR06 trace-sketch — 简笔画描红
- TR07 trace-plating — 摆盘描红
- TR08 trace-cube — 魔方描红（探针先行）

探针（不占编号、不上清单）：trace-probe-seals、trace-probe-sign。

完整清单见 [根 README](../README.md)。
