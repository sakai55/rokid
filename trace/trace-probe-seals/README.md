# Trace Probe Kuji · 印を結ぶ探针（九字印识别试验）

**Studio 导入地址**（复制到 Global AIUI Studio 的 Import Project 输入框）：

```
https://github.com/sakai55/rokid/tree/agent-trace-probe-seals
```

描红系列的识别可行性探针，**不占 TR 编号、不上根清单**：测 LLM 靠一张定格照片认九字印（臨・兵・闘・者・皆・陳・烈・在・前）到底准不准。结果决定 TR02「印を結ぶ」正式版的收录范围（事先定死的门槛：认对进计分档、认错只进不计分练习档、看不清复测后不收、全集认对不足一半则正式版降级为自评描红）。

v2.0.0 起：内容集由十二地支印改为九字印 9 印，**UI 全日语**，存储键换为 `trace.probe.kuji.v1`（旧键数据不迁移）。v1.x 的十二印中文版已废弃。

## 玩法（试验流程）

1. **说明页（説明）**：摆位要求（双手举到眼前约 50cm、背景尽量素、光线均匀）、佩戴者视角声明、见本数据收录状态、已测进度（可续测）。
2. **轮测页（輪測）**：逐印显示单帧见本（中央小图、高约 92px）+ 每印一句要点。照要点结好，**点头拍照**，LLM 从 9 印名单中判定（固定输出：认成什么 / 像不像目标 / 哪根手指对不上；认不出、判别不能如实说）。随后由佩戴者点「正解 / 不正解」定真值，落盘。
3. **结果页（結果）**：逐项表（目标 / LLM 认成什么 / 对错）+ 汇总；回传方式 = 把集计数口述给维护者。

## 范本数据（见本）——做法与当前状态

- **唯一参照**：GO 定版的九栏黑白图谱（仓库外参照图 `~/workspace/rokid/kuji-reference-chart.jpg`，GO 评「这个最规矩」）。印刷页照片已退出参照——印形与要点文案都不用它。
- **做法 = 参照重绘，不做提取**：以图谱为底稿重新描画自有线稿：指尖与手腕沿图谱自身线条走向延长补完（原图每栏有框、手在框下缘被切断，直接提取会继承这个缺陷）、统一线宽、左右反转到佩戴者视角；定版后栅格化到高 92px（屏高约 26%，按眼到手约 50cm 的对位比例，待真机校准），按行程编码（runs：`{ w, h, rows }`，每行 `[y, x0, len0, x1, len1, ...]`）存入 `data.js` 的 `art` 字段，页面用 Canvas 逐行画 1px 细线（`#7dff9e`）。
- **当前状态（2.0.0）**：前四印（臨兵闘者）重绘样张已由主聊按此法做出、待 GO 点头；点头后按同法补全 9 印数据。**本版 `art` 全印为 null**，轮测页对无数据印如实显示「見本準備中」空框 + 要点文字，不放代用图、不拿提取数据凑数。

## 要点文案出典（一句版，逐印标注）

要点只认图谱各栏下方的竖排说明（崩し字）。读到的断片与定版方式如下；读不出的不编造：

| 印 | 定版 | 根拠（图谱断片） |
|---|---|---|
| 臨 独古印 | 提炼 | 「左右の手」「指を揃へて合はせる」断片可读 |
| 兵 大金剛輪印 | 一般说明 | 断片は「指を揃へて結ぶ」程度まで、文として読解不能 |
| 闘 外獅子印 | 提炼 | 「人差し指・中指を立て」「無名指・小指」断片可读 |
| 者 内獅子印 | 一般说明 | 指名の断片が散在するのみ、文として読解不能 |
| 皆 外縛印 | 一般说明 | 「外へ」の断片のみ、文として読解不能（方向は図と一致） |
| 陳 内縛印 | 一般说明 | 「指を内へ」の断片のみ、文として読解不能（方向は図と一致） |
| 烈 智拳印 | 提炼 | 「左」「人差し指」「添へて」断片可读 |
| 在 日輪印 | 提炼 | 「左右の大指」「つける」「開く」断片可读 |
| 前 隠形印 | 提炼 | 「手の上に置く」断片可读 |

「見分け方」行是本探针自撰的混淆提示（不是图谱原文），只用于摆印时对照。

## 方向性 / 交互

核心 = SCAN（拍照）+ HEAD（点头触发拍照）。手势：点头 = 拍照判定 / 执行焦点；单指点按 = 确认（Enter）；上下滑 = 切焦点；双击 = 返回（Backspace）。屏幕按钮与手势一一对应，手势可独立跑完一轮。判定只发生在定格单张照片上——这是定格判定，不是连续追踪，本探针不暗示能实时纠正手势。
