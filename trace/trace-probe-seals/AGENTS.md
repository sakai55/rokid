# Trace Probe Kuji — Agent Notes

描红系列识别探针（不占 TR 编号、不上根清单、不挂徽章）。壳版本：描红壳 v1（ModelView / StepRail / PhotoJudge / Progress 四部件的探针形态）。v2.0.0 起内容集 = 九字印 9 印、UI 全日语（v1.x 的十二地支印 + 中文 UI 已废弃）。

## Design contract

- 目的只有一个：测 LLM 定格拍照认九字印（臨・兵・闘・者・皆・陳・烈・在・前）的命中率，探针结果决定 TR02「印を結ぶ」正式版的收录范围（认对进计分、认错只进不计分练习、看不清复测后不收、全集认对不足一半则正式版降级自评描红）。
- 说明页：摆位（双手举到眼前约 50cm、素背景、匀光）、佩戴者视角声明、进度续测、见本数据收录状态如实显示。
- 轮测页：每印单帧见本（再描画线画、装着者视点、表示高 92px）+ 要点文字，见本在上/旁、印名与要点不遮挡见本；摆好后点头（或选「撮影して判定」）拍照；判定只对定格单张照片，不是连续追踪。
- 见本数据（`data.js` 的 `art`）：以九栏图谱（唯一参照）为底稿**重新描画**的自有线稿（指尖与手腕沿图谱自身线条走向延长补完、统一线宽、左右反转至佩戴者视角），栅格化到高 92px 后按行程编码（runs）入工程。**不许把源图的提取/描摹数据当成品入工程**；提取骨架只可作重绘底稿。2026-10-29 时点：前四印重绘样张待 GO 定版，`art` 全印为 null，页面如实显示「見本準備中」，不放代用图。
- 判定：拍照 → 缩图（失败回退原图并标注）→ `arrayBuffer` + 分块 `btoa` 转 data URL → `LanguageModel` 图片输入，固定三行输出（GUESS / MATCH / FINGER），认不出写 NONE、判别不能写 UNSURE，不编造。
- 真值：判定后由佩戴者点「正解 / 不正解」定对错（真值不由 LLM 定），记录落盘 `trace.probe.kuji.v1`（旧键 `trace.probe.seals.v1` 不迁移）；结果页逐项表 + 汇总，回传 = 口述汇总数。
- 手势映射：点头 = 拍照判定（轮测页）/ 执行焦点（其余页）；单指点按 = 确认（Enter）；上下滑动 = 切焦点（ArrowUp/Down）；双击 = 返回（Backspace）。

## Technical honesty

- 唯一参照 = GO 定版的九栏图谱（`~/workspace/rokid/kuji-reference-chart.jpg`，「この図が一番規矩」）；印刷页照片已退出参照，印形与要点文案都不许用。要点文字出处分两类并在 README 逐印标注根拠断片：图谱竖排说明（崩し字）断片可读 → 转写/提炼（臨・闘・烈・在・前）；文として読解不能 → 印名与図形からの一般説明（兵・者・皆・陳）。手腕/指尖の補完は図譜自身の線の走向に沿う延長のみ。
- LLM 判定会出错、会看不清：MATCH=UNSURE 与 GUESS=NONE 都如实呈现，不包装成结论；探针不下任何「识别率」结论，只交原始逐项记录。
- Web 预览无相机与 LLM 时，拍照 / 判定会以裸错误码如实失败，不模拟结果。
