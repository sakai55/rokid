# Trace Plating (TR07) — Agent Notes

描红系列正式台 TR07。壳版本：描红壳 v1（ModelView 线条示意图文字描述形态 / StepRail / PhotoJudge / Progress）。

## 自评描红口径（本台建台即定，PLAN §6，置顶）

**本台建为自评描红**：LLM 只给三粗项差异提示（主菜落位 / 色块分区 / 留白边距），过与不过由用户自定，不硬判。对位页用户三选：算过 / 再摆一张 / 跳过；算过进下一步（记自判），跳过也进下一步但记一次跳过与一次改判。
**退化红线**：若判定只能复述盘子里有什么，即退化为慧眼问答，本台不以此计数——对位页提示词只许答三粗项差异，明确不许复述盘中菜品。

## Design contract

- 场景：家宴上桌前照着范本把一盘菜摆出餐馆样子。
- 六页闭环：今日（续练优先 + 今日推荐 + 总进度）→ 构图集（8 套带步数/难度/完成次数/断点）→ 练习（中央范本：本步摆盘构图线条示意图文字描述，盘内分区与落位；右侧步骤栏给步名、本步要点；TTS 同步念）→ 对位（把这一步举到眼前拍照，LLM 只给三粗项差异提示；用户三选：算过 / 再摆一张 / 跳过）→ 结算（对完结算 / 本人改判结算，如实记 partial）→ 进度（逐套完成次数/断点/改判数/跳过数 + 续练入口）。
- 步进口径钉死：进度键的 step 只有对位页「算过」或「跳过」才 +1；算过须先有一条看清的差异提示，没对位不许凭空算过；跳过记 skips 与 overrides；练习页「回看上一步」只看不改。
- 验收口径钉死：只提示三粗项差异（主菜落位、色块分区、留白边距），不评口味、不打分；看不清如实说没看清、重拍；不做连续追踪、不做实时纠偏。
- 内容集：8 套构图共 41 步（家常红烧肉摆盘 6、清蒸鱼摆盘 5、凉菜拼盘 5、水果拼盘 6、便当摆盘 6、面条摆盘 4、沙拉摆盘 5、点心摆盘 4），每步在 `platings.js` 有 t/tip/target/diagram 四字段，可数可查；范本为本系列自绘线条示意图的文字描述，步骤要点自撰，不抄图库与菜谱书图。
- 进度落盘键 `trace.trace-plating.v1`，结构 `{done:{itemId:{count,lastAt,overrides}}, today, lastItem}`（另记 step/runOverrides/partial/selfPass/skips 作断点与结算口径）；跨页传构图用 `trace.plating.tmp`（交接，非持久）。
- 手势映射：点头 = 执行焦点（对位页 = 拍照）；点按 = 确认（Enter）；上下滑 = 切焦点；双击 = 返回（Backspace，构图集页已接线）。
- 按钮形态：盘沿式（圆角 20px + 双圈盘沿阴影），与 TR04 的纸签式、TR05 的绳环式刻意不同。

## Permissions

`CAMERA`（逐步对位拍照），仅此一项，与 app.json 一致。TTS 无独立权限。

## Validation

- Static: JSON parse；全部脚本 syntax 检查；禁用 API grep 0 命中；绿色色阶无纯白；内容集断言 8 套 × 步数 4–6、合计 41 步；对位页提示词含自评口径与不复述菜品禁令。
- Device stage (pending): 真机核线条示意图文字描述可读性、举盘拍照差异提示、自评三选与结算落盘；提审等 GO 说「真机测试完成了」。
