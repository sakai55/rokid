# Trace Brush (TR01) — Agent Notes

描红系列正式台 TR01。壳版本：描红壳 v1（ModelView 笔画形态 / StepRail / PhotoJudge / Progress）。

## Design contract

- 场景：书法初学者在书桌前铺纸研墨，一笔一笔练完今天的一个字，写完当场知道差在哪，下次接着练。
- 七页闭环：今日（今日一字 + 进度摘要）→ 字库（20 字带笔画数与次数）→ 学字（中央范字逐笔渲染，当前笔最亮绿 #7dff9e、已学中绿、未学暗绿；右侧本笔要点 + TTS 同步念）→ 字义笔法（读音 / 字义 / 结构 / 重心 / 逐笔类型）→ 验收（低头拍自己写的字，LLM 粗查三项）→ 点评（三项结果 + 一句人话 + 用户覆盖「这字算过」落盘计数）→ 进度（已练字集 / 每字次数 / 练习天数 + 复习抽查：只给拼音不给范字）。
- 验收口径钉死：只查粗项（少笔多笔、结构重心、最明显的 1–2 处），不打分、不装专业书法评分；判定看不清如实说（CLEAR: NO → 重拍）；「算过」以本人改判为准（覆盖次数单独记 overrides），没验收过的字不许凭空算过。
- 判定只对用户自己写的字；不拍他人正脸（验收页明示）；无医疗 / 康复类声明。
- 进度落盘键 `trace.trace-brush.v1`；跨页传字用 `trace.brush.tmp`（交接，非持久）。
- 手势映射：点头 = 执行焦点（验收页 = 拍照）；点按 = 确认（Enter）；上下滑 = 切焦点 / 选字；双击 = 返回（Backspace，字库页已接线）。

## 字库与数据来源

- 20 字：永 人 大 天 上 下 山 川 水 火 木 日 月 田 口 中 心 正 生 白（全简繁同形）。
- 分笔数据：`chars.js`，取自 hanzi-writer-data（Make Me a Hanzi 项目；数据由 Arphic 文鼎字体提取，Arphic Public License，许可证全文 `LICENSE-data.txt` 随工程）。`strokes[]` 逐笔 SVG 路径（序即笔顺）供 Canvas 填充渲染，`medians[]` 为退路折线。
- 笔画数逐字核对结果：永 5、人 2、大 3、天 4、上 3、下 3、山 3、川 3、水 4、火 4、木 4、日 4、月 4、田 5、口 3、中 4、心 4、正 5、生 5、白 5。**注意：永是 5 画**——「永字八法」指永字含八种基本笔法，不是八画；PLAN 原稿写的「永（8)」已按核对结果纠正。逐笔类型逐字人工核定，笔顺口径对《通用规范汉字笔顺规范》GF0023-2020。
- 逐笔要点为本系列自撰的粗练习提示（起笔 / 行笔 / 收笔），不是评分标准，字义笔法页已明示。
- 学字页渲染：SVG 路径解析（数据只含 M/L/C/Q/Z）→ Canvas 填充，坐标变换 X=x·S/1024、Y=(900−y)·S/1024；填充异常自动退 medians 折线粗描边并在 EVT 行标注。

## Permissions

`CAMERA`（验收拍照），仅此一项，与 app.json 一致。TTS 无独立权限。

## Validation

- Static: JSON parse；全部脚本 `node --check`；禁用 API grep 0 命中；绿色色阶无纯白；字库 20 字笔画数断言（生成时逐字 assert 与人工核定表一致）。
- Device stage (pending): 真机核逐笔渲染方向、TTS 念要点、低头拍照粗查与改判落盘；提审等 GO 说「真机测试完成了」。
