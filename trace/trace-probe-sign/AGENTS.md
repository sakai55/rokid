# Trace Probe Sign — Agent Notes

描红系列识别探针（不占 TR 编号、不上根清单、不挂徽章）。壳版本：描红壳 v1（探针形态）。UI 全日语（TR03 已定日本手语 JSL）。

## Design contract

- 定位钉死：这是**学 / 练手语的识别试验，不是手语翻译工具**——说明页第一条即明示，文案不暗示能翻译、能与聋人实时对话（连续追踪眼镜没有）。
- 内容集 22 项（可数，在 `data.js`）：指文字元音 あいうえお、各行あ段 かさたなはまやらわ、混淆组补项 に・て・ほ、数字 1–5。靠动作区分的浊音 / 半浊音 / 促音 / 拗音 / 长音一律不收（静止写真で判定できない），理由写在 data.js 头部。
- 范本：佩戴者视角单手线条模式图（Canvas 自绘）+ 日语要点文字；模式图只是目安，手指配置以要点为准（UI 与 README 均标注）。手の甲 / 手のひら、向き（上 / 下 / 横 / 相手方向）在图内明示——な・に・は、て・ほ 这类同手形异方向组正是本探针的重点测量对象。
- 流程与结印探针同构：摆好 → 点头拍照 → LLM 从 22 项名单里认（GUESS / MATCH / FINGER 三行固定输出）→ 本人确定真值 → 落盘 `trace.probe.sign.v1` → 结果页分页逐项表 + 汇总。
- 收录门槛（事先定死）：认对进正式版练习范围、认错只进不计分练习、看不清复测后不收、全集认对不足一半则 TR03 降级自评描红。
- 手势映射：点头 = 拍照判定（测定页）/ 执行焦点（其余页）；点按 = 确认（Enter）；上下滑 = 切焦点；双击 = 返回（Backspace）。

## Technical honesty

- 范本是模式图，不是标准手形图谱；JSL 手形以《わたしたちの手話》系教材的描述为据由要点文字表达，图形只作目安。
- 数字 1–5 与部分指文字（あ/1、た/2、か/3、て/5）在静态手形上天然近似，探针就是来量这批混淆的——不预先粉饰。
- Web 预览无相机 / LLM 时以裸错误码如实失败，不模拟判定。

## Permissions

`CAMERA`（定格拍照判定），仅此一项，与 app.json 一致。

## Validation

- Static: JSON parse；全部脚本 `node --check`；禁用 API grep 0 命中；UI 日语纯度（无简体中文特有字 / 中文短语）；绿色色阶无纯白。
- Device stage (pending): GO 真机摆一轮（22 项）回汇总数后，按门槛回填 TR03 收录表。
