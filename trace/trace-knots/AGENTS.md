# Trace Knots (TR05) — Agent Notes

描红系列正式台 TR05。壳版本：描红壳 v1（ModelView 线条示意图文字描述形态 / StepRail / PhotoJudge / Progress）。

## Design contract

- 场景：出门露营或教孩子系鞋带前，把一个结从头打到对，打错当步就知道。
- 六页闭环：今日（续练优先 + 今日推荐 + 总进度）→ 结集（8 个结带步数/难度/完成次数/断点）→ 练习（中央范本：本步绳结线条示意图文字描述，绳走向与交叉点；右侧步骤栏给步名、本步要点与本步粗查清单；TTS 同步念）→ 验形（把这一步举到眼前拍照，LLM 按固定提示词合同判定：对照范本描述 → 只查清单内粗项 → 输出结构化判定 {pass, issues[], confidence} → 看不清就说看不清；判定后用户覆盖口三选：算过 / 不算过 / 重拍，覆盖落盘）→ 结算（验完结算 / 本人改判结算，如实记 partial）→ 进度（逐结完成次数/断点/改判数 + 续练入口）。
- 步进口径钉死：进度键的 step 只有验形页「算过」才 +1；没验过不许凭空算过；机器说不过而用户坚持算过，记一次本人改判（overrides，本轮另记 runOverrides）；机器说过而用户选不算过，同样记一次改判并回练习页重做；练习页「回看上一步」只看不改。
- 验收口径钉死：只查粗项（圈数、穿向、收尾位置），不评美观、不打分；看不清如实说没看清、重拍；不做连续追踪、不做实时纠偏。
- 内容集：8 个结共 42 步（平结 5、八字结 4、双渔人结 6、称人结 7、蝴蝶结 5、单结 4、接绳结 6、活结 5），每步在 `knots.js` 有 t/tip/target/checks/diagram 五字段，可数可查；每结有 staticNote 注明静态可验性（结形定格后圈数、穿向、绳头位置都留在绳上，一张照片足以粗查）；范本为本系列自绘线条示意图的文字描述，步骤要点自撰，不抄图库与绳结书图。
- 进度落盘键 `trace.trace-knots.v1`，结构 `{done:{itemId:{count,lastAt,overrides}}, today, lastItem}`（另记 step/runOverrides/partial 作断点与结算口径）；跨页传结用 `trace.knots.tmp`（交接，非持久）。
- 手势映射：点头 = 执行焦点（验形页 = 拍照）；点按 = 确认（Enter）；上下滑 = 切焦点；双击 = 返回（Backspace，结集页已接线）。
- 按钮形态：绳环式（圆角 12px + 2px 粗边框），与 TR04 的纸签式刻意不同。

## Permissions

`CAMERA`（逐步验形拍照），仅此一项，与 app.json 一致。TTS 无独立权限。

## Validation

- Static: JSON parse；全部脚本 syntax 检查；禁用 API grep 0 命中；绿色色阶无纯白；内容集断言 8 结 × 步数 4–8、合计 42 步。
- Device stage (pending): 真机核线条示意图文字描述可读性、举绳拍照粗查、断点续练与结算落盘；提审等 GO 说「真机测试完成了」。
