# TR06 Trace Sketch · 简笔画描红练习

**Studio 导入地址**（复制到 Global AIUI Studio 的 Import Project 输入框）：

```
https://github.com/sakai55/rokid/tree/agent-trace-sketch
```

描红系列 TR06：中央范本 + 边上步骤 + 做一步验一步。想在手账本上学画简笔画的人打开它，范本逐笔亮起，一笔一笔在真纸上跟画，整幅画完拍照对形——只查粗项，画完当场知道哪笔漏了、哪处比例最偏；进度跨会话保存，还有只给名字的复习抽查。

## 功能（6 页闭环）

| 页 | 内容 |
|---|---|
| 今日（手账首页） | 今日一图（按日期轮换）、上次画到哪、已画幅数 / 累计次数 |
| 图库 | 12 幅分页陈列：笔数、画过次数、是否算过，选图进描红页 |
| 描红 | 中央范本逐笔绘制：当前笔最亮绿粗线、已画笔中绿、未画笔暗绿细线；右侧本笔名 + 要点，TTS 同步念要点；闭合图形会提示收尾合口 |
| 验收点评 | 整幅拍一次，LLM 对照本幅分笔清单粗查三项：有没有漏线、比例最偏的一处、闭合图形开没开口；一句人话点评；用户可改判「这幅算过」，没验过不许凭空算过 |
| 复习抽查 | 只给图名不给范本，凭记忆画完整幅再验；偷看范本会如实记「协助完成」，不冒充凭记忆 |
| 进度 | 逐幅次数 / 算过 / 复习过关 / 协助 / 改判数与汇总、动手天数，跨会话保存 |

## 内容集（自绘自撰，可数）

12 幅简笔画共 83 笔：猫 8、鱼 7、小鸟 7、花 8、房子 7、树 8、帆船 7、蘑菇 6、茶杯 6、星月 5、兔子 7、热气球 7。每笔在 `pics.js` 里有笔名、本笔要点、坐标点列与是否闭合四字段，全部线条为本系列原创坐标数据，不用任何图片文件、不抄图库图。

## 与同系列的区别

TR01 毛笔字是逐笔学、整字验、验收与点评分两页；TR04 折纸是逐步折、逐步验。本台是逐笔学、**整幅验一次**，验收与点评同页——因为简笔画的毛病（漏线、比例、开口）要看整幅才成立。

## 方向性 / 交互

核心 = SCAN（整幅拍照对形）+ HEAD（点头执行 / 验收页点头拍照）。手势：点头 = 执行焦点；单指点按 = 确认（Enter）；上下滑 = 切焦点；双击 = 返回（Backspace）。描红页 TTS 同步念每笔要点。页面排版与按钮走手账风：横线账本 + 铅笔下划线按钮。
