- FI02 [sign-filter](sign-filter/) — 目標を先に宣言し、街を走査して一致する看板だけを光らせる
- FI03 [buy-filter](buy-filter/) — リスト・予算・忌避の3条件、合う商品だけが光る
- FI04 [meeting-filter](meeting-filter/) — 長い会議を聞き守り、名前やキーワードに一致したときだけ画面が光る
- FI05 [lecture-filter](lecture-filter/) — 授業を聞き守り、合図の文に一致したらノートに保存
