# フィルター型 FILTER（filter/）

[中文](README.md) | [English](README.en.md) | 日本語
中国語版（2026-10-29 時点）の翻訳。

注意力アドオンシリーズ。FI01–FI05、全5件。通すのは、宣言した種類だけ。

- FI01 [focus-shield](focus-shield/) — ホワイトリストの音だけを通し、それ以外はタイムラインに記録だけして、休憩時にまとめて要約する
- FI02 [sign-filter](sign-filter/) — 目標を先に宣言し、街をスキャンして一致する看板だけを光らせる
- FI03 [buy-filter](buy-filter/) — リスト・予算・忌避食材の3条件に合う商品だけを光らせる
- FI04 [meeting-filter](meeting-filter/) — 長い会議を聞き張り、自分の名前やキーワードが出たときだけ画面を光らせる
- FI05 [lecture-filter](lecture-filter/) — 授業を聞き張り、合図のフレーズが出たらノートに保存する

全リストはルートの [README](../README.md) 末尾にある Agent リストを参照。
