# Filter (filter/)

[中文](README.md) | English | [日本語](README.ja.md)
Translated from the Chinese version (as of 2026-10-29).

Attention add-on series · IDs FI01–FI05, 5 in total. Only the one kind you declared gets through.

- FI01 [focus-shield](focus-shield/) — Only whitelisted sounds get through; everything else is logged to a timeline and summarized when you rest
- FI02 [sign-filter](sign-filter/) — Declare the target first; scanning the street lights up only matching signs
- FI03 [buy-filter](buy-filter/) — Three conditions — list, budget and dietary restrictions; only matching products light up
- FI04 [meeting-filter](meeting-filter/) — Listens through long meetings; the screen lights only when a name or keyword hits
- FI05 [lecture-filter](lecture-filter/) — Listens in class; saves a note whenever a signal sentence hits

For the full list, see the Agent list at the end of the [repository root README](../README.md).
