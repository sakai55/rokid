# clean-check

Rokid 眼镜清洁复查智能体（AIUI Agent）。

## 身份

一个运行在 Rokid 眼镜上的「打扫后环视复查」助手，解决打扫总漏
边角的问题——窗台、柜顶、墙角、桌下，每次漏的都是这些地方，
复查又要弯腰低头逐个看。它的做法是眼镜独有的：把房间的六个
易漏区域绑在你的头部朝向上，打扫完站在房间里慢慢环视一周，
你的视线在哪个区域稳稳停满 2 秒，哪个区域才算「看过」被打勾；
没看向的角落，它用相对方向把你领过去。全六处都看过，它才
朗读收尾。

## 能力

- 朝向读取：AbsoluteOrientationSensor（约 5Hz）四元数算 yaw 朝向角，
  界面如实标注来源 SENSOR / DEMO / NONE；无传感器时不编造朝向，
  SETUP 登记会拒绝并说明原因（同 #07 find-my-thing）。
- 区域（固定 6 个易漏点）：窗边 / 门口 / 床边 / 柜顶 / 墙角 /
  桌下，每个都带一句亲眼核对的线索（如柜顶「柜顶积灰最厚，踮脚
  看清楚」、墙角「墙角和踢脚线交界，蜘蛛网在这」）。
- 登记朝向（SETUP 模式，一次性）：站在你平时打扫时会站的位置，
  看着区域点 REG（或头部稳定时点头、Enter），把
  {区域名， 朝向°} 存入 wx 同步存储（key `cleanCheckZones`，
  onLoad 载入、onUnload 落盘）。同一个区域重新登记会覆盖旧
  朝向。没登记的区域没有凝视覆盖和转向指引，只能靠眼睛找、
  MARK 手动打勾。
- 凝视覆盖（SWEEP 模式，默认，本 Agent 的核心）：慢慢转头，
  当你的朝向落在某个未覆盖区域登记朝向的 ±25° 内、且头部
  保持稳定（onOrientationStabilityChange），驻留计时开始；
  连续停满 2 秒，该区域记为 `✓ gaze` 并记下时间。计时每
  250ms 推进一次：朝向离开锥形区、换到别的区域、或头部
  不稳，计时立即清零重来——快速摇一圈头骗不到覆盖。
- 指引（相对方向，永不报东南西北）：没有在驻留时，指引框
  给出角度上最近的未覆盖区域与「TURN: RIGHT-BACK 130° —
  reg 270°」和 8 向箭头；驻留进行中，指引越过当前区域指向
  下一个最近的未覆盖区域。SPEAK 用中文朗读还差哪几处、
  最近的一处在你哪个方向。
- 打勾方式如实入账：在驻留之外也能用 MARK（按钮 / Enter /
  头部稳定时点头）手动打勾，优先打你正对着（锥形区内）的
  区域，否则打 ZONE 选中的区域，记为 `✓ tap`，列表里和
  `✓ gaze` 分得清清楚楚。点头在 SWEEP 里永远只记 tap，
  绝不冒充凝视覆盖——2 秒驻留是拿到 gaze 勾的唯一途径。
- 全覆盖收尾：6/6 后大字「SWEEP DONE — 每个角落都看过了」
  并自动 TTS 朗读收尾（朗读里同样说明记录的只是看过）。
  RESET 开新一轮复查（清覆盖、保留登记）；CLEAR 清除全部
  登记朝向。
- DEMO：内存里给 6 个区域绑上演示朝向 30° / 90° / 150° /
  210° / 270° / 330°（不写入存储、不覆盖你的真实登记）。
  演示设定为环视已经开始：视线从窗边（30°）起步、已用完整
  2 秒驻留覆盖它（覆盖时间由一次 Date 快照生成），演示头部
  现在停在 90° 正对门口、头部稳定，门口的驻留定格在 1.2 秒
  供预览看清（真机上驻留按真实时间推进）；落在 1/6，指引
  越过门口指向床边（TURN: RIGHT-FRONT 60°）。之后每点一次
  DEMO 朝向 +45°，并把定格驻留换到新锥形区内的区域。
  DEMO 中点 CLEAR 退出演示并恢复真实登记。

## 行为边界

- **覆盖 = 你看过，不是那里干净**：眼镜没有任何能力判断
  一块地方擦没擦干净——它只记录你的视线在哪里稳稳停留
  满 2 秒。打扫动作是你的手做的：正确用法是边看边擦，
  看的那 2 秒正好用来动手。把它当「防漏看清单」，不要
  当「洁净检测仪」。界面页脚、收尾朗读与 README 都如实
  写明。
- 2 秒驻留就是为防作弊而设：快速转头扫一圈，每个区域
  都「看过」却哪个都没看清——驻留规则让这种假覆盖拿
  不到 gaze 勾；真用手 MARK 的，如实记 tap，账面诚实。
- 朝向只对你登记时站的位置成立（同 #07 / #10 的几何
  边界）：登记的是「从我站的地方看向这个区域」的方向；
  复查时站回登记位置附近慢慢转头，锥形区与指引才有
  意义。换一个站位，几何关系就变了。
- 朝向缺失（SRC NONE 且非 DEMO）时拒绝登记，绝不编造
  朝向；复查本身不完全依赖朝向——没有传感器时仍可按
  区域名单逐个找、MARK 打勾（全部记 tap）。
- 不需要任何权限：不用相机、不用麦克风、不用定位；
  朝向传感器不需要单独权限声明，故 app.json 无
  permissions 字段（同 #07 / #15 / #28）。登记只存本机
  wx 同步存储，不上传；覆盖记录只在内存里（一轮复查的
  事），页面关掉即清；DEMO 朝向只在内存里，永不落盘
  覆盖真实登记。
