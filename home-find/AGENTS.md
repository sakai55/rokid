# home-find

Rokid 眼镜家中寻物智能体（AIUI Agent）。

## 身份

一个运行在 Rokid 眼镜上的「收纳记忆」助手，解决证件、工具、药
收起来就找不到的问题：护照塞进哪个柜子？备用钥匙挂哪儿了？
药盒在床头柜还是书房？手机备忘录能记文字，记不了「你当时
站在哪、面朝哪看着它收进去的」。本 Agent 把登记动作挂在
视线上：收纳时看着收纳处，说出物品和具体位置，眼镜把
「物品 + 房间 + 口头线索 + 你当时的头部朝向 + 日期时间」
一起存下来；找的时候选中物品，大字回忆线索先把你领回
对的房间和柜子，再转头对齐登记朝向，确认你正对着当时
收纳的方向。

## 能力

- 朝向读取：AbsoluteOrientationSensor（约 5Hz）四元数算 yaw
  朝向角，界面如实标注来源 SENSOR / DEMO / NONE；无传感器时
  不编造朝向，SAVE 会拒绝并说明原因（同 #07 find-my-thing）。
- 登记（STORE 模式，默认）：ITEM 用一次性 SpeechRecognition
  （zh-CN）说物品——先按文档方式用 `getUserMedia({audio:
  {captureSource:'microphone', microphoneMode:'wearer'}})` 做
  佩戴者模式麦克风检查（4 麦优先收你自己的声音，检查完立即
  停轨道），识别结果**原样**显示在 ITEM 行等你核对；主机
  没有识别能力时 ITEM 如实显示 SKIP，并改为轮换五个预置
  物品（护照 / 备用钥匙 / 工具箱 / 药盒 / 充电器）。ROOM 轮换
  房间（客厅 / 卧室 / 书房 / 厨房 / 玄关 / 阳台）。CLUE 用
  第二次一次性识别说具体位置（如「书柜第二层」），纪律同
  ITEM：原样显示等核对，不可用时 SKIP 走四个预置线索
  （柜子抽屉 / 架子第二层 / 盒子里 / 门后挂钩）。SAVE（或
  头部稳定时点头）把 {物品， 房间， 线索， 朝向°， 日期，
  时间} 存入 wx 同步存储（key `homeFind`，最多 12 条，
  onLoad 载入、onUnload 落盘）。**同一物品重新登记会覆盖
  旧记录**——东西挪了窝，最新位置说了算，界面与状态行会
  如实标注「old spot replaced」。
- 寻物（FIND 模式）：ITEM 轮换已登记物品；回忆线索大字
  显示「护照 → 书房 · 书柜第二层 · 朝向 210° 登记」；相对角
  = 登记朝向 − 当前朝向，归一化 −180°…180°，显示 8 向箭头
  与「TURN: …」提示；回到登记房间、站到当初登记位置附近
  慢慢转头，|相对角| ≤ 15° 时高亮「FACING THE SPOT — look
  there」。SPEAK 用中文朗读线索：「护照在书房，书柜第二层。
  你当时站在书房朝向 210 度登记的。」（外加当前相对方向）。
- 拍照留底（LOOK，只作记录）：默认模式 `ImageCapture.
  takePhoto({mode:'default'})` 拍下收纳处当你自己的视觉
  副本（不可用时回退 wx.media CameraContext），界面只显示
  字节数并标注 record only。运行时没有 OCR，照片永远不会
  被读取，收纳位置只来自你亲口说的线索。
- DEMO：用一次时钟快照（同一快照以纯字符串推导全部日期与
  时间——预览主机的 Date 是虚拟化的、多次采样会漂移，#25
  的教训）登记 3 个标注 DEMO 的物品（护照 书房 书柜第二层
  @210° / 备用钥匙 玄关 门后挂钩 @40° / 药盒 卧室 床头柜
  抽屉 @300°）并切到 FIND 选中护照；之后每点一次 DEMO
  朝向 +45°，朝向转到 225° 时护照的相对角 −15°，进入
  FACING THE SPOT 高亮态，预览可完整演示。重入 DEMO 会先
  清掉旧的 DEMO 记录再登记，不重复堆积。
- 凝视/点头：开启世界感知（enableWorldAwareness）显示头部
  稳定状态；STORE 模式下头部稳定时点头 = SAVE，FIND 模式
  下点头 = SPEAK。

## 行为边界

- **朝向只对你登记时站的位置成立**（同 #07 的几何边界）：
  登记的是「从我站的地方看向这个收纳处」的方向。找东西时
  先按回忆线索回到登记的房间、站到当初登记位置附近，再
  转头让 FACING THE SPOT 亮起来；站在别的房间转头，角度
  对不上是几何使然，不是故障。
- **这是「收纳记忆」，不是物品追踪**：眼镜记住的是你当时
  把它收在哪、面朝哪，不是物品现在在哪；东西被别人拿走
  或挪过（且没重新登记），指引到的仍是你上次登记的位置。
- **物品名与线索是 ASR 转写**：ITEM / CLUE 把听到的原文
  原样显示，就是为了让你在按 SAVE 之前亲眼核对——听错的
  物品名存进去，FIND 时就按错名字找。识别不可用时如实
  SKIP 走预置项，不伪造识别结果。
- 麦克风只在用户点 ITEM / CLUE 时启动：佩戴者检查的音频流
  读完设置立即停掉全部轨道，一次性识别结束即 abort；相机
  只在点 LOOK 时启动，拍完立即停轨道；页面隐藏/卸载时
  同样停识别器、停相机流、停传感器、清定时器。
- 不录音、不上传：识别由系统识别服务处理，照片只作本机
  视觉副本；记录只存本机 wx 同步存储。
- 声明权限：CAMERA（LOOK 拍收纳处留底）、RECORD_AUDIO
  （ITEM / CLUE 的麦克风检查与语音识别）；朝向传感器在
  AIUI 里不需要单独的权限声明，不用定位。
