# sound-compass

Rokid 眼镜声源罗盘智能体（AIUI Agent）。

## 身份

一个运行在 Rokid 眼镜上的「听声辨位」助手，解决水声、烧水壶、
另一个房间里响的手机、有人喊你名字 — 声音发生了，却分不清是
从哪个方向来的问题。手机帮不上忙：它不知道你面朝哪儿。眼镜
知道你的头部朝向，于是用「转头扫描」的办法：你慢慢转一圈，
麦克风把每个朝向上的响度记下来，转完它告诉你「刚才最响的
方向在你右后方」，你转回去找就行。

## 能力

- 转头电平扫描（SCAN，本 Agent 的核心）：点 SCAN 后按文档
  方式用 `getUserMedia({audio:{captureSource:'microphone',
  microphoneMode:'omnidirectional'}})` 开麦（全向模式均衡收各
  方向的声音，不偏向佩戴者），接 Web Audio `AudioContext` +
  `AnalyserNode`（只接分析器，绝不接 destination 防啸叫）；
  20 秒内（或点 STOP 提前结束）每 100ms 用
  `getFloatTimeDomainData` 算一次 RMS 电平，按当前头部朝向
  分进 72 个 5° 的桶，每桶只留最大值。界面实时显示当前朝向、
  电平条与已覆盖桶数。
- 朝向读取：`AbsoluteOrientationSensor`（约 5Hz）四元数算
  yaw 朝向角，界面如实标注来源 SENSOR / DEMO / NONE。
  **没有朝向就不能扫描**：真实 SCAN 时朝向缺失（SRC NONE）
  会如实拒绝 — 转头扫描没有朝向就是一串没有地址的响度，
  绝不编造方向。麦克风不可用同样 FAIL 并写明原因；
  `omnidirectional` 模式被设备拒绝（OverconstrainedError）时
  回退默认麦克风并如实提示，不假装模式生效。
- 结果指引：扫描结束取电平最高的桶为「最响方向」，相对你
  **当前**朝向算相对角（−180°…180°），显示 8 向大箭头与
  「LOUDEST: RIGHT-BACK 140° — turn around right」式提示，
  |相对角| ≤ 15° 时高亮「LOUDEST: AHEAD」；另给电平最高
  的 3 个桶（TOP 行）。你继续转头，相对角实时更新，你转回去
  对上它就行。SPEAK 用中文朗读结果：「刚才最响的方向在你
  右后方，大约 140 度。」
- 点头朗读：开启世界感知（`enableWorldAwareness`）显示头部
  稳定状态；有结果时头部稳定点头 = SPEAK。Enter / GlobalHook
  = 开始扫描 / 停止，方向键只提示转头。
- DEMO：不用麦克风不用传感器，合成一次完整转头：朝向
  0°→355° 扫一圈，电平剖面是 140° 处的高斯峰 + 噪声底，
  填满 72 个桶后走正常结果路径 — 停在朝向 0°，峰值落在
  142° 的桶（140° 所在的 5° 桶），相对角 +142°，显示
  RIGHT-BACK 142°，预览可完整演示。

## 行为边界

- **这是粗略的电平扫描，不是测向仪**：运行时没有波束成形
  （beamforming）声源角度 API，本 Agent 绝不假装有。它测的
  是「你转这一圈里，哪个朝向最响」，给的是 5° 桶级的粗
  方向。房间反射、风噪、持续不断的背景声（空调、电视）都会
  把结果带偏；太轻的声音可能根本测不到。界面常驻一行
  COARSE 说明，README 同样如实写明。
- 麦克风只在用户点 SCAN 后开启，扫描结束（20 秒到时或
  STOP）立即停掉全部媒体轨道并关闭 AudioContext；页面
  隐藏/卸载时同样停麦、关上下文、停传感器、清定时器。
- 不录音、不落盘：电平是实时算出的 RMS 数值，音频数据不
  保存、不上传；桶数据只在内存里，CLEAR 一键清空。
- 声明权限只有 RECORD_AUDIO；朝向传感器在 AIUI 里不需要
  单独的权限声明。
