# Rokid Korea Localization

[中文](SKILL.md) | [English](SKILL.en.md) | 日本語
本書は中文版（2026-10-29 時点）をもとに作成した。内容に食い違いがある場合は中文版を正とする。

KR Agent のローカライズを扱う層である。制作手順の共通部分（能力面のレッドライン、三つのゲート、9 ステップの SOP、パッキング／プレビュー／README／GitHub 同期）は `rokid-agent-sop` が担い、本 skill では韓国固有の決め事だけを扱う。KR と名乗れるのは、次の 3 点をすべて満たす Agent に限る。KR 番号が付いていること。プロジェクトが `korea/<slug>/` 配下にあること。場面そのものが韓国ならではのものであること（後述）。

## 韓国ならでは、と呼べる条件

場面の出どころは、韓国の実際の制度、礼儀作法、サービスでなければならない。汎用 Agent に韓国語の文章を貼っただけのものは KR ではない。実績のある題材は次のとおり。いずれも具体的な困りごとは 1 つに絞り、SOP のゲートが求める閉じたループを備えている。

- **制度・仕組み**：종량제（容量制のごみ袋とその価格体系）、계（回していく貯蓄の会）、층간소음（階間騒音）をめぐる調停の文化、宮殿近くにある 한복 のレンタル・返却店、PC방 の席と軽食の課金方式、배달 공동현관（共用玄関）向けの配達コード。
- **仕組みとして組み込む礼儀作法**：소주 を両手で受け、年長者からは顔をそらして飲む作法、노래방 での順番の回し方、삼겹살 を焼くタイミング。
- **地域のサービス・習慣**：김장 の一括作業での数の数え方、등산 のペースと水分管理、한강 でのピクニック拠点の管理、카페 도장 のスタンプカード。

設計に入る前に、ループが何に依存しているかを言語化しておく。その韓国のルール、制度、習慣を名指しできること。どの国に持っていってもそのまま成り立つループなら、KR Agent ではない。

## 言語ルール（2026-10-25 の言語純化インシデント）

- **利用者に見える文字列は、初稿からすべて韓国語（ハングル）で書く** ― ステータス、ヒーロー表示、行、マーク、ガイド、TTS の発話文、SCAN のプロンプト、シードデータ／デモデータが対象である。英語のまま残してよいのは、英語の体裁要素だけである（ページタイトル、ボタンラベル、`EVT:` プレフィックス）。README のドキュメントは中国語のままにする（UI ではなく、GO 向けの文書だからである）。
- **パッキング前の機械チェック**（対象はソースだけでなく、ビルド済みの `.ink` ファイル）：UI 文字列では**かなの数 = 0 かつ CJK 表意文字の数 = 0**を満たすこと。これは落とせないゲートである。当該インシデントのビルドでは、KR の UI が丸ごと日本語で出荷された例（noise-diary、baedal-code）、日本語の断片が混入した例（hangang-base、soju-turn、deungsan-pace）、jongnyang-gauge の本文が日本語になっていた例、KR04 に中国語の SCAN プロンプトが入っていた例があった。（₩、数字、英語の体裁要素は問題ない。生成側のドキュメントコメントは UI ではない。）
- **日本語コピーの混入パターン**（チェックで検出できるが、書く段階で避けられるよう列挙する）：向かい → 맞은편、済み → 완료、守候 のような中国語のステータス文、かなは種類を問わずすべて。漢字由来の語が必要な場合は、ハングルで表記する。
- TTS の発話文も扱いは同じ。話すのは韓国語のみとする。ホスト TTS の `lang` 属性は設定しない（効果がないとドキュメントに明記されているため）。

## 環境ゲート（韓国の場合）

舞台は、人々が実際に眼鏡をかける場所でなければならない。**対象外**は 찜질방 / 사우나、および入浴・蒸気・熱を伴うあらゆる環境である。KR09 `jjimjil-rest` はまさにこの判断でその場で引退扱いになった（残置し、削除はしない。同じ枠は `pcbang-session` が引き継いだ）。市場、交通、食事、自宅、屋外、社交の場面はいずれも対象になる。

## この skill のバージョン管理

本 skill はインプレースで更新し、semver で管理する。

- **patch**（1.0.x）：新しい混入パターンの語の追加、文言の修正、事例の追加。
- **minor**（1.x.0）：新しい題材の追加、新しいチェックルールの追加、新しい引退事例の追加。
- **major**（x.0.0）：ゲートまたは言語ルールの変更。

変更時は、冒頭の `version:` を上げ、下記の Change Log に項目を追加し（日付、どの制作で何を学んだか、何を変えたか）、同じターンで導入済みミラー `~/workspace/custom-skills/rokid-kr-localization/SKILL.md` を更新し、両方を 1 コミットで push する。KR に限らずすべての Agent に当てはまる教訓は本 skill には書かず、`rokid-agent-sop` 側に入れる。重複はさせない。
