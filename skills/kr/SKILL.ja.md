# Rokid Korea Localization

[中文](SKILL.md) | [English](SKILL.en.md) | 日本語
中文版（2026-10-29 時点）からの翻訳。齟齬がある場合は中文版が優先する。

KR Agent のロケール層。生産パイプラインの共通部分（能力のレッドライン、三つのゲート、9 ステップの SOP、パッケージング / プレビュー / README / GitHub 同期）は `rokid-agent-sop` にあり、この skill は韓国に固有のものだけを加える。Agent が KR であるのは、次の 3 点がすべて成り立つ時だけである：KR 番号があること、プロジェクトが `korea/<slug>/` の下にあること、本物の韓国の場面であること（以下）。

## 韓国の在地性として数えるもの

場面は、本物の韓国の制度、礼儀、サービスから来なければならない — 韓国語の文章を貼った汎用 Agent ではない。実証済みの源泉（それぞれ具体的な問題を 1 つ持ち、SOP のゲートが求めるクローズドループを備える）：

- **制度と仕組み**：종량제 の容量制ごみ袋とその価格設定、계 という回転式の貯蓄サークル、층간소음（階間騒音）の調停文化、宮殿近くの 한복 レンタルと返却の店、PC방 の座席と軽食の課金、배달 공동현관（共用玄関）の配達コード。
- **仕組みとしての礼儀**：소주 を両手で受け、年長者から顔を背けること、노래방 の順番のローテーション、삼겹살 を焼くタイミング。
- **地元のサービスと習慣**：김장 の一括の数え方、등산 のペースと水の規律、한강 のピクニック拠点の管理、카페 도장 のスタンプカード。

設計する前に判定する：そのループが依存する韓国のルール、制度、習慣を名指しする。そのループがどの国でも変わらず成り立つなら、それは KR Agent ではない。

## 言語ルール（2026-10-25 の純化事件）

- **ユーザーが見るすべての文字列は、最初の草稿から韓国語（ハングル）である** — 状態、ヒーロー、行、マーク、ガイド、TTS の文、SCAN のプロンプト、シード / デモデータ。英語のまま残るのは英語の装飾だけである（ページタイトル、ボタンのラベル、`EVT:` 接頭辞）。README のドキュメントは中国語のままである（UI ではなく、GO 向け）。
- **パッケージング前の機械チェック**（ソースだけでなく、作られた `.ink` ファイルに対して）：UI 文字列において**仮名の数 = 0 かつ CJK 表意文字の数 = 0**。これは硬いゲートである — 事件のあったビルドでは、KR の UI 全体が日本語で出荷され（noise-diary、baedal-code）、他のものには日本語の断片が入り（hangang-base、soju-turn、deungsan-pace）、jongnyang-gauge には日本語の本文が入り、KR04 には中国語の SCAN プロンプトが入った。（₩、数字、英語の装飾は問題ない。生成側のドキュメントコメントは UI ではない。）
- **日本語文案の落とし穴**（チェックで捕捉されるが、著者が避けられるよう列挙する）：向かい → 맞은편、済み → 완료、守候 のような中国語の状態文、あらゆる仮名そのもの。漢字由来の語が必要な文字列は、ハングルで書く。
- TTS の文も同じルールに従う — 話される韓国語のみ。ホスト TTS の `lang` 属性は決して設定しない（効果がないと文書化されている）。

## 環境ゲート（韓国の事例）

設定は、人々が実際にグラスをかける場所でなければならない。**対象外**：찜질방 / 사우나 と、入浴 / 蒸気 / 熱を伴うあらゆる設定 — KR09 `jjimjil-rest` はまさにこの裁定によりその場で引退した（保持され、決して削除されず、同じ枠で `pcbang-session` に置き換えられた）。市場、交通、食事、自宅、屋外、社交はいずれも通る。

## 形式と名簿

- 各 KR Agent は独自の対話哲学と UI の形を持つ（フリート統一の様式に対する、このシリーズの常設の例外）。ボタンは形ごとに様式を決め、共通の初期値を決して使わない。SOP に従い、グリーンのみの配色とする。
- 名簿と番号の権威：`~/workspace/goals/20-agent-rokid-aiui-2/files/PLAN-20-JPKR-Agents.md`（KR01–KR10 が元のライン、KR11 以降が継続分）と `korea/` ディレクトリ。KR の行へのバッジの帰属：頭の向きが主入力である時だけ指向性（soju-turn）、それ以外は注意力 — バッジの定義は固定。SOP を参照。

## この skill のバージョン管理

この skill はその場で更新し、semver を使う：

- **patch**（1.0.x）：新しい落とし穴の語、文言の修正、例の追加。
- **minor**（1.x.0）：新しい在地性の源泉、新しいチェックルール、新しい引退事例。
- **major**（x.0.0）：ゲート、または言語ルールについての変更。

すべての変更：上の `version:` を上げ、下に Change Log の項目を追加し（日付、どの生産ランが何を教えたか、何が変わったか）、同じターンでインストール済みミラー `~/workspace/custom-skills/rokid-kr-localization/SKILL.md` を更新し、両方を 1 つのコミットで push する。すべての Agent に当てはまる教訓（KR だけではないもの）は、代わりに `rokid-agent-sop` へ入れる — ここに重複させない。
