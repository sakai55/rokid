# Rokid Japan Localization

[中文](SKILL.md) | [English](SKILL.en.md) | 日本語
本書は中文版（2026-10-29 時点）をもとに作成した。内容に食い違いがある場合は中文版を正とする。

JP Agent のローカライズを扱う層である。制作手順の共通部分（能力面のレッドライン、三つのゲート、9 ステップの SOP、パッキング／プレビュー／README／GitHub 同期）は `rokid-agent-sop` が担い、本 skill では日本固有の決め事だけを扱う。JP と名乗れるのは、次の 3 点をすべて満たす Agent に限る。JP 番号が付いていること。プロジェクトが `japan/<slug>/` 配下にあること。場面そのものが日本ならではのものであること（後述）。

## 日本ならでは、と呼べる条件

場面の出どころは、日本の実際の制度、礼儀作法、サービスでなければならない。汎用 Agent に日本語の文章を貼っただけのものは JP ではない。実績のある題材は次のとおり。いずれも具体的な困りごとは 1 つに絞り、SOP のゲートが求める閉じたループを備えている。

- **制度・仕組み**：免税ショッピングのルール（免税・密封袋）、駅のコインロッカー（コインロッカー）、町内を回す回覧板、防災用品の点検、自治体ごとのゴミ分別ルール、回転寿司の皿の価格体系。
- **仕組みとして組み込む礼儀作法**：神社参拝の作法（二拝二拍手一拝）、静粛車両で通話を切る規範、飲み会の幹事の役割、山手線での乗り換え時の配慮。
- **地域のサービス・習慣**：コンビニでの買い物かごの使い方、職場への贈り物を漏れなく用意するお土産の管理、自転車の駐輪と施錠忘れへの対処。

設計に入る前に、ループが何に依存しているかを言語化しておく。その日本のルール、制度、習慣を名指しできること。どの国に持っていってもそのまま成り立つループなら、JP Agent ではない。

## 言語ルール（2026-10-25 の言語純化インシデント）

- **利用者に見える文字列は、初稿からすべて日本語で書く** ― ステータス、ヒーロー表示、行、マーク、ガイド、TTS の発話文、SCAN のプロンプト、シードデータ／デモデータが対象である。英語のまま残してよいのは、英語の体裁要素だけである（ページタイトル、ボタンラベル、`EVT:` プレフィックス）。README のドキュメントは中国語のままにする（UI ではなく、GO 向けの文書だからである）。
- **中国語コピーの混入パターン**（生成側のデフォルトは中国語が漏れやすい。下記の語とその同類が残っていないか探す）：柜 → ロッカー / 棚、点头 → うなずき、守候 → 見守り、取回 → 受け取り、越線 → 超過、寄存 → 預け、ほか、ガイド文や SCAN のプロンプトが中国語の文のまま書かれているケース。中国語と共通する漢字自体は問題ではない。問題になるのは、*フレーズ*として自然な日本語になっていない場合である。
- **パッキング前の機械チェック**（対象はソースだけでなく、ビルド済みの `.ink` ファイル）：UI 文字列のどこにも中国語特有のフレーズを残さない。ガイド文と SCAN のプロンプトはとくに混入が隠れやすいため、目視でも通読する。このチェックに落ちた JP ビルドはパッキングしない。
- TTS の発話文も扱いは同じ。話すのは日本語のみとし、中国語の残りを残さない。ホスト TTS の `lang` 属性は設定しない（効果がないとドキュメントに明記されているため）。

## 環境ゲート（日本の場合）

舞台は、人々が実際に眼鏡をかける場所でなければならない。**対象外**は温泉、および入浴・蒸気・熱を伴うあらゆる環境である。JP05 `onsen-gate` はまさにこの判断でその場で引退扱いになった（残置し、削除はしない。同じ枠は `coin-locker` が引き継いだ）。通勤、食事、買い物、自宅、屋外、社交の場面はいずれも対象になる。

## この skill のバージョン管理

本 skill はインプレースで更新し、semver で管理する。

- **patch**（1.0.x）：新しい混入パターンの語の追加、文言の修正、事例の追加。
- **minor**（1.x.0）：新しい題材の追加、新しいチェックルールの追加、新しい引退事例の追加。
- **major**（x.0.0）：ゲートまたは言語ルールの変更。

変更時は、冒頭の `version:` を上げ、下記の Change Log に項目を追加し（日付、どの制作で何を学んだか、何を変えたか）、同じターンで導入済みミラー `~/workspace/custom-skills/rokid-jp-localization/SKILL.md` を更新し、両方を 1 コミットで push する。JP に限らずすべての Agent に当てはまる教訓は本 skill には書かず、`rokid-agent-sop` 側に入れる。重複はさせない。
