# Rokid Japan Localization

[中文](SKILL.md) | [English](SKILL.en.md) | 日本語
中文版（2026-10-29 時点）からの翻訳。齟齬がある場合は中文版が優先する。

JP Agent のロケール層。生産パイプラインの共通部分（能力のレッドライン、三つのゲート、9 ステップの SOP、パッケージング / プレビュー / README / GitHub 同期）は `rokid-agent-sop` にあり、この skill は日本に固有のものだけを加える。Agent が JP であるのは、次の 3 点がすべて成り立つ時だけである：JP 番号があること、プロジェクトが `japan/<slug>/` の下にあること、本物の日本の場面であること（以下）。

## 日本の在地性として数えるもの

場面は、本物の日本の制度、礼儀、サービスから来なければならない — 日本語の文章を貼った汎用 Agent ではない。実証済みの源泉（それぞれ具体的な問題を 1 つ持ち、SOP のゲートが求めるクローズドループを備える）：

- **制度と仕組み**：免税買い物のルール（免税・密封袋）、駅のコインロッカー（コインロッカー）、回覧板（町内を回す連絡板）、防災キットのチェック、ゴミ分別の自治体ルール、回転寿司の皿の価格設定。
- **仕組みとしての礼儀**：神社参拝の順序（二拝二拍手一拝）、静粛車両で電話を切る規範、飲み会幹事の務め、山手線の乗り換えでの配慮。
- **地元のサービスと習慣**：コンビニの買い物かごの規律、お土産で職場への贈り物の務めをカバーすること、自転車の駐輪 / ロックアウトの習慣。

設計する前に判定する：そのループが依存する日本のルール、制度、習慣を名指しする。そのループがどの国でも変わらず成り立つなら、それは JP Agent ではない。

## 言語ルール（2026-10-25 の純化事件）

- **ユーザーが見るすべての文字列は、最初の草稿から日本語である** — 状態、ヒーロー、行、マーク、ガイド、TTS の文、SCAN のプロンプト、シード / デモデータ。英語のまま残るのは英語の装飾だけである（ページタイトル、ボタンのラベル、`EVT:` 接頭辞）。README のドキュメントは中国語のままである（UI ではなく、GO 向け）。
- **中国語文案の落とし穴**（生成側の初期値は中国語が漏れる。これらとその同類を探す）：柜 → ロッカー / 棚、点头 → うなずき、守候 → 見守り、取回 → 受け取り、越線 → 超過、寄存 → 預け、ガイドの文と SCAN のプロンプトが中国語の文として書かれていること。中国語と共有する漢字は、その*フレーズ*が自然な日本語である時にだけ問題ない。
- **パッケージング前の機械チェック**（ソースだけでなく、作られた `.ink` ファイルに対して）：UI 文字列のどこにも、中国語だけのフレーズがあってはいけない。ガイドと SCAN のプロンプトは、最も隠れやすい場所なので、手作業で通読する。チェックに失敗した JP ビルドはパッケージングしない。
- TTS の文も同じルールに従う — 話される日本語であり、中国語の残りはない。ホスト TTS の `lang` 属性は決して設定しない（効果がないと文書化されている）。

## 環境ゲート（日本の事例）

設定は、人々が実際にグラスをかける場所でなければならない。**対象外**：温泉と、入浴 / 蒸気 / 熱を伴うあらゆる設定 — JP05 `onsen-gate` はまさにこの裁定によりその場で引退した（保持され、決して削除されず、同じ枠で `coin-locker` に置き換えられた）。通勤、食事、買い物、自宅、屋外、社交はいずれも通る。

## 形式と名簿

- 各 JP Agent は独自の対話哲学と UI の形を持つ（フリート統一の様式に対する、このシリーズの常設の例外）。ボタンは形ごとに様式を決め、共通の初期値を決して使わない。SOP に従い、グリーンのみの配色とする。
- 名簿と番号の権威：`~/workspace/goals/20-agent-rokid-aiui-2/files/PLAN-20-JPKR-Agents.md`（JP01–JP10 が元のライン、JP11 以降が継続分）と `japan/` ディレクトリ。JP の行へのバッジの帰属：頭の向きが主入力である時だけ指向性（jinja-bow）、それ以外は注意力 — バッジの定義は固定。SOP を参照。

## この skill のバージョン管理

この skill はその場で更新し、semver を使う：

- **patch**（1.0.x）：新しい落とし穴の語、文言の修正、例の追加。
- **minor**（1.x.0）：新しい在地性の源泉、新しいチェックルール、新しい引退事例。
- **major**（x.0.0）：ゲート、または言語ルールについての変更。

すべての変更：上の `version:` を上げ、下に Change Log の項目を追加し（日付、どの生産ランが何を教えたか、何が変わったか）、同じターンでインストール済みミラー `~/workspace/custom-skills/rokid-jp-localization/SKILL.md` を更新し、両方を 1 つのコミットで push する。すべての Agent に当てはまる教訓（JP だけではないもの）は、代わりに `rokid-agent-sop` へ入れる — ここに重複させない。
