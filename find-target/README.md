# 找方向 Find Target

**Studio 导入地址**（复制到 Global AIUI Studio 的 Import Project 输入框）：

```
https://github.com/sakai55/rokid/tree/agent-find-target
```

头部动作小游戏系列 G13，C 组（观察 / 控制：头稳住 = 确认）的开篇游戏，极简设计：一页、三态（准备 / 进行 / 完成），语音一次只报一个方向，凭头稳住确认找到。一局 8 个方向：先坐稳 / 站稳，点一下开始：先校准两次（低一下头、向左转一下，记下上下左右），然后语音报「请看向左」（或下 / 右 / 上），屏幕同时显示同一个大箭头——慢慢转头找到、停 0.8 秒算找到，语音说「找到了」，再回正到中间，下一个方向才报。屏幕上只有所报方向（大箭头 + 一个字）、找到数 x / 8 和一行提示；你的转头本身就是游戏动作，由方向传感器对照开局那一刻的头向判定。

与 G05 / G10 / G12 的区别：G05 跟的是语音报的时钟点位序列，G10 跟的是屏幕上的视觉光点，G12 是凭记忆复现一串方向；本游戏每局只有一个语音指令——报一个方向、找一个方向、稳住确认，不跟随、不记忆。

方向固定顺序（不是随机，预览与真机行为可复现）：左、下、右、上、右、左、上、下；该顺序不含任何顺时针连转三连（无上→右→下、右→下→左、下→左→上、左→上→右），且每个方向之间都必须回正到中间，故不可能出现转圈。

## 系列宪法：颈部安全（GO 的规则）

**转圈是错误的。** 只做分段动作：正中 → 向一个方向转 → 停住 → 回正到中间 → 下一个方向。每次只报一个方向，找到就回正，下一个方向只在回正后才报。绝不从一边直接扫到另一边，绝不快速甩动。慢、小幅度、到微酸即止；上方向只到轻微拉伸，绝不用力往后仰、绝不向后甩头。出现痛、晕、麻、恶心，立刻停。一局很短：8 个方向，可重玩。本游戏是日常活动娱乐，**不是医疗诊断、治疗或康复处方**；有颈椎病、眩晕、术后、头颈伤史的人请先问医生。短版印在游戏内的准备屏上；完整版见 AGENTS.md。

## 玩法

1. **准备**：坐稳 / 站稳，头摆正，读一遍安全提示，点「开始」。
2. **校准（进行中，前置两步）**：屏幕先显示「请低一下头」，慢慢低头一次——游戏记下你真实的向下方向（上即反方向）；「回正到中间」后显示「请向左转一下」，慢慢向左转一次——游戏记下你真实的向左方向（右即反方向）。这样宿主上下、左右符号即使反了也不会算反。重开一局会重新校准两次。校准完成前什么都不计分。
3. **找方向（进行中，每个方向）**：语音报「请看向左」（或下 / 右 / 上），屏幕大箭头指向同一方向。慢慢转头找到，超过约 27 度并停住 0.8 秒，语音说「找到了」，找到数 +1。
4. **找错 / 没找到**：向着错误方向转过阈值，语音说「不是这个方向」，本方向 0 分；4 秒内没转到正确方向，语音说「没找到」，本方向 0 分。找到一半没停够就缩回来，不算分，4 秒时钟继续走。
5. **回正**：每个方向结束后必须回正到中间（上下、左右均 <10 度），下一个方向才报；4 秒内没回正，语音提醒「请回正」，宽限计时重置——宽限本身不计分，下一个方向也绝不提前报出（与 G09 的宽限到期照常宣布不同，这是本游戏分段规则的硬性要求）。最后一个方向结束即直接出完成屏（没有下一个方向可等）。
6. **完成**：屏幕显示「找到 x / 8」，点「再来一局」重新校准、重新开始。进行中点一下（真机）是重读当前指令。

## 技术诚实说明

- **无眼动追踪**：平台没有眼动 API；头部方向只来自 `AbsoluteOrientationSensor`。
- **头部手势事件官方文档只写了 `'nod'`**：本游戏不声称任何手势事件，也不装点头事件处理；方向判定全部来自传感器四元数。
- **俯仰与偏航公式（代码原样，G05 同款）**：俯仰 `pitch = asin(2*(w*x - y*z))`（钳制后转度），偏航 `yaw = atan2(2*(w*z + x*y), 1 - 2*(y*y + z*z))`，单位度；只用相对校准中心的差值，宿主的绝对零点不影响判定。
- **上下、左右符号都是学来的，不是假设的**：开局两次校准（请低一下头、请向左转一下）分别记下玩家真实向下、向左的符号，宿主符号反了也不会把上下、左右算反；残留前提是玩家按提示动作——做反了会学反，重开即重新校准；两次校准完成前什么都不计分。
- **阈值**：方向约 27 度（25–30 度档）；回正 <10 度且须上下、左右双轴同时满足；停稳约 0.8 秒（宿主上报稳定性事件时以稳定为准，不上报时以计时为准，已如实说明的回退，不是假装稳定）；一方向 4 秒无正确方向即判没找到；回正宽限 4 秒（到期语音提醒请回正并重置计时，不计分、不提前报下一个方向）；校准卡住 8 秒重提示一次，绝不自动计分。
- **方向顺序固定**：左、下、右、上、右、左、上、下，不是随机；不含任何顺时针连转三连。
- **传感器缺失 = SKIP / 演示，绝不假装通过**：网页预览没有方向传感器，屏幕明示 SKIP，演示按钮只走标注的演示方向（先演示两次校准，再每方向找到一次，回正折叠），完成屏写「演示找到 x / 8」；真机有传感器时没有演示路径。
- **零持久化**：不调任何存储 API；找到数、方向序、中心与上下左右符号只活在页面内存里。

### Feature Description

> Find-the-direction game for Rokid glasses, voice-guided. Eight fixed trials, one at a time: voice cues one direction (left, down, right, up, right, left, up, down) and the screen shows the same arrow. Turn to it and hold 0.8 seconds to find it, then return to center before the next cue. A wrong-direction turn is an instant miss; no correct turn within 4 seconds is a miss. Slow, small range, never jerk; stop at any pain. Entertainment only, not medical advice.
