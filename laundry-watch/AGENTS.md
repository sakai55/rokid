# laundry-watch

Rokid 眼镜洗衣守望智能体（AIUI Agent），注意力外挂系列 W03
（守望型 WATCH）。

## 身份

一个运行在 Rokid 眼镜上的「替你盯着洗衣机」助手，解决洗衣
机在阳台、洗完没人知道、衣服闷一天的问题：站在面板前看
一眼登记——头部朝向就是洗衣机的地址，面板上显示的分钟
数（你亲眼读的）就是唯一的时钟——之后倒计时在你视线里
走着，你尽管离开阳台；剩 3 分钟它先轻喊一声，估时走完
它按「相对你的方向」叫你回去，并把横幅留在眼前，直到你
真的走回阳台看回洗衣机——回看本身就是确认。它外包的是
「反复跑去阳台看洗完没」的那份注意力。

## 能力

- 登记洗衣机（SET，一次一筒）：站在面板前看着它点
  SET，当前头部朝向（`AbsoluteOrientationSensor` 四元
  数算 yaw）被绑给这筒衣服；下滑选衣量（小件 / 日常 /
  大件），上滑选面板分钟数（15 / 30 / 45 / 60 / 90 分
  钟预设档），再单击开始。没有朝向读数时登记如实拒
  绝，绝不编造方向（同 #07 / #28 的纪律）。**衣量只是
  贴在估时上的标签，从不参与计算**——倒计时就是面板
  显示、你亲手填的分钟数。洗涤中再点 SET 只「武装」
  替换，必须再点一次打开登记、单击确认后才真正换掉
  当前这筒，绝不静默丢弃。洗涤中的筒点 TIME 可加 5
  分钟（脱水/漂洗常常比面板估时久）。
- 剩 3 分钟轻喊（tick 引擎，250ms 一拍、拍数累计、不
  反复读时钟）：估时超过 5 分钟的筒，在还剩 3 分钟时
  TTS 轻喊一次「洗衣快结束了，还剩大约三分钟，准备
  晾衣服」——只是倒计时算术，不是它「看出」快洗完
  了；短估时（≤5 分钟）不需要预热，不喊。
- 到点叫回（同一 tick 引擎）：估时走完，按洗衣机相对
  你当时朝向的方向朗读一次「右后方的洗衣机到时间
  了，去晾衣服」，横幅留在眼前，不重复喊。方向永远
  是相对量（目标朝向 − 当前朝向，+ 为右），不报东南
  北；清单与指南框随时显示剩余时间与洗衣机在你的哪
  个方向，让你知道往哪儿回去。
- 回看确认（核心闭环）：确认只有两种：**走回去看回洗
  衣机**——头稳住、朝向落入登记朝向的 ±15° 内，入锥
  只算开始，再连续停满 1 秒（4 拍），记 `face`；或点
  ACK，记 `tap`。快速转头扫过不算数，离开锥形区重新
  计时——它要的是你真的回去看了一眼。
- 守听电平（LISTEN，可选层）：点 LISTEN 后按文档方式
  用 `getUserMedia({audio:{captureSource:'microphone',
  microphoneMode:'omnidirectional'}})` 开麦——全向模式
  只给一条 Web Audio `AnalyserNode` 电平流（只接分析
  器，绝不接 destination 防啸叫），每拍算一次 RMS 电
  平显示在界面上。守听只在**最后 20% 时段**（或估时已
  到、横幅还等着回看时）睁眼：电平跳到很响、又在 2 秒
  内落回安静——一个「短促响声」的形状——它提醒一
  次：「刚才有一声响亮的短音，去看一眼洗衣机」。同
  一段响声（episode）只提醒一次，需要 4 秒安静重新
  布防后，新的短音才算新的一段。窗口外的短音（电视、
  关门声）一律忽略；**持续的大声响（脱水轰鸣本身）故
  意不作信号**——它太含糊，什么都说明不了。模式被设
  备拒绝（OverconstrainedError）时回退默认麦克风并如
  实提示。STOP / 页面隐藏 / 卸载立即停掉全部媒体轨道
  并关闭 AudioContext。没开 LISTEN 时，计时闭环照样
  完整成立——守听只是加层。
- 朗读状态（SPEAK / 点头）：随时点 SPEAK 听洗涤进
  度；头部稳定时点头只等同 SPEAK。
- 手势优先（档案 §3.2.1 触控板手势）：单击（Enter）
  = 情景主操作（登记中 = 开始守望；洗衣机在等回看 =
  确认；替换已武装 = 打开登记；其余 = 登记或朗读状
  态）；滑动（ArrowUp/Down）= 登记中选面板分钟/衣
  量；双击（Backspace）= 返回，由宿主处理；头部稳定
  时点头 = 朗读状态。屏幕保留 6 个按钮（SET / TIME /
  ACK / LISTEN / SPEAK / DEMO），README「手势映射」
  逐个说明保留理由。
- DEMO：内存里播入一筒演示衣——面板 45 分钟、已洗
  85%，洗衣机在正前方 0°、演示头先停在 180° 背对
  它，LISTEN 以模拟电平开启（安静约 2 秒后抛出一声短
  促响音，窗口已开，短音提醒触发）；每点一次 DEMO
  朝向 +45° 并把洗涤快进估时的 6%：剩 3 分钟轻喊在
  途中响起，估时走完正式报警；转头一圈回到正对洗衣
  机（0°）停满 1 秒触发回看确认；转满一圈后再点一
  次退出演示、恢复你真实的这筒（演示期间真实筒的计
  时在内存里暂停，退出后接着走），全程不写任何存
  储。

## 行为边界

- **电平不是蜂鸣识别**：AIUI 运行时没有声音分类器，
  本 Agent 绝不声称能「听出洗完蜂鸣 / 提示音」。它
  只认电平的形状：窗口内一声短促的响亮声音，可能是
  洗衣机叫你，也可能是微波炉好了、门铃响了、电视里
  的音效——它只负责说「刚才有一声响亮的短音」，判
  断那声是什么的是你的眼睛。界面常驻行写明这一
  点。持续轰鸣（脱水声）故意不用作信号：它一直在
  响，响停的时刻和「洗完」之间没有可靠对应。
- **估时就是面板估时**：倒计时的源头是洗衣机面板显
  示的分钟数，由你的眼睛读、你的手填。暂停、加衣、
  水压变化都会让真实结束时刻漂移——所以到点后它不
  替你断言「洗完了」，只按方向叫你回去看，并把确认
  权留给你的回看。
- **全向麦克风模式只作用于电平流**（2026-10-24 能力
  边界审计口径）：`microphoneMode: 'omnidirectional'`
  只决定这条 getUserMedia 流怎么收音、喂给电平表；
  本 Agent 没有语音识别环节，更不存在「模式让识别
  更准」之类说法。
- **守望只在本页打开时存在**：倒计时、轻喊、到点播
  报、电平守听都只在 Agent 打开期间运行；关掉页
  面、眼镜息屏后什么都不会响——衣服还在闷着也不会
  有人推送。它不是远程监护。界面常驻行写明，README
  同口径。
- **不存任何记录**：本 Agent 不写任何 wx 存储。登
  记、剩余时间、电平读数都只活在本次会话内存里，
  页面关掉一切消失；麦克风音频从不录制、不保存、
  不上传，电平只是实时算出的 RMS 数值。
- **确认 = 你看过了**：回看确认记录的是「你转头看
  向了洗衣机的方向并停住」，它没法判断衣服是否真
  的洗完、筒门是否真的能开——看过一眼之后做什么，
  仍由你决定。登记朝向只对登记时站的位置成立：换
  个站位，几何关系就变了（同 #07 / #28）。
- TTS 从不设置 `utterance.lang`（宿主不采纳该属
  性，档案 §2.6）。麦克风只在用户点 LISTEN 后开
  启；声明权限只有 RECORD_AUDIO（电平守听的麦克
  风流）。不用相机、不用定位。
