# 身体型 BODY（body/）

[中文](README.md) | [English](README.en.md) | 日本語
中国語版（2026-10-29 時点）の翻訳。

注意力アドオンシリーズ。BO01–BO05、全5件。身体のサインはこちらで受け止める。

- BO01 [eye-rest](eye-rest/) — 頭を固定して近くを20分見続けたら、遠くを見るよう促し、顔を上げて確認する
- BO02 [water-watch](water-watch/) — 長くコップを見ていないと画面を点灯させて水分補給を促し、視線を向けて確認する
- BO03 [breath-pace](breath-pace/) — 視界の中に呼吸ペースの光点。目で追うだけ
- BO04 [stand-move](stand-move/) — 座りっぱなしが閾値を超えたら立ち上がるよう促し、周りを見回して確認する
- BO05 [snack-aware](snack-aware/) — お菓子に目を向けると、まず今日何回目かを表示。食べるかどうかは自分次第

全リストはルートの [README](../README.md) 末尾にある Agent リストを参照。
