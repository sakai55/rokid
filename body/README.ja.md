# 身体型 BODY（body/）

[中文](README.md) | [English](README.en.md) | 日本語
中文版（2026-10-29 時点）からの翻訳。

注意力アドオンシリーズ · 番号 BO01–BO05、全5件。身体が出す信号を、代わりに受け止める。

- BO01 [eye-rest](eye-rest/) — 頭を止めて近くを20分見つめ続けたら遠くを見るよう促し、顔を上げて確認
- BO02 [water-watch](water-watch/) — 長くコップを見ていないと画面が光って水分補給を促し、見つめて確認
- BO03 [breath-pace](breath-pace/) — 視界内に呼吸ペースの光点、目で追うだけ
- BO04 [stand-move](stand-move/) — 座りすぎが閾値を超えたら起立を促し、一周見回して確認
- BO05 [snack-aware](snack-aware/) — お菓子を見るとまず今日何回目かを表示、食べるかどうかは自分で決める
