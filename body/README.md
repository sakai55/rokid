# 身体型 BODY（body/）

中文 | [English](README.en.md) | [日本語](README.ja.md)

注意力外挂系列 · 编号 BO01–BO05，共 5 个。身体发的信号，它替你收着。

- BO01 [eye-rest](eye-rest/) — 头稳凝视近处满20分钟提醒远眺，抬头确认
- BO02 [water-watch](water-watch/) — 久未看向水杯亮屏提醒喝水，凝视确认
- BO03 [breath-pace](breath-pace/) — 视线内呼吸节拍光点，跟着看就行
- BO04 [stand-move](stand-move/) — 久坐超阈值提醒起身，环视一圈作确认
- BO05 [snack-aware](snack-aware/) — 看向零食先亮今天第几次，吃不吃你决定
