# 保持型 HOLD（hold/）

[中文](README.md) | [English](README.en.md) | 日本語
中国語版（2026-10-29 時点）の翻訳。

注意力アドオンシリーズ。HO01–HO05、全5件。もう頭の中で復唱し続けなくていい。

- HO01 [number-catch](number-catch/) — 番号を撮って拡大して照合。視界に常時出しておくので暗唱いらず
- HO02 [code-hold](code-hold/) — 一時コードを声に出して保存。入力するときに区切って表示する
- HO03 [voice-list](voice-list/) — 声に出した内容をリストにして視界に固定。棚を見ながら、うなずきで1つずつ消していく
- HO04 [route-hold](route-hold/) — 行き方を声に出して手順として保存。歩くときは今の一歩だけを表示し、うなずきで次へ進む
- HO05 [seat-catch](seat-catch/) — 半券を撮って座席番号を保存。列ごと・席ごとに、現在地との差だけを知らせる

全リストはルートの [README](../README.md) 末尾にある Agent リストを参照。
