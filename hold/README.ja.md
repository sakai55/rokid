# 保持型 HOLD（hold/）

[中文](README.md) | [English](README.en.md) | 日本語
中文版（2026-10-29 時点）からの翻訳。

注意力アドオンシリーズ · 番号 HO01–HO05、全5件。頭の中で繰り返し唱え続ける必要がなくなる。

- HO01 [number-catch](number-catch/) — 番号を撮って拡大確認、視界に常時表示されるので暗唱は不要
- HO02 [code-hold](code-hold/) — 一時コードを唱えて保存、入力時に区切って表示
- HO03 [voice-list](voice-list/) — 唱えた内容がリストになって視界に残り、棚を見て一つずつうなずいて消していく
- HO04 [route-hold](route-hold/) — ルートを唱えて手順を保存、歩行中は現在の一歩だけを表示し、うなずいて前進
- HO05 [seat-catch](seat-catch/) — チケットの半券を撮って座席番号を保存、列ごと席ごとに相対差だけを知らせる

全リストは[リポジトリ ルート README](../README.md) 末尾の Agent リストを参照。
