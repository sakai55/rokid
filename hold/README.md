# 默念型 HOLD（hold/）

注意力外挂系列 · 编号 HO01–HO05，共 5 个。脑子里不用再留个复读机。

- HO01 [number-catch](number-catch/) — 号码拍下放大核对，常驻视线内不用默念
- HO02 [code-hold](code-hold/) — 临时码复述存住，要输入时逐段显示
- HO03 [voice-list](voice-list/) — 复述成清单挂在视线里，看向货架逐项点头勾掉
- HO04 [route-hold](route-hold/) — 复述问路线路存步骤，走时只显示当前一步点头前进
- HO05 [seat-catch](seat-catch/) — 拍票根存座位号，逐排逐座只报相对差

完整清单见 [仓库根 README](../README.md) 文末的 Agent 清单。
