# home-patrol

Rokid 眼镜出门巡检智能体（AIUI Agent）。

## 身份

一个运行在 Rokid 眼镜上的「出门前巡检清单」助手，解决出门前总
不放心门窗、燃气、水龙头关没关的问题——锁了门走出去一百米，
又开始怀疑燃气阀到底拧没拧。它把巡检拆成固定的六个检查点摆在
你眼前，逐个领你走到跟前、看清楚、打勾；登记过朝向的检查点，
还会用相对方向告诉你往哪边转、什么时候正对着它。全六项打完
勾，它才朗读「可以出门」。

## 能力

- 朝向读取：AbsoluteOrientationSensor（约 5Hz）四元数算 yaw 朝向角，
  界面如实标注来源 SENSOR / DEMO / NONE；无传感器时不编造朝向，
  SETUP 登记会拒绝并说明原因（同 #07 find-my-thing）。
- 检查点（固定 6 个）：大门锁 / 客厅窗 / 卧室窗 / 燃气阀 /
  水龙头 / 空调电源，每个都带一句你亲眼核对的具体线索（如
  燃气阀「看阀门手柄，确认已关到位再打勾」、水龙头「看龙头口
  无滴水」、大门锁「拉一下门把，确认已经反锁」）。
- 登记朝向（SETUP 模式，可选）：站在你巡检时会站的位置，看着
  检查点点 REG（或头部稳定时点头、Enter），把
  {检查点名， 朝向°} 存入 wx 同步存储（key `homePatrolPoints`，
  onLoad 载入、onUnload 落盘）。朝向只是加分指引，不是必需：
  没登记的点靠眼睛看 + 点按打勾，照样巡检。
- 巡检（PATROL 模式，默认）：按清单顺序逐项走。当前检查点
  大字显示 + 核对线索；登记过朝向的显示 8 向箭头与
  「TURN: RIGHT-FRONT 45°」，|相对角| ≤ 20° 时高亮
  「FACING IT — look carefully, then CHECK」。CHECK（按钮 /
  Enter / 正对或未登记时头部稳定点头）打勾并自动跳到下一项；
  ITEM 可在未打勾项之间切换。
- 打勾方式如实记录：每一项打勾时记下是怎么打的——正对着
  登记朝向打的记 `✓ facing`，其余（没登记、没对上、手动
  点按）记 `✓ by tap`，列表里逐项可见。不做假门禁：CHECK
  点按永远可用，朝向只是引导你真的走到跟前看。
- 全绿播报：6/6 打完勾，大字「ALL CLEAR — 可以出门」并自动
  TTS 朗读「全部检查完，可以出门了」。RESET 开新一轮巡检
  （清打勾、保留登记）；CLEAR 清除全部登记朝向。
- DEMO：内存里给 6 个点绑上演示朝向 40° / 90° / 160° /
  230° / 300° / 340°（不写入存储、不覆盖你的真实登记），
  朝向从 45° 起步——离第一个点（大门锁 40°）只差 −5°，
  处于 FACING 状态并预打勾，落在 1/6、当前项客厅窗
  （90°，TURN: RIGHT-FRONT 45°）；之后每点一次 DEMO
  朝向 +45°。DEMO 中点 CLEAR 退出演示并恢复真实登记。
- 朗读：SPEAK 用中文朗读进度：「还剩 X 项。当前一项：
  <检查点>。<核对线索>」；全打完时朗读出门播报。

## 行为边界

- **它确认的是「你看过」，不是「关好了」**：眼镜没有能力
  判断燃气阀是不是真的关到位、窗户锁扣是不是真的扣上——
  检查的是你的眼睛，Agent 只负责把六个点逐个摆到你面前、
  一个都不漏，并如实记下你是怎么打的勾（facing / by tap）。
  界面页脚常驻说明，README 同样如实写明。
- 燃气阀线索只说「看阀门手柄，确认已关到位」：不同阀门
  （球阀/旋塞阀）手柄方向的含义不同，本 Agent 不断言哪种
  朝向是关——以你家阀门自身的标识和平时用法为准。闻到
  燃气味时不要对着眼镜慢慢核对，直接关阀开窗、联系燃气
  公司。
- 朝向只对你登记时站的位置成立（同 #07 / #10 的几何边界）：
  登记的是「从我站的地方看向这个检查点」的方向；巡检时
  站回登记位置附近转头，FACING 才有意义。
- 朝向缺失（SRC NONE 且非 DEMO）时拒绝登记，绝不编造朝向；
  巡检本身不依赖朝向——没有传感器也能看清单逐项点按打勾。
- 不需要任何权限：不用相机、不用麦克风、不用定位；朝向
  传感器不需要单独权限声明，故 app.json 无 permissions
  字段（同 #07 / #15）。登记只存本机 wx 同步存储，不上传；
  DEMO 朝向只在内存里，永不落盘覆盖真实登记。
