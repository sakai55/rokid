# repair-buddy

Rokid 眼镜修理搭档智能体（AIUI Agent）。

## 身份

一个运行在 Rokid 眼镜上的家庭小维修向导，解决「修水龙头、自行车、
马桶时双手都占着，没法举着手机看教程；零件又小，凑近了也看不清」
的问题。你选好要修的项目，眼镜在视线内一步一步带你做：语音念一步
你做一步，点头进下一步，步骤全程不用腾手；动手前还能对着小零件
用长焦拍一张特写留档。

## 能力

- 凝视确认：开启世界感知（enableWorldAwareness），头部稳定
  （onOrientationStabilityChange stable）后显示「HEAD STEADY」；
  点头（onHeadGesture nod）：没有计划时触发 LOOK 拍照，计划
  进行中则推进一步——双手在扳手/阀芯上时用点头代替腾手点按钮。
- 看零件长焦拍照（只作记录）：getUserMedia({video:true}) 取流后
  用 ImageCapture.takePhoto({mode:'telephoto'}) 对手里的小零件
  （阀芯、垫圈、拍盖、顶丝）拍特写留作视觉记录，界面显示照片
  字节数；ImageCapture 不可用时回退 wx.media CameraContext。
  照片不参与任何判断，界面如实标注 record only。
- 项目选择：JOB 在 4 个内置常见维修项目间切换（水龙头滴水 /
  自行车掉链 / 马桶一直流水 / 门把手松动），每个项目带工具清单
  一行；ArrowUp / ArrowDown 同样换项目（会重置计划）。项目由
  用户自己选，Agent 不做故障诊断。
- 安全第一步：每个项目的第 1 步都是它的安全动作——水龙头先
  关总水阀、马桶先关进水角阀、自行车先支稳车身、门把手先确认
  松动来源（无水电危险）。START 尝试 LanguageModel 生成计划时，
  提示词强制第 1 步原样使用该项目的安全动作。
- 维修计划：START 先尝试 LanguageModel 按所选项目生成简短
  计划（解析出 ≥4 个编号步骤才采用，标注来源 LLM）；不可用或
  解析失败时用内置项目表（每项目 5 个具体步骤），标注来源
  built-in guide。NEXT / 点头逐步推进；最后一步后显示
  「找专业人员」的收尾语（如 still dripping → book a plumber）。
- 零件状态（你亲眼判断）：PART 轮换你看到的零件状态（零件完好 /
  磨损 / 裂了），每个状态给一句后果（如「裂了 → 这件要换新，
  别硬装」）。照片不判断零件好坏，状态一律由佩戴者确认。
- 收尾检查：全部步骤做完后按 CHECK，显示该项目的验收一行
  （如水龙头：慢慢开总水阀 → 看 1 分钟不滴 = 成功），状态进入
  DONE；计划没做完时 CHECK 会如实提示先做完。
- 朗读：SPEAK 用 speechSynthesis.speak 朗读当前步骤（无计划
  时朗读所选项目的工具清单 + 安全第一步；做完朗读收尾语；
  CHECK 后朗读验收行）。
- DEMO：直接载入「水龙头滴水」的内置计划并停在第 2 步，
  方便在没有相机/大模型的预览环境里看到修到一半的步骤视图。

## 行为边界

- 只给 4 个内置项目的常见 DIY 指引，不做故障诊断、不替代
  专业维修：项目由用户选定，照片只作记录，绝不声称从照片
  判断出了故障或零件状态。
- **燃气与强电不在范围内**：燃气管道/灶具、220V 强电线路、
  配电箱、密封机芯内部一概不提供步骤；内置表与大模型提示词
  都明确排除。遇到这类问题请关阀/断电并找专业人员。
- 相机只在用户点 LOOK、点头或按 Enter 时启动，拍完立即停掉
  全部媒体轨道；大模型会话用完即 destroy；页面卸载时同样清理。
- 主机没有相机时 LOOK 显示 FAIL 并写明原因，不伪造照片；
  大模型不可用时如实回退内置表并标注来源。
- 不上传照片，不保存拍摄内容；照片只取字节数用于状态显示。
