# 方向记忆 Memory Seq

**Studio 导入地址**（复制到 Global AIUI Studio 的 Import Project 输入框）：

```
https://github.com/sakai55/rokid/tree/agent-memory-seq
```

头部动作小游戏系列 GA12，B 组（头当控制器）的收官游戏，极简设计：一页、三态（准备 / 进行 / 完成），考的是方向记忆，不是跟随。语音先报一轮方向顺序（屏幕上只写「听」，绝不写方向），再由玩家按顺序一步一步做出来：每步转到方向、停 0.8 秒、回正到中间，下一步才开始。

与 GA05（听语音点位）、GA10（追视觉光点）不同：本游戏在报顺序和回忆时都不给任何屏幕提示——方向只报不写，记不住就过不了这轮。

## 系列宪法：颈部安全（GO 的规则）

**转圈是错误的。** 本游戏只用分段动作：中间 → 一个方向 → 停住 → 回正 → 下一步。顺序从不连续扫动、从不画圈；回忆时也是一步一步带回正地重做，和报顺序时完全一样。慢、小幅度、到微酸即止；上只到轻微拉伸，绝不用力往后仰。痛、晕、麻、恶心立刻停。先坐稳 / 站稳。一局 3 轮，很短。本游戏是日常活动娱乐，**不是医疗诊断、治疗或康复处方**；有颈椎病、眩晕、术后、头颈伤史的人请先问医生。短版印在游戏内的准备屏上；完整版见 AGENTS.md。

## 玩法

1. **准备**：坐稳 / 站稳，头摆正，读一遍安全提示，点「开始」。
2. **校准**：开始时先校准中心（头摆正），再跟两句校准提示：低一下头（学下方向）、向左转一下（学左方向），每次校准后都要回正。两项校准都完成前什么都不算；重玩会重新校准。
3. **听**：每轮先报顺序，语音一秒报一个方向，屏幕只写「听」+ 轮次，绝不写方向。
4. **做**：语音说「请按顺序做出来」后，按顺序做每一步：转到方向、停 0.8 秒、回正到中间。做对一步语音说「对」；转错方向一过阈值，本轮立刻失败（语音「错了，这轮没过」），本轮内不重做；失败后回正到中间，下一轮才开始报顺序。
5. **固定顺序（不随机，方便复现）**：第 1 轮：左、上、右；第 2 轮：下、左、下（重复的下是允许的，因为每步之间都有回正）；第 3 轮：右、下、左、上。
6. **卡住怎么办**：某一步 8 秒没动，语音只提醒一次「轮到你了，按顺序做」，然后继续等——卡住本身绝不会判失败。
7. **完成**：3 轮走完，屏幕显示「赢了 x / 3」，点「再来一局」重新校准，用同一组顺序再玩。

| 双击 | Backspace | 系统返回（不拦截） |
| 长按 | — | 唤醒助手（系统级，不拦截） |

屏幕按钮只有一个（主按钮，文案随状态变：开始 / 朗读 / 再来一局）；网页预览无传感器时它显示为演示步进按钮（见下）。本游戏故意不用任何头部手势事件：该 API 官方文档只写了 `'nod'`，而点头不是本游戏的动作。

## 技术诚实说明

- **无眼动追踪**：平台没有眼动 API；方向只来自方向传感器四元数相对校准中心的俯仰 / 偏航。
- **头部手势事件官方文档只写了 `'nod'`**：本游戏不声称任何其他手势事件；方向全部来自传感器，绝不来自手势事件。
- **阈值与时序（代码原样）**：方向到达约 25–30 度（代码 27 度，俯仰管上下、偏航管左右）；回正须俯仰与偏航同时小于 10 度；每步停稳约 0.8 秒（宿主报稳定事件时只在稳定中累计，否则用经过时间兜底，已如实说明，不是假装稳定）；报顺序每词间隔 1 秒；回忆卡住 8 秒提醒一次，绝不自动判失败。
- **双轴校准（代码原样）**：开局两句提示分别学下方向与左方向的符号，上取俯仰反号、右取偏航反号，符号一律不假设。残留风险已如实说明：校准相信玩家跟提示做——低头做成抬头、左转做成右转会把该轴学反；兜底是两项校准完成前什么都不算、第一轮第一步就是左、第二步就是上，学反立刻感觉不对、重玩重新校准。
- **传感器缺失 = SKIP / 演示，绝不假装通过**：网页预览没有方向传感器，屏幕明示 SKIP，演示按钮（「演示报方向」「演示做对一步」等）走同一套轮次流程，完成屏写「演示赢了 x / 3」；真机有传感器时没有演示路径。
- **零持久化**：不调任何存储 API；轮次、步数与校准只活在页面内存里。
