# 回正定点 Stop Center

**Studio 导入地址**（复制到 Global AIUI Studio 的 Import Project 输入框）：

```
https://github.com/sakai55/rokid/tree/agent-stop-center
```

头部动作小游戏系列 GA24，Wave 2 的 E 组（精准控制），极简设计：一页、三态（准备 / 进行 / 完成），语音一次只报一边，转过去再回正停住计分。一局 8 题：先坐稳 / 站稳，点一下开始：先校准一次（向左转一下，记下左右），然后语音报「向左转」，屏幕同时显示同一目标（箭头 + 一边）——慢慢转头，转到位（≥20 度）语音说「回正，停住」，慢慢回正，停在正中间 ±5 度内、停稳 0.8 秒，语音说「停住了」，停住数 +1，下一题才报。冲过正中间到另一边 5 度外，语音说「过冲了」，本题 0 分。屏幕上只有目标（箭头 + 一边）、停住数 x / 8 和一行提示；你的转头本身就是游戏动作，由方向传感器对照开局那一刻的头向判定。

与 GA21（对角度）的区别：GA21 判的是**出去**时落进所报的角度带；本游戏判的是**回来**时能不能停死在正中间——转过去只是起手，停住才是得分点。与 GA13（找方向）的区别：GA13 只判转到某个方向；本游戏转到一边后还必须回正停稳，且过冲判错。第一波各游戏把回正只当作题与题之间的门；本游戏把回正本身做成了玩法。

题目固定顺序（不是随机，预览与真机行为可复现）：左、右、左、右、左、右、左、右；每题之间都在正中间停住，故不可能出现转圈。

## 系列宪法：颈部安全（GO 的规则）

**转圈是错误的。** 只做分段动作：正中 → 向一边转 → 回正停住 → 下一题。每次只向一边转，停住后下一题才报。绝不从一边直接扫到另一边，绝不快速甩动。慢、小幅度、到微酸即止。出现痛、晕、麻、恶心，立刻停。一局很短：8 题，可重玩。本游戏是日常活动娱乐，**不是医疗诊断、治疗或康复处方**；有颈椎病、眩晕、术后、头颈伤史的人请先问医生。短版印在游戏内的准备屏上；完整版见 AGENTS.md。

## 玩法

1. **准备**：坐稳 / 站稳，头摆正，读一遍安全提示，点「开始」。
2. **校准（进行中，前置一步）**：屏幕显示「请向左转一下」，慢慢向左转一次——游戏记下你真实的向左方向（右即反方向）。这样宿主左右符号即使反了也不会算反。回正后第 1 题才报。重开一局会重新校准。校准完成前什么都不计分。
3. **转过去（进行中，每一题）**：语音报「向左转」（或向右），屏幕显示同一目标。慢慢转头，转到位（向所报一边 ≥20 度）语音说「回正，停住」。
4. **回正停住（进行中，每一题）**：慢慢回正，停在正中间（左右 ±5 度、上下 <10 度），停稳 0.8 秒，语音说「停住了」，停住数 +1，下一题立刻报（已经停在正中间，无需再等回正）。
5. **过冲 / 没停住**：停住阶段冲过正中间到另一边 5 度外，语音说「过冲了」，本题 0 分；14 秒内没停住，语音说「没停住」，本题 0 分。没停住的题结束后必须回正到中间（上下、左右均 <10 度），下一题才报；4 秒内没回正，语音提醒「请回正」，宽限计时重置——宽限本身不计分，下一题也绝不提前报出。最后一题结束即直接出完成屏。
6. **完成**：屏幕显示「停住 x / 8」，点「再来一局」重新校准、重新开始。进行中点一下（真机）是重读当前指令。

## 技术诚实说明

- **无眼动追踪**：平台没有眼动 API；头部方向只来自 `AbsoluteOrientationSensor`。
- **头部手势事件官方文档只写了 `'nod'`**：本游戏不声称任何手势事件，也不装点头事件处理；角度判定全部来自传感器四元数。
- **偏航与俯仰公式（代码原样）**：偏航 `yaw = atan2(2*(w*z + x*y), 1 - 2*(y*y + z*z))`（GA02 同款），单位度；俯仰 `pitch = asin(2*(w*x - y*z))`（钳制后转度，GA01 / GA04 同款）。题目只判偏航（所报目标都是左右角度）；俯仰只用于回正判定（双轴同 <10 度）。只用相对校准中心的差值，宿主的绝对零点不影响判定。
- **左右符号是学来的，不是假设的**：开局一次校准（请向左转一下）记下玩家真实向左的符号，宿主符号反了也不会把左右算反；残留前提是玩家按提示动作——做反了会学反，重开即重新校准；校准完成前什么都不计分。
- **阈值**：转到位 ≥20 度；停住带为左右 ±5 度（上下 <10 度）；带内停稳约 0.8 秒（宿主上报稳定性事件时以稳定为准，不上报时以计时为准，已如实说明的回退，不是假装稳定）；停住阶段过冲到另一边 5 度外即判没停住；一题 14 秒无停住即判没停住；没停住后的回正 <10 度且须上下、左右双轴同时满足；回正宽限 4 秒（到期语音提醒请回正并重置计时，不计分、不提前报下一题）；校准卡住 8 秒重提示一次，绝不自动计分。
- **题目顺序固定**：左、右、左、右、左、右、左、右，不是随机。
- **传感器缺失 = SKIP / 演示，绝不假装通过**：网页预览没有方向传感器，屏幕明示 SKIP，演示按钮只走标注的演示路径（先演示校准，再每题停住一次，回正折叠），完成屏写「演示停住 x / 8」；真机有传感器时没有演示路径。
- **零持久化**：不调任何存储 API；停住数、题目序、中心与左右符号只活在页面内存里。

## 提审资料 (Review Submission)

### Feature Description

> Return-to-center stopping game for Rokid glasses, voice-guided. Eight alternating trials call a side; turn to that side, then return to center and stop inside plus or minus 5 degrees without overshooting to the other side, holding 0.8 seconds to hit. Overshoot or 14 seconds without a stop is a miss. Slow, small range, never jerk; stop at any pain. Entertainment only, not medical advice.

### Opening Message

> ## 回正定点
>
> 坐稳，点一下开始：先校准一次（向左转一下），然后一次只报一边——**向左转就慢慢向左转到位，向右转就慢慢向右转到位**。转到位语音说「回正，停住」，慢慢回正，停在正中间 ±5 度内、停稳 0.8 秒算停住，语音说「停住了」，下一题才报。冲过正中间到另一边算过冲，14 秒没停住算没停住。8 题左右交替，不是随机。一边一题，从不转圈，慢、小幅度、不甩头，痛、晕、麻、恶心立刻停。本游戏是日常活动娱乐，不是医疗建议。
