# 渐进保持 Hold Ramp

**Studio 导入地址**（复制到 Global AIUI Studio 的 Import Project 输入框）：


头部动作小游戏系列 GA25，Wave 2 的 E 组（精准控制），极简设计：一页、三态（准备 / 进行 / 完成），语音报一级的保持秒数，低头保持够秒数爬一级。一局 5 级：先坐稳 / 站稳，点一下开始：先校准一次（低一下头，记下低头方向），然后语音报「第 1 级，低头保持 2 秒」，屏幕同时显示同一目标（箭头 + 秒数）——慢慢低头，低到 20 度以上，保持够 2 秒，语音说「爬上去了」，爬上数 +1，再回正到中间，下一级才报（第 2 级 3 秒、第 3 级 4 秒、第 4 级 5 秒、第 5 级 6 秒，一级比一级久）。中途抬头离开低头区，保持计时清零、不计分；一级时钟（秒数 + 8 秒宽裕）到点还没保持够，语音说「没爬上去」，本题 0 分。屏幕上只有目标（箭头 + 秒数）、爬上数 x / 5 和一行提示；你的低头本身就是游戏动作，由方向传感器对照开局那一刻的头向判定。

与 GA04（仰低拉伸）的区别：GA04 是固定 5 秒、上下交替各 3 次；本游戏只低头一个方向，练的是**保持时间一级一级爬上去**（2 / 3 / 4 / 5 / 6 秒），不是换方向。与 GA03（贴耳操）的区别：GA03 保持的是侧屈；本游戏保持的是低头俯仰。与 GA21 / GA24 的区别：那两个判角度（出去落进带、回来停在正中间）；本游戏判保持时长。

阶梯固定（不是随机，预览与真机行为可复现）：2、3、4、5、6 秒；每级之间都必须回正到中间，故不可能出现转圈。

## 系列宪法：颈部安全（GO 的规则）

**转圈是错误的。** 只做分段动作：正中 → 低头保持 → 回正 → 下一级。每次只低头一次，保持够秒数再回正，下一级只在回正后才报。绝不从一边直接扫到另一边，绝不快速甩动。慢、小幅度、低头只到微酸、不勉强。出现痛、晕、麻、恶心，立刻停。一局很短：5 级，可重玩。本游戏是日常活动娱乐，**不是医疗诊断、治疗或康复处方**；有颈椎病、眩晕、术后、头颈伤史的人请先问医生。短版印在游戏内的准备屏上；完整版见 AGENTS.md。

## 玩法

1. **准备**：坐稳 / 站稳，头摆正，读一遍安全提示，点「开始」。
2. **校准（进行中，前置一步）**：屏幕显示「请低一下头」，慢慢低头一次——游戏记下你真实的低头方向。这样宿主俯仰符号即使反了也不会算反。回正后第 1 级才报。重开一局会重新校准。校准完成前什么都不计分。
3. **保持（进行中，每一级）**：语音报「第 1 级，低头保持 2 秒」（各级秒数递增），屏幕显示同一目标。慢慢低头，低到 20 度以上，保持够该级秒数，语音说「爬上去了」，爬上数 +1。
4. **没稳住 / 没爬上去**：保持够秒数前抬头离开低头区，保持计时清零、不计分，一级时钟继续走；一级时钟（秒数 + 8 秒宽裕）到点还没保持够，语音说「没爬上去」，本题 0 分。
5. **回正**：每一级结束后必须回正到中间（上下、左右均 <10 度），下一级才报；4 秒内没回正，语音提醒「请回正」，宽限计时重置——宽限本身不计分，下一级也绝不提前报出。最后一级结束即直接出完成屏。
6. **完成**：屏幕显示「爬上 x / 5」，点「再来一局」重新校准、重新开始。进行中点一下（真机）是重读当前指令。

## 技术诚实说明

- **无眼动追踪**：平台没有眼动 API；头部方向只来自 `AbsoluteOrientationSensor`。
- **头部手势事件官方文档只写了 `'nod'`**：本游戏不声称任何手势事件，也不装点头事件处理；保持时长判定全部来自传感器四元数。
- **俯仰与偏航公式（代码原样）**：俯仰 `pitch = asin(2*(w*x - y*z))`（钳制后转度，GA01 / GA04 同款）；偏航 `yaw = atan2(2*(w*z + x*y), 1 - 2*(y*y + z*z))`（GA02 同款），单位度。题目只判俯仰（所报目标都是低头保持）；偏航只用于回正判定（双轴同 <10 度）。只用相对校准中心的差值，宿主的绝对零点不影响判定。
- **低头符号是学来的，不是假设的**：开局一次校准（请低一下头）记下玩家真实低头的符号，宿主符号反了也不会把低头算反；残留前提是玩家按提示动作——做反了会学反，重开即重新校准；校准完成前什么都不计分。
- **阈值**：低头区为向低头方向 ≥20 度；保持时长为该级秒数（2 / 3 / 4 / 5 / 6 秒，宿主上报稳定性事件时以稳定为准，不上报时以计时为准，已如实说明的回退，不是假装稳定）；一级时钟为秒数 + 8 秒宽裕，到点没保持够即判没爬上去；回正 <10 度且须上下、左右双轴同时满足；回正宽限 4 秒（到期语音提醒请回正并重置计时，不计分、不提前报下一级）；校准卡住 8 秒重提示一次，绝不自动计分。
- **阶梯固定**：2、3、4、5、6 秒，不是随机。
- **传感器缺失 = SKIP / 演示，绝不假装通过**：网页预览没有方向传感器，屏幕明示 SKIP，演示按钮只走标注的演示路径（先演示校准，再每级爬上一次，回正折叠），完成屏写「演示爬上 x / 5」；真机有传感器时没有演示路径。
- **零持久化**：不调任何存储 API；爬上数、级序、中心与低头符号只活在页面内存里。
