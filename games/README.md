# 头部动作小游戏（games/）

头部动作 + 拍照现实交互小游戏系列 · 编号 GA01–GA50：头部动作 GA01–GA40 与拍照游戏 GA41–GA50。用头部动作或拍照与现实互动玩的极简小游戏。

- GA01 [nod-count](nod-count/) — 语音指导10次慢速点头，低头回正算一次
- GA02 [turn-count](turn-count/) — 语音指导左右转头交替，各5次满10次
- GA03 [ear-tilt](ear-tilt/) — 左右贴耳各3次，稳住5秒才算一次
- GA04 [stretch-hold](stretch-hold/) — 仰头低头交替拉伸，各保持5秒各3次
- GA05 [neck-clock](neck-clock/) — 按报出的时钟点位转头，每点必回正
- GA06 [chin-tuck](chin-tuck/) — 下巴小幅后收保持5秒，8次收下巴操
- GA07 [steady-hold](steady-hold/) — 头稳住不动满10秒胜，动了重计
- GA08 [nod-catch](nod-catch/) — 10 个球下落，点头踩线接住计分
- GA09 [turn-dodge](turn-dodge/) — 障碍在左向右躲，10 回合回正计分
- GA10 [follow-dot](follow-dot/) — 光点跳到哪就跟到哪，停稳算中
- GA11 [rhythm-nod](rhythm-nod/) — 16 拍固定节拍，拍点点头打中计分
- GA12 [memory-seq](memory-seq/) — 语音报出方向序列，记住并依次复现
- GA13 [find-target](find-target/) — 语音报方向，转过去停稳算找到
- GA14 [level-keep](level-keep/) — 头端平保持水平，歪了小球偏，满10秒胜
- GA15 [slow-scan](slow-scan/) — 从左到右慢速扫一遍，太快语音纠偏
- GA16 [nod-quiz](nod-quiz/) — 是非题点头答是，侧转停稳答否计分
- GA17 [breathe-turn](breathe-turn/) — 吸气慢慢转头，呼气慢慢回正，左右各3次
- GA18 [guess-direction](guess-direction/) — 猜保密方向，语音报近了远了，转到算中
- GA19 [traffic-light](traffic-light/) — 绿灯转向报出的方向，红灯稳住不动
- GA20 [daily-routine](daily-routine/) — 点头转头贴耳仰低收下巴，一套2分钟走完
- GA21 [angle-match](angle-match/) — 报一边一个角度，转进±5度带停稳算对上
- GA22 [tilt-match](tilt-match/) — 贴耳对小角度，进±5度带停稳算对上
- GA23 [pace-turn](pace-turn/) — 单次转头用时3到5秒算匀速，快慢都不算
- GA41 [snap-hunt](snap-hunt/) — 屏幕出目标物，在真实环境里找到拍照，大模型判有没有
完整清单见 [仓库根 README](../README.md) 文末的 Agent 清单。
