头部动作小游戏系列 GA10，B 组（头当控制器）的追光点游戏，极简设计：一页、三态（准备 / 进行 / 完成），语音指导追 10 个光点。先坐稳 / 站稳，点一下开始：先校准两次（低一下头、向左转一下，记下上下左右），然后一次只出现一个光点——光点在左就向左转，在右就向右转，在上就抬头，在下就低头，慢慢转头跟上、停 0.8 秒算跟到，点消失，再回正到中间，下一个点才出现。屏幕上只有光点位置（大圆点在上 / 下 / 左 / 右四格之一）、跟到数 x / 10 和一行提示；你的转头本身就是游戏动作，由方向传感器对照开局那一刻的头向判定。

与 GA05 的区别：GA05 跟的是语音报的时钟点位，本游戏跟的是屏幕上的视觉光点——点的位置就是指令，语音只报出点的位置。

光点固定顺序（不是随机，预览与真机行为可复现）：左、上、左、下、右、上、下、右、左、上；该顺序不含任何顺时针相邻步骤（无上→右、右→下、下→左、左→上），故不可能出现顺时针连转。注：任务简报的示例顺序（左、上、右、下、左、下、右、上、下、左）本身含有顺时针三连（上→右→下、右→下→左），故未照搬，改用上面这条 honoring「不顺时针」规则的顺序。

## 系列宪法：颈部安全（GO 的规则）

**转圈是错误的。** 只做分段动作：正中 → 向一个位置转 → 停住 → 回正到中间 → 下一个点。光点从不连续移动、从不画圈：它在 4 个位置之间离散跳动，跟到就消失，下一个点只在回正后才出现。绝不从一边直接扫到另一边，绝不快速甩动。慢、小幅度、到微酸即止；上点只到轻微拉伸，绝不用力往后仰、绝不向后甩头。出现痛、晕、麻、恶心，立刻停。一局很短：10 个点，可重玩。本游戏是日常活动娱乐，**不是医疗诊断、治疗或康复处方**；有颈椎病、眩晕、术后、头颈伤史的人请先问医生。短版印在游戏内的准备屏上；完整版见 AGENTS.md。

## 玩法

1. **准备**：坐稳 / 站稳，头摆正，读一遍安全提示，点「开始」。
2. **校准（进行中，前置两步）**：屏幕先显示「请低一下头」，慢慢低头一次——游戏记下你真实的向下方向（上即反方向）；「回正到中间」后显示「请向左转一下」，慢慢向左转一次——游戏记下你真实的向左方向（右即反方向）。这样宿主上下、左右符号即使反了也不会算反。重开一局会重新校准两次。校准完成前什么都不计分。
3. **追点（进行中，每个点）**：语音报「光点在左」（或上 / 下 / 右），屏幕大圆点出现在对应位置。慢慢转头跟上，超过约 27 度并停住 0.8 秒，语音说「跟到了」，跟到数 +1，点消失。
4. **跟错 / 没跟到**：向着错误位置转过阈值，语音说「不是这个方向」，本点 0 分，点消失；4 秒内没转到正确位置，语音说「没跟到」，本点 0 分。跟到一半没停够就缩回来，不算分，4 秒时钟继续走。
5. **回正**：每个点结束后必须回正到中间（上下、左右均 <10 度），下一个点才出现；4 秒内没回正，语音提醒「请回正」，宽限计时重置——宽限本身不计分，下一个点也绝不提前出现（与 GA09 的宽限到期照常宣布不同，这是本游戏分段规则的硬性要求）。最后一个点结束即直接出完成屏（没有下一个点可等）。
6. **完成**：屏幕显示「跟到 x / 10」，点「再来一局」重新校准、重新开始。进行中点一下（真机）是重读当前指令。

## 技术诚实说明

- **无眼动追踪**：平台没有眼动 API；头部方向只来自 `AbsoluteOrientationSensor`。
- **头部手势事件官方文档只写了 `'nod'`**：本游戏不声称任何手势事件，也不装点头事件处理；点位判定全部来自传感器四元数。
- **俯仰与偏航公式（代码原样，GA05 同款）**：俯仰 `pitch = asin(2*(w*x - y*z))`（钳制后转度），偏航 `yaw = atan2(2*(w*z + x*y), 1 - 2*(y*y + z*z))`，单位度；只用相对校准中心的差值，宿主的绝对零点不影响判定。
- **上下、左右符号都是学来的，不是假设的**：开局两次校准（请低一下头、请向左转一下）分别记下玩家真实向下、向左的符号，宿主符号反了也不会把上下、左右算反；残留前提是玩家按提示动作——做反了会学反，重开即重新校准；两次校准完成前什么都不计分。
- **阈值**：点位约 27 度（25–30 度档）；回正 <10 度且须上下、左右双轴同时满足；停稳约 0.8 秒（宿主上报稳定性事件时以稳定为准，不上报时以计时为准，已如实说明的回退，不是假装稳定）；一点 4 秒无正确位置即判没跟到；回正宽限 4 秒（到期语音提醒请回正并重置计时，不计分、不提前出下一个点）；校准卡住 8 秒重提示一次，绝不自动计分。
- **点位顺序固定**：左、上、左、下、右、上、下、右、左、上，不是随机；不含任何顺时针相邻步骤。
- **传感器缺失 = SKIP / 演示，绝不假装通过**：网页预览没有方向传感器，屏幕明示 SKIP，演示按钮只走标注的演示点（先演示两次校准，再每点跟到一次，回正折叠），完成屏写「演示跟到 x / 10」；真机有传感器时没有演示路径。
- **零持久化**：不调任何存储 API；跟到数、点序、中心与上下左右符号只活在页面内存里。

## 权限

无。`permissions` 为空数组：传感器与 TTS 不在仅有的三项权限（`GEOLOCATION`、`CAMERA`、`RECORD_AUDIO`）之中，代码也不用这三项对应的任何功能，故一项不声明。空权限打包已验证通过。

## 提审资料 (Review Submission)

### Feature Description

> Follow-the-dot game for Rokid glasses, voice-guided. Ten fixed dots, one at a time: a visual dot jumps discretely between up, down, left and right — it never moves continuously and never traces a circle. Turn to the dot and hold 0.8 seconds for a hit, then return to center before the next dot appears. A wrong-direction turn is a miss; no correct turn within 4 seconds is a miss. Slow, small range, never jerk; stop at any pain. Entertainment only, not medical advice.

### Opening Message

> ## 追光点
>
> 坐稳，点一下开始：先校准两次（低一下头、向左转一下），然后一次只出现一个光点——**光点在左就向左转，在右就向右转，在上就抬头，在下就低头**。慢慢转头跟上，停 0.8 秒算跟到，点消失，再回正到中间，下一个点才出现。转错方向是没跟对，4 秒没跟上是没跟到。10 个点固定顺序，不是随机。光点从不连续移动、从不画圈，慢、小幅度、不甩头，痛、晕、麻、恶心立刻停。本游戏是日常活动娱乐，不是医疗建议。
