## 系列宪法：颈部安全（GO 的规则）

**转圈是错误的。** 本游戏只做一次从左到右的慢扫，绝不转圈，绝不来回扫，绝不快速甩动。慢的本身就是目的：快扫不计数。慢、小幅度、到微酸即止，不到疼痛。出现痛、晕、麻、恶心，立刻停。先坐稳 / 站稳。一局就是一次慢扫，可重玩，很短。本游戏是日常活动娱乐，**不是医疗诊断、治疗或康复处方**；有颈椎病、眩晕、术后、头颈伤史的人请先问医生。短版印在游戏内的准备屏上；完整版见 AGENTS.md。

## 玩法

1. **准备**：坐稳 / 站稳，头摆正，读一遍安全提示，点「开始」。
2. **校准（仅一句提示）**：按提示慢慢向左转一下，Agent 记住哪边是左；再慢慢回正到中间。校准期间不计数。
3. **到最左**：按提示「先转到最左，停一下」——向左转过约 27°，停住约 0.8 秒；没停够就缩回不开始慢扫。
4. **慢扫**：从最左出发，慢慢向右转，屏幕进度条从左向右走，提示只有一句「慢，再慢一点」。必须同时满足两条才算数：(a) 从离开最左到抵达最右至少 8 秒；(b) 途中经过中心（偏航角 10° 以内）。不到 8 秒就到最右，语音「太快了，回到最左，重新慢扫」，不计数、重回最左；中途又转回最左（反向了），同样回到最左重扫；中途某一下转得过快（瞬时速度超约 45°/秒），只警告一次「慢一点」，不直接判失败——判失败只看 8 秒这条规则。
5. **完成**：到最右立刻停——不要继续转成圈。完成屏报出慢扫总秒数（「慢扫完成，用了 9.6 秒」），点「再来一局」重新校准中心与左右、再扫一次。完成之后再怎么转头都不再影响结果。

## 技术诚实说明

- **无眼动追踪**：平台没有眼动 API；头部方向只来自 `AbsoluteOrientationSensor`。
- **头部手势事件官方文档只写了 `'nod'`**：不声称转头、摇头、倾斜等手势事件；左右判定全部来自传感器四元数。
- **阈值**：左右极限约 25–30°（代码取 27°），中心带 <10°，最左停留约 0.8 秒（提前缩回 22° 以下则中止、不开始慢扫），慢扫时钟从离开最左（降到 22° 以下）起算，最少 8 秒（≥8000 毫秒才算），瞬时速度警告阈值约 45°/秒（每局慢扫最多警告一次、不判失败），反向定义为慢扫中又回到 27° 以上左极限；偏航角公式为标准四元数转偏航角（`atan2(2*(w*z + x*y), 1 − 2*(y*y + z*z))`，只用相对校准中心的差值）。
- **左右方向符号是学习的，不是假设的**：开局一句「请向左转一下」，玩家实际转过去的方向即被记为左，因此宿主偏航角符号即使反了也不会把左算成右。剩余注意事项：校准默认玩家按提示真的向左转——若反向转，符号会学反；但校准期间不计数，且任何重开都会重新校准。真机验收必须确认：校准提示出现、真向左转能完成校准、之后真向左转计为左而非右、故意快扫（<8 秒）被拒绝重扫、故意慢扫（>8 秒且过中心）完成并报秒数。
- **传感器缺失 = SKIP / 演示，绝不假装通过**：网页预览没有方向传感器，屏幕明示 SKIP，演示按钮只走标注的演示路径（校准两步 + 到最左 + 每点一次走三分之一慢扫，固定标注 9.6 秒完成），完成屏写「演示慢扫完成」；真机有传感器时没有演示路径。
- **零持久化**：不调任何存储 API；中心、学到的左右符号、慢扫时间与警告标志只活在页面内存里。

## 提审资料 (Review Submission)

### Feature Description

> One slow head scan for Rokid glasses, voice-guided. Sit or stand steady, tap start: one calibration prompt asks you to turn left once so the agent learns which way is left, then turn to the left limit, hold briefly, and scan slowly to the right limit. The scan counts only if it takes at least 8 seconds and passes through center; too fast, and it restarts. A single fast moment only earns one slow-down warning. Never a circle, never back and forth. Entertainment only, not medical advice.

### Opening Message

> ## 慢速扫描
>
> 坐稳，头摆正，点一下开始：我先请你向左转一下，记住哪边是左，然后请你**先转到最左，停一下，再慢慢向右扫到最右**。整个慢扫至少 8 秒才算数——越慢越好，快了不算，重新慢扫。
>
> 到了最右就停，不要继续转成圈。痛、晕、麻、恶心，立刻停下来。本游戏是日常活动娱乐，不是医疗建议。
