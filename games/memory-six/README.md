头部动作小游戏系列 GA26，Wave 2 的 F 组（记忆与节奏进阶），极简设计：一页、三态（准备 / 进行 / 完成），语音报六个方向的顺序，照顺序做出来计分。一局 3 轮：先坐稳 / 站稳，点一下开始：先校准三个方向（向左转一下、低一下头、向左贴一下耳，各记下真实方向），然后第 1 轮语音报 3 个方向（屏幕不显示方向，只显示「听…」，必须靠记）——报完轮到你，照顺序一步一步做：每步做到所报方向（转 / 上 / 下 ≥25 度，贴耳 ≥15 度），语音说「对」，再回正到中间，下一步才做。做错方向（做到别的方向）语音说「顺序错了」，本轮 0 分；一步 10 秒没做对，本轮 0 分。第 2 轮 4 步、第 3 轮 5 步，一轮比一轮长。屏幕上只有轮次、记住数 x / 3 和一行提示；你的头部动作本身就是游戏动作，由方向传感器对照开局那一刻的头向判定。

与 GA12（方向记忆）的区别：GA12 只有左 / 右 / 上 / 下四个方向、3–4 步；本游戏加到**六个方向**（多了左贴耳、右贴耳），轮次加到 3 / 4 / 5 步，记忆负担实实在在更大，而且复现时必须把贴耳和转头分开——转头不能冒充贴耳。与 GA22（贴耳对角度）的区别：GA22 判的是贴耳角度精度（对小目标角）；本游戏贴耳只是记住的顺序里的一个元素，只判方向、不判角度精度。与 GA33（路径跟随，计划中）的区别：GA33 是屏幕给出路径照做练执行；本游戏顺序只靠语音报、必须记住。

轮次固定顺序（不是随机，预览与真机行为可复现）：第 1 轮（3 步）左、上、右贴耳；第 2 轮（4 步）下、左贴耳、右、上；第 3 轮（5 步）右贴耳、左、下、左贴耳、右；每步之间都必须回正到中间，故不可能出现转圈。

## 系列宪法：颈部安全（GO 的规则）

**转圈是错误的。** 只做分段动作：正中 → 一个方向 → 回正 → 下一个方向。每次只做一个方向，做完回正，下一步才做。绝不从一边直接扫到另一边，绝不快速甩动。慢、小幅度、到微酸即止。出现痛、晕、麻、恶心，立刻停。一局很短：3 轮，可重玩。本游戏是日常活动娱乐，**不是医疗诊断、治疗或康复处方**；有颈椎病、眩晕、术后、头颈伤史的人请先问医生。短版印在游戏内的准备屏上；完整版见 AGENTS.md。

## 玩法

1. **准备**：坐稳 / 站稳，头摆正，读一遍安全提示，点「开始」。
2. **校准（进行中，前置三步）**：屏幕依次显示「请向左转一下」「请低一下头」「请向左贴一下耳」，每步慢慢做一次、回正后下一步——游戏记下你真实的三个方向（右、上、右贴耳即反方向）。这样宿主符号即使反了也不会算反。重开一局会重新校准三个方向。校准完成前什么都不计分。
3. **听顺序（进行中，每一轮）**：语音一秒多报一个方向，屏幕只显示「听…」和轮次，不显示方向名——必须靠记。
4. **照顺序做（进行中，每一步）**：做到所报方向（转 / 上 / 下 ≥25 度，贴耳 ≥15 度），语音说「对」，再回正到中间（上下、左右、侧屈均 <10 度），下一步才做；4 秒内没回正，语音提醒「请回正」，宽限计时重置——宽限本身不计分，下一步也绝不提前开始。
5. **做错 / 超时**：做到别的方向，语音说「顺序错了」，本轮 0 分；一步 10 秒没做对，本轮 0 分。错了一轮不结束游戏，下一轮照常进行；每轮结束后必须回正到中间，下一轮才报。
6. **完成**：屏幕显示「记住 x / 3」，点「再来一局」重新校准、重新开始。进行中点一下（真机）是重读当前指令。

## 技术诚实说明

- **无眼动追踪**：平台没有眼动 API；头部方向只来自 `AbsoluteOrientationSensor`。
- **头部手势事件官方文档只写了 `'nod'`**：本游戏不声称任何手势事件，也不装点头事件处理；方向判定全部来自传感器四元数。
- **偏航、俯仰与侧屈公式（代码原样）**：偏航 `yaw = atan2(2*(w*z + x*y), 1 - 2*(y*y + z*z))`（GA02 同款）；俯仰 `pitch = asin(2*(w*x - y*z))`（钳制后转度，GA01 / GA04 同款）；侧屈 `roll = atan2(2*(w*x + y*z), 1 - 2*(x*x + y*y))`（单位度）。一步只判它自己的轴（贴耳只判侧屈，转头只判偏航），转头冒充不了贴耳。只用相对校准中心的差值，宿主的绝对零点不影响判定。
- **三个符号是学来的，不是假设的**：开局三次校准（向左转、低头、向左贴耳）记下玩家真实的三个方向符号，宿主符号反了也不会把方向算反；残留前提是玩家按提示动作——做反了会学反，重开即重新校准；校准完成前什么都不计分。
- **阈值**：转 / 上 / 下做到 ≥25 度；贴耳做到 ≥15 度；步回正与轮回正均 <10 度且须三轴同时满足；一步 10 秒没做对即判本轮没记住；报序节奏为每 1.2 秒一个；回正宽限 4 秒（到期语音提醒请回正并重置计时，不计分、不提前开始下一步）；校准卡住 8 秒重提示一次，绝不自动计分。
- **轮次固定**：第 1 轮左、上、右贴耳；第 2 轮下、左贴耳、右、上；第 3 轮右贴耳、左、下、左贴耳、右，不是随机。
- **传感器缺失 = SKIP / 演示，绝不假装通过**：网页预览没有方向传感器，屏幕明示 SKIP，演示按钮只走标注的演示路径（先演示三步校准，报序跳过，再每步做对一次，回正折叠），完成屏写「演示记住 x / 3」；真机有传感器时没有演示路径。
- **零持久化**：不调任何存储 API；记住数、轮次、步序、中心与三个符号只活在页面内存里。

### Feature Description

> Six-direction memory game for Rokid glasses, voice-guided. Three rounds listen to sequences over left, right, up, down, left tilt and right tilt (3, then 4, then 5 steps) and reproduce them step by step, returning to center between steps. A wrong direction or 10 seconds without the right step fails the round. Slow, small range, never jerk; stop at any pain. Entertainment only, not medical advice.
