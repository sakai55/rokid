# 太极游戏 - Agent Notes

GA96. 中国在地 × 游戏 × 指向性（转头选招式）。

## Design contract

中国家庭太极时间，孩子与家人用眼镜玩 10 轮太极招式比拼，转头选招式、点头开练。

## Counts

太极招式 8 式：起势、野马分鬃、白鹤亮翅、搂膝拗步、手挥琵琶、倒卷肱、云手、金鸡独立。10 轮固定目标序列 [3, 0, 6, 2, 7, 4, 1, 5, 3, 0] 写在代码里。

## Storage

存储键 `chinaTaijiGameV1`（最佳成绩、已结算记录、lastError）。

## Gesture map

| 单指点按 | Enter | 主确认 |
| 上滑／下滑 | ArrowUp / ArrowDown | 切换选项 |
| 点头 | onHeadGesture('nod') | 等同主确认 |
| 双击 | Backspace | 返回上一页 |

## Honest boundaries

- 分数只来自真实点头与点按，不虚构分数。
- 招式判定为演示判定、非物理识别：点头开练只比对选定招式与目标招式，不检测真实太极动作。
- 分段动作：一次转头只换一个招式，须回中再换，绝不转圈。
- 目标序列固定写在代码里，不声称随机抽取。
- 无传感器时按钮切招式可玩，计分规则不变。

## Validation

- 中文纯度：假名与韩文字符数为 0（静态机检）。
- 禁用名单 grep：0 命中。
- 独占接线：pages/play/index.ink _startSensor＋_onYaw（回正武装）＋点头开练。
- 10 轮固定序列 [3, 0, 6, 2, 7, 4, 1, 5, 3, 0] 写在代码里，与 GA93/GA83/GA87/GA94（哈卡 [3, 6, 1, 7, 0, 4, 2, 5, 3, 6]）均不同，结算按真实命中数。
