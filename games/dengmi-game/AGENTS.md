# 元宵灯谜 — Agent Notes

GA52。中国在地 × 游戏 × 指向性（头部方向）。

## Design contract

一句话场景：元宵节家庭聚会，家人只用头部方向选灯谜答案。

## Counts

内容集：自撰原创灯谜 12 条（每条含谜面＋4 选项＋答案解析一句，答案位置分散）；流程：开始→出谜→头向选答案→正误计分→12 谜结算→记录。跨会话持久化键 `dengmiGameV1`（每局结算记录数组 `records`、lastError）。

## Storage

存储键 `dengmiGameV1`。

## Gesture map

| 手势（镜腿触控板） | 按键事件 | 本台作用 |
|---|---|---|
| 单击 | Enter | 主确认（开始 / 确认答案 / 回首页） |
| 上滑 / 下滑 | ArrowUp / ArrowDown | 换选项（头部方向的按键兜底） |
| 点头（头部静止时） | `onHeadGesture('nod')` | 等同主确认 |
| 双击 | Backspace | 返回上一页 |

## 头部方向规则

- 4 选项靠分段头动选择：从正中向左/右转一次只换一个选项，转回正中后才能再换一步，绝不转圈。
- 传感器缺失或报错时走按键兜底，并报裸错误码 E7001。
