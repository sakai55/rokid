# glasses-benchmark

Rokid 眼镜全功能基准测试智能体（AIUI Agent）。

## 身份

一个运行在 Rokid 眼镜上的硬件/运行时自检工具。界面只有一个按钮：
打开后单击镜腿即开始，按官方能力档案的顺序逐项测试，每测完一项
语音播报结果（通过 / 失败 / 跳过），全部跑完后汇总；结果不滚动，
用镜腿滑动翻页查看（每页 4 项，共 6 页）。失败项可点头选中、单击单独重测。

## 能力（测试项）

- 设备信息：navigator 身份、语言、地区、Ink/Skia 版本
- 显示：视口尺寸、渲染开关、连续重绘耗时
- 算力：JS 数学循环吞吐
- 加密：Web Crypto 随机数 + SHA-256
- 存储：localStorage + wx 同步存储读写
- 网络信息：在线状态、连接类型/质量
- 网络请求：HTTPS fetch 往返耗时
- Canvas 2D：渐变、图形、文字绘制 + flush
- 音频：Web Audio 振荡器发声（扬声器链路）
- 麦克风：设备枚举 + 四种官方麦克风模式逐个探测（wearer / far-field / near-field / omnidirectional，不支持的模式记为不支持而非失败）+ wearer 模式 0.9 秒录音
- 相机：取流 + ImageCapture 三种官方模式各拍一张（wide 扫码 / telephoto 远读 / default），解码报告实际像素（失败时回退 wx CameraContext，该路径无模式参数）
- 传感器：加速度计、陀螺仪、绝对方向
- 定位：navigator.geolocation 单次定位
- 蓝牙：BLE 可用性 + 已配对设备
- 电池：BatteryManager 电量/充电状态（主机不支持时 SKIP）
- 语音合成 TTS：synthesize 生成；且每项测试结果都经 speak 语音播报（播报本身即扬声器可听确认）
- 语音识别 ASR：能力查询（SpeechRecognitionSession 能力 + 构造器存在性）
- 大模型：LanguageModel 可用性 + 一次短推理耗时
- 条码：BarcodeDetector 支持格式
- 交互（引导式）：语音+屏幕提示佩戴者依次做 6 个动作——左转头、右转头、抬头、低头、点头、单击镜腿——用方向传感器（相对起始姿态判方向，左右/上下必须反向）、头部手势事件、按键事件逐个验证，完成数如实记录
- 平台边界（恒为 SKIP，永不 PASS）：眼动追踪——平台无此 API，「凝视」=头部朝向（绝对方向传感器）+头稳+点头；OCR——平台无 OCR API，读文字的官方路径是 telephoto 拍照 + LLM 图片输入

## 操作（镜腿手势优先）

- 界面只有一个按钮「开始测试」。单击镜腿（Enter / GlobalHook）= 开始测试；跑完后单击 = 全部重新测试。运行中单击无动作；跑完 2 秒内的单击会被忽略（防镜腿单击重复投递导致刚跑完又重开）。
- 点头 = 选择下一个失败项（仅在未运行时；引导交互测试内的点头仍是第 5 个动作）。点头不启动测试——跑完后的点头曾导致整轮自动重开（v2.0.0 缺陷，v2.0.1 已修）。
- 失败项重测：跑完后点头在失败项之间循环选中（页面自动跟随、高亮显示、语音播报选中项），单击单独重测该项；通过后选择自动清除，仍失败则保留选择可再重测。
- 滑动（ArrowUp / ArrowDown）= 翻页查看结果（每页 4 项，共 6 页；运行中结果页自动跟随最新完成项，也可随时手动翻页；滑动会清除当前选择）。
- 双击（Backspace）= 交给系统（返回/退出），页面不拦截。
- 每测完一项语音播报一次结果；全部完成播报汇总（通过/失败/跳过计数）。
- 屏幕按钮同时保留 bindtap，供 Studio 模拟器/预览里用鼠标点击。

## 行为边界

- 只做本机自检，不上传任何数据；唯一的网络请求是取 example.com 首页测延迟。
- 麦克风/相机/定位在用户点击运行时才启动，用完立即释放轨道与传感器。
- 权限被拒或硬件不支持时记为 FAIL/SKIP 并写明原因，不崩溃、不假装通过。
