# name-call

Rokid 眼镜喊名提醒智能体（AIUI Agent）。

## 身份

一个运行在 Rokid 眼镜上的「有人喊你名字」守望助手，解决在嘈杂的
办公室、车间或家庭聚会里，有人隔着房间喊你名字你却没听见的
问题 — 尤其当你戴着耳机或听力不佳时。手机不能替你听名字，
眼镜整天戴在你头上，可以：它一轮一轮地听房间里的说话声，
一旦识别结果里出现你的名字，就在你眼前亮起大字并出声提醒。

## 能力

- 目标名字（NAME / SET）：NAME 在预设名字间轮换（五郎 /
  小明 / 小红 / 老王）；SET 让你自己说一次名字 — 用一次
  `SpeechRecognition` 近讲录下你说的词，原样设为目标
  （界面如实显示听到的字符串，听错了你看得见、可以重说，
  Agent 绝不偷偷「纠正」）。目标名字存入 wx 同步存储
  （key `nameCallTarget`），下次打开自动载入。
- 守望（WATCH）：先按文档方式用 `getUserMedia({audio:
  {captureSource:'microphone', microphoneMode:'far-field'}})`
  做一次远场模式可用性检查（读回 `track.getSettings()`，
  检查完立即停轨道 — 远场模式让 4 麦阵列去收房间那头
  的声音，而不是佩戴者自己）；然后以基准 Agent 的
  `SpeechRecognition` 模式（zh-CN）一轮接一轮地识别：
  每轮把听到的整句短暂显示为「heard: …」，界面显示当前
  轮次（round n）。`SpeechRecognition` 不可用时如实
  FAIL / SKIP，绝不假装在听。
- 匹配与报警：每轮识别文本做**子串匹配** — 含有目标
  名字即触发：眼前亮起大字「有人喊你: <整句原文>」，
  TTS 朗读「有人喊你」，报警时间与命中的整句记入日志
  （wx 存储 `nameCallLog`，含日期/时间/整句/是否 DEMO，
  最多 20 条）。没命中的轮次文本不保存，闪过即弃。
- 轮次间错误：no-speech（这轮没人说话）是常态，安静计数
  不反复报错；not-allowed / service-not-allowed /
  audio-capture 这类持续性错误会停掉守望并把原因写在
  界面上；连续 5 轮出错同样停机说明，不无限空转。
  STOP 立即结束循环并 abort 当前识别器；页面隐藏/卸载
  同样处理。
- DEMO：不用麦克风不用识别器，按节奏喂两轮合成文本 —
  第 1 轮「今天中午吃什么」（不命中，只更新 heard 行），
  第 2 轮「<你的名字>，你的快递到了」（命中）— 走的是
  与真实识别**同一套** `_handleTranscript` 匹配路径，
  报警点火，日志条目标注 DEMO。

## 行为边界

- **这是 ASR 关键词守望，不是声纹识别**：它比对的是识别
  出来的文字里有没有你的名字，与谁在说话无关 — 任何人
  的声音都可能触发，电视里的人喊出同名也会触发；发音
  相近的词可能误触发；在真实噪声里它**一定会漏喊**
  （喊了没识别出来、识别错字都会漏）。它提高你听见的
  概率，不做任何保证。界面常驻一行「ASR keyword watch -
  NOT voiceprint; may miss / false-fire」，README 同样
  如实写明。
- **守望时麦克风在听整个房间**：只有你点 WATCH 才开始、
  点 STOP（或页面隐藏/卸载）就停。本 Agent 不录音、
  不上传音频；未命中的轮次文本不落盘，只有命中的那句
  连同时间存进本机日志（为的是你回头能看「几点、喊的
  是什么」），CLEAR LOG 一键清空。
- 远场 ASR 的错误率在真机上未验证：距离、混响、多人
  同时说话都会让它错得更多 — 这也是为什么 SET 录进来
  的名字要原样显示给你确认：目标一旦听错，守望就守
  错了人。
- 戴着耳机或听力不佳时 TTS 提醒可能听不清 — 可靠的
  报警通道是眼前的高亮大字，语音只是第二通道。
- 声明权限只有 RECORD_AUDIO。
