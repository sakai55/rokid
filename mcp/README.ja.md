# mcp/ — Rokid プロジェクトの MCP レジストリ

[中文](README.md) | [English](README.en.md) | 日本語
本書は中文版（2026-10-29 時点）に準拠する。解釈に相違がある場合は中文版を正とする。

このディレクトリは、Model Context Protocol（MCP）サーバーの登録簿である。本プロジェクトで実際に使っている MCP について、用途と接続方法をここに集約する。MCP を追加したら、その都度ここへ登録すること。各マシンのローカル設定に情報が散らばるのを防ぐのが目的である。

## 使用中

| MCP | 用途 | 接続方法 | 状態 |
|---|---|---|---|
| GitHub 公式 MCP Server | リポジトリの読み書き（ファイル、ブランチ、コミットの照会） | GitHub コネクタ（OAuth、アカウント `sakai55`） | 使用中（読み取り専用クエリとテキストファイル操作に使用） |

> 補足: 日常の GitHub 操作（バイナリの .aix や PNG の扱い、ブランチの整理を含む）は、端末の **`gh` / `git`** を正とする（sakai55 でログイン済み。詳細はルート README の「メンテナンス規約」を参照）。GitHub MCP はコネクタの機能として残すが、用途は手早い読み取り専用クエリが中心になる。どちらの手段でも操作先は同じリポジトリ `sakai55/rokid` なので、コミット時にどちらの経由かを取り違えないよう注意すること。

## MCP を追加するとき

1. このディレクトリに `<name>/` というサブディレクトリを作り、その MCP の `README.md` を置く。README には、サーバーの提供元（公式リポジトリやパッケージ名）、起動方法、必要な認証情報の**保管場所**、公開されるツールの一覧と代表的な使い方を書く。保管場所は Secure Vault や環境変数名といった場所の指定だけを書き、**認証情報の値そのものは絶対に書かない**。
2. 上の表に 1 行追加して登録する。
3. 認証情報の入力が必要な場合は Secure Vault の安全な入力フローを使い、チャットやリポジトリに値を残さない。
