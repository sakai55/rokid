# mcp/ — Rokid プロジェクトの MCP 登録所

[中文](README.md) | [English](README.en.md) | 日本語
中文版（2026-10-29 時点）からの翻訳。齟齬がある場合は中文版が優先する。

Model Context Protocol サーバーとその接続方法を登録するディレクトリ。本プロジェクトで実際に使っている MCP、その用途、接続方法をここに記す。新しいものを 1 つ追加するごとに 1 件登録し、各マシンのローカル設定に散らばらないようにする。

## 使用中

| MCP | 用途 | 接続方法 | 状態 |
|---|---|---|---|
| GitHub 公式 MCP Server | リポジトリの読み書き（ファイル、ブランチ、コミットの照会） | GitHub コネクタ（OAuth、アカウント `sakai55`） | 使用中（読み取り専用の照会とテキストファイルの場面） |

> 説明：日常の GitHub 操作（バイナリの .aix / PNG、ブランチの整理などを含む）は、現在は**端末の `gh` / `git`** を基準とする（sakai55 でログイン済み。ルート README の「メンテナンス規約」を参照）。GitHub MCP はコネクタの能力として残し、速い読み取り専用の照会に適している。両者は同じリポジトリ `sakai55/rokid` を操作するので、コミットの出典を取り違えなければよい。

## MCP を 1 つ追加する時

1. 本ディレクトリに `<name>/` サブディレクトリを作り、その MCP の `README.md` を置く：サーバーの出典（公式リポジトリ / パッケージ名）、起動方法、必要な認証情報の**保管場所**（Secure Vault / 環境変数名など、保管場所だけを書き、**認証情報の値そのものは決して書かない**）、公開されるツールの一覧と代表的な使い方を明記する。
2. 上の表に 1 行登録する。
3. 認証情報を入力する必要がある場合は、Secure Vault の安全な入力手順を使い、チャットにもリポジトリにも入れない。
