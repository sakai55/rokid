# 並行型 DUAL（dual/）

[中文](README.md) | [English](README.en.md) | 日本語
中国語版（2026-10-29 時点）の翻訳。

注意力アドオンシリーズ。DU01–DU05、全5件。本線は自分、脇の見張りはこちら。

- DU01 [play-watch](play-watch/) — 遊び場の脇役として定期的に振り返りを促し、確認がなければ段階的に強める
- DU02 [bag-watch](bag-watch/) — 荷物の脇役として定期的に振り返りを促し、出がけに未確認なら呼び止める
- DU03 [dog-walk](dog-walk/) — 散歩の脇役として、犬が止まったらその場で分類。帰宅時は玄関で項目ごとに確認してから通す
- DU04 [tour-watch](tour-watch/) — ツアーの脇役として集合の呼びかけだけを拾い、時刻が近づくと方角で帰隊を促す
- DU05 [queue-roam](queue-roam/) — 番号札の脇役として呼び出しを聞き張り、あと5番以内になったら戻って待つよう呼ぶ

全リストはルートの [README](../README.md) 末尾にある Agent リストを参照。
