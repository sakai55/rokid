# 並行型 DUAL（dual/）

[中文](README.md) | [English](README.en.md) | 日本語
中文版（2026-10-29 時点）からの翻訳。

注意力アドオンシリーズ · 番号 DU01–DU05、全5件。本線はあなた、副線はこちらが担当。

- DU01 [play-watch](play-watch/) — 遊び場の副線で定時に振り返りを促し、未確認なら段階的にエスカレーション
- DU02 [bag-watch](bag-watch/) — 荷物の副線で定時に振り返りを促し、ドアを出る際の未確認は呼び止める
- DU03 [dog-walk](dog-walk/) — 犬の散歩の副線で犬が止まったらその場で分類し、帰宅時はドアで項目ごとに確認してから入室
- DU04 [tour-watch](tour-watch/) — ツアーの副線では集合の呼びかけだけを拾い、時間が近づくと方角で帰隊を促す
- DU05 [queue-roam](queue-roam/) — 番号取りの副線で呼び出しを聞き守り、5番以内になったら戻って待つよう呼ぶ

全リストは[リポジトリ ルート README](../README.md) 末尾の Agent リストを参照。
