# 并行型 DUAL（dual/）

注意力外挂系列 · 编号 DU01–DU05，共 5 个。主线你做，副线它管。

- DU01 [play-watch](play-watch/) — 游乐场副线定时提醒回看，未确认逐级升级
- DU02 [bag-watch](bag-watch/) — 行李副线定时提醒回看，离开门未确认喊停
- DU03 [dog-walk](dog-walk/) — 遛狗副线狗停当场定性，回家门逐项核对才放行
- DU04 [tour-watch](tour-watch/) — 跟团副线只捞集合句，快到点按朝向提醒归队
- DU05 [queue-roam](queue-roam/) — 取号副线守听叫号，距5号内叫你回去等着

完整清单见 [仓库根 README](../README.md) 文末的 Agent 清单。
