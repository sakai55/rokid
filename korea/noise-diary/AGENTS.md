# Noise Diary — Agent Notes

KR02（korea 本地化系列）。交互哲学：**夜间日记 Night Diary**。UI 形态：时钟弧线：夜间 8 小时弧 + 峰值时刻点，晨起复盘。

## Design contract

本 Agent 只记自己家的账：夜间守候自家近场声响，超过阈值的时刻被钉在一条 22:00→06:00 的弧线上，晨起一次复盘播报——昨晚响了几次、最响在几点。它从不录音、不转写、不指向邻居（只测佩戴者近场，方向如实标注），更不会实时指责你：夜里它沉默记账，早上你才看日记。它与底座字幕/转写的区别是根本性的：它连声音内容是什么都不知道，只知道「几点、家里响了一声」。

## 在地性

층간소음（层间噪音）是韩国公寓生活的头号邻里矛盾，严重到有专门的调解机构与「이웃사이센터」。矛盾的另一面是：很多人并不知道自家孩子跑跳、洗衣机夜洗、椅子拖动在楼下听起来有多响。

## 闭环（与底座能力的分工）

- 守候：夜间 ARM 后只算声压峰值事件（不录存），事件按时刻钉上夜间弧
- 日记：峰值事件保留时刻与相对强度（前 3 件），其余计数
- 复盘：REVIEW 播报昨夜汇总（次数/最响时刻/安静段），点头清空昨夜，关页即忘

底座七项（实时翻译/实时字幕+历史/会议转写+摘要/提词器/慧眼问答/AR导航/语音笔记）均不构成其本体：识别或定位只在闭环中作一步出现且永远标暂定，失败即 SKIP。

## 诚实边界

- 近场声压无法区分声源（自家/楼上/窗外），日记只证明「这一带响过」，归因必须由人结合时刻判断，界面明示
- 声压为相对强度非校准分贝；麦克风不可用时报 SKIP，不伪造日记

## Permissions

`RECORD_AUDIO`。TTS 用宿主固定音色，永不设置 utterance 的 `lang`（官方文档注明不生效）。
