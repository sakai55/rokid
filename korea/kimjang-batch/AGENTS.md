# Kimjang Batch — Agent Notes

KR08（korea 本地化系列）。交互哲学：**批次大数 Batch Counter**。UI 形态：巨号计数面：一屏一个大数字 + 阶段带。

## Design contract

本 Agent 为沾满料的手而设计：屏幕上只有一个 62px 的大数字——当前阶段的棵数。计数靠点头（+1）与语音口令（宿主识别听到「다음」即 +1，识别不可用自动降级并明示），手几乎不用碰任何东西；+10 应对整筐过数，下滑纠错 -1。三段流水线各自计数，段目标达成才放行下一段。它不辨识白菜品质、不提供配方（那是菜谱与慧眼的事），只在你双手最忙的时候，把「数到几了」这件事稳稳接住。

## 在地性

김장（泡菜季腌制）是韩国冬初的家族级工程：几十上百棵白菜，절이기（盐渍）→헹구기（冲洗）→양념 바르기（抹料）三段流水线，手上沾满辣椒面，一数错，盐和料的配比全乱。

## 闭环（与底座能力的分工）

- 大数：一屏一个巨号计数，阶段带显示 절이기/헹구기/양념 当前段与段目标
- 免手：点头 +1、语音「다음」+1（ASR 守护式，失败即明示降级）、+10 整筐、下滑 -1 纠错
- 段进：STAGE 在段目标达成后放行下一段（未达成时拒绝并播报还差几棵）

底座七项（实时翻译/实时字幕+历史/会议转写+摘要/提词器/慧眼问答/AR导航/语音笔记）均不构成其本体：识别或定位只在闭环中作一步出现且永远标暂定，失败即 SKIP。

## 诚实边界

- 语音计数依赖宿主 ASR（韩语口令 다음），环境嘈杂时可能漏计；计数以屏幕大数为准，漏计用 +10/下滑当场修正
- 棵数目标为演示 60 棵；盐料配比不在本 Agent 范围，请按自家配方

## Permissions

`RECORD_AUDIO`。TTS 用宿主固定音色，永不设置 utterance 的 `lang`（官方文档注明不生效）。
