# 김장 단계 - Agent Notes

KR28. 한국 현지 × 배려 설계 × 주의력.

## 설계 약속

겨울에 온 가족이 김장을 담글 때, 양손이 양념으로 바쁜 사람이 고개 끄덕임으로 단계를 넘긴다.

## 내용 집합 수

6개 단계 × 4단계씩, 모두 24단계. 세션 간 저장 키 `kimjangStepsV1`(진행 위치, 완성한 통 수, 완성 기록 배열, lastError).

## 솔직한 경계

소금 농도를 재지 않고 발효 정도를 재지 않는다. 익음은 날짜와 본인 확인으로만 적는다.

## 저장

저장 키 `kimjangStepsV1`.

## 제스처

| 제스처 | 키 | 역할 |
|---|---|---|
| 한 번 누르기 | Enter | 주 동작 |
| 위아래 밀기 | ArrowUp / ArrowDown | 단계 고르기 |
| 고개 끄덕이기 | `onHeadGesture('nod')` | 주 동작과 같음 |
| 두 번 누르기 | Backspace | 이전 페이지로 돌아가기 |
