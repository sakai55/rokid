# 韓国ローカライズ（korea/）

[中文](README.md) | [English](README.en.md) | 日本語
中国語版（2026-10-29 時点）の翻訳。

日韓ローカライズシリーズ。KR01–KR10、全10件。韓国の生活シーンに合わせたローカライズ Agent。

- KR01 [samgyeop-flip](samgyeop-flip/) — サムギョプサルを焼く裏返しのリズム。時間になると裏返すよう呼びかける
- KR02 [noise-diary](noise-diary/) — 自宅の夜の音だけを記録し、朝に再生して自分で確認する
- KR03 [soju-turn](soju-turn/) — ソジュの作法。両手で注ぎ、横を向いて飲む所作を組み立てる
- KR04 [jongnyang-gauge](jongnyang-gauge/) — 従量制ゴミ袋の容量目盛りと、排出量の帳簿
- KR05 [hangang-base](hangang-base/) — 漢江キャンプの合言葉・受け取り番号・ゴミの返却をすべて保持する
- KR06 [deungsan-pace](deungsan-pace/) — 登山の水分補給・休憩・下山のペースを登録する帳簿
- KR07 [noraebang-rotation](noraebang-rotation/) — カラオケの歌い手の順番と曲番号を公平に回すローテーション
- KR08 [kimjang-batch](kimjang-batch/) — キムジャンの時期の白菜の株数とバッチを、大きな文字で数える
- KR09 [jjimjil-rest](jjimjil-rest/) — チムジルバンの温冷サイクルを交互に計るタイマー。効能はうたわない
- KR10 [baedal-code](baedal-code/) — 配達の玄関コードと注文番号を1文字ずつ表示し、使い終われば忘れる

全リストはルートの [README](../README.md) 末尾にある Agent リストを参照。
