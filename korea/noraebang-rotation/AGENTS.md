# Noraebang Rotation — Agent Notes

KR07（korea 本地化系列）。交互哲学：**公平轮值 Fair Rotation**。UI 形态：圆桌轮盘：上一位/当前大字/下一位 + 人名环。

## Design contract

本 Agent 就是那个轮盘：四位歌手的名字排成环，当前唱者大字居中，上一位、下一位半亮待命；每首歌的预约号登记在唱者名下，唱完 DONE 自动轮转。PASS 是明着来的跳过（记「양보」让唱，不算偷唱）。它不听唱功、不打分、不录音（那是底座转写与评分机厂商的事），只守公平这一件事：麦克风该在谁手里。

## 在地性

노래방（练歌房）是韩国聚会的第二场标配，规矩就一条：轮流唱，谁也不能霸麦，谁也不许被落下。实际包厢里总有人连唱三首、有人整晚没摸到麦——缺的不是规矩，是一个不偏心的轮盘。

## 闭环（与底座能力的分工）

- 轮盘：4 人环序常驻，当前唱者满亮大字，前后位半亮
- 点歌：SONG# 为当前唱者轮换登记预约号预设（唱前报号给点歌机）
- 轮转：DONE/点头 = 唱完轮转；PASS = 本轮让唱（环上标 양보，下轮回到队首优先）

底座七项（实时翻译/实时字幕+历史/会议转写+摘要/提词器/慧眼问答/AR导航/语音笔记）均不构成其本体：识别或定位只在闭环中作一步出现且永远标暂定，失败即 SKIP。

## 诚实边界

- 人名为演示四人组；增减人数未做（环序逻辑支持，登记 UI 是后续课题）
- 预约号是主流点歌机的编号目安，实际以包厢机器曲库为准；本 Agent 不联网查曲

## Permissions

none。TTS 用宿主固定音色，永不设置 utterance 的 `lang`（官方文档注明不生效）。
