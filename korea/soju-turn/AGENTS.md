# Soju Turn — Agent Notes

KR03（korea 本地化系列）。交互哲学：**尊重编排 Respect Choreography**。UI 形态：舞台站位图：你与长辈的相对方位 + 中央转头弧线。

## Design contract

本 Agent 编排的正是身体：四段固定舞台（两手接杯→两手斟酒→侧头饮→空杯确认），其中「侧头」一段由头部偏航传感器判定——相对基线转过 35° 再回正才算完成，转头的方向与幅度就是交互本身。长辈不在席时（ELDER 切换）该段自动改为正对饮用，规矩随席面而变。它不录酒桌、不转写祝酒词（底座的事），只守年轻人身体的朝向。

## 在地性

韩国회식（会餐）的烧酒礼仪是身体性的：给长辈倒酒要两手（두 손으로 따르기），自己喝时要侧过头去（고개를 돌려 마시기），空杯才会被续。规矩不在嘴上，在手和头的朝向上——新人最怕的就是身体跟不上规矩。

## 闭环（与底座能力的分工）

- 站位：舞台图常驻「你 ↔ 长辈」相对方位，长辈在席状态可切换
- 编排：四段顺序推进（接杯/斟酒/侧头/空杯），侧头一段以头部偏航 >35° 自动判定（传感器缺失降级为点按）
- 轮回：一段走完回到接杯，轮数计数；空杯状态由 GLASS 手动登记（满/空/待续）

底座七项（实时翻译/实时字幕+历史/会议转写+摘要/提词器/慧眼问答/AR导航/语音笔记）均不构成其本体：识别或定位只在闭环中作一步出现且永远标暂定，失败即 SKIP。

## 诚实边界

- 偏航角为相对基线的头部转动，不是礼仪评分；阈值 35° 为待真机标定值
- 传感器不可用时侧头段降级为本人确认，界面明示；本 Agent 不做饮酒量健康建议，过量请自控
