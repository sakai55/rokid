# 경복궁 사진 확인 - Agent Notes

KR27. 한국 현지 × 방향성 × 주의력.

## 설계 약속

가이드북을 든 경복궁 첫 방문자가 구역을 바라보고 고개를 끄덕여 사진을 찍고, 12곳을 체크한 뒤에만 정산할 수 있습니다. 빠진 곳은 정산 전에 안내합니다.

## 개수

내용 집합: 6개 구역 × 12곳(구역마다 2곳). 정산 기록은 실제 건수로 셉니다.

## 저장

저장 키 `seoulPalacePhotoV1`(선택한 구역, 체크 상태, 사진 촬영 시각과 바이트 수, 정산 기록 배열, lastError). 사진 자체는 세션 메모리에만 두고 저장하지 않습니다.

## 제스처

| 손놀림 | 키 | 이 Agent에서의 역할 |
|---|---|---|
| 한 번 누르기 | Enter | 사진 촬영(사진 확인 페이지의 주 동작) |
| 위아래 밀기 | ArrowUp / ArrowDown | 항목 바꾸기 |
| 고개 끄덕이기 | onHeadGesture nod | 주 동작과 동일: 사진 촬영 |
| 두 번 누르기 | Backspace | 이전 페이지로 돌아가기 |

## 정직한 경계

- 사진은 방문자 본인의 확인용 증거일 뿐입니다. 명소를 자동으로 판별하지 않으며 다른 사람 얼굴을 인식하지 않습니다. 체크는 방문자가 직접 합니다.
- 정산 게이트: 사진이 없으면 정산할 수 없고, 체크가 끝나지 않으면 안내만 하고 정산 기록을 남기지 않습니다.
- 카메라는 시선과 같은 방향을 보므로 구역을 바라보는 것이 사진 방향을 정하고, 고개를 끄덕이면 촬영합니다.

## 검증

- 언어 순도: .ink 파일에 가나와 한자가 0건이며 한글만 사용합니다.
- 금지 목록 검사: 코드 파일에서 0건이며, Blob 변환은 arrayBuffer와 나눈 btoa로만 합니다.
- 사진 연결: pages/check photoTap에서 getUserMedia와 ImageCapture takePhoto를 실행하고, 변환 실패와 촬영 실패, 카메라 수단 부재를 각각 코드로 표시합니다.
