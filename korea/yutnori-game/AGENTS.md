# Yutnori Game — Agent Notes

KR17（韩国在地 × 游戏 × 注意力）。精品线新 Agent：家人春节/中秋聚会时只用头部动作玩 윷놀이。

一句话场景：家人在春节或中秋聚会时，不用手、只用点头与头部动作掷 윷、走棋，先到 20 格者胜，胜负与记录留在端末。

## Design contract

- 总览（index）：棋盘＋骰棒形态——20 格棋盘两行串＋双方棋子位置＋比分，全部读持久化实数。
- 掷棒（throw）：点头或 Enter 掷棒；5 种结果内容集（도 1格／개 2格／걸 3格／윷 4格＋再掷／모 5格＋再掷，每种含步数、说明与棒面显示）；按结果移子，TTS 报结果与步数；先到 20 格结算胜负、记胜场并重置棋盘；ArrowUp/ArrowDown 可逐条浏览 5 种结果说明。
- 记录（record）：胜场（双方）／总掷棒次数／最少掷棒获胜记录，全部跨会话持久化（存储键 `yutnoriV1`）；Enter/点头由 TTS 朗读记录。

方向构成：韩国在地（설날·추석 家族 윷놀이）× 游戏（单机制＋完整玩法闭环：开始／输赢／计分）× 注意力（棋子位置与比分守候、记录保持）。游戏承担玩法闭环一环，注意力承担位置与成绩守候一环。

## 诚实边界

- 掷棒是演示随机数（Math.random 在 5 种结果中选一），不是物理 윷 识别；棒面显示是结果的可视化，不是传感器读数。界面与 README 均明示这一点。
- 棋盘 20 格与结果集是内置内容集，不联网。

## Permissions

none。TTS 用宿主固定音色，永不设置 utterance 的 `lang`。

## Validation

- 语言纯度：.ink 内假名 = 0、CJK 汉字 = 0（静态机检）；静态校验与打包结果见精品线台账；预览截图在仓库 `screenshots/yutnori-game/`。
