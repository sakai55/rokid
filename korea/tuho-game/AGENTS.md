# 투호 게임 — Agent Notes

KR21(한국 현지 × 게임 × 지향성). 가족 모임에서 머리 방향만으로 투호를 던져 10번의 던지기로 최고 점수에 도전합니다.

## Design contract

- 전체 보기(index): 게임 설명 3줄 + 최고 점수(저장된 실수 표시).
- 던지기(play): 위아래로 겨냥 3방향 순환, 거리 버튼 1m/2m/3m 순환(10점/30점/50점), 고개 끄덕임 또는 Enter로 던지기, 한 게임 10번, 던질 때마다 겨냥은 가운데로 복귀, 목표 구역 순서 10가지와 겨냥이 맞으면 거리 점수 획득, 게임 종료 시 최종 점수 저장 및 최고 점수 갱신.
- 기록(record): 최근 게임 6회 + 최고 점수.
- 지향성: 머리 yaw는 감지기가 있을 때만 힌트 표시를 바꾸고, 겨냥 선택은 언제나 버튼으로도 됩니다. 감지기 값을 읽은 척하지 않습니다.

방향 구성: 한국 현지(전통 놀이 투호의 모임 장면) × 게임(10번 던지기 한 판 + 거리별 점수 + 최고 점수) × 지향성(머리 방향 겨냥이 던지기의 핵심 입력). 세 고리가 모여야 한 판이 성립합니다.

## 정직한 경계

- 던지기 판정은 화면 속 시범 점수이고, 실제 화살을 인식하거나 추적하지 않습니다.
- 동작은 한 구간씩 끊어서 하고, 던질 때마다 겨냥은 가운데로 복귀합니다. 빙글빙글 도는 동작은 하지 않습니다.

## Permissions

없음. TTS는 호스트 고정 음색을 사용하고, utterance의 `lang`은 설정하지 않습니다.

## Validation

- 언어 순도: .ink 안의 가나 = 0, CJK 한자 = 0(정적 기계 검사); 정적 검사와 패키징 결과는 부티크 라인 대장에; 미리보기 스크린샷은 저장소 `screenshots/tuho-game/`에.
