# Hangang Base — Agent Notes

KR05（korea 本地化系列）。交互哲学：**营地持有 Basecamp Holder**。UI 形态：俯视野餐垫：垫面四格分别放暗号、号牌、归还与片付け。

## Design contract

本 Agent 是坐在垫子上的那个人：交付点暗号、取餐号、垫子归还时刻、片付け四件套，全钉在垫面四格里。你去浪，它替你坐着记；回来瞥一眼，四格状态尽收眼底。它不导航去交付点（底座导航的事）、不替你点外卖，只持有「营地信息」这一件事——这正是出门玩时最容易被快乐冲散的注意力。

## 在地性

周末的한강공원（汉江公园）有一套成熟玩法：铺돗자리（垫子）占位、点外卖到指定交付点自取、吃完把垫子与垃圾按规矩收走。营地一铺，人就四散——拍照的、放风筝的、去取餐的，最后全靠一个人记着所有琐事。

## 闭环（与底座能力的分工）

- 四格：暗号（交付点コード）/取餐号/垫子归还时刻/片付け进度，垫面格即信息格
- 轮换：CODE 换交付点暗号预设、FOOD# 取餐号 +1、 CLEAN 片付け四件套逐件推进
- 宣告：GO 轮流播报四格现状；归还时刻到点由计时提醒（页面内存计时，明示）

底座七项（实时翻译/实时字幕+历史/会议转写+摘要/提词器/慧眼问答/AR导航/语音笔记）均不构成其本体：识别或定位只在闭环中作一步出现且永远标暂定，失败即 SKIP。

## 诚实边界

- 暗号与号牌为演示预设，实际请在 CODE/FOOD# 登记为当次真实值后使用（登记即显示，关页即忘）
- 归还提醒是本页计时，不是系统闹钟；页面被关闭后不保证触达，重要归还请同时设手机提醒

## Permissions

none。TTS 用宿主固定音色，永不设置 utterance 的 `lang`（官方文档注明不生效）。
