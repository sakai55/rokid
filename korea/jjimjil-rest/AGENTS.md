# Jjimjil Rest — Agent Notes

KR09（korea 本地化系列）。交互哲学：**冷热循环 Thermal Cycle**。UI 形态：双环：热环与休环交替点亮，环心是剩余时间。

## Design contract

本 Agent 只管循环节奏：热段 12 分钟、休段 8 分钟，双环交替，当前环满亮，段终轻声播报一次并自动换段。它把「还要待多久」从意志力问题变成看一眼双环的问题。声明在先：它不做任何疗效承诺（排毒、治病一概不提），不测体温心率（平台没有这能力），只是一个懂汗蒸房规矩的计时环——热段超时未出，它会多提醒一次，仅此而已。

## 在地性

찜질방（汗蒸房）的玩法是循环：高温房里出一身汗，出来在休息厅吃식이（米露）与烤鸡蛋，缓过来再进去。节奏对了是享受，节奏乱了——在热房里待过头——就成了遭罪。

## 闭环（与底座能力的分工）

- 双环：热环（12:00）/休环（08:00）交替，当前环大字倒数，非当前环显示全长
- 切换：段终自动换段 + TTS 一句；SWITCH 可手动跳段，+2MIN 给当前段加时（加时会被如实标注）
- 收口：一轮（热+休）计 1 循环，循环数常驻；全程零健康断言，界面明写「节奏だけ」

底座七项（实时翻译/实时字幕+历史/会议转写+摘要/提词器/慧眼问答/AR导航/语音笔记）均不构成其本体：识别或定位只在闭环中作一步出现且永远标暂定，失败即 SKIP。

## 诚实边界

- 时长为汗蒸房常见节奏目安，个人耐受不同请随时出房；本 Agent 不提供任何医疗或疗效判断
- 计时在页面隐藏时暂停（Ink 生命周期），回页续计，README 明示

## Permissions

none。TTS 用宿主固定音色，永不设置 utterance 的 `lang`（官方文档注明不生效）。
