# 강릉 여행 수첩 - Agent Notes

KR48. 한국 현지 × 집합 총괄 × 주의력. 한국 현지가 강릉이라는 장소를, 집합 총괄이 20가지 여행 도구를 한 권의 수첩으로 묶는 일을, 주의력이 사진 확인과 순서, 퀴즈, 세기로 각 장소를 가려내는 일을 맡는다.

## Design contract

강릉을 여행하는 사람이 한 권의 수첩으로 20가지 여행 도구를 끝까지 돌린다.

## Counts

20가지 여행 도구: 사진 확인 3가지(경포해변／강릉중앙시장／강릉 사진 명소, 네 곳씩 표시)＋순서 5가지(안목해변 커피거리／초당순두부／강릉역 환승／커피박물관／강릉 기념품 목록, 5단계씩)＋퀴즈 5가지(오죽헌／선교장／강릉단오제／강릉 올림픽파크／강릉 날씨 옷차림)＋세기 2가지(대관령 10마리／주문진항 12척)＋방향 맞추기 2가지(경포호／하슬라아트월드, 1회에 6차례)＋방위 안내 1가지(정동진)＋계산 1가지(아르떼뮤지엄 강릉 9＋5)＋강릉 여행 기록 1가지. 도구 이름 4가지는 PLAN의 일반 이름을 다른 허브와 겹쳐 강릉을 붙여 바꾸었다(사진 명소／기념품 목록／날씨 옷차림／여행 기록 → 강릉 사진 명소／강릉 기념품 목록／강릉 날씨 옷차림／강릉 여행 기록). 나머지 16가지는 950개 기존 허브 이름과 겹침 0건이다.

## Storage

저장 키 `gangneungTripHubV1`(고른 도구, 도구별 최고, 끝낸 기록, 정동진역 등록 위치, 사진 기록, lastError).

## Gesture map

| 한 번 누르기 | Enter | 주 확인 |
| 위아래 밀기 | ArrowUp / ArrowDown | 선택 전환 |
| 끄덕임 | onHeadGesture('nod') | 주 확인과 동일 |
| 두 번 누르기 | Backspace | 돌아가기 |

## Honest boundaries

- 점수와 기록은 실제 끄덕임과 누르기, 사진으로만 정하며, 지어낸 기록은 없다.
- 세기 도구의 수는 눈앞에 보이는 것을 직접 세어 넣은 수이며, 카메라가 세는 것이 아니다.
- 사진은 본인 확인에만 쓰며, 찍지 않았거나 네 곳에 표시가 없으면 끝낼 수 없다.
- 방위와 거리는 추정치이며, 등록하지 않았거나 위치를 쓸 수 없을 때는 지어내지 않는다. 정동진역 위치는 사용자가 도착해 직접 등록한 위치이다.
- 강릉단오제는 계절 축제라서 정보만 본다고 적었으며, 지금 열린다고 말하지 않는다.
- 한 번 돌릴 때 한 구역만 바뀌며, 가운데로 돌아오지 않으면 다시 바꿀 수 없고, 빙글빙글 돌지 않는다.
- 센서가 안 될 때는 버튼으로 고른다. 판정은 달라지지 않는다. 센서 실패는 E7001을 남긴다.

## Validation

- 언어 순도: 가나 0, CJK 한자 0(정적 기계 검사).
- 금지 목록 grep: 0건.
- 독점 접선: 사진 페이지 t01／t04／t17의 photoTap＋confirmTap(사진이 없으면 끝낼 수 없다), 방향 페이지 t08／t13의 _startSensor＋_onYaw(가운데로 돌아와 다시 무장), 정동진 페이지 t06의 GPS 방위＋거리(_calc, CARD 8방향), 전 페이지의 끄덕임 주 확인.
- 20곳 장소는 모두 웹 검색으로 확인한 진짜 강릉 장소이다. 커피박물관은 강릉커피박물관(한국 첫 커피박물관)이다.
