# Noise Map（噪音方位图）

**Studio 导入地址**（复制到 Global AIUI Studio 的 Import Project 输入框）：

```
https://github.com/sakai55/rokid/tree/agent-noise-map
```

注意力外挂系列 E03（AMBIENT 环境型，本组第三个，系列第 48 个）。在家/办公室找最安静的角落办公，凭感觉选总是选错。本 Agent 把「选角落」外包出去：你顺时针转头扫一周，每转到一个方向点 SCAN 记一次电平，8 个扇区生成噪音方位图，最安静的朝向出声报一次。

## 解决的问题

安静角落的注意力是凭感觉猜的：坐下来才发现旁边就是说话声、空调声，来回换座位浪费时间。本 Agent 管五件事：扫描（顺时针转头，每方向点 SCAN 记电平）、成图（扫满 8 个扇区生成方位图，各扇区电平分低/中/高三档）、指出（最安静的朝向横幅 + 恰好出声一次）、重扫（RESCAN 再扫一轮）、小结（扫描成图几轮、最安静朝向是哪，确认后清空）。它不识别声音、不测分贝——只负责让你在坐下之前看一眼哪边最安静。

## 注意力外挂设计（AMBIENT 环境型）

- **电平不等于识别**：本 Agent 没有声音分类 API。电平高低只说明响不响，不知道是什么声音——说话声、空调声、施工声分不出来，这一点 UI 与本 README 如实写明。
- **电平是相对分级，不是分贝读数**：平台没有校准过的声压计。RMS 阈值（低 < 0.15、中 < 0.4、高以上）是固定档位，不是分贝值；最安静的朝向是本次扫描内的相对最低，不是绝对安静保证——再吵的房间也有个「最安静」的角落。
- **扇区按顺时针顺序记录，不单独验证每个方向角**：你每右转一个扇区点一次 SCAN，Agent 按固定顺序（前 → 右前 → 右 → 右后 → 后 → 左后 → 左 → 左前）记录；它不验证你的头实际指向哪个方向角，这一点 UI 与本 README 如实写明。
- **最安静的朝向恰好出声一次**：扫满 8 个扇区成图时横幅 + 一次语音（「最安静的朝向是左后方」）；RESCAN 不出声，SPEAK 只在你主动点时重读。
- **点头既不记电平也不成图**：电平来自麦克风，成图来自 8 个已记扇区，点头不能凭空编一个。头稳点头在待机可开始扫描、小结页可确认清空；扫描中与成图时的点头一律忽略并说明。
- **纠错便宜，销毁需确认**：扫描页或成图页返回键回待机（本轮保留，START 恢复同一轮）；小结页返回键回原态（不删东西，小结重建）；确认（小结页点 END 或头稳点头）才清空本轮；没有 DEL 键。
- **为什么胸前设备做不了**：噪音方位图是「头部朝向 × 电平」的配对——胸前设备既不知道你的头转向哪、也没法把「左后方最安静」钉在你眼前。转头扫描、方位成图、最安静指出三条都只有头戴设备成立。

## 与邻近 Agent 的分工

- 注意力系列 `light-change`（E01）：相机定时测光 + 光线低于阈值提醒开灯。本 Agent 完全不用相机：它边转头边采电平，输出的是一张方向图，不是一句开灯提醒。
- 注意力系列 `sky-watch`（E02）：晾晒方向登记 + 定时测天空 + 亮度大跌时 TTS 云层预警。本 Agent 不登记方向、不定时测光：它一次转头扫 8 个方向，报出最安静的那一个。
- 注意力系列 `eye-rest`（B01）：近视持续计时 + 满 20 分钟远眺提醒。本 Agent 不计时：它一次转头就成图。

## 功能流程

1. **开始（START）**：待机点 START 开始扫描；头稳点头也可开始。
2. **扫描（SCAN）**：顺时针转头，每转到一个方向点 SCAN 记一次电平（低/中/高）；扫满 8 个扇区自动成图。
3. **成图与指出**：成图时横幅 + 恰好一次语音报最安静的朝向（并列最低时取先扫到的那一个）。
4. **重扫（RESCAN）**：成图页点 RESCAN 清空本轮扇区再扫一轮（成图轮数保留）。
5. **结束与小结（END）**：扫描中或成图页点 END 出小结（扫描成图几轮、最安静朝向是哪）；返回键回去（不删东西），小结页点 END 或头稳点头确认后清空本轮。

## 权限

- RECORD_AUDIO（`permissions: ["RECORD_AUDIO"]`）：扫描扇区电平需要麦克风。不拍照、不定位。

## 手势映射

- 点按（tap / Enter）：待机 START 开始扫描；扫描中 Enter 记下一个扇区；成图页 Enter 重扫；小结页 END 确认清空。
- 双击（double-tap / Backspace）：返回上一态（扫描/成图→待机保留本轮；小结→原态不删东西）。
- 滑动（swipe / ArrowUp-Down）：在八行扇区（前 / 右前 / 右 / 右后 / 后 / 左后 / 左 / 左前）间切换焦点。
- 头稳 + 点头（head-steady + nod）：待机开始扫描；小结页确认清空；扫描中与成图时的点头一律忽略（点头不是扇区电平）。
- 单指长按：唤出 AI 语音助手（系统默认）；双指长按：AI 快捷指令（固定文本，零 ASR 启动）。
