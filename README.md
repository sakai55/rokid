注意力外挂系列 CO03（COVER 覆盖型，本组第三位）。读长合同、说明书、条款时最典型的焦虑：读完一页，感觉都读了，却不知道中间哪几行其实跳过去了。本 Agent 的做法：拍一页，模型读出行文本，你逐行读——读完一行点 READ；点中后面的行名直接跳读时，中间被跳过的行当场标「漏读」并点名提醒；页末小结前还有未读行会被拒绝并点名；只有全部读完，小结才报「本页全部读完」并给出覆盖率。多页文档按页累计总覆盖率。

## 解决的问题

校对难的不是认字，是「无法证明读完了」：眼睛扫过一页，大脑自动补全了没读的部分，而跳过的行恰恰是最容易藏坑的那几行。本 Agent 把「读完了」变成一张看得见的表：每行只有三种状态——未读、已读、漏读；跳过的行不会自己消失，必须回去补读；小结的覆盖率是算出来的（已读行 ÷ 总行数），不是感觉出来的。它不替你理解条款（那需要它读懂合同），它只替你证明「这一页我确实逐行读完了，而且跳过的那几行没有被含糊掉」。

## 注意力外挂设计（COVER 覆盖型）

- **覆盖表就是产品，跳行检测是核心**：一页的行（示例页 8 行，实拍页最多 12 行）是全部模型。读完一行点 READ；点中后面的行名跳读时，中间的未读行当场标漏读；漏读行必须回去点 READ 补读，补完才消失。小结里有漏读行时，永远不会出现「本页全部读完」。
- **小结有门，不是谁都能进**：FIN 时只要还有未读行，小结直接被拒绝，并且拒绝时会点名：还差哪几行。带窟窿的小结就是本 Agent 要消灭的虚假安心。
- **多页累计，页页有数**：PAGE 把本页的已读/总行归档进累计，下一页重新载入；计数行同时显示本页覆盖率和累计覆盖率。页只能向前，整份文档重读用小结页的 DEL 两下清空。
- **读到哪行以你的动作为准（诚实边界，第一位）**：本平台没有眼球注视检测，本 Agent 永远不假装知道你的眼睛在看哪行——「读到第 N 行」的意思是你点了 READ、点了头、或点了那一行名。界面、朗读、README 都明说这一点。
- **行文本来自拍照模型读数，可能读错（诚实边界，第二位）**：LOAD 为整页拍 default 照片，模型按 `L1: …` 格式读出行文本；读不清（少于 3 行、空回复、模型不可用）时页面保持空白并说明原因，绝不猜一行出来。行文本以模型返回为准，你对照纸面判断，读错的行照样可以逐行确认或重拍。
- **只记本次会话，关掉即清（诚实边界，第三位）**：全部内容只存本次会话内存，关掉 Agent 即清——适用窗口就是正在读的这份文档，零隐私残留。
- **为什么胸前设备做不了**：逐行指读要求「点中哪行、读到哪行」的同轴对应（胸口相机不知道你在看第几行）；跳行提醒要求行名与你当前行的对应；小结必须进视线（低头看胸口设备等于又一次离场）。三条都只有头戴设备成立。

## 与邻近 Agent 的分工

- CO01 `last-glance`：离开时按朝向拍照存档、路上回放——存的是「离开时看到的东西」，不追踪阅读进度。
- CO02 `room-sweep`：同一覆盖表模式用于房间安全项（通过/待处理）——查的是物理项，不是文本行。
- 指向性系列 `board-capture`：把板书拍成笔记；`word-look`：查生词。两者都不追踪你是否逐行读完、不点名跳过的行、不报覆盖率。
- 本 Agent：只做逐行覆盖追踪 + 跳行提醒 + 覆盖率，三者都不重叠。

## 功能流程

1. **载入（LOAD / DEMO）**：LOAD 为整页拍照（default），模型读出行文本后从第 1 行开始；读不清时说明原因并保持空白。DEMO 载入 8 行示例页（全程标注 DEMO，不用相机），已有真实页时 DEMO 拒绝，绝不覆盖真实页。
2. **逐行读（READ）**：读完当前行点 READ（或头稳点头），该行变已读，焦点移到下一未读行；NEXT/PREV 换行；点中后面的行名直接跳读，中间行当场标漏读；点中前面的行名是重读，不算跳行。
3. **漏读拦截（FIN）**：点 FIN 时有未读行 → 拒绝并点名缺失行；全部已决（已读或漏读）→ 进入小结。
4. **小结（SUMMARY）**：全部读完 → 「本页全部读完」+ 覆盖率 100%；有漏读行 → 只列漏读行 + 本页覆盖率，不报全读。READ 回去补读（焦点落在第一个漏读行），PAGE 归档本页并开始下一页，DEL 两下清空整份文档。
5. **演示（DEMO）**：四段演示——3 行已读 → 模拟跳行（4–6 行漏读）→ 漏读小结 → 补读后全读小结；已有真实页时 DEMO 拒绝。

## 手势映射

| 手势/按键 | 动作 |
|---|---|
| 点按（Enter） | 读完当前行进下一行（小结页：回去补读） |
| 双击（Backspace） | 回到上一行 |
| 上滑（ArrowUp） | 下一页（归档本页，开始新页） |
| 下滑（ArrowDown） | 上一页提示（页只能向前；整份重读用小结页 DEL 两下） |
| 头稳 + 点头 | 确认当前行已读（仅逐行读页；其他状态下点头无效并说明原因） |
| 屏上按钮 | LOAD 拍照读页 / READ 读完 / PREV 上一行 / NEXT 下一行 / FIN 小结 / PAGE 下一页 / SPEAK 朗读 / DEMO 演示 / DEL 取消或两下清空 |

## 权限说明

- `CAMERA`：为整页拍 default 照片作模型读数输入（照片当场丢弃，只留行文本，不存档）。没有它，DEMO 示例页仍可演示逐行逻辑。
- 不申请 `RECORD_AUDIO`（无口述环节，读行/跳行/补读全靠点按、行名点选与点头）、不申请 `GEOLOCATION`（文档不需要定位）。

## 提审资料 (Review Submission)

### Feature Description

校对覆盖外挂：读长合同、说明书时，拍一页、模型读出行文本，你逐行读完才算读完。读完一行点 READ；点中后面的行名跳读时，中间行当场标漏读并点名提醒；页末小结前有未读行会被拒绝；全部读完才报覆盖率 100%。多页文档按页累计总覆盖率。读到哪行以你的逐行动作为准（本平台无眼球注视检测）；全部数据只存本次会话内存，关掉即清。

### Opening Message

**逐行读完，才算读完。**

- LOAD 拍一页，模型读出行文本；读不清时说明原因，绝不猜
- 读完一行点 READ（或头稳点头），焦点移到下一未读行
- 点中后面的行名直接跳读，中间行当场标漏读，必须回去补读
- 点 FIN：有未读行会被点名拒绝；全部已决才进小结
- 小结只报两种实话：全部读完（100%），或漏读行 + 本页覆盖率
- PAGE 归档本页开始下一页，累计覆盖率一直算着
