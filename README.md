注意力外挂系列 CO02（COVER 覆盖型，本组第二位）。每晚睡前巡查孩子房间最典型的焦虑：窗、插座、小物件、床护栏、门、夜灯——明明绕了一圈，躺下还是不确定是不是都查过了。本 Agent 的做法：按进门顺序逐项检查，看向一项、点头或点按才算通过；发现问题就标记待处理，**绝不刷绿**；小结前漏查的项会按方位点名提醒补看；只有全部通过，小结才说「可以安心睡了」。

## 解决的问题

睡前巡查难的不是记性，是「无法证明」：你绕了一圈，躺下还是不确定是不是都看过了——而问题项最容易在这种不确定里被含糊过去。本 Agent 把「都查过了」变成一张看得见的表：6 项，确认一个亮一个，标记问题的一个永远待处理，漏一个就明明白白空着。它不替你判断窗关没关（那需要它联网家居或看懂房间），它只替你证明「这一圈我确实查完了，而且有问题的那一项没有被含糊掉」。

## 注意力外挂设计（COVER 覆盖型）

- **覆盖表就是产品，拒绝刷绿是核心**：6 项固定清单（窗户·左、插座·右前、地面小物件·中央、床护栏·右、门·后、夜灯·左前）是全部模型。确认一个亮一个；标记待处理的一项不计入通过——小结里有待处理项时，永远不会出现「可以安心睡了」。处理完回来点 OK，才能把那一项改成通过。
- **小结有门，不是谁都能进**：FIN 时只要还有未查项，小结直接被拒绝，并且拒绝时会点名：还差哪几项、分别在哪个方位。带窟窿的小结就是本 Agent 要消灭的虚假安心。
- **照片只是留档凭证，绝不分析（诚实边界，第一位）**：SNAP 为当前项拍一张大视场照片，只记一个「已拍照留档」标记，照片本身当场丢弃，不分析、不判断状态、不用来通过或标记任何一项。相机不可用时查项照常进行——拍照是留档，不是门槛。
- **Agent 不检测物理状态、不联网家居（诚实边界，第二位）**：窗关没关、插座盖没盖，只能由你看向确认。本 Agent 没有传感器链接、没有家居联网，界面、朗读、README 都明说这一点。
- **方位是进门起的巡查顺序，不是实测位置（诚实边界，第三位）**：项名后的方位（左、右前……）是你从门口开始走的顺序，本 Agent 没有室内定位、没有房间地图，永远不知道东西在房间的哪一边。
- **只记今晚，关掉即清（诚实边界，第四位）**：全部内容只存本次会话内存，关掉 Agent 即清——适用窗口就是今晚这一次巡查，明晚重新巡查正是正确用法，零隐私残留。
- **为什么胸前设备做不了**：逐项确认要求「看向哪项、确认哪项」的同轴对应（胸口相机不知道你在看窗还是看插座）；漏查提醒要求头部朝向与巡查顺序的对应；小结必须进视线（低头看胸口设备等于又一次离场）。三条都只有头戴设备成立。

## 与邻近 Agent 的分工

- CO01 `last-glance`：离开时按朝向拍照存档、路上回放——存的是「离开时看到的东西」，没有通过/待处理语义。
- 指向性系列 `home-patrol`：出门前全屋通用检查（门、燃气、水龙头、窗）——一次性的出门检查。
- 本 Agent：每晚、固定一个房间、固定的 6 个安全项，问题项不放行。三者共用覆盖表模式，其他都不重叠。

## 功能流程

1. **巡房（SWEEP）**：按进门顺序逐项检查；当前项看向确认：OK 通过（头稳点头也可确认），FLAG 标记待处理，SNAP 拍照留档（可选），NEXT/PREV 换项，DEL 取消当前项的确认/标记。
2. **漏查拦截（FIN）**：点 FIN 时有未查项 → 拒绝并点名缺失项与方位；全部已决（通过或待处理）→ 进入小结。
3. **小结（SUMMARY）**：全部通过 → 「可以安心睡了」+ TTS；有待处理项 → 只列待处理项，不报全绿。OK 回巡房继续处理（焦点落在第一个待处理项），DEL 两下清空重查。
4. **演示（DEMO）**：四段演示——2 项通过 → 4 项通过 + 1 项待处理 → 待处理小结 → 处理后全绿小结；已有真实确认时 DEMO 拒绝，绝不覆盖真实巡查。

## 手势映射

| 手势/按键 | 动作 |
|---|---|
| 点按（Enter） | 确认当前项通过（小结页：回巡房） |
| 双击（Backspace） | 返回（由宿主处理关闭） |
| 上滑/下滑（ArrowUp/Down） | NEXT/PREV 换项 |
| 头稳 + 点头 | 确认当前项通过（仅巡房页；其他状态下点头无效并说明原因） |
| 屏上按钮 | SNAP 拍照留档 / OK 通过 / FLAG 标记问题 / FIN 小结 / SPEAK 朗读 / DEMO 演示 / DEL 取消或两下清空 |

## 权限说明

- `CAMERA`：为当前项拍大视场照片作本次会话留档标记（照片当场丢弃，只记标记，不分析）。没有它，查项功能本身不受影响。
- 不申请 `RECORD_AUDIO`（无口述环节，确认/标记全靠点按与点头）、不申请 `GEOLOCATION`（方位是巡查顺序，不是定位）。

### Feature Description

睡前巡房外挂：每晚按进门顺序逐项检查孩子房间（窗户、插座、地面小物件、床护栏、门、夜灯）。看向一项、点头或点按即确认通过；发现问题标记待处理，绝不刷绿；漏查项在小结前按方位点名提醒；全部通过才报「可以安心睡了」。拍照仅作本次会话留档，不分析、不判断状态；全部数据只存会话内存，关掉即清。

### Opening Message

**今晚巡房，逐项查完再睡。**

- 按进门顺序查 6 项：窗户、插座、地面小物件、床护栏、门、夜灯
- 看向一项，点 OK 或头稳点头即通过；发现问题点 FLAG 标记，绝不刷绿
- SNAP 可为当前项拍照留档（仅本次会话，不分析）
- 查完点 FIN：有漏查项会被点名提醒；全部通过才说「可以安心睡了」
- 有待处理项时小结只列待处理项，处理完回来点 OK 才能通过
