注意力外挂系列 RE04（REVIEW 回顾型，本组第四位）。通勤路上发现的施工/危险点，第二天出门全忘，又踩一遍——路上有施工围挡、路面大坑、积水路段，看的时候都记得，第二天出门就全忘在脑子里。本 Agent 把路线预告外包出去：路上看向危险点停稳，登记一处——描述 + 方位 + 当时拍一张画面；次日出门前按登记顺序逐个预告，GOT 确认知道了才走下一处；结束小结钉住登记几处、预告确认几处。

## 解决的问题

通勤踩坑不是没看见，是没留痕——施工点混在路上、方位混在方向里、画面混在记忆里，第二天出门想一处就得把整条路重走一遍。本 Agent 管三件事：路上把每处危险点钉上一格（描述、方位、画面三样齐），出门前按登记顺序走一遍预告（不用重走那条路），每处确认知道了才走下一处（不用凭记忆赌哪处还没看）。

## 注意力外挂设计（REVIEW 回顾型）

- **预告是登记，不是检测**：危险点是你登记的，不是 Agent 检测出来的——描述是你选的、方位是你标的、画面是你拍的。预告列的是登记原样，不加检测、不加判断。路上的坑第二天还在不在，Agent 不知道、也不替你核实。
- **画面是当时拍的原图（会话内），不是识别结果**：SNAP 拍一张 wide 照片，转成 data URL 只存在会话内存里，钉在登记的那一处上；预告显示「已拍（会话内）」加字节数，不渲染图库、不做识别；关掉 Agent，照片和点位一起清。预览里没有相机，DEMO 点位的画面一律标 DEMO 示例占位，绝不假装是实拍。
- **方位是记忆线索，不是导航**：每处带的方位是你登记时面对的方向，帮你想起「那个大坑在左前方」——顺着方位想起来的是点位（那处围挡、那个大坑），不是路线。
- **预告是确认走线，不是齐全检查**：PREVIEW 按登记顺序逐个预告，GOT 确认知道了才走下一处；已确认的再点 GOT 会拒绝；全部确认后状态明说「全部已确认」。小结即使有处没确认也照实报确认数（比如 1/3），不假装整条路都预告过了；它也不拦你出门——这是提醒，不是门。
- **「次日」按单会话实现，代价写在明处**：舰队零落盘纪律不许调用存储 API，所以登记与预告发生在同一次打开的会话内；DEMO 种子点位展示的就是预告格式。想今天记、明天看，需要跨日留存——是否破例由 GO 另行决定，本 Agent 绝不偷偷存下来再假装是次日预告。
- **点头只确认和走线，从不替你选**：头稳点头在登记时确认当前选择为一处、在预告时确认当前处知道了、在小结页确认清空；不稳的点头不计入 1.2 秒锁；点头从不切换描述或方位。
- **纠错便宜，销毁需确认**：小结页返回键回到预告（不删东西，小结重建）；预告页返回键回到登记（点位全在）；确认（小结页点 END 或头稳点头）才清空本轮路线；没有 DEL 键。
- **只记本轮路线，关掉即清**：点位、照片、焦点、计数只存会话内存，关掉 Agent 即清——上一轮的危险点对下一轮没有任何意义，存下来才是误导。
- **为什么胸前设备做不了**：预告的线索是「这处是朝哪个方向看过去的」——胸前设备不知道你的视线朝向，也就给不出方位标记；预告必须贴在视线里一眼走完（低头翻手机等于又一次离场，线走到一半就断了）。两条都只有头戴设备成立。

## 与邻近 Agent 的分工

- 注意力系列 `shop-replay`（RE03）：购物回放模板——候选带价格和当时画面，收尾是最便宜一跳。本 Agent 没有价格、没有最便宜一跳：它的单位是危险点，收尾是确认数小结。
- 注意力系列 `day-lookback`（RE01）：白天时间线模板——你标记的凝视，分画面 / 数字 / 承诺三类，画面以文字描述登记。本 Agent 不是一天：它的单位是路线点位（描述 + 方位 + 实拍），回放是确认走线，不是时间线。
- 注意力系列 `last-glance`（CO01）：离开存档模板——按区拍照 + LLM 一句描述，6/6 齐了才能离开。本 Agent 没有 LLM 描述、没有离开门：它的照片是每处点位的当时画面，它的收尾是预告确认，不是齐全检查。

## 功能流程

1. **路线登记（DESC / DIR / SNAP / MARK）**：DESC 在施工围挡 / 路面大坑 / 积水路段 / 脚手架 / 井盖缺失间选描述，DIR 在前方 / 左前方 / 右前方 / 左方 / 右方 / 后方间标方位，SNAP 拍一张当时画面（wide，会话内），MARK 登记一处；没拍也能登记（画面记为未拍），预告照样列出它。
2. **次日预告（PREVIEW / GOT / NEXT / PREV）**：至少登记了一处才能 PREVIEW；预告按登记顺序列出每一处，大字显示当前处描述 + 方位，小字显示时间 + 画面状态 + 确认状态 + 第几处；GOT 确认知道了并走下一处未确认的，已确认的再点 GOT 会拒绝；NEXT/PREV 换处，点按行也能聚焦。
3. **结束与小结（END）**：小结列出共几处、预告确认几处，并把全部点位列在下面；返回键回到预告（不删东西），小结页点 END 或头稳点头确认后清空本轮路线。
4. **演示（DEMO）**：六段演示——施工围挡前方（DEMO 示例）→ 路面大坑左前方 → 积水路段右前方 → 预告聚焦第 1 处 → GOT 确认第 1 处、聚焦第 2 处 → 小结（共 3 处，已确认 1 处）；已有用户点位或用户预告进行时 DEMO 拒绝，绝不覆盖。

## 手势映射

| 手势/按键 | 动作 |
|---|---|
| 点按（Enter） | 登记：确认当前选择为一处；预告：确认当前处知道了；小结页：确认并清空 |
| 双击（Backspace） | 小结页：回到预告；预告页：回到登记；登记页：无动作并说明 |
| 上滑（ArrowUp） | 登记/预告：下一处 |
| 下滑（ArrowDown） | 登记/预告：上一处 |
| 头稳 + 点头 | 登记：确认当前选择为一处；预告：确认当前处知道了；小结页：确认并清空；不稳的点头不计入 1.2 秒锁；点头从不切换描述或方位 |
| 屏上按钮 | DEMO 演示 / DESC 选描述 / DIR 标方位 / SNAP 拍一张 / MARK 登记一处 / PREVIEW 次日预告 / GOT 确认知道了 / END 结束出小结（小结页点 END 即确认清空）/ SPEAK 朗读当前状态 / BACK 返回 / NEXT 下一处 / PREV 上一处 |

## 权限说明

- 只申请 `CAMERA`（app.json 的 `permissions` 为 `["CAMERA"]`，静态校验明确断言这一点）：当时拍画面（wide 模式，会话内）。
- 不申请 `RECORD_AUDIO`（没有任何收听环节：没有 ASR 路径，没有 onASRResult 处理）、不申请 `GEOLOCATION`（方位是你登记时面对的方向，不是定位：Agent 从不知道你在哪）。
