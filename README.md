头部动作小游戏系列 GA05，系列里的反转圈教学旗舰游戏，极简设计：一页、三态（准备 / 进行 / 完成），语音指导做 8 个时钟点位。坐稳或站稳、头摆正，点一下开始：先校准——Agent 请你低一下头（记住哪边是低，仰头即反方向），再请你向左转一下（记住哪边是左，向右即反方向），然后一句一句报点位——12、9、6、3、9、12、3、6，每个点位都必须转到位、稳住约 0.8 秒、回正到中心，下一个点位才会被报出。屏幕上只有大时钟点位（例如「9 · 左」）、计数和一行提示；你的转头本身就是游戏动作，由方向传感器对照校准中心判定。

与 GA01–GA04 不同：本游戏不数单一方向的重复次数，它教的就是「点位与转圈的区别」——顺序故意不按顺时针走（没有 12-3-6-9 的转圈跑法），而且任何从一个点位直接扫到下一个点位、不回正的动作都不计数。

## 系列宪法：颈部安全（GO 的规则）

**转圈是错误的。** 只做分段动作：中心 → 一个方向 → 停住 → 回正到中心 → 再换方向。绝不连续转圈，绝不从一个极端直接扫到另一个极端，绝不快速甩动。慢、小幅度、到微酸即止，不到疼痛。**12 点（仰头）特别规则：只到轻微拉伸，绝不用力把头往后仰、绝不向后甩头、绝不过度后伸（hyperextend）**（语音指导里会反复说这一点）；6 点（低头）也只到微酸，不压下巴贴胸。出现痛、晕、麻、恶心，立刻停。先坐稳 / 站稳。一局 60–180 秒。本游戏是日常活动娱乐，**不是医疗诊断、治疗或康复处方**；有颈椎病、眩晕、术后、头颈伤史的人请先问医生。短版印在游戏内的准备屏上；完整版见 AGENTS.md。

## 反转圈教学句

开局语音与准备屏都有一句原话：

> 这是点位，不是转圈：每次只到一个点位，停住，回正，再报下一个。

完成时的语音收束也是教学句：「完成，8 个点位都到过了，没有转圈。」

## 玩法

1. **准备**：坐稳 / 站稳，头摆正，读一遍安全提示与点位顺序，点「开始」。
2. **校准（两句提示，进行中）**：按提示慢慢低一下头（Agent 记住哪边是低），慢慢回正；再按提示慢慢向左转一下（Agent 记住哪边是左），慢慢回正。校准期间不计数；每次回正都会把中心重设到当前正前方。
3. **进行**：每一次 = 转到报出的点位（约 27°：12 = 仰头、6 = 低头、3 = 向右、9 = 向左）→ 稳住约 0.8 秒 → 回正到双轴 10° 以内，TTS 才报下一个点位。没稳住满 0.8 秒就松开不计数；没回正就不算一次，也不能直接开始下一个点位（从一个点位直接扫到下一个点位不计数并提示「请先回正，不要直接转到下一个点」）；动错点位不计数并提示纠正；一次卡住不动，TTS 只重提示一次，绝不自动计数。
4. **完成**：8/8（12、9、6、3、9、12、3、6 全到过），点「再来一局」重新校准中心与上下左右、再玩一局。

## 技术诚实说明

- **无眼动追踪**：平台没有眼动 API；头部方向只来自 `AbsoluteOrientationSensor`。
- **头部手势事件官方文档只写了 `'nod'`**：不声称时钟点位、转头、摇头、倾斜、仰头、低头等手势事件；点位判定全部来自传感器四元数。
- **阈值**：方向到位约 25–30°（代码取 27°，12/6 用俯仰角、3/9 用偏航角），回正 <10° 且要求俯仰与偏航双轴同时在 10° 以内，稳住约 0.8 秒（有 `onOrientationStabilityChange` 稳定事件时仅在稳定时累计稳住时间，无事件时以计时为准并如实说明）；俯仰角公式与 GA01/GA04 一致（`asin(2*(w*x − y*z))`），偏航角公式与 GA02 一致（`atan2(2*(w*z + x*y), 1 − 2*(y*y + z*z))`），只用相对校准中心的差值。
- **上下左右方向符号都是学习的，不是假设的**：开局两句提示——「请低一下头」学到哪边是低（仰头取反方向），「请向左转一下」学到哪边是左（向右取反方向），因此宿主俯仰角或偏航角符号即使反了也不会把方向算错。剩余注意事项：校准默认玩家按提示真的低头 / 真的左转——若反向动作，相应轴的符号会学反；但校准期间不计数、第一局第一点位仍是 12、第二点位是 9（学反了立刻会觉得不对），且任何重开都会重新校准。真机验收必须确认：两句校准提示都出现、真低头与真左转都能完成校准、之后真低头计为 6 而非 12、真仰头计为 12 而非 6、真左转计为 9 而非 3、真右转计为 3 而非 9，以及不回正直接扫到下一个点位确实不计数。
- **传感器缺失 = SKIP / 演示，绝不假装通过**：网页预览没有方向传感器，屏幕明示 SKIP，演示按钮只走标注的演示计数（校准四步 + 每点一次算一整个点位），完成屏写「演示完成」；真机有传感器时没有演示路径。
- **零持久化**：不调任何存储 API；计数、中心与学到的方向符号只活在页面内存里。

## 提审资料 (Review Submission)

### Feature Description

> Clock-point neck exercise for Rokid glasses, voice-guided. Tap start: look down once, then turn left once, to calibrate down and left. Then it calls eight clock points in a fixed non-circular order — 12, 9, 6, 3, 9, 12, 3, 6. Turn to each point, hold 0.8 seconds, return to center, and only then is the next point called. Points, not circling: sweeping to the next point without returning counts nothing. Up (12) only to a mild stretch. Entertainment only, not medical advice.

### Opening Message

> ## 时钟点位
>
> 坐稳，头摆正，点一下开始：我先请你低一下头、再向左转一下，记住哪边是低、哪边是左，然后一句一句报点位——**12、9、6、3、9、12、3、6，每个点位转到位、稳住 0.8 秒、回正到中心，下一个点位才会被报出**。
>
> 记住：**这是点位，不是转圈**。不回正就直接转到下一个点，不算数。12 点只到轻微拉伸，绝不用力往后仰。痛、晕、麻、恶心，立刻停下来。本游戏是日常活动娱乐，不是医疗建议。
