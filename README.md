注意力外挂系列 FI05（FILTER 过滤型，本组第五位，过滤组收官）。一堂课信息密度不均，老师随口说的「考试重点」「作业截止日」那几句最容易漏听——整堂课不敢走神的结果是注意力被全程征用，而那几句来临时你反而因为听累了而错过。本 Agent 把这个「竖耳朵」的活外包出去：课前先声明信号词（示例：重点·考试·作业），然后只管放空；守听时 ASR 转写逐段过门，只有命中信号词的句子才亮起横幅、TTS 报一次「命中：重点，已记入本课笔记」，并把这句话原样存入本课笔记（带第几分钟标记）；没命中的句子只让「已听」计数走一格，句子本身立即丢弃——不亮屏、不出声、不存全文。课后小结列出本课笔记逐条，确认后清空。

## 解决的问题

课堂的注意力税：老师讲的九成内容你要全程在线，生怕错过那一成信号句；可全程在线恰恰最耗注意力，到了关键句反而走神。本 Agent 把「听 + 判断」外包：规则事先定好（信号词），守听时你只管不听；命中时它负责叫你并把句子记下来，没命中时它只负责计数——结束时的小结就是本课笔记，你可以重读，但不必当时被整堂课打断。

## 注意力外挂设计（FILTER 过滤型）

- **先声明信号词，规则课中不改**：信号词组、收音模式只能在待机时换（SIG 在 重点·考试·作业 / 截止日·必考·复习 / 六词全集 间轮换，MODE 在 far-field / omnidirectional 间轮换）；守听中改规则会被拒绝并说明原因——信任中的过滤器不能在你不注意时被改写规则。
- **匹配规则只有一条，这是第一位的诚实边界**：转写文本（归一化后）含信号词组里的词即命中，按组内顺序第一个命中的词被点名。没有说话人识别、没有分说话人、没有课堂纪要引擎——门禁测的是文本，不是人；ASR 听错一个字就可能漏报或误报，界面、朗读、README 都明说。
- **命中才亮，且亮的是「关键词 + 原句笔记」**：TTS 只点名关键词并说已记入笔记，不把整句话再念一遍——刚省下的注意力不能又被朗读吃回去。笔记存原句 + 第几分钟，课后小结可逐条重读。
- **故意没有滚动转写缓冲**：FI04 会议过滤保留约 10 秒前文，因为会议命中只有配上前文才有用；课堂命中不同——信号句本身就是完整的，缓冲只会把没命中的话也留下来。本 Agent 在判定点就把没命中句子丢弃，源码里根本没有缓冲（断言扫描过）。
- **没命中的句子只动计数器**：没命中只让「已听」加一，不弹横幅、不播报、不存句子；空转写根本不计数——你并没有真的听到一段话，计进去就是假覆盖。过滤器如果每句话都报一遍，过滤器本身就成了干扰源。
- **开始/结束守听必须是 deliberate 的点按**：点按（Enter）开始/结束守听；头稳点头只在待机开始守听和小结确认时有效，守听中点头无效——门的开关绝不能因为一次无意的点头就触发；不稳的点头不占 1.2 秒锁。
- **纠错便宜，销毁需确认**：守听中 DEL 只清命中横幅，绝不动笔记列表、不结束守听；无横幅时 DEL 被忽略，不会「静默清掉什么」；小结页返回键回到守听（不删东西），确认（点按/点头）才清空本次记录。
- **只记本课，关掉即清（诚实边界，第二位）**：全部内容只存本次会话内存，关掉 Agent 即清——适用窗口就是正在上的这堂课，零隐私残留；没有全程录音可泄露，因为没命中句子判定即弃，只有命中句才在内存里待到小结；下一堂课重新从空白笔记开始，正是正确用法。
- **收音模式的诚实边界（第三位）**：MODE 选的是 getUserMedia 音频流的拾音方向（far-field 适合大教室、omnidirectional 适合圆桌讨论），宿主 ASR 用的是宿主麦克风，模式**不改变**识别的拾音——本 Agent 从不声称「模式把识别对准了某个人」。
- **为什么胸前设备做不了**：命中横幅必须进视线（低头看胸口设备等于又一次离场）；没命中的句子必须静默计数并丢弃（胸口设备出声报「这句和你无关」等于把过滤反过来变成打断）；笔记小结要一眼扫全（语音逐条报一遍等于重新占用注意力）。三条都只有头戴设备成立。

## 与邻近 Agent 的分工

- FI04 `meeting-filter`：会议门禁 + 命中前约 10 秒回放缓冲——它是**带回放的门禁**；本 Agent 没有缓冲、没有回放：课堂命中是自足的信号句，直接存成笔记。
- 指向性系列 `board-capture`：把板书拍成笔记——它是**视觉笔记员**；本 Agent 从不拍照，它捕捉的是**口头**信号句，而且只捕捉命中的那几句。
- 指向性系列 `far-ear`：把远处人声变成实时字幕让你听得清——它是**助听器**；本 Agent 对没命中的句子恰恰相反：它故意不把全部字幕都推给你，因为全部推出来就是让你全程在线。
- `focus-shield`（FI01）：声音的会话门禁——白名单词打断，其余只记时间线；本 Agent 是它的课堂孪生，区别是命中变成逐条笔记而不是时间线：命中只有存成句子，课后才可重读。

## 功能流程

1. **定信号词（SIG / MODE，待机时）**：在示例信号词组、收音模式间轮换；守听中改规则会被拒绝。
2. **开始守听（START / 点按 / 头稳点头）**：状态行明说「只有命中信号词的句子才亮并记入笔记，未命中只计不存」。
3. **守听过门（ASR 转写逐段）**：宿主 ASR 最终结果逐段过门；没命中只让「已听」加一，不亮屏、不出声、不存句子；空转写不计数。
4. **命中才亮并记笔记（命中）**：信号词命中 → 视线内横幅 + TTS 报一次关键词并说已记入笔记，原句存入本课笔记（带第几分钟）；DEL 只清横幅，不动笔记列表。
5. **结束与小结（END）**：小结列出已听几段、记了几条笔记、笔记关键词与时间；返回键回到守听（不删东西），确认后清空本次记录。
6. **演示（DEMO）**：四段演示——守听开始（信号词 重点·考试·作业，收音 far-field）→ 两段没命中字幕静默计数并丢弃（天气、社团招新，无横幅、无 TTS）→ 命中句「这道题是考试重点，下周复习要看」横幅 + TTS + 存入笔记 1 → 本课小结（已听 3 段、笔记 1 条、关键词 重点）；已有用户守听时 DEMO 拒绝，绝不覆盖。

## 手势映射

| 手势/按键 | 动作 |
|---|---|
| 点按（Enter） | 待机：开始守听；守听中：结束出小结；小结页：确认并清空 |
| 双击（Backspace） | 小结页：回到守听；守听中：无动作并说明（END 结束守听，DEL 清横幅）；待机：无动作并说明 |
| 上滑（ArrowUp） | 笔记列表下一条 |
| 下滑（ArrowDown） | 笔记列表上一条 |
| 头稳 + 点头 | 待机：开始守听；小结页：确认并清空；守听中：无效并说明（点头绝不开关守听）；不稳的点头不计入 1.2 秒锁 |
| 屏上按钮 | DEMO 演示 / START 开始 / END 结束出小结 / SIG 换信号词组 / MODE 换收音模式 / SPEAK 朗读当前状态 / DEL 清横幅 / BACK 返回 / NEXT 下一条笔记 |

## 权限说明

- 只申请 `RECORD_AUDIO`（app.json 的 `permissions` 为 `["RECORD_AUDIO"]`，静态校验明确断言这一点）。
- 收音流：getUserMedia 音频流按 `microphoneMode`（far-field / omnidirectional）拾音；转写：宿主 SpeechRecognition 最终结果逐段过门，两者都包在 try/catch 里，预览环境不可用时软失败（DEMO 照常走）。
- 不申请 `CAMERA`（没有任何拍照环节：信号词从示例池里选，确认靠手势）、不申请 `GEOLOCATION`（上课不需要定位）。
