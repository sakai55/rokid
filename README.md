# 투호 게임

**Studio 가져오기 주소**(Global AIUI Studio의 Import Project 입력란에 붙여 넣으세요):

```
https://github.com/sakai55/rokid/tree/agent-tuho-game
```

**AIX 직접 다운로드**(최신 버전): [tuho-game.aix](https://raw.githubusercontent.com/sakai55/rokid/main/aix/tuho-game.aix)

한 줄 장면: 가족 모임에서 머리 방향만으로 투호를 던져 10번의 던지기로 최고 점수에 도전합니다.

방향 구성: 한국 현지 × 게임 × 지향성. 현지는 한국 전통 놀이 투호가 모임 장면에 뿌리내리고, 게임은 10번 던지기, 거리별 점수, 최고 점수 저장이 한 판의 완결된 놀이를 맡고, 지향성은 머리 방향 겨냥이 던지기의 핵심 입력을 맡습니다.

## 구조와 기능

- 페이지 목록(3개 페이지): 전체 보기 index(게임 설명 3줄 + 최고 점수) / 투호 던지기 play(겨냥, 거리, 점수, 던지기) / 투호 기록 record(최근 게임 6회 + 최고 점수).
- 콘텐츠 집합 수: 겨냥 방향 3가지(왼쪽, 가운데, 오른쪽), 거리 3가지(1m 10점, 2m 30점, 3m 50점), 한 게임 10번 던지기, 목표 구역 순서 10가지, 기록은 최근 6회까지 보여 줍니다.
- 폐쇄 루프: 전체 보기에 들어와 → 던지기 페이지에서 위아래로 겨냥하고, 거리를 고르고, 고개를 끄덕여 던지고, 10번을 마치면 최종 점수와 최고 점수가 저장됩니다. 기록은 세션을 넘어 저장되며(저장 키 `tuhoGameV1`), 반복해서 쓸 수 있습니다.

## 제스처 매핑

| 조작 | 효과 |
|---|---|
| 첫 페이지 ArrowUp/ArrowDown | 설명 줄 바꾸기 |
| 첫 페이지 Enter | 게임 시작 |
| 던지기 페이지 ArrowUp/ArrowDown | 겨냥 바꾸기(왼쪽, 가운데, 오른쪽 순환) |
| 던지기 페이지 Enter | 던지기 |
| 고개 끄덕임 | 던지기(Enter와 동일) |
| 머리 좌우 돌리기 | 던지기 페이지에서 머리 방향 힌트 표시(겨냥은 버튼으로 바꿉니다) |
| 던지기 페이지 Backspace | 돌아가기 |

## 권한

없음. TTS는 호스트 고정 음색을 사용하고, utterance의 `lang`은 설정하지 않습니다. 카메라와 위치 권한도 사용하지 않습니다.

## 정직한 경계

- 던지기 판정은 화면 속 시범 점수이고, 실제 화살을 인식하거나 날아가는 화살을 추적하지 않습니다. 목표 구역은 던지기마다 화면 안에서 정해지는 순서입니다.
- 머리 방향 힌트는 감지기가 있을 때만 표시되고, 감지기가 없으면 버튼만으로 겨냥이 끝까지 됩니다. 감지기 값을 읽은 척하지 않습니다.
- 동작은 한 번에 한 구간씩 끊어서 하고, 던질 때마다 겨냥은 가운데로 돌아갑니다. 빙글빙글 도는 동작은 하지 않습니다.

## 오류 코드

실패하면 화면에 있는 그대로의 코드를 보여 주고, TTS는 코드만 읽으며, 최근 오류는 저장 데이터의 `lastError`에 남깁니다(코드, slug, 버전, 원문 포함). 이 기기에서 나올 수 있는 코드:

- `E5001` 기록 저장 실패(저장 쓰기 예외)
- `E5002` 기록 읽기 실패(읽기, 파싱 예외)
- `E3005` 읽어 주기 실패(TTS speak 예외)
- `E8001` 페이지 이동 실패(navigateTo, navigateBack 예외)
