注意力外挂系列 SO01（SOCIAL 社交型，本组第一个，系列第 36 个）。和人谈话走神十几秒，回来完全接不上，又不好意思让对方重复。本 Agent 把接续外包出去：far-field 守听谈话，ASR 字幕默记进最近 15 秒滚动缓冲；你摇头或点 HELP 求助时，眼前给出最近 15 秒的要点摘要（无声），看完 BACK 回守听，缓冲继续滚动；结束出小结（求助几次、已听几段）。

## 解决的问题

谈话走神不是没听见，是断掉的那十几秒接不回来了：对方刚说的条件、数字、时间点全卡在断点上，开口问等于承认走神，不问就只能含糊点头。本 Agent 管四件事：守听默记（字幕逐段进最近 15 秒缓冲，超期段丢弃，不存整场谈话）、无声求助（摇头或 HELP，眼前列出缓冲内字幕原句，不出声，不打断对方）、回守听（BACK 回去继续记，缓冲不停）、结束小结（求助几次、已听几段、缓冲几段钉在下面）。

## 注意力外挂设计（SOCIAL 社交型）

- **求助摘要无声，默认不出声**：HELP（或守听中摇头）冻结缓冲内字幕成要点，只在视线内呈现，不调用 TTS——把摘要读出来会打断你正在接的谈话，违背求助本意。摘要页主动点 SPEAK 才会把要点读出来，那是你主动点的，不是 HELP 自带的。
- **摘要是原句摘录，不是语义提炼**：Agent 不理解谈话内容——帮助页只是把缓冲内字幕原句按顺序摆出来，没有关键词提取、没有 LLM 浓缩、没有「对方的意思是」。UI 与本 README 如实写明这一点。
- **缓冲是最近 15 秒，不是整场记录**：每段字幕带时间戳，超 15 秒的段在进新段时、以及 HELP 求助时重剪，过期即弃，绝不出现在摘要里。缓冲不是录音、不是谈话存档。
- **求助是摇头或 HELP，不是点头**：守听中点头会被忽略并说明——字幕只能由谈话声流进来，点头不能替你编一段；点头在待机是开始守听、在摘要页是回守听、在小结页是确认清空，从不切换焦点、从不求助。摇头只在守听中求助，其他态忽略并说明；摇头手势以宿主发送 shake 事件为准，若宿主不发送则以 HELP 按键为准。
- **缓冲不分说话方**：没有说话人识别，帮助页不对任何一句标说话人——这一点与 talk-replay 故意相反（talk-replay 是用户切换 SIDE 标注说话方、谈完回放三类句；本 Agent 是谈话中无声接续，不标注、不分类）。
- **纠错便宜，销毁需确认**：摘要页返回键回守听（缓冲继续滚，不删东西）；小结页返回键回守听（不删东西，小结重建）；确认（小结页点 END 或头稳点头）才清空本轮缓冲与计数；没有 DEL 键。
- **只记本轮谈话，关掉即清**：缓冲、要点、求助次数、小结只存会话内存，关掉 Agent 即清——上一轮谈话的缓冲对下一轮谈话没有任何意义，存下来才是误导。
- **收音模式诚实边界**：far-field 只影响 getUserMedia 流的拾音，不改变宿主 ASR 的拾音（舰队审计结论，UI 与本 README 均明说）。
- **为什么胸前设备做不了**：求助的线索是「你正在面对面谈话、视线还对着对方」——胸前设备不知道你是在谈话还是在旁听，也就分不出「该默记」和「不该记」；摘要也必须贴在视线里无声呈现（掏手机看等于又一次离场，刚回来就断了）。两条都只有头戴设备成立。

## 与邻近 Agent 的分工

- 注意力系列 `meeting-filter`（FI04）：会议名字/议题关键词门 + 命中前 10 秒回放缓冲——只有命中关键词才亮，缓冲是为命中服务的。本 Agent 没有关键词门：每段字幕都进缓冲，缓冲是为你主动求助服务的，谈话中随时可求助。
- 注意力系列 `talk-replay`（RE02）：谈话字幕按说话方标注 + 谈完回放只列承诺/数字/期限三类句。本 Agent 不是谈完回放、不分类、不标注说话方：它是谈话中走神时的无声接续，摘要就是最近 15 秒原句。
- 注意力系列 `lecture-filter`（FI05）：课堂信号句捕捉成笔记。本 Agent 不存笔记、不捕捉信号句：它的唯一输出是求助时的最近 15 秒原句视图。
- 注意力系列 `tour-watch`（DU04）：导游广播集合信息门 + 集合点朝向 + 归队提醒。本 Agent 不设关键词门、不登记朝向：它只守听谈话、只在你求助时给最近 15 秒。

## 功能流程

1. **开始守听（START）**：START 开始 far-field 守听，ASR 字幕逐段进最近 15 秒缓冲（待机时点 HELP/END 会拒绝并说明先 START）；大字显示守听中几段，小字钉住最新一段。
2. **守听默记**：字幕逐段进缓冲，超 15 秒的段自动丢弃；NEXT/PREV 在守听中无动作（焦点只在摘要页走要点）。
3. **求助（HELP / 摇头）**：守听中点 HELP 或摇头 → 眼前列出缓冲内字幕原句（无声），求助计 1 次；摘要页 NEXT/PREV 走要点、点行聚焦，BACK 回守听继续记。
4. **结束与小结（END）**：守听中或摘要页点 END 出小结（求助几次、已听几段、缓冲几段）；返回键回守听（不删东西），小结页点 END 或头稳点头确认后清空本轮缓冲与计数。
5. **演示（DEMO）**：七段演示——开始守听 → 字幕 1（明天三点前把货送到仓库）→ 字幕 2（预算先定五千，超了再商量）→ 字幕 3（周五前把合同发过来）→ HELP 给 3 条要点（无声）→ BACK 回守听 → END 出小结（求助 1 次、已听 3 段）；已有用户守听或用户字幕进行时 DEMO 拒绝，绝不覆盖。

## 手势映射

| 手势/按键 | 动作 |
|---|---|
| 点按（Enter） | 待机：开始守听；守听中：求助（HELP）；摘要页：回守听；小结页：确认并清空 |
| 摇头（shake） | 守听中：求助（HELP）；其他态：忽略并说明；若宿主不发送 shake 事件，以 HELP 按键为准 |
| 双击（Backspace） | 摘要页/小结页：回守听；守听中：无动作并说明；待机页：无动作并说明 |
| 上滑（ArrowUp） | 摘要页：下一点；其他态：无动作并说明 |
| 下滑（ArrowDown） | 摘要页：上一点；其他态：无动作并说明 |
| 头稳 + 点头 | 待机：开始守听；守听中：忽略并说明（字幕只能由谈话声流进来）；摘要页：回守听；小结页：确认并清空；不稳的点头不计入 1.2 秒锁；点头从不切换焦点、从不求助 |
| 屏上按钮 | DEMO 演示 / START 开始守听 / HELP 求助最近 15 秒要点（无声）/ END 结束出小结（小结页点 END 即确认清空）/ NEXT 下一点 / PREV 上一点 / BACK 返回 / SPEAK 朗读当前状态（摘要页主动点才读要点） |

## 权限说明

- 只申请 `RECORD_AUDIO`（app.json 的 `permissions` 为 `["RECORD_AUDIO"]`，静态校验明确断言这一点）：far-field 守听 + ASR 字幕缓冲需要麦克风。
- 不申请 `CAMERA`（没有任何拍照环节）、不申请 `GEOLOCATION`（Agent 从不知道你在哪）。
