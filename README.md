注意力外挂系列 CU04（CUE 提示型，本组第四个，系列第 34 个）。换包/换外套出门，东西总落在上一个包里。本 Agent 把装包确认外包出去：看向今天要背的包停稳才触发按目的地清单——逐项看向包内格层确认装入，全装完说「都装好了」，提前结束当场点名未装项（提醒，不是拦门），小结照实记未装。

## 解决的问题

换包出门不是没带齐，是上一个包里的东西没挪过来——装没装全凭临场想起，到了门口才发现耳机还躺在旧包里。本 Agent 管五件事：看向今天要背的包停稳才触发清单（不是一打开就弹，弹的时机就是你拿起今天要背的包的那一刻），逐项看向格层确认装入（每项都要你本人点一下，含糊不得），提前结束报漏装（点名还没装哪几件，换包是在家门口、可回头补装，报完仍可结束）。

## 注意力外挂设计（CUE 提示型）

- **提前结束报漏装，提醒不是拦门**：TRIG 只在待机态、且头部停稳时触发清单（真机上由头部停稳判定）；GOT 确认当前项装入；清单里的 END 是结束——第一次 END 有未装项时横幅与一次 TTS 点名未装项，计报漏 1 次，留在清单里；再点 END 才真正结束，小结照实记未装。这一点与 cue-door 故意相反：换包是在家门口、可回头补装，假装拦住你才是误导。
- **确认装入只是表态，格层只是分组标注**：Agent 没有相机、麦克风、定位，也没有任何装包传感器——它不检测东西是不是真的在包里。GOT 记录的是你本人说「装了」。格层（主袋 / 侧袋 / 内袋）只是清单行的分组标注，不是包内实测位置。UI 与本 README 如实写明这两点。
- **看向触发，不是一打开就弹**：清单只在你看向今天要背的包停稳后才出现——触发时机贴在拿起包的动作本身上，而不是靠你记得打开它；预览中触发由 DEMO 演示，真机上由头部停稳判定。
- **目的地是你预设的**：清单按目的地编排，预览中以通勤为示例（钥匙 / 手机 / 钱包 / 工牌 / 耳机）；换目的地换预设，Agent 不读任何行程应用。
- **纠错便宜，销毁需确认**：小结页返回键回到清单（不删东西，小结重建）；清单页返回键回到待机（已装保留，再触发恢复同一张清单）；确认（小结页点 END 或头稳点头）才清空本轮清单；没有 DEL 键。
- **只记本轮换包，关掉即清**：清单、已装、报漏次数、小结只存会话内存，关掉 Agent 即清——上一轮的确认对下一轮换包没有任何意义，存下来才是误导。
- **为什么胸前设备做不了**：触发的线索是「你正在看向今天要背的包」——胸前设备不知道你的视线朝向，也就分不出「拿起包要装了」和「路过包」；格层确认也必须贴在视线里一眼走完（低头翻手机等于又一次离场，刚回来就断了）。两条都只有头戴设备成立。

## 与邻近 Agent 的分工

- 注意力系列 `cue-door`（CU01）：看向大门触发的出门清单凝视确认门——未全过不放行，缺项时 END 喊停并拦住。本 Agent 不是门：提前结束只报漏装并记录，从不拦你结束。
- 注意力系列 `pack-sweep`（CO04）：出门前在家装箱清点。本 Agent 不是通用装箱：它的触发是看向今天要背的包本身，清单按目的地编排、逐项按格层确认。
- 注意力系列 `bag-watch`（DU02）：在途行李副线 + 离开门拦截——看向行李方向登记朝向、坐等时定时提醒、离开时未确认不放行。本 Agent 没有方向登记、没有坐等守望：它的工作是出门前在家里的装包清单。
- 注意力系列 `cue-fridge`（CU02）：看向冰箱触发的待拿清单 + 缺货标记 + 关门前报漏拿（提醒不是拦门）。本 Agent 与它同形不同事：触发是看向今天要背的包，收尾是已装/未装 verdict，不是漏拿报告。
- 注意力系列 `attention-diary`（RE05）：注意力账单——触发按分类计数，收尾是一句「偷走最多」。本 Agent 没有分类、没有账单：它的单位是五件装包项，收尾是已装 verdict。

## 功能流程

1. **触发（TRIG）**：看向今天要背的包停稳，TRIG 触发按目的地清单（待机时头不稳点 TRIG 会拒绝并说明先停稳）；清单打开在第 1 项，5 项全列在下面（每项带格层：主袋 / 侧袋 / 内袋）。
2. **逐项确认装入（GOT / NEXT / PREV）**：GOT 确认当前项装入（已装过的再点会拒绝）；NEXT/PREV 走项，点行也可聚焦；大字显示已装几项，小字钉住还没装哪几项。
3. **提前结束报漏装（END）**：第一次 END 有未装项时横幅与一次 TTS 点名未装项，计报漏 1 次，留在清单里；再点 END 才真正结束，小结照实记未装；全装完 END 直接出「都装好了」小结，不出声。
4. **结束与小结（END）**：小结列出已装几项、未装是哪几项、报漏几次；返回键回到清单（不删东西），小结页点 END 或头稳点头确认后清空本轮清单。
5. **演示（DEMO）**：五段演示——触发清单（0/5）→ 确认钥匙 → 确认手机 → END 报漏装（钱包、工牌、耳机）→ END 出小结（已装 2 / 未装 3）；已有用户确认或用户清单进行时 DEMO 拒绝，绝不覆盖。

## 手势映射

| 手势/按键 | 动作 |
|---|---|
| 点按（Enter） | 待机：触发清单（需头稳）；清单：确认当前项装入；小结页：确认并清空 |
| 双击（Backspace） | 小结页：回到清单；清单页：回到待机（已装保留）；待机页：无动作并说明 |
| 上滑（ArrowUp） | 清单/小结：下一项 |
| 下滑（ArrowDown） | 清单/小结：上一项 |
| 头稳 + 点头 | 待机：触发清单；清单：确认当前项装入；小结页：确认并清空；不稳的点头不计入 1.2 秒锁；点头从不切换焦点 |
| 屏上按钮 | DEMO 演示 / TRIG 触发清单 / GOT 确认装入当前项 / END 结束（第一次报漏装、第二次出小结；小结页点 END 即确认清空）/ NEXT 下一项 / PREV 上一项 / BACK 返回 / SPEAK 朗读当前状态 |

## 权限说明

- 不申请任何权限（app.json 的 `permissions` 为 `[]`，静态校验明确断言这一点）：看向触发 + 装包提醒不需要相机、麦克风、定位。
- 不申请 `CAMERA`（没有任何拍照环节）、不申请 `RECORD_AUDIO`（没有任何收听环节：没有 ASR 路径，没有 onASRResult 处理）、不申请 `GEOLOCATION`（Agent 从不知道你在哪）。
