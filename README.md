注意力外挂系列 SO03（SOCIAL 社交型，本组第三个，系列第 38 个）。陪老人聊天，老人反复叮嘱的事（吃药、门锁、子女电话）记不全、回头就忘。本 Agent 把叮嘱外包出去：wearer/far-field 守听聊天，只把「叮嘱/需求」类句子存成清单，聊完 TTS 复述给你逐条确认；结束出小结（叮嘱几条、已确认几条、只听过几段）。

## 解决的问题

陪老人聊天的注意力是两头的：你要接着话、陪着笑，老人随口说的「记得吃药」「出门锁门」又不能当耳旁风——当时点头答应了，回家就忘。本 Agent 管四件事：守听（wearer/far-field 收音 + 宿主 ASR 转写逐段过叮嘱关键词门）、存清单（命中句亮横幅存入，原句 + 时间标记，守听中不朗读、不打断聊天）、聊完复述（点 DONE，TTS 逐条读给你逐条确认）、结束小结（叮嘱、已确认、只听过段数三项计数钉在下面）。

## 注意力外挂设计（SOCIAL 社交型）

- **门是关键词，不是理解**：每段转写只过一张关键词表（吃药/门锁/电话/记得/别忘/明天/打电话/锁门，表顺序首词胜出）——含词即存档，不含词只计数、判定即丢弃，不存全文。含关键词的句子未必真是叮嘱，ASR 听错也可能漏存/错存，清单只是候选，UI 与本 README 如实写明这一点。
- **守听不说话，聊完才复述**：命中只是横幅，守听中一次 TTS 都没有——出声会打断正在聊的天。语音只发生在复述里：DONE 读第一条，每确认一条读下一条，最后一条确认完报一句「叮嘱都确认了」。
- **清单不分说话方**：没有说话人识别，清单只按关键词归档，不按谁说的分——老人说的和你说的含词句都会进清单，复述时逐条确认才是过滤。
- **点头不能替你编一句**：守听中点头与 Enter 一律忽略并说明——字幕只能由谈话声流进来，点头不能替你编一段叮嘱。点头只在待机起守听、在复述中确认当前条、在小结页确认清空；不稳的点头不计入 1.2 秒锁；点头从不切换焦点。
- **纠错便宜，销毁需确认**：复述页返回键回守听（清单与确认保留，DONE 从第一条重新复述）；守听页返回键回待机（清单保留，START 恢复同一张单）；小结页返回键回复述（不删东西，小结重建）；确认（小结页点 END 或头稳点头）才清空本轮清单与计数；没有 DEL 键。
- **只记本轮聊天，关掉即清**：叮嘱、只听过段数、确认与小结只存会话内存，关掉 Agent 即清——上一轮聊天的叮嘱对下一轮聊天没有任何意义，存下来才是误导。
- **收音模式只管拾音流**：MODE 在守听前切换 wearer/far-field，只影响 getUserMedia 流的拾音，不改变宿主 ASR 的拾音；守听中 MODE 拒绝。
- **为什么胸前设备做不了**：叮嘱的线索是「你正在陪老人聊天、视线和注意力都在对方面上」——胸前设备分不出「陪聊」和「路过」，也就分不出「该默记」和「不该打扰」；复述也必须贴在视线里逐条确认（读一条、认一条），掏手机翻记录等于当场离场。两条都只有头戴设备成立。

## 与邻近 Agent 的分工

- 注意力系列 `lecture-filter`（FI05）：课堂信号句捕捉成笔记——预设信号词在上课时变成笔记。本 Agent 不是课堂工具：它的关键词是聊天里的叮嘱与需求，收口是聊完后的语音复述确认，不是一张笔记。
- 注意力系列 `talk-replay`（RE02）：谈话字幕按说话方标注、谈完回放只列承诺/数字/期限三类句。本 Agent 不标说话方、不分类：它在聊天中按关键词存档，聊完立刻语音复述。
- 注意力系列 `chat-catchup`（SO01）：谈话中走神时的无声接续——滚动字幕缓冲，HELP 给最近 15 秒要点。本 Agent 不留滚动缓冲、不在谈话中服务：它只存命中句，守听中保持沉默，语音只在复述里出现。

## 功能流程

1. **收音模式（MODE）**：待机时点 MODE 在 wearer/far-field 间切换（默认 wearer）；守听中点 MODE 会拒绝并说明只在守听前切换。
2. **开始守听（START）**：待机时点 START 开始守听，ASR 转写逐段过叮嘱关键词门；待机时点 DONE/CONF/END 会拒绝并说明先 START。
3. **命中存清单**：含关键词的句子亮横幅存入（原句 + HH:MM 时间 + 首词关键词），守听中不朗读；不含关键词的句子只计入「只听过段数」、判定即丢弃；空转写与无文本 ASR 忽略。
4. **聊完复述（DONE）**：守听中点 DONE 进入复述，TTS 读第一条；CONF 确认当前条并读下一条未确认条；最后一条确认完报「叮嘱都确认了」一次；已确认条再点 CONF 会拒绝；无存档时点 DONE 会拒绝并说明无可复述。
5. **结束与小结（END）**：守听或复述中点 END 出小结（叮嘱几条、已确认几条、只听过几段）；返回键回复述或守听（不删东西），小结页点 END 或头稳点头确认后清空本轮清单与计数。
6. **演示（DEMO）**：八段演示——START 开始守听 → 非命中句只听不存 → 命中吃药存 1 条 → 命中门锁存 2 条 → DONE 复述第 1 条 → CONF 确认第 1 条读第 2 条 → CONF 确认第 2 条全部确认 → END 出小结（叮嘱 2 条、已确认 2 条、只听过 3 段）；已有用户守听或用户清单进行时 DEMO 拒绝，绝不覆盖。

## 手势映射

| 手势/按键 | 动作 |
|---|---|
| 点按（Enter） | 待机：开始守听；守听中：忽略并说明（字幕只能由谈话声流进来）；复述中：确认当前条；小结页：确认并清空 |
| 双击（Backspace） | 小结页：回复述；复述中：回守听（清单与确认保留）；守听中：回待机（清单保留）；待机页：无动作并说明 |
| 上滑（ArrowUp） | 守听/复述中：下一条叮嘱；其他态：无动作并说明 |
| 下滑（ArrowDown） | 守听/复述中：上一条叮嘱；其他态：无动作并说明 |
| 头稳 + 点头 | 待机：开始守听；守听中：忽略并说明；复述中：确认当前条；小结页：确认并清空；不稳的点头不计入 1.2 秒锁；点头从不切换焦点、从不编句子 |
| 屏上按钮 | DEMO 演示 / START 开始守听 / MODE 换收音模式 / DONE 聊完复述 / CONF 确认当前条 / NEXT 下一条 / PREV 上一条 / END 结束出小结（小结页点 END 即确认清空）/ BACK 返回 / SPEAK 朗读当前状态 |

## 权限说明

- 只申请 `RECORD_AUDIO`（app.json 的 `permissions` 为 `["RECORD_AUDIO"]`，静态校验明确断言这一点）：守听聊天 + 宿主 ASR 转写需要麦克风。
- 不申请 `CAMERA`（没有任何拍照环节）、不申请 `GEOLOCATION`（Agent 从不知道你在哪）。
