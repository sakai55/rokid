# Light Change（光线变化）

**Studio 导入地址**（复制到 Global AIUI Studio 的 Import Project 输入框）：

```
https://github.com/sakai55/rokid/tree/agent-light-change
```

注意力外挂系列 E01（AMBIENT 环境型，本组第一个，系列第 46 个）。看书/做手工太投入，天黑了还在昏光里用眼，伤眼不自知。本 Agent 把「盯光线」外包出去：相机测光变化 + 定时回看，光线低于阈值在视线内提醒开灯。

## 解决的问题

光线变化的注意力是事后才到的：天黑了还在昏光里用眼，眼睛先抗议你才想起开灯。本 Agent 管四件事：测光（定时用相机拍一张，分级为明/偏暗/暗）、回看（定时回看最近一次测光结果）、提醒（暗级时视线内提醒开灯，横幅 + 一次语音）、小结（测光几次、提醒几次、开灯确认几次，确认后清空）。它不诊断、不承诺护眼效果——只负责让你看见光线暗了。

## 注意力外挂设计（AMBIENT 环境型）

- **没有环境光传感器，照片亮度只是近似**：本 Agent 的「测光」不是勒克斯读数，而是相机照片平均亮度的分级估计（明 ≥150、偏暗 ≥80、暗 ＜80），阈值是固定档位、没有校准。这一点 UI 与本 README 如实写明。
- **照片只用于当次测光、会话内即弃**：照片不存档、不上传、不展示——页面只保留分级（明/偏暗/暗）与计数。照片要是留下来，就是另一个 Agent、另一个权限故事。
- **偏暗只显示、不提醒；暗级提醒恰好一次**：偏暗读数只显示「偏暗」继续监测；暗级读数打开提醒并恰好出声一次（「光线暗了，开灯吧」），提醒开着时再暗也不重复提醒、不重复出声。
- **开灯确认是 LIGHT 或下次回明**：开灯后点 LIGHT 确认，提醒解除；下次测光回到明级也自动解除并计一次确认——房间亮了，提醒就没有存在的理由。点头既不测光也不确认开灯：读数来自相机，确认来自 LIGHT 或回明，点头不能凭空编一个。
- **定时重测是计时器，DEMO 会停掉它**：监测中每 10 分钟自动测一次；DEMO 停掉计时器，staged 帧才不会被实况 tick 漂移——DEMO 是 staged 样本，不是实况监测。
- **纠错便宜，销毁需确认**：监测页返回键回待机（本轮保留，START 恢复同一轮）；小结页返回键回监测（不删东西，小结重建）；确认（小结页点 END 或头稳点头）才清空本轮；没有 DEL 键。
- **不是医疗建议**：本 Agent 不诊断视力问题、不承诺任何护眼效果、不按你的眼睛状态调整阈值——阈值是固定档位。
- **为什么胸前设备做不了**：光线变化是「视线方向测光 + 视线内提醒 + 开灯确认」——胸前设备既不知道你眼前光线如何变化、也看不到你正在看的书，更没法把「光线暗了，开灯吧」钉在你眼前。测光、提醒、确认三条都只有头戴设备成立。

## 与邻近 Agent 的分工

- 注意力系列 `room-sweep`（C02）：出门前逐项扫视确认。本 Agent 不为确认拍照：它拍照的唯一用途是亮度分级，且当次即弃。
- 注意力系列 `eye-rest`（B01）：近视持续计时 + 满 20 分钟远眺提醒 + 抬头看远自动确认。本 Agent 不计时近视、不要求远眺：它定时测光、暗了提醒开灯。
- 注意力系列 `snack-aware`（B05）：零食方向登记 + 无声看向计数。本 Agent 不登记方向、不数看向：它测光、计提醒与开灯确认。

## 功能流程

1. **开始（START）**：点 START 开始监测，定时测光启动；头稳点头也可开始。
2. **测光（METER）**：监测中点 METER 测一次（相机拍一张，分级为明/偏暗/暗）；每 10 分钟也会自动测一次。
3. **提醒与确认（LIGHT）**：暗级时横幅 + 一次语音提醒开灯；开灯后点 LIGHT 确认，或等下次测光回明自动解除。
4. **结束与小结（END）**：监测中点 END 出小结（测光几次、提醒几次、开灯确认几次）；返回键回监测（不删东西），小结页点 END 或头稳点头确认后清空本轮。

## 权限

- CAMERA（`permissions: ["CAMERA"]`）：定时测光需要每读数拍一张照片。不录音、不定位。

## 手势映射

- 点按（tap / Enter）：待机 START 开始测光；监测中 Enter 测一次；小结页 END 确认清空。
- 双击（double-tap / Backspace）：返回上一态（监测→待机保留本轮；小结→监测不删东西）。
- 滑动（swipe / ArrowUp-Down）：在三行信息（最近测光 / 提醒开灯 / 开灯确认）间切换焦点。
- 头稳 + 点头（head-steady + nod）：待机开始测光；小结页确认清空；监测中的点头一律忽略（点头不是测光、也不是开灯确认）。
- 单指长按：唤出 AI 语音助手（系统默认）；双指长按：AI 快捷指令（固定文本，零 ASR 启动）。
