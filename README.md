# 节奏点头 Rhythm Nod

**Studio 导入地址**（复制到 Global AIUI Studio 的 Import Project 输入框）：

```
https://github.com/sakai55/rokid/tree/agent-rhythm-nod
```

头部动作小游戏系列 GA11，B 组（头当控制器）的节奏游戏，极简设计：一页、三态（准备 / 进行 / 完成），语音指导跟着节拍轻轻点头。先听 4 拍慢速准备（1、2、3、4），再跟 16 拍节拍点头：每拍间隔固定 1 秒，不加速，拍点前后 300 毫秒内点头就是打中。屏幕上只有当前拍数 x / 16、节拍指示（拍点闪烁）、得分和一行提示；点头本身就是游戏动作。

与 GA08（点头接球）不同：本游戏考的是点头对节拍的准度——点头早了、晚了、漏了都算这拍没打中，一拍只能点头一次，没有第二次机会。

## 系列宪法：颈部安全（GO 的规则）

**转圈是错误的。** 本游戏只用小幅轻轻点头：不转圈、不扫动、不快速甩头。点头即使踩在拍点上也保持小幅、不赶拍——节拍特意放慢到 1 秒一拍，就是为了不用甩头抢拍。慢、小幅度、到微酸即止。出现痛、晕、麻、恶心，立刻停。先坐稳 / 站稳。一局很短：16 拍，可重玩。本游戏是日常活动娱乐，**不是医疗诊断、治疗或康复处方**；有颈椎病、眩晕、术后、头颈伤史的人请先问医生。短版印在游戏内的准备屏上；完整版见 AGENTS.md。

## 玩法

1. **准备**：坐稳 / 站稳，头摆正，读一遍安全提示，点「开始」。
2. **数拍子**：语音先报「准备，1、2、3、4」，一秒一拍；数拍子时点头不算，安心听节拍。
3. **进行中**：数完 4 拍后 1 秒，第 1 拍到来；之后每 1 秒一拍，共 16 拍，绝不加速。拍点前后 300 毫秒内轻轻点头 = 打中（+1，语音「对」）。
4. **点头早了 / 晚了 / 漏了**：在拍点窗口之前点头，语音说「早了」；窗口之后、下个窗口打开之前（拍点后 300–700 毫秒）点头，语音说「晚了」；到下个窗口打开还没点头，语音说「漏了」——这拍都算没打中，一拍只能点头一次，没有第二次机会。
5. **完成**：16 拍走完，屏幕显示「对了 x / 16」，点「再来一局」重新数拍子。进行中点一下（真机）只重读提示，绝不会替你打拍——打拍只能靠点头。

| 单击 | Enter | 开始 / 进行中重读提示 / 完成时再来一局 |
| 双击 | Backspace | 系统返回（不拦截） |
| 长按 | — | 唤醒助手（系统级，不拦截） |
| 点头（头部手势） | `onHeadGesture('nod')` | 打拍——游戏的主动作，窗口内点头 = 打中 |

## 技术诚实说明

- **无眼动追踪**：平台没有眼动 API；打拍信号只来自官方文档化的点头事件与方向传感器（备用）。
- **头部手势事件官方文档只写了 `'nod'`**：本游戏不声称任何其他手势事件；点头事件是主打拍信号，传感器俯仰是备用信号，两者共用同一个「一拍一判」守卫，绝不会把同一拍算两次。
- **节拍与窗口（代码原样）**：节拍固定每 1000 毫秒一拍，无加速；数拍子 4 拍（开始后 +0 / +1000 / +2000 / +3000 毫秒，语音「准备，1、2、3、4」），数拍子时点头不算；进行阶段从开始后 +4000 毫秒起（语音「开始」），第 1 拍拍点在 +5000 毫秒，第 16 拍在 +20000 毫秒；打中窗口 = 拍点前后 ±300 毫秒；晚了区间 = 拍点后 300–700 毫秒；一拍在拍点后 700 毫秒推进到下一拍——正好是下一拍窗口打开的时刻（1000 − 300 毫秒）；拍点指示闪烁 200 毫秒；计时 tick 50 毫秒。
- **一拍一判（代码原样）**：点头处理只在进行阶段且本拍未判过时生效；打中、早了、晚了判负后，到下一拍窗口打开之前的点头一律忽略；数拍子、准备、完成中的点头一律忽略，绝不会漏进下一拍。最后一拍判负或判中后直接结束；最后一拍无点头时在拍点后 700 毫秒以「漏了」结束。
- **早了的诚实边界（代码原样）**：因为已判过的拍只在下一拍窗口打开时才推进，唯一能在窗口打开前仍待判的拍是第 1 拍——数拍子结束（+4000 毫秒）到第 1 拍窗口打开（+4700 毫秒）之间的点头算第 1 拍「早了」；之后的拍在成为待判拍时窗口已经打开，所以窗口前的点头只会是已判拍后的忽略，而非早判。早了规则是通用实现，不是只写给第 1 拍的特例，这个边界已如实说明。
- **拍点报数（代码原样）**：每拍拍点到来时，若该拍仍待判，语音报拍数（中文数字 1–16）；已判过的拍不报数，所以判罚语音不会被自己的拍数盖住。
- **备用点头（代码原样）**：方向传感器四元数算俯仰（GA01 同款公式 `pitch = asin(2*(w*x - y*z))`，只用相对开局校准中心的差值），俯仰低过 20 度再回正到 10 度内 = 一次备用点头。注意：轻轻的点头可能不到 20 度——备用路径需要一次明显的点头，这个限制已如实说明；主路径（点头事件）接轻轻的点头。俯仰下方向沿用 GA01 的假设（低头 = 负相对俯仰），若真机符号相反，备用路径只会不触发、绝不会误判，主路径不受影响。
- **传感器缺失 = SKIP / 演示，绝不假装通过**：网页预览没有方向传感器，屏幕明示 SKIP，演示按钮（「演示点头」）按当前拍点时间走同一套一拍一判流程，完成屏写「演示对了 x / 16」；真机有点头事件时没有演示路径。
- **零持久化**：不调任何存储 API；得分、拍状态与校准只活在页面内存里。

## 提审资料 (Review Submission)

### Feature Description

> Rhythm-nod game for Rokid glasses, voice-guided. Four slow count-in beats teach the tempo, then 16 beats follow one second apart at a fixed tempo. Nod gently within 300 ms of a beat to hit it; early, late and missed beats are called aloud, one nod per beat only. Score is hits out of 16. Small slow nods only, no circling, no jerking; stop at any pain. Entertainment only, not medical advice.

### Opening Message

> ## 节奏点头
>
> 坐稳，点一下开始：先听 4 拍慢速准备——语音报「准备，1、2、3、4」，一秒一拍，数拍子时点头不算。数完 1 秒后第 1 拍到来，之后每 1 秒一拍，共 16 拍，绝不加速。**拍点前后 300 毫秒内轻轻点头，就是打中**；早了说「早了」，晚了说「晚了」，到下个窗口打开还没点头说「漏了」——一拍只能点头一次，没有第二次机会。最后看你打中几个（满分 16 个），点一下再来一局。只小幅轻轻点头，不转圈、不甩头，痛、晕、麻、恶心立刻停。本游戏是日常活动娱乐，不是医疗建议。
