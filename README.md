注意力外挂系列 RE01（REVIEW 回顾型，本组第一位）。晚上复盘：今天看过的号码、答应的事、路过的店，全混成一团——白天每一眼都过去了，晚上想捡回来却想不起哪件是哪件。本 Agent 把复盘外包出去：白天每一次凝视登记一格（类型三选一：画面 / 数字 / 承诺 + 一句描述 + 你当时的朝向，自动带时间标记），晚上按时间顺序走一条注意力时间线，每格显示时间 + 朝向 + 类型 + 描述；FILTER 按类型过滤（只看画面 / 只看数字 / 只看承诺 / 看全部）；结束给一张本次复盘小结：各类型各几格、最早最晚时间。

## 解决的问题

复盘的注意力负担：白天看过的东西不是没看见，是没留痕——号码记在脑子里、答应的事记在嘴边、路过的店记在脚边，晚上全混成一团，想一件就得把一天重想一遍。本 Agent 管三件事：白天把每一眼凝固成一格（类型 + 一句话 + 朝向 + 时间），晚上按时间顺序排成一条线给你走，需要时按类型只看一类——复盘时你不用再重想一天，只要顺着线走。

## 注意力外挂设计（REVIEW 回顾型）

- **登记是凝固，不是记录**：MARK 记一格，包含四样东西——类型（画面 / 数字 / 承诺）、一句描述（你选的句子）、朝向（你登记时面对的方向）、时间（点按时的钟点）。四样里没有照片、没有录音、没有定位：描述是你自己记的一句话，不是拍照/录音原文；朝向是你登记时的头部方向，不是定位导航。
- **时间线按你记的顺序走，不重排、不猜测**：回放按登记顺序列出每一格，每格显示时间 + 朝向 + 类型 + 描述；朝向标记帮你想起「当时朝哪边看」，不是导航——顺着朝向想起来的是场景，不是路线。
- **过滤只筛类型，不筛内容**：FILTER 在全部 / 画面 / 数字 / 承诺间循环，只列该类型；某类型下没有格时明说「暂无此类型」，不编一条出来；过滤不删东西，换回全部就全在。
- **小结只数数，不总结**：结束小结列出各类型各几格、最早最晚时间——它不替你判断今天哪件事重要，重要性由你自己在回放时定。
- **单会话时间线，代价明说（诚实边界）**：登记与回放发生在同一次打开的会话内，关掉即清——白天记、晚上看需要当天一直开着它（或分段打开、当次看当次的），不做跨时段存档。这不是功能缺失的遮掩：舰队零落盘纪律不允许调用任何存储 API，是否要为本 Agent 破例由 GO 决定，在此之前宁可把代价写在屏上也不偷偷存下来。
- **点头只记格和走线，从不替你选**：头稳点头在登记时记一格、在回放时走下一格、在小结页确认清空；它从不切换类型、描述或朝向——那些是选择，点头不能替你默认选一个；不稳的点头不计入 1.2 秒锁。
- **纠错便宜，销毁需确认**：小结页返回键回到回放（不删东西，小结重建）；回放页返回键回到登记（格子全在）；确认（小结页点 END / 点按 / 头稳点头）才清空本次记录；没有 DEL 键。
- **只记本次会话，关掉即清**：格子、过滤、焦点、计数只存会话内存，关掉 Agent 即清——昨天的线对今天没有任何意义，存下来才是误导。
- **为什么胸前设备做不了**：复盘的线索是「你当时朝哪边看」——胸前设备不知道你的视线朝向，也就给不出朝向标记；时间线必须贴在视线里一眼走完（低头翻手机等于又一次离场，线走到一半就断了）。两条都只有头戴设备成立。

## 与邻近 Agent 的分工

- 注意力系列 `last-glance`（CO01）：离开存档模板——离开时按区拍照存档、事后回放。本 Agent 不拍照：它的「画面」是你选的一句话，时间线覆盖全天，不是一次离开。
- 注意力系列 `talk-replay`（RE02，下一个）：谈话回放模板——谈话字幕按朝向标注说话方，谈完回放只列承诺 + 数字 + 期限三类句。本 Agent 不是谈话：没有字幕、没有说话方、没有期限——它的格子是你标记的凝视，分画面 / 数字 / 承诺三类。
- 注意力系列 `queue-roam`（DU05）：同组模板——同一条点头纪律、同一条零落盘规则、同一条 DEMO 五段弧、同一条按钮带布局；但它的门是号段、提醒是号距。本 Agent 没有门、没有提醒：核心是记格 → 回放 → 过滤 → 小结。

## 功能流程

1. **白天登记（TYPE / DESC / DIR / MARK）**：看向目标停稳，TYPE 在画面 / 数字 / 承诺间选类型，DESC 在六句描述间选一句，DIR 在前方 / 左前方 / 右前方 / 左方 / 右方 / 后方间选朝向，MARK 记一格（自动带钟点）；点按或头稳点头都能记。
2. **晚上回放（REPLAY / NEXT / PREV）**：至少记了一格才能 REPLAY；时间线按登记顺序列出每一格，大字显示当前格的描述，小字显示时间 + 朝向 + 类型 + 第几格；NEXT/PREV 换格，点按行也能聚焦。
3. **按类型过滤（FILTER）**：回放中 FILTER 在全部 / 画面 / 数字 / 承诺间循环，只列该类型；某类型下没有格时显示「暂无此类型」，不编造。
4. **结束与小结（END）**：小结列出共几格、各类型各几格、最早最晚时间；返回键回到回放（不删东西），小结页点 END 或头稳点头确认后清空本次记录。
5. **演示（DEMO）**：五段演示——画面格（路过的店：街角便利店招牌，前方，示例）→ 数字格（看过的号码：车牌 沪A·12345，右前方，示例）→ 承诺格（答应的事：明天还书给小李，后方，示例）→ 回放过滤到承诺（3 格中只列 1 格）→ 小结（共 3 格：画面 1、数字 1、承诺 1）；已有用户登记或用户回放进行时 DEMO 拒绝，绝不覆盖。

## 手势映射

| 手势/按键 | 动作 |
|---|---|
| 点按（Enter） | 登记：记一格；回放：走下一格；小结页：确认并清空 |
| 双击（Backspace） | 小结页：回到回放；回放页：回到登记；登记页：无动作并说明 |
| 上滑（ArrowUp） | 登记/回放：下一格 |
| 下滑（ArrowDown） | 登记/回放：上一格 |
| 头稳 + 点头 | 登记：记一格；回放：走下一格；小结页：确认并清空；不稳的点头不计入 1.2 秒锁；点头从不切换类型、描述或朝向 |
| 屏上按钮 | DEMO 演示 / TYPE 选类型 / DESC 选一句 / DIR 选朝向 / MARK 记一格 / REPLAY 回放 / FILTER 过滤 / END 结束出小结（小结页点 END 即确认清空）/ SPEAK 朗读当前状态 / BACK 返回 / NEXT 下一格 / PREV 上一格 |

## 权限说明

- 不申请任何权限（app.json 的 `permissions` 为 `[]`，静态校验明确断言这一点）：凝视登记 + 时间线回放不需要拍照、录音或定位。
- 不申请 `CAMERA`（没有任何拍照环节：「画面」是你选的一句话，按区拍照存档是 last-glance 的活）、不申请 `RECORD_AUDIO`（没有任何收听环节：没有谈话字幕，谈话字幕是 talk-replay 的活）、不申请 `GEOLOCATION`（朝向是你登记时的头部方向，不是定位：Agent 从不知道你在哪）。
