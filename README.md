注意力外挂系列 P03（CUE 提示型，本组第三个，系列第 33 个）。坐到书桌前先刷十分钟手机才进入状态，站起来又忘刚才做到哪。本 Agent 把续接确认外包出去：看向书桌停稳才亮今日三件事——按你预设的三件事（写报告 / 回邮件 / 整理桌面）做完一项勾一项，起身时按未完成项给一句「回来从这继续」，全做完起身则说「三件事都做完了」。

## 解决的问题

坐到书桌前先刷手机不是没事做，是三件事没摆在眼前——做到哪全凭临场想起，站起来倒杯水回来就忘了刚才做到哪。本 Agent 管三件事：看向书桌停稳才亮三件事（不是一打开就弹，弹的时机就是你坐到书桌前的那一刻），做完一项勾一项（每项都要你本人点一下，含糊不得），起身时给一句续接（点名第一个没做完的，回来不用重新想）。

## 注意力外挂设计（CUE 提示型）

- **起身是你点的，不是检测到的**：TRIG 只在待机态、且头部停稳时亮三件事（真机上由头部停稳判定）；GOT 勾掉当前项；清单里的 UP 是起身——有未完成项时横幅与一次 TTS 给一句「回来从这继续：<首个未完成项>」，计起身 1 次，出小结并把续接句钉在里面；三项全做完起身则说「三件事都做完了」。UP 从不拦你起身：它只报告、只记录，假装检测到你站起来才是误导。
- **三件事是你预设的，不是日历同步的**：Agent 不读任何日历或任务应用——三件事就是你预设的（预览中以写报告 / 回邮件 / 整理桌面为 DEMO 示例）。它不声称同步，因为平台上没有这条路。
- **勾掉只是表态**：Agent 没有相机、麦克风、定位，也没有任何做事传感器——它不检测任务是不是真的做完了。GOT 记录的是你本人说「做了」。UI 与本 README 如实写明这一点。
- **看向触发，不是一打开就弹**：三件事只在你看向书桌停稳后才出现——触发时机贴在坐到书桌前的动作本身上，而不是靠你记得打开它；预览中触发由 DEMO 演示，真机上由头部停稳判定。
- **纠错便宜，销毁需确认**：小结页返回键回到三件事（不删东西，小结重建）；清单页返回键回到待机（已做保留，再触发恢复同一张三件事）；确认（小结页点 UP 或头稳点头）才清空本轮三件事；没有 DEL 键。
- **只记本轮坐桌，关掉即清**：三件事、已做、起身次数、小结只存会话内存，关掉 Agent 即清——上一轮的勾选对下一轮坐桌没有任何意义，存下来才是误导。
- **为什么胸前设备做不了**：触发的线索是「你正在看向书桌」——胸前设备不知道你的视线朝向，也就分不出「坐下要做事了」和「路过书桌」；续接句也必须贴在视线里一眼走完（低头翻手机等于又一次离场，刚回来就断了）。两条都只有头戴设备成立。

## 与邻近 Agent 的分工

- 注意力系列 `cue-door`（P01）：看向大门触发的出门清单凝视确认门——未全过不放行，缺项时 END 喊停并拦住。本 Agent 不是门：起身只报告续接句并记录，从不拦你起身。
- 注意力系列 `cue-fridge`（P02）：看向冰箱触发的待拿清单 + 缺货标记 + 关门前报漏拿（提醒不是拦门）。本 Agent 不是拿东西：它的触发是看向书桌本身，收尾是续接句，不是漏拿报告。
- 注意力系列 `attention-diary`（R05）：注意力账单——触发按分类计数，收尾是一句「偷走最多」。本 Agent 没有分类、没有账单：它的单位是三件事，收尾是续接 verdict。

## 功能流程

1. **触发（TRIG）**：看向书桌停稳，TRIG 亮三件事（待机时头不稳点 TRIG 会拒绝并说明先停稳）；三件事打开在第 1 项，3 项全列在下面。
2. **做完一项勾一项（GOT / NEXT / PREV）**：GOT 勾掉当前项（已做过的再点会拒绝）；NEXT/PREV 走项，点行也可聚焦；大字显示已做几项，小字钉住还没做哪几项。
3. **起身续接（UP）**：有未完成项时 UP 给一句「回来从这继续：<首个未完成项>」——横幅与一次 TTS，计起身 1 次，出小结并把续接句钉在里面；三项全做完起身直接出「三件事都做完了」小结。
4. **结束与小结（UP）**：小结列出已做几项、未完成是哪几项、起身续接句（或「三件事都做完了」）、起身几次；返回键回到三件事（不删东西），小结页点 UP 或头稳点头确认后清空本轮三件事。
5. **演示（DEMO）**：七段演示——亮三件事（0/3）→ 勾掉写报告 → 勾掉回邮件 → UP 起身续接（整理桌面）→ 返回三件事 → 勾掉整理桌面 → UP 起身出「三件事都做完了」小结；已有用户勾选或用户清单进行时 DEMO 拒绝，绝不覆盖。

## 手势映射

| 手势/按键 | 动作 |
|---|---|
| 点按（Enter） | 待机：亮三件事（需头稳）；清单：勾掉当前项；小结页：确认并清空 |
| 双击（Backspace） | 小结页：回到三件事；清单页：回到待机（已做保留）；待机页：无动作并说明 |
| 上滑（ArrowUp） | 清单/小结：下一项 |
| 下滑（ArrowDown） | 清单/小结：上一项 |
| 头稳 + 点头 | 待机：亮三件事；清单：勾掉当前项；小结页：确认并清空；不稳的点头不计入 1.2 秒锁；点头从不切换焦点 |
| 屏上按钮 | DEMO 演示 / TRIG 亮三件事 / GOT 勾掉当前项 / UP 起身给续接句与小结（小结页点 UP 即确认清空）/ NEXT 下一项 / PREV 上一项 / BACK 返回 / SPEAK 朗读当前状态 |

## 权限说明

- 不申请任何权限（app.json 的 `permissions` 为 `[]`，静态校验明确断言这一点）：看向触发 + 三件事提醒不需要相机、麦克风、定位。
- 不申请 `CAMERA`（没有任何拍照环节）、不申请 `RECORD_AUDIO`（没有任何收听环节：没有 ASR 路径，没有 onASRResult 处理）、不申请 `GEOLOCATION`（Agent 从不知道你在哪）。
