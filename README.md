一句话场景：初めての駅ホームで車椅子・ベビーカー利用者が並ぶ列とドア位置を頭振りで確認し、到着を見逃さない。

## 方向构成

日本在地 × 指向性 × 注意力：

- **日本在地**：山手線ホームの並び方・ドア位置という日本の駅日常そのもの（UI 全日语、駅名・側・車両号は日本の実在感覚に即した内容集）。
- **指向性**：頭の向き（yaw）が列選択の核心入力——左右を向いて列を選び、正面に戻る分段動作で確定する。
- **注意力**：到着までの守候（手動開始カウントダウン）と乗車記録の保持が各页承担的一环。

## 与 JP20 eki-dekake 的区别

JP20 `eki-dekake` は駅の出発まわり——昇降機のある側の確認＋シェア傘の借り・期限守候・返却確認＋出行記録。**本 Agent はホーム上だけに絞る**：並ぶ列とドア位置の確認＋到着守候＋乗車記録。**駅設備（昇降機・改札まわり）と傘は扱わない**。両者は駅シーンで接するが、担当する区間が重ならない。

## 结构与功能

三页，形态各异（横断ストリップ＋駅板／頭振りゲージ／大時計カウントダウン）：

- **駅ボード（pages/index）**：山手線 6 駅の横断ストリップ（●／○＋駅名＋レール線）と、引き継いだ駅の詳細（ホーム側・ドア位置・乗車記録件数）、二子页菜单（▶ 标记）。
- **並び確認（pages/queue）**：二段階。第 A 段階で 6 駅から選択（上下移動・Enter 決定）、第 B 段階で列を確認：頭の yaw（±20° 閾値）で左右の列を選び、上下キーでも選べ、点头または Enter で確定。確定時 TTS で「左側の列です。ドアは3号車・前寄りです」式に播报し、選択を保存。
- **到着守候（pages/arrival）**：手動開始の到着カウントダウン（1／3／5 分プリセット、上下で切替、Enter／点头で開始、1 秒 tick）。到着時に TTS 播报（確定した列とドア位置付き）し、乗車記録（駅・列・ドア・時刻）を追加。途中停止は記録しない。

内容集计数：駅 6 駅 ×（ホーム側＋ドア位置車両号）＝12 項（新宿 左側／3号車・前寄り・渋谷 右側／5号車・中央・池袋 左側／2号車・後寄り・東京 右側／7号車・中央・品川 左側／4号車・前寄り・上野 右側／6号車・後寄り）；列 2 項（左側の列／右側の列）；カウントダウンプリセット 3 項。跨会话持久化键：`homeNarabiV1`（選択駅・確定した列・乗車記録）。

## 手势映射

| 操作 | 镜腿／头部 | 作用 |
| --- | --- | --- |
| 上／下移动 | ArrowUp／ArrowDown | 总览：循环选子页；並び確認：駅／列的上／下一项；到着守候：プリセット切替 |
| 确认 | Enter | 总览：打开选中子页；並び確認：駅決定／列確定；到着守候：開始 |
| 左右转头 | yaw ±20° 以上 | 並び確認：第 B 段階で列を選択（分段动作、回正强制） |
| 点头 | onHeadGesture('nod') | 子页主动作（列確定／カウント開始） |
| 返回 | Backspace（镜腿双击）／BACK 按钮 | 回上一页；首页 onShow 时选中项复位为第 1 项 |

## 权限

无。TTS 用宿主固定音色，永不设置 utterance 的 `lang`。

## 诚实边界

- 駅のホーム側・ドア位置は内容集の固定値であり、列車のリアルタイム運行情報ではない；ダイヤ乱れ・車両変更には追従しない。
- 頭振り判定はセンサー読取であり、センサー不可用時はキー選択のみで、読取を装わない。
- 到着カウントダウンは手動開始の目安タイマーで、列車の到着検知ではない；乗り遅れ防止の補助にとどまる。
