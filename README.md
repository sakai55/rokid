头部动作小游戏系列 GA22，Wave 2，E 组（精准控制），极简设计：一页、三态（准备 / 进行 / 完成），语音一次只报一边一个小角度，凭把贴耳角度对准并停稳计分。一局 6 题：先坐稳 / 站稳，点一下开始：先校准一次（向左贴一下，记下左右），然后语音报「向左贴，12 度，肩膀别抬」，屏幕同时显示同一个目标（箭头 + 一边 + 度数）——耳朵慢慢向那侧肩膀贴，让侧屈角落进目标带（目标 ±5 度），语音说「停，稳住」，在带内停稳 0.8 秒，语音说「对上了」，对上数 +1，再回正到中间，下一题才报。屏幕上只有目标（箭头 + 一边 + 度数）、对上数 x / 6 和一行提示；你的贴耳本身就是游戏动作，由方向传感器对照开局那一刻的头向判定。

本游戏是 GA21（对角度）的侧屈轴对应版：GA21 在偏航轴上判角度精度（左右转头对带），本游戏在侧屈轴上判同样的精度（左右贴耳对带）。与 GA03（贴耳操）的区别：GA03 是贴到舒适极限、保持 5 秒的拉伸练习；本游戏对的是**小角度精度**：只对所报的小目标（12 度或 20 度，±5 度）并停稳 0.8 秒。把 12 度题贴到 20 度不算对上，必须退回带内重新停稳；中途离开目标带，停稳计时清零。

题目固定顺序（不是随机，预览与真机行为可复现）：（左，12°）、（右，20°）、（左，20°）、（右，12°）、（左，12°）、（右，20°），左右各 3 题；每题之间都必须回正到中间，故不可能出现转圈。

## 系列宪法：颈部安全（GO 的规则）

**转圈是错误的。** 只做分段动作：正中 → 向一边贴到所报角度 → 停住 → 回正到中间 → 下一题。每次只报一边一个角度，对上就回正，下一题只在回正后才报。绝不从一边直接扫到另一边，绝不快速甩动。贴耳要轻：耳朵向肩膀靠近，绝不硬压，**肩膀别抬**（不许耸肩去迎耳朵）——这句话每题语音都说。慢、小幅度、到微酸即止。出现痛、晕、麻、恶心，立刻停。一局很短：6 题，可重玩。本游戏是日常活动娱乐，**不是医疗诊断、治疗或康复处方**；有颈椎病、眩晕、术后、头颈伤史的人请先问医生。短版印在游戏内的准备屏上；完整版见 AGENTS.md。

## 玩法

1. **准备**：坐稳 / 站稳，头摆正，读一遍安全提示，点「开始」。
2. **校准（进行中，前置一步）**：屏幕显示「请向左贴一下」，耳朵慢慢向左肩贴一次——游戏记下你真实的向左贴方向（右即反方向）。这样宿主侧屈符号即使反了也不会算反。回正后第 1 题才报。重开一局会重新校准。校准完成前什么都不计分。
3. **对角度（进行中，每一题）**：语音报「向左贴，12 度，肩膀别抬」（或向右 / 20 度），屏幕显示同一目标。慢慢贴耳，侧屈角进入目标带（目标 ±5 度：12 度题判 7–17 度，20 度题判 15–25 度）时语音说「停，稳住」；在带内停稳 0.8 秒，语音说「对上了」，对上数 +1。
4. **没稳住 / 没对上**：停稳满 0.8 秒前离开目标带（退回或贴过头都一样），停稳计时清零、不计分，10 秒题目时钟继续走；向没报的那一边贴过 15 度，语音说「没对上」，本题 0 分；10 秒内没对上（包括停稳没停满时钟就到点），语音说「没对上」，本题 0 分。
5. **回正**：每一题结束后必须回正到中间（侧屈、俯仰、偏航三轴均 <10 度），下一题才报；4 秒内没回正，语音提醒「请回正」，宽限计时重置——宽限本身不计分，下一题也绝不提前报出（与 GA09 的宽限到期照常宣布不同，这是本游戏分段规则的硬性要求）。最后一题结束即直接出完成屏（没有下一题可等）。
6. **完成**：屏幕显示「对上 x / 6」，点「再来一局」重新校准、重新开始。进行中点一下（真机）是重读当前指令。

## 技术诚实说明

- **无眼动追踪**：平台没有眼动 API；头部方向只来自 `AbsoluteOrientationSensor`。
- **头部手势事件官方文档只写了 `'nod'`**：本游戏不声称任何手势事件，也不装点头事件处理；角度判定全部来自传感器四元数。
- **侧屈与俯仰 / 偏航公式（代码原样）**：侧屈 `roll = atan2(2*(w*x + y*z), 1 - 2*(x*x + y*y))`（GA03 同款），单位度；俯仰 `pitch = asin(2*(w*x - y*z))`（钳制后转度，GA01 / GA04 同款）；偏航 `yaw = atan2(2*(w*z + x*y), 1 - 2*(y*y + z*z))`（GA02 同款）。题目只判侧屈（所报目标都是左右贴耳角度）；俯仰与偏航只用于回正判定（三轴同 <10 度）。只用相对校准中心的差值，宿主的绝对零点不影响判定。
- **左右符号是学来的，不是假设的**：开局一次校准（请向左贴一下）记下玩家真实向左贴的符号，宿主符号反了也不会把左右算反；残留前提是玩家按提示动作——做反了会学反，重开即重新校准；校准完成前什么都不计分。
- **阈值**：目标带为所报角度 ±5 度；带内停稳约 0.8 秒（宿主上报稳定性事件时以稳定为准，不上报时以计时为准，已如实说明的回退，不是假装稳定）；贴错边过 15 度即判没对上；一题 10 秒无对上即判没对上；回正须侧屈、俯仰、偏航三轴同时 <10 度；回正宽限 4 秒（到期语音提醒请回正并重置计时，不计分、不提前报下一题）；校准触发为任意方向贴满 15 度（把实际动的方向学作向左），校准卡住 8 秒重提示一次，绝不自动计分。
- **题目顺序固定**：（左，12°）、（右，20°）、（左，20°）、（右，12°）、（左，12°）、（右，20°），不是随机。
- **传感器缺失 = SKIP / 演示，绝不假装通过**：网页预览没有方向传感器，屏幕明示 SKIP，演示按钮只走标注的演示路径（先演示校准，再每题对上一次，回正折叠），完成屏写「演示对上 x / 6」；真机有传感器时没有演示路径。
- **零持久化**：不调任何存储 API；对上数、题目序、中心与左右符号只活在页面内存里。
