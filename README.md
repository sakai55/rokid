# TR01 Trace Brush · 毛笔字描红练习

**Studio 导入地址**（复制到 Global AIUI Studio 的 Import Project 输入框）：

```
https://github.com/sakai55/rokid/tree/agent-trace-brush
```

描红系列 TR01：中央范本 + 边上步骤 + 做一步验一步。书法初学者在书桌前打开它，逐笔学一个范字，在自己面前的真纸上用真毛笔写，写完低头拍照验字——只查粗项，不装专业评分；进度跨会话保存，下次接着练。

## 功能（7 页闭环）

| 页 | 内容 |
|---|---|
| 今日 | 今日一字（按日期轮换）、上次练到哪、已练字数 / 累计次数 |
| 字库 | 20 字总表：每字标拼音、笔画数、练过次数，选字进学字页 |
| 学字 | **范字全屏**（v1.1.0 起；v1.3.0 再改）：画布占满整页，逐笔渲染（笔画本体统一低亮度——半透明淡绿，所有笔画所有状态一致；高亮只给笔顺标注）；范字为**空心描边**（字帖式空心字，只描边不填充），主体高度约 205px 居中（桌面描红距离口径：眼到桌面约 40cm、字帖格字约 9cm，屏上与纸上接近 1:1）；每笔一支**与字身分离的笔顺弧**（贝塞尔简化弧，与笔画轮廓之间留黑色间隙，逐采样点硬校验不进任何轮廓及其 6px 邻域，放不下就缩短或以终段小弧兜底），只保留末段约 1/4 的短弧 + 弧末实心箭头头（最亮绿，箭头方向按本笔行笔方向、不取短弧弦向），**笔顺数字**（圆圈序号）落在弧尾外侧，弧 / 数字统一高亮；底部窄栏只放「第 X 笔 / 共 N 笔（笔型）+ 本笔要点一句」与最少控件，TTS 同步念要点；逐笔推进，**当前笔位逐步落盘、重进同字自动恢复**（见下「平台边界」） |
| 字义笔法 | 读音、字义一句、结构、重心提示、逐笔类型清单 |
| 验收 | 低头对准自己写的字拍照，LLM 对照范字粗查三项：有没有少笔多笔、结构重心偏没偏、最明显的 1–2 处；看不清如实说、重拍 |
| 点评 | 一句人话点评 + 三项结果；用户可自己确认「这字算过」覆盖机器判定，覆盖落盘计数 |
| 进度 | 已练字集、每字次数、练习天数；复习抽查（只给拼音不给范字，凭记忆写完再验） |

## 字库与数据来源（双源，缺一不收）

- **分笔数据**：`hanzi-writer-data`（Make Me a Hanzi 项目）——逐字 JSON 的 `strokes[]` 逐笔 SVG 路径（序即笔顺）与 `medians[]` 中线点列。数据由 Arphic（文鼎）字体提取，依 **Arphic Public License** 再分发，许可证全文见工程内 `LICENSE-data.txt`。
- **笔顺校对**：《通用规范汉字笔顺规范》GF0023-2020（教育部、国家语委发布）。
- **收字结果**：20 字笔画数逐字核对通过——永 5、人 2、大 3、天 4、上 3、下 3、山 3、川 3、水 4、火 4、木 4、日 4、月 4、田 5、口 3、中 4、心 4、正 5、生 5、白 5。**纠正一处常见误记：永是 5 画**，「永字八法」说的是永字包含八种基本笔法，不是八画。20 字全为简繁同形，避开字形分歧。台湾教育部笔顺学习网数据因 CC BY-NC-ND（非商业 + 禁改作）与提审冲突，只作人工参考、不取数据。
- 逐笔要点（第 X 笔 · 笔型：起笔 / 行笔 / 收笔）为本系列自撰的练习提示，不是书法评分标准。

## 方向性 / 交互

核心 = SCAN（拍照验字）+ HEAD（点头执行 / 验收页点头拍照）。手势：点头 = 执行焦点；单指点按 = 确认（Enter）；上下滑 = 切焦点 / 选字；双击 = 返回（Backspace）。学字页 TTS 同步念每笔要点。

## 平台边界：描红进行中与熄屏

描红时用户低头对纸写字、手不离笔，没法腾手唤醒屏幕——理想是学字页进行中常亮。**查证结论（2026-10-29）**：官方文档全量（`documentation/` 479 篇）与 aiui-dev references 全量检索 `wakeLock / WakeLock / keepScreenOn / screenOn / 常亮 / 熄屏 / 息屏 / 灭屏 / 休眠` 等关键词，**没有任何 wake lock / 保持常亮的 API 或页面配置**；设备类 API 只有传感器 / 蓝牙 / 电量 / 条码，框架 Page / App 配置无屏幕项，微信兼容 API 列表亦无。按 API 清单纪律（文档查不到 = 不存在），本台**不做伪常亮实现**，熄屏与否由宿主决定、Agent 侧无法阻止。

已落地的缓解（v1.2.0）：学字页**当前笔位逐步落盘**（键 `trace.brush.learn`，交接键、非进度）；页面实例还在时回页按内存笔位原样重绘；实例被回收 / 退出重进时，进学字页按落盘笔位恢复到当前笔（同字才恢复，换字从第一笔起），明暗进度与离开时一致——熄屏后重新打开，抬眼仍是写到一半的那一笔。

## 提审资料 (Review Submission)

- **Feature Description**（≤500 字）：毛笔字描红练习：20 个常用字逐笔范字浮在眼前（空心字帖字，按桌面距离与纸上字接近 1:1 大小，范字笔画统一低亮度，每笔带高亮的笔顺数字和与字身拉开距离的短弧形笔顺箭头），跟着在真纸上用真毛笔写，写完低头拍照，只查少笔多笔、结构重心和最明显的差别，给一句人话点评；判定可由本人改判，进度保存、下次续练，写到一半熄屏重进仍回到当前笔，还有只给拼音的复习抽查。
