注意力外挂系列 AM02（AMBIENT 环境型，本组第二个，系列第 47 个）。晒着衣服/被子出门，天什么时候阴的完全没察觉，回来全淋透。本 Agent 把「盯天空」外包出去：出门前看向晾晒区登记，定时提醒回看天空，云层变化大时 TTS 预警。

## 解决的问题

天空变化的注意力是事后才到的：出门时天还亮着，云什么时候厚起来的完全没察觉，回来衣服全淋透。本 Agent 管五件事：登记（出门前看向晾晒区停稳记下）、提醒（每 30 分钟定时提醒回看天空，横幅、不出声）、测光（相机定时测光，分级为明/偏暗/暗）、预警（亮度显著下降时恰好出声一次）、小结（测光几次、提醒几次、预警几次、回看几次，确认后清空）。它不预报天气、不替你决定收不收——只负责让你在天变之前看一眼。

## 注意力外挂设计（AMBIENT 环境型）

- **它测不出天气，亮度下降只是代理信号**：本 Agent 没有天气预报、没有雨滴传感器。「云层变化大」是指相机照片亮度较上次下降两个档位（明 → 暗）；一档滑动（明 → 偏暗、偏暗 → 暗）只显示、不预警。亮度下降只是云层变厚的代理信号，不是下雨预报，这一点 UI 与本 README 如实写明。
- **照片只用于当次测光、会话内即弃**：照片不存档、不上传、不展示——页面只保留分级（明/偏暗/暗）与计数。照片要是留下来，就是另一个 Agent、另一个权限故事。
- **定时提醒不出声；云层预警恰好出声一次**：定时回看提醒只亮横幅、不打断你；亮度显著下降时横幅 + 恰好一次语音（「天空变暗了，可能是云层变厚，回去看看晾晒」），预警开着时再暗也不重复预警、不重复出声。一次只开一个横幅：横幅开着时定时提醒不重复计数。
- **回明自动解除预警，但不算回看**：下次测光回到明级，预警自动解除——天又亮了，预警就没有存在的理由；但它不计一次回看，只有你点 SKY 才算回看。读数不能替你编一次回看。
- **标记是你的决定，不是它的**：MARK 在「已看 / 要收 / 不收」间轮换，SKY 记录当前显示的那一个。Agent 永远不替你决定衣服收不收——「收不收衣服最终由你回看判断」写在 UI 与本 README 里。
- **登记要头稳，开始要先登记**：出门前看向晾晒区并停稳才能登记（晃着头登记会被拒绝）；没登记就点 START 会被拒绝。头稳点头在待机可登记（已登记则开始守望）。
- **点头既不测光也不确认回看**：读数来自相机，回看来自 SKY，点头不能凭空编一个。守望中的点头一律忽略并说明。
- **定时测光与定时提醒都是计时器，DEMO 会停掉它们**：守望中每 10 分钟自动测一次、每 30 分钟提醒一次回看；DEMO 停掉两个计时器，staged 帧才不会被实况 tick 漂移——DEMO 是 staged 样本，不是实况守望。
- **纠错便宜，销毁需确认**：守望页返回键回待机（本轮与登记都保留，START 恢复同一轮）；小结页返回键回守望（不删东西，小结重建）；确认（小结页点 END 或头稳点头）才清空本轮，且登记一并清空——下次出门再登记；没有 DEL 键。
- **为什么胸前设备做不了**：天空守望是「晾晒方向登记 + 视线方向测光 + 视线内提醒预警 + 回看标记」——胸前设备既不知道你晾晒区在哪、也看不到你头顶的天空变化，更没法把「天变暗了」钉在你眼前。登记、测光、预警、回看四条都只有头戴设备成立。

## 与邻近 Agent 的分工

- 注意力系列 `light-change`（AM01）：相机定时测光 + 光线低于阈值提醒开灯。本 Agent 复用同一套亮度分级，但先登记晾晒区、加定时回看提醒、只在两档大跌时预警——它从不提开灯。
- 注意力系列 `eye-rest`（BO01）：近视持续计时 + 满 20 分钟远眺提醒 + 抬头看远自动确认。本 Agent 不计时近视、不要求远眺：它定时测天空、亮度大跌时预警。
- 注意力系列 `snack-aware`（BO05）：零食方向登记 + 无声看向计数。本 Agent 也登记方向，但计的是测光、定时提醒、云层预警与带标记的回看——不是看向零食的次数。

## 功能流程

1. **登记（REG）**：出门前看向晾晒区并停稳，点 REG 记下；晃着头会被拒绝。头稳点头也可登记。
2. **开始（START）**：已登记后点 START 开始守望，定时测光与定时提醒启动；没登记会被拒绝。
3. **测光（METER）**：守望中点 METER 测一次（相机拍一张，分级为明/偏暗/暗）；每 10 分钟也会自动测一次。
4. **提醒与预警**：每 30 分钟横幅提醒回看天空（不出声）；亮度较上次下降两档时横幅 + 恰好一次语音预警。
5. **回看标记（MARK / SKY）**：MARK 在「已看 / 要收 / 不收」间轮换，SKY 记录当前标记并解除横幅；没有横幅开着时 SKY 会被拒绝。
6. **结束与小结（END）**：守望中点 END 出小结（测光几次、提醒几次、预警几次、回看几次）；返回键回守望（不删东西），小结页点 END 或头稳点头确认后清空本轮（含登记）。

## 权限

- CAMERA（`permissions: ["CAMERA"]`）：定时测光需要每读数拍一张照片。不录音、不定位。

## 手势映射

- 点按（tap / Enter）：待机 REG 登记晾晒区（已登记则 START 开始守望）；守望中 Enter 测一次；小结页 END 确认清空。
- 双击（double-tap / Backspace）：返回上一态（守望→待机保留本轮与登记；小结→守望不删东西）。
- 滑动（swipe / ArrowUp-Down）：在三行信息（最近测光 / 天空提醒 / 回看标记）间切换焦点。
- 头稳 + 点头（head-steady + nod）：待机登记或开始守望；小结页确认清空；守望中的点头一律忽略（点头不是测光、也不是回看确认）。
- 单指长按：唤出 AI 语音助手（系统默认）；双指长按：AI 快捷指令（固定文本，零 ASR 启动）。

## 如实说明

- 它测不出天气：没有天气预报、没有雨滴传感器，亮度下降只是云层变厚的代理信号，不是下雨预报；阈值是固定档位。

- 计数只在本次打开会话内有效：不调用任何存储 API，关掉即清；没有室内定位。
