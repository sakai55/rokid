**先说清楚一件关键事：眼镜测不到呼吸。** Rokid 眼镜没有呼吸传感器，本游戏的呼吸从来不是被测出来的——语音只定节奏（吸气 4 秒、呼气 4 秒），传感器测的只是转头和回正。准备屏、AGENTS.md 和这里都明说这一点，绝不假装眼镜能感知呼吸。

## 系列宪法：颈部安全（GO 的规则）

**转圈是错误的。** 本游戏每次呼吸只转一边，呼气一定回正再开始下一轮，绝不转圈，绝不左右连甩，绝不憋着一口气连转几轮。慢、小幅度、到微酸即止，不到疼痛；不憋气、不刻意深呼吸——按自己舒服的节奏呼吸，语音只定节奏，不开任何呼吸疗法处方。出现痛、晕、麻、恶心、喘不上气，立刻停。先坐稳 / 站稳。一局 8 次呼吸，很短。本游戏是日常活动娱乐，**不是医疗诊断、治疗、康复或呼吸疗法**；有颈椎病、眩晕、术后、头颈伤史、呼吸或心脏问题的人请先问医生。短版印在游戏内的准备屏上；完整版见 AGENTS.md。

## 玩法

1. **准备**：坐稳 / 站稳，头摆正，读一遍安全提示和「眼镜测不到呼吸」的说明，点「开始」。
2. **校准（仅一句提示）**：按提示慢慢向左转一下，Agent 记住哪边是左；再慢慢回正到中间。校准期间不计数。
3. **吸气（4 秒）**：语音「吸气，慢慢向左转」（或向右），左右交替（左、右、左、右、左、右、左、右）。吸气期间任何时刻转到提示的一侧（约 27°）就算转到了；吸气不要求停留，停留是回正的事。
4. **呼气（4 秒）**：语音「呼气，慢慢回正」。呼气期间任何时刻回到中心（偏航角与俯仰角都 <10°）就算回正了。转到了 + 回正了，这一轮才算跟上；缺一样都算没跟上，语音鼓励一句，继续下一轮。
5. **轮间停 1 秒**：上一轮结束停 1 秒，再开始下一轮的吸气。
6. **完成**：8 轮结束，完成屏报出跟上几轮（「跟上 x / 8 轮」），点「再来一局」重新校准中心与左右、再做 8 轮。完成之后再怎么转头都不再影响结果。
7. **回正保护**：上一轮没回正就进了下一轮吸气时，新的一转不算数——必须先经过中心（偏航角 <10°）再转到提示侧才算。还转着的头绝不会被悄悄算成新的一转。

## 技术诚实说明

- **无呼吸传感器，呼吸从不被测量**：眼镜没有呼吸传感器；本游戏是语音定节奏（吸气 4 秒、呼气 4 秒、轮间停 1 秒），传感器只判定转头与回正。任何「眼镜感知呼吸」的说法都是错的。
- **无眼动追踪**：平台没有眼动 API；头部方向只来自 `AbsoluteOrientationSensor`。
- **头部手势事件官方文档只写了 `'nod'`**：不声称转头、摇头、倾斜等手势事件；左右判定全部来自传感器四元数。
- **阈值**：提示侧约 25–30°（代码取 27°），回正带偏航角与俯仰角都 <10°，吸气 4 秒、呼气 4 秒、轮间停 1 秒，一局 8 轮、左右交替（左、右、左、右、左、右、左、右），偏航角公式为标准四元数转偏航角（`atan2(2*(w*z + x*y), 1 − 2*(y*y + z*z))`），俯仰角公式为 `asin(2*(w*x − y*z))`，只用相对校准中心的差值。
- **左右方向符号是学习的，不是假设的**：开局一句「请向左转一下」，玩家实际转过去的方向即被记为左，因此宿主偏航角符号即使反了也不会把左算成右。剩余注意事项：校准默认玩家按提示真的向左转——若反向转，符号会学反；但校准期间不计数，且第一轮又是向左（学反了立刻感觉不对），任何重开都会重新校准。真机验收必须确认：校准提示出现、真向左转能完成校准、之后真向左转计为左而非右、转了没回正的一轮不计数、上一轮没回正时下一转须先过中心才算、4 秒 + 4 秒节奏在真机上感觉舒服（不赶、不拖）。
- **传感器缺失 = SKIP / 演示，绝不假装通过**：网页预览没有方向传感器，屏幕明示 SKIP，演示按钮只走标注的演示路径（校准两步 + 每轮吸气一按、呼气一按，共 8 轮演示），完成屏写「演示完成」；真机有传感器时没有演示路径。
- **零持久化**：不调任何存储 API；中心、学到的左右符号、轮次与跟上数只活在页面内存里。

## 提审资料 (Review Submission)

### Feature Description

> Voice-paced breathing turns for Rokid glasses. Tap start: one prompt asks you to turn left once so the agent learns which way is left, then follow 8 breaths — inhale 4 seconds and turn to one side, exhale 4 seconds and return to center, sides alternating, 1 second between breaths. A breath counts only if you both turned and returned. Glasses cannot sense breath: voice sets the rhythm, the sensor checks only head movement. Never a circle. Entertainment only, not medical advice.

### Opening Message

> ## 呼吸转头
>
> 坐稳，头摆正，点一下开始：我先请你向左转一下，记住哪边是左，然后跟我做 **8 次呼吸——吸气 4 秒慢慢转到一侧，呼气 4 秒慢慢回正，左右交替**，轮与轮之间停 1 秒。
>
> 转到了、回正了，这一轮才算跟上；没跟上也没关系，下一轮继续。**先说清楚：眼镜测不到呼吸，语音只定节奏**，测的只是你的转头和回正。绝不转圈，不憋气，不刻意深呼吸。痛、晕、麻、恶心、喘不上气，立刻停下来。本游戏是日常活动娱乐，不是医疗建议。
