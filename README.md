注意力外挂系列 FI01（FILTER 过滤型，本组第一位）。深度工作最怕的不是没声音，而是不敢错过声音：环境里任何动静都可能重要，于是注意力被迫一直留一只耳朵在门外——这正是专注被偷走的方式。本 Agent 的做法：开一个会话门禁——会话进行时全向守听，只放行白名单：你预设的自己名字（示例名「小林」）和自定义关键词（如「开会」「找你」），命中时立即 TTS + 视线内横幅打断；白名单之外的一切响动，一律只记不报——音量突变只记一条时间线（时间 + 响度等级），不播报、不弹横幅，休息时的小结里才列出来。它不替你判断「这声重不重要」，它只替你执行一条你事先定好的规则：名单上的进来，名单外的等你休息时再看。

## 解决的问题

专注时段的注意力税：你不敢完全不听（怕错过喊你、找你的事），又不能全听（每个动静都打断思路）。结果是注意力被迫分一半去当门卫。本 Agent 把门卫外包出去：规则事先定好（名字 + 关键词），会话期间你只管工作；真正命中时它负责叫你，没命中时它只负责记账——休息时的小结告诉你：这段时间放行打断了几次、记录了几条响动，你可以回看，但不必当时被打断。

## 注意力外挂设计（FILTER 过滤型）

- **门禁只有两档，绝不混档**：放行档（打断）只对 ASR 转写文本匹配白名单——名字或关键词命中时 TTS + 横幅立刻打断；记录档（不打断）是音量突变的时间线——响度分低/中/高三档，只记不报，休息小结时回看。响动升级成打断的口子不存在：门禁一旦开了这个口子，门禁本身就成了打断源。
- **没有声音分类，这是第一位的诚实边界**：本平台没有声音分类 API、没有说话人识别，分不清门铃、报警和孩子哭——所以记录档条目永远标注「响动（未分类）」，界面、朗读、README 都明说：门铃/报警/孩子哭这类非语音声只能做到「响动记录 + 休息时回看」，**不能保证识别**（电平 ≠ 声音分类，沿用 WA01 的同款标注）。放行档只匹配 ASR 转写文本，也分不清是谁说的名字——它只认词，不认人。
- **设置只在待机时改**：时长（25/50 分钟预设）、白名单名字、关键词组只能在会话开始前换；会话中改设置会被拒绝并说明原因——信任中的门禁不能在你不注意时被改写规则。
- **暂停是真实的门状态**：暂停时转写命中、响动、手动记录一律忽略，状态行明说已暂停——暂停的护盾如果还记账，时间线就是假的；如果还打断，门禁就是假的。
- **纠错便宜，销毁两步**：会话中 DEL 只清横幅，绝不动时间线、不结束会话；整段会话记录只能在小结页 DEL 两下清空（6 秒内有效，其他动作取消）；小结页返回键回到会话而不删任何东西，小结在 END 时重建。
- **只记本次会话，关掉即清（诚实边界，第二位）**：全部内容只存本次会话内存，关掉 Agent 即清——适用窗口就是正在专注的这段时间，零隐私残留；下个会话重新从空白门禁开始，正是正确用法。
- **为什么胸前设备做不了**：门禁的横幅必须进视线（低头看胸口设备等于又一次离场）；白名单命中要立刻打断而不惊动旁人（胸口设备出声播报等于把打断扩散给全屋）；时间线要在休息时一眼扫全（语音逐条报一遍等于重新占用注意力）。三条都只有头戴设备成立。

## 与邻近 Agent 的分工

- `name-call`：报喊话的方位 + 内容——它回答「从哪喊的」；本 Agent 从不报方位，只决定「这次要不要打断你」。
- `cry-watch`：婴儿房守听——守一个房间、一种事件；本 Agent 守你自己的会话、白名单词，其他一律记账。
- `sound-compass`：转头定位声源——本 Agent 没有定位问题：白名单命中无论哪来都打断，记录条目不带方向。
- 指向性系列 `ambient-captions`：给一切配字幕——本 Agent 什么都不配字幕：专注时段的大多数声音本就不该到达你。

## 功能流程

1. **定规则（DUR / NAME / KW，待机时）**：DUR 在 25/50 分钟预设间切换；NAME 换白名单名字（示例：小林 → 阿哲）；KW 换关键词组（开会/找你 → 电话/找你 → 开会/电话）；会话中改设置会被拒绝。
2. **开始会话（START / 点按 / 头稳点头）**：会话进行中，状态行明说「白名单外一律只记不打断」；全向守听开始（预览环境无麦克风流时会软失败，会话仍可用 DEMO/手动记录）。
3. **放行打断（白名单命中）**：转写文本命中名字或关键词 → TTS 播报 + 视线内横幅留待回看；DEL 只清横幅，不动时间线。
4. **静默记录（响动 / NOTE）**：音量突变自动记一条（响度中/高，未分类）；NOTE 手动记一条；两者都不播报、不弹横幅。
5. **暂停（PAUSE / 返回键）**：暂停时命中、响动、手动记录一律忽略；恢复后继续。
6. **结束与小结（END）**：小结列出专注时长、放行打断次数、记录响动条数与时间线；返回键回到会话（不删东西），确认后清空本次记录。
7. **演示（DEMO）**：四段演示——会话开始（25 分钟，小林，开会/找你）→ 白名单命中横幅 + TTS → 两条响动静默记录 → 休息小结（放行 1 次，记录 2 条）；已有用户会话时 DEMO 拒绝，绝不覆盖。

## 手势映射

| 手势/按键 | 动作 |
|---|---|
| 点按（Enter） | 待机：开始会话；会话中：结束会话出小结；小结页：确认并清空 |
| 双击（Backspace） | 小结页：回到会话；会话中：暂停/恢复；待机：无动作并说明 |
| 上滑（ArrowUp） | 时间线下一条 |
| 下滑（ArrowDown） | 时间线上一条 |
| 头稳 + 点头 | 待机：开始会话；小结页：确认并清空；会话中：无效并说明（点头绝不结束会话）；不稳的点头不计入 1.2 秒锁 |
| 屏上按钮 | DEMO 演示 / START 开始 / PAUSE 暂停 / KW 换关键词 / NAME 换名字 / DUR 换时长 / NOTE 手动记录响动 / SPEAK 朗读当前状态 / DEL 清横幅、小结页两下清空 |

## 权限说明

- 只申请 `RECORD_AUDIO`（app.json 的 `permissions` 为 `["RECORD_AUDIO"]`，静态校验明确断言这一点）。
- 全向守听：getUserMedia 的 `microphoneMode: 'omnidirectional'` + AnalyserNode RMS（响度档）+ ASR 转写文本（白名单门）；两者都包在 try/catch 里，预览环境不可用时软失败。
- 不申请 `CAMERA`（没有任何拍照环节）、不申请 `GEOLOCATION`（专注会话不需要定位）。
