# 運動会集合 — Agent Notes

JP51。日本在地 × 指向性 × 路縁坡

## Design contract

運動会で子どもとはぐれた保護者が、両手がお弁当やカメラでふさがっていても、登録した集合場所へ方角と距離をたよりに戻る

## Counts

内容集の数：集合場所 6か所；方位 8方向；到着記録は実際の条数で数える。セッションをまたぐ永続化：ストレージキー `undoukaiShuugouV1`（選択場所、登録した集合場所の名称と緯度経度と登録時刻、到着記録の配列、`lastError`）。

## Storage

ストレージキー `undoukaiShuugouV1`。
