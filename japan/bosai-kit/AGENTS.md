# Bosai Kit — Agent Notes

JP04（japan 本地化系列）。交互哲学：**榻榻米覆盖格 Coverage Grid**。UI 形态：格阵：8 格大标记阵 + 当前格说明行。

## Design contract

本 Agent 把防灾包变成一张覆盖格：8 个品类一人一格，查过打 ●，过期或需更换打 △，没查是 ○。只有 8 格全部离开 ○，它才说「点检完了」。期限靠 telephoto 拍包装日期 + LLM 读年月（暂定，显示原文等你确认），或由你直接 FLAG。它不辨识灾害、不播报情报、不导航去避难所——那些是底座与自治体的事；它只证明一件事：这个包，今天真的被完整查过一遍。

## 在地性

日本家庭的防灾（防災）不是可选项：各自治体都发防災手册，超市有专门的防灾货架，防灾包讲究「备齐 + 没过期」。水、非常食、药品都有有效期，点检的难点从来不是认不认识这些东西，而是八个品类到底哪格查过、哪格过期。

## 闭环（与底座能力的分工）

- 覆盖：8 品类格阵（水/非常食/電灯/ラジオ/電源/常備薬/軍手/笛），滑动选格
- 点检：OK 落 ●、FLAG 落 △（过期/待换），点头 = OK；SCAN 拍期限作暂定メモ
- 收口：8/8 非 ○ 才报完了，并单独列出 △ 清单提醒更换

底座七项（实时翻译/实时字幕+历史/会议转写+摘要/提词器/慧眼问答/AR导航/语音笔记）均不构成其本体：识别或定位只在闭环中作一步出现且永远标暂定，失败即 SKIP。

## 诚实边界

- 期限读数来自拍照+LLM，属暂定信息：必须与包装原文对照，读错以包装为准；SCAN 失败即 SKIP，不影响手工点检
- 品目为东京常见防灾包构成，依各自治体手册增减是后续课题；本 Agent 不提供任何避难判断

## Permissions

`CAMERA`。TTS 用宿主固定音色，永不设置 utterance 的 `lang`（官方文档注明不生效）。
