# 習い事お迎え — Agent Notes

JP39（日本在地 × 路縁坡 × 注意力）。交互哲学：**お迎えのしおり**。一文の場面：習い事の送迎をする保護者が、今日のお迎えと持ち物を眼鏡で確認して迎えに行く。

## Design contract

入り口は習い事の一覧、過程はお迎えチェック、結果は記録。内容集は逐項数えられる。跨セッション永続化キー `naraiOkuriV1`。

## Page duties

- `pages/index/` 習い事一覧：習い事 6つとそれぞれのお迎えの時間と場所を表示する。
- `pages/check/` お迎えチェック：5 項目（迎えの時間、迎えの場所、持ち物、連絡先、帰りの交通手段）を項目ごとに切替え、5 つそろったときに音声で知らせて記録を残す。
- `pages/record/` 記録：直近 6 件の記録と合計を表示する。

## Counts

習い事 6つ、チェック項目 5つ。記録は実際の条数で数える。

## Storage

ストレージキー `naraiOkuriV1`（選択項目、チェック状態、記録の配列、`lastError`）。

## Gesture map

| ジェスチャ | キーイベント | 役割 |
|---|---|---|
| シングルタップ | Enter | 主確認 |
| 上スワイプ／下スワイプ | ArrowUp / ArrowDown | 前後の項目 |
| うなずき | onHeadGesture nod | 主確認と等価 |
| ダブルタップ | Backspace | 前のページに戻る |

## Validation notes

- ボタン形状は破線の枠つき四角で、他機と共用しない。
- 色は緑色階のみ。純白と白の rgba は使わない。
- 権限はなし。TTS とセンサーにマニフェストの権限は不要で、カメラの呼び出しはゼロ。
- 誠実な境界：お迎えの時間と場所は本人の登録内容であり、習い事の教室のシステムとは連動しない。
