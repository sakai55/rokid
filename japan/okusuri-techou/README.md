ワンセンテンスの場面：高齢者がお薬手帳を眼鏡で守る——服薬時刻を逃さず、残量と次回受診を一冊で管理する。

## 方向の構成

日本ローカル × カーブカット × 注意力：

- **日本ローカル**：お薬手帳は日本の薬局・受診制度に根ざした生活物で、薬の呼び名・服用時刻・受診の回し方が日本の日常そのものである（UI は全て日本語）。
- **カーブカット**：高齢者の服薬継続という具体的なバリアを先に立てる——時刻を覚えきれない、残量を見落とす、受診日を忘れる、という3つのつまずきに直接応える。
- **注意力**：服薬時刻の見守り（今日のチェック）、残量の見守り（7以下で警告）、受診の記録（前回＋30日）という保持モードが各ページで一環を担う。

## 構造と機能

3ページで、形態はそれぞれ異なる（手帳の表紙＋背表紙 / 横罫ページ / 台帳表）。

- **手帳の概要（pages/index）**：今日の服薬進捗（x / 6）、残量7以下の警告一覧、次回受診予定（前回受診日＋30日）、2つの子ページへのメニュー（▶ マーク）。
- **今日の服薬チェック（pages/medicine）**：薬6種——朝の血圧薬（7:00・朝食前）・昼の胃薬（12:30・昼食後）・夜の睡眠薬（21:30・就寝前）・食後のビタミン（8:30・朝食後）・週1回の骨の薬（日曜 9:00）・頓服の痛み止め（必要なとき）。うなずきか Enter で一つずつチェックする。チェックするとその日の分が永続化され、残量が1減る。6種がそろうと TTS で完了を読み上げる。
- **残量・受診記録（pages/record）**：6種の残量数（既定数 28 / 28 / 28 / 30 / 4 / 10、7以下は ⚠ を表示）。Enter かうなずきで、選択中の薬を既定数まで補充する。「受診日を記録」で当日を前回受診日として記録し、次回予定は前回＋30日とする。

コンテンツセットの数：薬6種（時刻・用法付き）、既定の残量6数、受診記録1件（前回日と、そこから導く次回予定）。セッションをまたぐ永続化キー：`okusuriTechouV1`（当日のチェック・残量・受診日）。

## ジェスチャー対応表

| 操作 | テンプル / 頭部 | 役割 |
| --- | --- | --- |
| 上 / 下への移動 | ArrowUp / ArrowDown | 概要：子ページを循環して選ぶ。子ページ：前 / 次の項目へ |
| 確認 | Enter | 概要：選択中の子ページを開く。子ページ：主な動作（チェック / 補充） |
| うなずき | onHeadGesture('nod') | 子ページの主な動作（チェック / 補充） |
| 戻る | Backspace（テンプルのダブルタップ）/ BACK ボタン | 前のページに戻る。ホームページの onShow 時、選択項目は1番目にリセットされる |

## 権限

なし。TTS はホストの固定音声を使い、utterance の `lang` は決して設定しない。

## 誠実な境界

- 服薬チェックは本人の申告（うなずき / ボタン）であり、実際に飲んだことの医学的な証明ではない。残量はチェック回数からの推定であり、薬の実物を数えたものではない。
- 残量の警告は7以下を目安とするものであり、処方・受診の判断は医師・薬剤師に委ねる。医療効果は主張しない。
- TTS は服薬時刻の案内のみを行い、服薬の指示・変更はしない。
