# ゴミ出しカレンダー — Agent Notes

JP38（日本在地 × 路縁坡 × 注意力）。交互哲学：**出し忘れ防止のしおり**。一文の場面：分別に迷う高齢者が収集日の朝、出すゴミと分別を確認して出し忘れを防ぐ。

## Design contract

入り口はゴミ種の一覧、過程は出す前チェック、結果は記録。内容集は逐項数えられる。跨セッション永続化キー `gomiCalendarV1`。

## Page duties

- `pages/index/` ゴミ種一覧：ゴミ種 8つとそれぞれの収集日の注記を表示する。
- `pages/check/` 出す前チェック：5 項目（分別済み、袋を縛った、収集場所を確認した、前夜か当日朝に出す、粗大ごみは申込済み）を項目ごとに切替え、5 つそろったときに音声で知らせて記録を残す。
- `pages/record/` 記録：直近 6 件の記録と合計を表示する。

## Counts

ゴミ種 8つ、チェック項目 5つ。記録は実際の条数で数える。

## Storage

ストレージキー `gomiCalendarV1`（選択項目、チェック状態、記録の配列、`lastError`）。

## Gesture map

| ジェスチャ | キーイベント | 役割 |
|---|---|---|
| シングルタップ | Enter | 主確認 |
| 上スワイプ／下スワイプ | ArrowUp / ArrowDown | 前後の項目 |
| うなずき | onHeadGesture nod | 主確認と等価 |
| ダブルタップ | Backspace | 前のページに戻る |

## Validation notes

- ボタン形状は丸みのある楕円形で、他機と共用しない。
- 色は緑色階のみ。純白と白の rgba は使わない。
- 権限はなし。TTS とセンサーにマニフェストの権限は不要で、カメラの呼び出しはゼロ。
- 誠実な境界：収集日と分別は本人の登録内容であり、市の収集システムとは連動しない。
