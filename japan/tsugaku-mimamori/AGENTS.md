# Tsugaku Mimamori — Agent Notes

JP26（日本在地 × 路缘坡 × 注意力）。一句话场景：小学生が眼鏡をかけて登校し、通学路のチェックポイントでうなずいて到着を記録し、帰宅後に記録を確認できる。

## 方向構成と各方向が担う一環

- 日本在地：日本の小学生の通学路（集合場所・横断歩道・公園前・踏切・コンビニ前・神社前・学校門・下校集合場所）そのものが場面であり、UI 文言はすべて日本語。
- 路缘坡：先行人群は通学児童（方向感覚・注意力が未発達で、道順の保持と到着確認に手助けが要る）。溢出先は方向感覚の弱い成人訪問者（初めての土地で道順を辿る人）であり、児童のための設計が薄まらない。
- 注意力：8 地点を順に盯守し、到着を 1 点ずつ記録して 8 点そろったことを確認する「見守り」閉環。未到達点は記録頁で提醒する。

## Design contract

- ルート总览（index）：8 地点をドットで結んだ通学路として一覧し、今日の登校の到達状況を ●／○ で示す。今日の登校／下校の進捗も数で出す。▶ 選択はチェック／記録の 2 行を ArrowUp/ArrowDown で循環し、Enter で開く。onShow で選択は必ず第 1 項（チェック）に復位するので、子頁から戻った直後の Enter は必ず pages 配列第 2 項（チェック）を開き、ArrowDown 1 回＋Enter で第 3 項（記録）を開く。子頁の戻りはすべて wx.navigateBack。
- チェック（check）：現在の地点を大きく表示し、その地点の一句话特徴を出す。うなずき／Enter で到着にチェックを入れ、時刻を記録する。ArrowUp/ArrowDown で前／次の地点に移る。登校／下校はボタンで切り替える。8 点そろったら「登校完了」／「下校完了」を TTS で播报する。
- 記録（record）：登校／下校の記録を日ごとに端末から読み、到達数と未到達点を示す。▶ 選択は登校／下校の 2 行を ArrowUp/ArrowDown で循環し、Enter で未到達点の提醒を読み上げる。

## インタフェース

- TTS：guarded な speechSynthesis helper。utterance に `lang` は決して設定しない。
- ストレージ鍵：`tsugakuMimamoriV1`（{ days: { 'YYYY-MM-DD': { to: [時刻|null × 8], from: [時刻|null × 8] } } }）。
- 権限：なし。位置情報は使わず、到着は本人のうなずき／Enter による申告のみで記録する（GPS による自動判定はしない）。

## 诚实边界

- 到着記録は本人の申告であり、眼鏡が位置を測った証明ではない。画面と記録はその旨に沿って「チェック」として扱う。
- センサー（うなずき検出）が使えない場合は Enter／ボタンでも記録できることを evt 行に示す。
