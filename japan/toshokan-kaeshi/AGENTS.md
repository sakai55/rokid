# 図書館返却 — Agent Notes

JP36（日本在地 × 注意力 × カーブカット）。交互哲学：**返却のしおり**。一文の場面：図書館の利用者が、借りた本の返却期限を眼鏡で逃さずに守る。

## Design contract

入り口は借りた本の一覧、過程は返却・延長チェック、結果は返却記録。内容集は逐項数えられる。跨セッション永続化キー `toshokanKaeshiV1`。

## Page duties

- `pages/index/` 借りた本一覧：本 8冊とそれぞれの返却期限を表示する。
- `pages/check/` 返却・延長チェック：本ごとに返却か延長を確認する。返却方法は 3つ（カウンター、返却ポスト、延長）から選ぶ。確認した時点で返却記録を残す。
- `pages/record/` 返却記録：直近 6件の返却記録（本と方法）を表示する。

## Counts

本 8冊、返却方法 3つ。記録は実際の条数で数える。

## Storage

ストレージキー `toshokanKaeshiV1`（選択項目、返却済みの状態、返却記録の配列、`lastError`）。

## Gesture map

| ジェスチャ | キーイベント | 役割 |
|---|---|---|
| シングルタップ | Enter | 主確認 |
| 上スワイプ／下スワイプ | ArrowUp / ArrowDown | 前後の項目 |
| うなずき | onHeadGesture nod | 主確認と等価 |
| ダブルタップ | Backspace | 前のページに戻る |

## Validation notes

- ボタン形状は角ばった左線つきで、他機と共用しない。
- 色は緑色階のみ。純白と白の rgba は使わない。
- 権限はなし。TTS とセンサーにマニフェストの権限は不要で、カメラの呼び出しはゼロ。
- 誠実な境界：期限は本人の登録内容であり、図書館システムとは連動しない。
