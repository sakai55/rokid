# Nomikai Kanji — Agent Notes

JP08（japan 本地化系列）。交互哲学：**干事账簿 Host Ledger**。UI 形态：居酒屋传票：右对齐金额列 + 终电大字倒计时。

## Design contract

本 Agent 就是干事的那本账：人数、品目合计、人均（自动按 100 円单位向上凑整，这是割り勘的在地规矩）、终电倒计时，全在一张传票上。它永远不录音、不转写、不总结你们聊了什么——会议转写是底座能力，也不是酒桌需要的东西；它只记钱、人头和时间这三样干事必须持有的数字，点头即结账确认。

## 在地性

日本の飲み会里，幹事（组织者）是最操心的角色：数人头、控节奏、算割り勘（还要照顾到100円単位的凑整礼仪）、盯終電。干事自己往往喝不好——注意力全在账本上。

## 闭环（与底座能力的分工）

- 记账：+ITEM 逐品累加（演示单价 ¥1,200/品）、+PERSON 调人数，人均自动 100 円凑整
- 守时：TRAIN 轮换终电时刻预设，倒计时以分钟常驻传票底部大字
- 结账：点头 = 结算确认，播报人均金额；全程零录音零转写，关页即忘

底座七项（实时翻译/实时字幕+历史/会议转写+摘要/提词器/慧眼问答/AR导航/语音笔记）均不构成其本体：识别或定位只在闭环中作一步出现且永远标暂定，失败即 SKIP。

## 诚实边界

- 单价与终电时刻为演示预设（单价 ¥1,200、终电三档），实际请按当店与当线修改登记（README 有方法）；合计是登记之和，不是收银小票
- 倒计时按分钟粒度走字，不联网校时；跨零点的终电以预设分钟数计

## Permissions

none。TTS 用宿主固定音色，永不设置 utterance 的 `lang`（官方文档注明不生效）。
