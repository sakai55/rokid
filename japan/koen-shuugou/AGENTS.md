# 公園集合 — Agent Notes

JP48。日本在地 × 路縁坡 × 指向性

## Design contract

公園で散らばった高齢者の集まりで、眼鏡をかけた高齢者が携帯を出さずに GPS の方角と距離で登録した集合ベンチへ戻る

## Counts

内容集の数：集合場所 6つ；到着記録は実際の条数で数える。セッションをまたぐ永続化：ストレージキー `koenShuugouV1`（集合場所の緯度・経度・登録時刻、到着記録の配列、`lastError`）。

## Storage

ストレージキー `koenShuugouV1`。
