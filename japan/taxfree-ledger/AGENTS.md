# Taxfree Ledger — Agent Notes

JP11（japan 本地化系列）。交互哲学：**免税账本 Taxfree Ledger**。UI 形态：护照本页：阈值横条 + 店铺三行账 + 大字合计。

## Design contract

本 Agent 是一本只记免税的账：按店铺记一般物品与消耗品两笔金额，合计满 5,000 日元线才算该店达标，达标后由你亲手确认密封袋已封。店铺一换，账就换一页；达标店数单独计数。它不判断免税资格（最终判断在店铺收银台，界面明写），不扫条码、不识商品，只守「凑线与封袋」这两件事。

## 在地性

日本免税购物（Tax Free）是外国游客在店内当场适用的制度：同一店铺同一天购物满线才能免税，消耗品必须装进密封袋且在日本境内不得开封，护照要在店头出示。最容易出错的不是价格，而是「这家店到底凑够线没有、密封袋到底封了没有」。

## 闭环（与底座能力的分工）

- 分店记账：同一店铺内一般物品与消耗品分开加（各按 1,000 日元一档手动加），合计实时对照 5,000 日元线
- 封袋确认：合计达线后 GO/点头才把密封袋记为已封，并 TTS 一句「日本国内では開けないでください」
- 换店结算：换店时若该店已达线，达标店数 +1，否则不计，账页清零重记

底座七项（实时翻译/实时字幕+历史/会议转写+摘要/提词器/慧眼问答/AR导航/语音笔记）均不构成其本体：识别或定位只在闭环中作一步出现且永远标暂定，失败即 SKIP。

## 诚实边界

- 5,000 日元线是本账本的目安合计口径，实际免税可否、分类口径与退税手续以店铺收银台的判断为准，界面明示
- 密封袋是否真的封好、护照是否出示，均由本人确认，Agent 只记确认结果，不做光学核验
- 金额为手动登记（无收银系统对接），输错请用换店前复核，关页后账本即忘

## Permissions

none。TTS 用宿主固定音色，永不设置 utterance 的 `lang`（官方文档注明不生效）。
