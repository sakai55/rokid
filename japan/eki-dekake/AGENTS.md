# Eki Dekake — Agent Notes

JP20（日本在地 × 路缘坡 × 指向性）。精品线合并重做：由 JP14 `kasa-share` 与 JP16 `eki-barrier` 按同一场景（车站出行）合并，原两个 Agent 原样封存。交互哲学：**駅ボード＋傘フロー＋記録 Station Board / Umbrella Flow / Trip Record**，三页结构。

一句话场景：雨天或初到车站时，行动不便者在眼镜上完成一段车站出行——先找到有电梯的一侧，再借共享伞、守住归还期限、最后确认归还。

## Design contract

- 駅ボード（index）：6 个车站的设施集（电梯侧/位置、伞点、归还期限小时数）常驻显示；上下滑选站，点头/GO 把车站定为「前回駅」并写入持久化；AbsoluteOrientationSensor 实时显示头部朝向（左/右/正面）与该站电梯侧对照。
- 傘フロー（kasa）：借りる登録→期限守候（30 秒刷新剩余分钟）→返却確認；返却只由本人确认（按钮/点头），确认即写入出行记录并清掉贷出状态。
- 記録（record）：出行记录（日期/时刻/车站/环节）与最常用车站，跨会话持久化（wx storage `ekiDekakeV1`），可由本人清空。

底座七项均不构成其本体：不用 AR 导航（电梯侧靠本人转头对照传感器读数）、不用语音笔记（记录是结构化出行账）。

## 诚实边界

- 车站设施集是内置的 6 站数据，不联网、不保证实时变更；伞的在库与可借状态 Agent 不知道、不代断。
- 传感器不可用时明确显示「センサーなし（手動で確認）」，不假装读数；返却済みは本人の確認だけが記す。

## Permissions

none。TTS 用宿主固定音色，永不设置 utterance 的 `lang`（官方文档注明不生效）。传感器与 wx storage 不需要权限声明。
