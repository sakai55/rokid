# 日本旅行手帳 — Agent Notes

JP42（日本在地 × 集合総控 × 注意力）。交互哲学：**旅の手帳一冊**。一文の場面：日本を旅する人が20の旅行道具を一本の手帳で回し終える。

## Design contract

入り口は旅行道具20種のハブ、過程は各道具のチェック・クイズ・声で伝える言葉・数え上げ、結果は進み具合と旅行記録。内容集は逐項数えられる。跨セッション永続化キー `nihonTabiHubV1`。

## Counts

道具20種、チェックリスト11ページ・計51項目、クイズ4ページ・計12問（各3択・計36選択肢）、定型文2ページ・計8文、数え上げ2ページ（目標5か所と4回）。全体の進み具合の分母は 80（チェック51＋クイズ12＋定型文8＋数え上げ9）。t20 の済み数と総数は表示枠6に対する直近記録数であり、全体の進み具合の分母には入りません。記録は実際の件数で数えます。

## Storage

ストレージキー `nihonTabiHubV1`（選んだ道具 `selected`、道具ごとの済み数と総数 `tools.<tXX>`、チェック状態 `marks`、数え上げ状態 `counts`、クイズ状態 `quiz`、伝えた言葉 `spoken`、完了記録の配列 `records`、`lastError`）。ハブは開く前に `selected` を保存し、道具ページは固定の `tXX` 鍵で書き込みます（ハブの選択位置に依存しません）。

## Validation notes

- 色は緑色階のみ。純白と白の rgba は使わない。
- ページの帯とボタンの形は種類ごとに変えてあり、チェックリスト2種・クイズ・声で伝える言葉・数え上げ・記録・ハブで計7種の見た目です。
- 権限はなし。TTS と頭の動きの検出にマニフェストの権限は要らず、カメラの呼び出しはゼロ。
- 誠実な境界：各道具の内容は収録済みの定型内容であり、生の時刻表や在庫の情報は出しません。
- 検証：`app.json` の pages 21件と `pages/` のディレクトリが一致し、21ページのファイルに同一バイトのものはなく、禁止 API の grep はゼロです。スクリーンショットとパックは本工程では作っていません。
