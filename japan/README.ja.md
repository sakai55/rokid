- JP04 [bosai-kit](bosai-kit/) — 防災バッグの品目と有効期限を二重に登録して点検する
- JP05 [onsen-gate](onsen-gate/) — 温泉の入浴前に門を1つずつ通る。先に洗ってから浸かる

- JP07 [yamanote-courtesy](yamanote-courtesy/) — 通勤の降車1駅前に、礼儀動作をリマインドする
- JP08 [nomikai-kanji](nomikai-kanji/) — 飲み会幹事の帳簿：人数・回数・割り勘・終電
- JP09 [omiyage-cover](omiyage-cover/) — お土産の贈り先リストを1人ずつ照合して、漏れをなくす
