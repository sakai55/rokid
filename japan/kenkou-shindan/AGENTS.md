# 健康診断準備 — Agent Notes

JP35（日本在地 × カーブカット × 注意力）。交互哲学：**健診のしおり**。一文の場面：健診をひかえた人が、前日の準備と当日の流れを眼鏡で忘れずに進める。

## Design contract

入り口は健診確認、過程は前日準備チェック、結果は受診記録と次回のメモ。内容集は逐項数えられる。跨セッション永続化キー `kenkouShindanV1`。

## Page duties

- `pages/index/` 健診確認：当日の流れ 6つと検査項目 8つを切り替えて確認する。持ち物 5つも表示する。
- `pages/check/` 前日準備チェック：前日チェック 8項目を一つずつ確認する。絶食と持ち物を含む。全部そろった時点で TTS で読み上げ、完了記録を残す。
- `pages/record/` 受診記録と結果フォロー：直近 6件の記録と次回の受診メモを表示する。

## Counts

流れ 6つ、検査項目 8つ、持ち物 5つ、前日チェック 8項目。記録は実際の条数で数える。

## Storage

ストレージキー `kenkouShindanV1`（選択項目、チェック状態、完了記録の配列、次回のメモ、`lastError`）。

## Gesture map

| ジェスチャ | キーイベント | 役割 |
|---|---|---|
| シングルタップ | Enter | 主確認 |
| 上スワイプ／下スワイプ | ArrowUp / ArrowDown | 前後の項目 |
| うなずき | onHeadGesture nod | 主確認と等価 |
| ダブルタップ | Backspace | 前のページに戻る |

## Validation notes

- ボタン形状は丸みのある太枠で、他機と共用しない。
- 色は緑色階のみ。純白と白の rgba は使わない。
- 権限はなし。TTS とセンサーにマニフェストの権限は不要で、カメラの呼び出しはゼロ。
- 誠実な境界：生活補助であり、医療診断や治療の助言ではない。
