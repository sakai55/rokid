# Jinja Bow — Agent Notes

JP02（japan 本地化系列）。交互哲学：**身体即输入 Ritual Sequence**。UI 形态：竖版绘卷：左侧竖线串起参拜步骤，逐格点亮。

## Design contract

参拜的难处是双手要空出来、眼睛要看着神前，没法盯屏幕点按钮。本 Agent 把整套序列装进眼镜：你只管低头——鞠躬的深度就是确认键。每一步只显示一行，做完一步才亮下一步；二拝需要真的鞠两次躬，拍手步需要你拍完手再点头确认（拍手声感应不了，如实说明）。它不辨识神社、不讲解神话（那是慧眼问答的事），只守着「顺序」这一件事。

## 在地性

日本神社参拜有一套身体记住的顺序：一の鳥居前一揖、手水舎净手漱口、拝殿前摇铃、二拝二拍手一拝。顺序错了不失礼，但心里没底；拿着手机查顺序又破坏了参拜本身。

## 闭环（与底座能力的分工）

- 序列守候：6 步固定序列（鳥居一揖→手水→摇铃→二拝→二拍手→一拝），当前步满亮，其余半亮
- 身体确认：头部俯仰传感器测鞠躬（相对基线 >16° 再回正 = 一揖），或点头/单击确认，传感器缺失自动降级
- 诚实分工：拍手无法被传感器证实，该步只接受本人确认，界面明写「拍手は自己確認」

底座七项（实时翻译/实时字幕+历史/会议转写+摘要/提词器/慧眼问答/AR导航/语音笔记）均不构成其本体：识别或定位只在闭环中作一步出现且永远标暂定，失败即 SKIP。

## 诚实边界

- 鞠躬角是相对头部基线的俯仰变化，不是礼仪评分；阈值 16° 为待真机标定值，README 已注明
- AbsoluteOrientationSensor 不可用时全程降级为点头/单击确认，序列逻辑不变
