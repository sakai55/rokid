# Coin Locker — Agent Notes

JP05（japan 本地化系列）。交互哲学：**寄存格账本 Locker Ledger**。UI 形态：储物柜段格：柜门号阵列 + 大字柜号 + 中身/场所行。

## Design contract

本 Agent 只做一张寄存账：存入时登记柜号（滑动选号）、中身一件（ITEM 切换）、场所固定写明在状态里；保管中它只显示这三件事；取回时先亮出中身名让你核对，TAKE 才记取回完成。它不帮你找空柜（那要看车站的实时空位屏）、不导航回柜子（底座的事）、不替你保管密码——它只保证你寄存的那一格，被完整地记住并核对着取回。

## 在地性

日本车站的コインロッカー是旅行与通勤的基础设施：大站按大中小分柜、Suica 或现金开锁、超时按日加算、三日无人取走移交遗失物。寄存时真正的风险从来不是柜子安不安全，而是人记不住——几号柜、在哪个口、哪一层、里面放了什么，回程时站在几百个柜门前发呆。

## 闭环（与底座能力的分工）

- 选格：滑动在演示柜号间切换，STORE 登记存入（柜号+中身锁定）
- 持有：保管中只显示柜号/中身/场所与加算目安，不催不扰
- 取回：TAKE 前先亮中身名核对，确认后记取回完了，格子清空

底座七项（实时翻译/实时字幕+历史/会议转写+摘要/提词器/慧眼问答/AR导航/语音笔记）均不构成其本体：识别或定位只在闭环中作一步出现且永远标暂定，失败即 SKIP。

## 诚实边界

- 柜号与场所是本人登记的备忘，不是与车站系统的实时联动；空位、费率、保管期限以车站告示为准
- 演示柜号与场所为新宿站西口的示例值，真机使用时按实际柜号登记
