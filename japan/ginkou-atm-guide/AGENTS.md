# 銀行ATM案内 - Agent Notes

JP69. 日本在地 × 指向性 × 注意力 × バリアフリー。指向性は手続きを選ぶ役目、注意力は確かめることを一つずつ守る役目、バリアフリーは年を重ねた人にも分かりやすい段取りの役目。

## Design contract

銀行のATMの前で、両手に荷物を持った人が、頭を向けて手続きを選び、うなずいて一つずつ確かめ、終わったら記録を残す。

## Counts

手続き6つ（引き出し／預け入れ／振り込み／残高照会／通帳記帳／暗証番号変更）×確かめること4つ（案内を読んだ／金額を確かめた／暗証番号を入れた／明細を受け取った）、全部で24の確かめどころ。記録は件数で数える。

## Storage

保存キー `ginkouAtmGuideV1`（選んだ手続き、手続きごとの確かめた数、ATM案内の記録、lastError）。

## Gesture map

| 単指タップ | Enter | 主確認 |
| 上下スワイプ | ArrowUp / ArrowDown | 選択切替 |
| うなずき | onHeadGesture('nod') | 主確認と同じ |
| ダブルタップ | Backspace | 戻る |

## Honest boundaries

- 手続きの中身は案内どおりで、銀行ごとの画面とちがうところがある。
- お金の動きはこの台では行わない。ATMの画面が正しい。
- センサーが使えないときはボタンで手続きを選べる。

## Validation

- 日本語純度：簡体字特有の字 0、韓国語 0（静的検査）。
- 禁止リスト grep：0件。
- 独占接線：pages/index/index.ink の _startSensor（存在性ガード）＋ _onYaw（±0.35 で手続きを替え、正面に戻ると再び構える）＋ onHeadGesture('nod') が主確認と同じ。
- センサー読取失敗は E7001。
