# Matsuri Taiko — Agent Notes

JP15（日本在地 × 指向性 × 游戏）。交互哲学：**祭り太鼓リズム Festival Drum**。一句话场景：夏祭りの待ち時間、家族が頭の動きだけで太鼓リズムを叩く。

## Design contract

本 Agent 只守一本账：当前项、确认状态、完成轮次。NEXT 选下一项，DONE 确认当前项，PREV 回上一项；点头（头稳时）等价于主确认；SPEAK 随时播报当前状态。全部项确认后计一轮，可反复使用。DEMO 只演示状态机，退出后真实状态原样恢复。

## 闭环（与底座能力的分工）

- 登记：当前项大字显示，进度以标记行表示。
- 确认：确认只由本人（按钮/点头）作出，Agent 不自动判定完成。
- 结算：全部项确认后轮次 +1；内容集（各项）与多步流程构成厚度。

底座七项（实时翻译/实时字幕+历史/会议转写+摘要/提词器/慧眼问答/AR导航/语音笔记）均不构成其本体。

## 诚实边界

- 採点は本人の完了確認による。Agent はリズムの正確さを自動判定しない。
- 動きは分段のみ：中心→一方向→戻る→次方向。首を回す動きは一切使わない。

## Permissions

none。TTS 用宿主固定音色，永不设置 utterance 的 `lang`（官方文档注明不生效）。
