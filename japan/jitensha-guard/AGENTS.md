# Jitensha Guard — Agent Notes

JP10（japan 本地化系列）。交互哲学：**运动锁闭 Motion Lockout**。UI 形态：极小面：骑行中一屏只剩一行大字，其余全黑。

## Design contract

本 Agent 的交互哲学是反交互：停车时它是点检单（ブレーキ/タイヤ/ライト/鍵逐项确认），一旦判定骑行中（GEO 速度或陀螺仪活动），主界面立刻塌缩成一行大字「走行中 — 画面は見ないで」，所有按钮按下只回 LOCKED（功能全部失效），只在状态切换时用 TTS 说一句话。它不导航、不测速显摆、不记录轨迹（那是底座导航与运动 App 的事）；它存在的意义就是在你骑车时拒绝被使用，并把这份拒绝做得理直气壮。

## 在地性

日本是自行车大国，也是规矩大国：ながらスマホ（骑车看手机）已入罚则，傘さし、イヤホン、並進都被交规点名。骑行中任何「看一眼屏幕」的设计，都是在诱导违法。

## 闭环（与底座能力的分工）

- 点检：停车状态逐项 CHECK（4 项），全过才显示「出発できます」
- 锁闭：速度 >2.2m/s 或陀螺活动超阈 → 骑行相：按钮全失效、屏幕单行化、仅 TTS 报状态切换
- 解锁：停稳 3 秒自动回到点检相；传感器全缺失时用 MODE 手动切换骑行相（SIM 为练习）

底座七项（实时翻译/实时字幕+历史/会议转写+摘要/提词器/慧眼问答/AR导航/语音笔记）均不构成其本体：识别或定位只在闭环中作一步出现且永远标暂定，失败即 SKIP。

## 诚实边界

- 骑行判定依赖 GEO 速度/陀螺仪，地下与隧道可能失效；判定不了时如实显示「判定不可」，并默认按停车相处理但播报提醒
- 本 Agent 不测距不测速存档；交规条文以日本现行道路交通法为准，罚则细节请查官方

## Permissions

`GEOLOCATION`。TTS 用宿主固定音色，永不设置 utterance 的 `lang`（官方文档注明不生效）。
