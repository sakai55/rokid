# 駅伝応援 - Agent Notes

JP74. 日本在地 × 注意力 × 指向性。日本在地が駅伝の沿道応援という場を、注意力が通過する走者を見分けて時刻を残す役を、指向性が頭の向きでチームをえらぶ役を担う。

## Design contract

駅伝の沿道で応援する人が、両手に旗と手荷物を持ったまま頭の向きでチームをえらび、うなずいて通過時刻を記録する。

## Counts

駅伝チーム6つ（青山学院大学／駒澤大学／東洋大学／早稲田大学／順天堂大学／國學院大學 — 第103回箱根駅伝の出場校一覧、日本テレビ番組公式サイトで確認）× 全10区間。選手名は入れない。記録は「通過時刻＋区間」だけ。

## Storage

保存キー `ekidenCheerV1`（えらんだチーム、応援記録、lastError）。

## Gesture map

| 単指タップ | Enter | 主確認 |
| 上下スワイプ | ArrowUp / ArrowDown | 選択切替 |
| うなずき | onHeadGesture('nod') | 主確認と同じ |
| ダブルタップ | Backspace | 戻る |

## Honest boundaries

- 通過時刻はうなずいた瞬間の手動記録で、公式計時を名乗らない。
- チーム名は実在の大学名だけで、選手名は入れない。
- 一回の向きでは一チームだけ変わり、中へ戻らないとまた変えられず、くるくる回らない。
- センサーが使えないときはボタンでえらぶ。応援の記録は変わらない。センサー失敗は E7001 を残す。

## Validation

- 日本語純度：簡体字特有の字 0（静的検査。学は日本語の新字体で、学校／大学の字として既存の日本 Agent にもあるため、検査の簡体字集合から除いた）。
- 禁止リスト grep：0件。
- 独占接線：pages/index/index.ink の _startSensor + _onYaw（中へ戻って再武装）＋ pages/play/index.ink のうなずきで通過を記録。
- 6チーム名は第103回箱根駅伝の出場校一覧で確認した実在の大学。
