# Kaiten Tally — Agent Notes

JP12（japan 本地化系列）。交互哲学：**传送带盘数 Conveyor Tally**。UI 形态：传送带横条：皿数带 + 大字合计 + 三色盘价行。

## Design contract

本 Agent 是传送带边的盘数账：白盘 110 日元、红盘 220 日元、黑盘 330 日元，吃一盘按颜色加一盘，合计实时就是结账目安。它不识寿司、不判断好不好吃，只数盘子；结账时 GO 一次锁定合计，再 GO 一次为下一桌清零。最后点单（ラストオーダー）时间必须问店员，界面明写不替你报。

## 在地性

回转寿司（回転寿司）的价格按盘子颜色定：不同颜色对应不同单价，吃完把盘子摞起来，店员数盘结账。最容易乱的是「到底吃了几盘、每种颜色几盘」，尤其一桌人一起吃、盘子混在一起时。

## 闭环（与底座能力的分工）

- 按色计数：白/红/黑三色盘各一键，吃一盘加一盘，合计与总盘数实时更新
- 传送带带：上方一条皿数带，皿数一目了然，空桌时明写「まだ皿はありません」
- 结账锁定：GO 锁定合计并 TTS 报数，再 GO 为下一桌清零，锁定期间加盘无效

底座七项（实时翻译/实时字幕+历史/会议转写+摘要/提词器/慧眼问答/AR导航/语音笔记）均不构成其本体：识别或定位只在闭环中作一步出现且永远标暂定，失败即 SKIP。

## 诚实边界

- 盘价（白 110/红 220/黑 330）是本账本的目安价目，各店价目不同，以店内标价为准，界面明示
- 盘子由本人按颜色手动加，Agent 不用相机数盘，数错请在结账前复核
- ラストオーダー与店内规则以店员与店内告示为准，Agent 不做实时查询

## Permissions

none。TTS 用宿主固定音色，永不设置 utterance 的 `lang`（官方文档注明不生效）。
