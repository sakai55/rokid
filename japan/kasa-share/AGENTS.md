# Kasa Share — Agent Notes

JP14（日本在地 × 路缘坡 × 注意力（HOLD/WATCH））。交互哲学：**駅前シェア傘帳簿 Umbrella Ledger**。一句话场景：雨天駅前、片手・車椅子の人がシェア傘を借りて返し忘れない。

## Design contract

本 Agent 只守一本账：当前项、确认状态、完成轮次。NEXT 选下一项，RETURN 确认当前项，PREV 回上一项；点头（头稳时）等价于主确认；SPEAK 随时播报当前状态。全部项确认后计一轮，可反复使用。DEMO 只演示状态机，退出后真实状态原样恢复。

## 闭环（与底座能力的分工）

- 登记：当前项大字显示，进度以标记行表示。
- 确认：确认只由本人（按钮/点头）作出，Agent 不自动判定完成。
- 结算：全部项确认后轮次 +1；内容集（各项）与多步流程构成厚度。

底座七项（实时翻译/实时字幕+历史/会议转写+摘要/提词器/慧眼问答/AR导航/语音笔记）均不构成其本体。

## 诚实边界

- 返却先・期限は本人の登録だけを守る。駅の傘在庫や返却可否は Agent は知らないし決めない。
- 返却済みは本人の確認だけが記す。Agent が返却を代行することはない。

## Permissions

none。TTS 用宿主固定音色，永不设置 utterance 的 `lang`（官方文档注明不生效）。
