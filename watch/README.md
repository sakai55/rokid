# 守望型 WATCH（watch/）

注意力外挂系列 · 编号 WA01–WA05，共 5 个。你专心做 A，它替你盯着 B。

- WA01 [stove-watch](stove-watch/) — 多锅看向登记计时，沸腾溢锅叫你回看
- WA02 [bath-watch](bath-watch/) — 浴缸放水登记守听，水满前叫你关水
- WA03 [laundry-watch](laundry-watch/) — 洗衣结束蜂鸣守听，第一时间叫你晾衣
- WA04 [signal-watch](signal-watch/) — 医院/银行/取餐叫号，大屏节律提醒回看，差3号喊你准备
- WA05 [door-watch](door-watch/) — 里屋开会戴耳机，守听门铃敲门快递叫你回看

完整清单见 [仓库根 README](../README.md) 文末的 Agent 清单。
