# 見守り型 WATCH（watch/）

[中文](README.md) | [English](README.en.md) | 日本語
中文版（2026-10-29 時点）からの翻訳。

注意力アドオンシリーズ · 番号 WA01–WA05、全5件。あなたが A に集中する間、B を代わりに見守る。

- WA01 [stove-watch](stove-watch/) — 複数の鍋を向いて登録しタイマー開始、沸騰して吹きこぼれたら呼び戻す
- WA02 [bath-watch](bath-watch/) — 浴槽の湯張りを登録して聞き守り、満水になる前に呼び戻して止水させる
- WA03 [laundry-watch](laundry-watch/) — 洗濯終了のブザーを聞き守り、すぐに干すよう呼び戻す
- WA04 [signal-watch](signal-watch/) — 病院・銀行・受け取りの呼び出し番号、大画面のリズムで振り返りを促し、3番前になったら準備を呼びかける
- WA05 [door-watch](door-watch/) — 奥の部屋で会議中ヘッドホンを着けていても、ドアベル・ノック・宅配を聞き守り呼び戻す
