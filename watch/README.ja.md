# 見守り型 WATCH（watch/）

[中文](README.md) | [English](README.en.md) | 日本語
中国語版（2026-10-29 時点）の翻訳。

注意力アドオンシリーズ。WA01–WA05、全5件。A に集中している間、B はこちらが見ておく。

- WA01 [stove-watch](stove-watch/) — 鍋を1つずつ見て登録しタイマーを開始。沸騰して吹きこぼれたら呼び戻す
- WA02 [bath-watch](bath-watch/) — 風呂の湯張りを登録して音を聞き張り、満水になる前に呼んで止水させる
- WA03 [laundry-watch](laundry-watch/) — 洗濯終了のブザーを聞き張り、終わったらすぐに干すよう呼び戻す
- WA04 [signal-watch](signal-watch/) — 病院・銀行・受け取りの番号呼び出し。大きな画面のリズムで振り返りを促し、3番手前で準備を呼びかける
- WA05 [door-watch](door-watch/) — 奥の部屋で会議中、イヤホンをしていても、チャイム・ノック・宅配便を聞き張って呼び戻す

全リストはルートの [README](../README.md) 末尾にある Agent リストを参照。
