跟 G13 的区别要讲清：G13 是明牌找方向（语音报「请看向左」，屏幕还给箭头）；这个是暗牌猜方向——只给距离，不给方向，全靠慢慢找。跟 G05 的区别是：G05 是按顺序报点位，这个是秘密顺序、按距离找。

## 系列宪法：颈部安全（GO 的规则）

**转圈是错误的。** 本游戏每次只找一个方向，找到要停稳、回正，下一轮才报，绝不转圈，绝不从一边直接扫到另一边，绝不快速甩动。慢、小幅度、到微酸即止；上方向只到轻微拉伸，绝不用力往后仰。出现痛、晕、麻、恶心，立刻停。先坐稳 / 站稳。一局 5 轮，很短。本游戏是日常活动娱乐，**不是医疗诊断、治疗或康复处方**；有颈椎病、眩晕、术后、头颈伤史的人请先问医生。短版印在游戏内的准备屏上；完整版见 AGENTS.md。

## 玩法

1. **准备**：坐稳 / 站稳，头摆正，读一遍安全提示，点「开始」。
2. **校准（两句提示）**：按提示慢慢低一下头（记住哪边是下），回正；再慢慢向左转一下（记住哪边是左），回正。校准期间不计数。
3. **猜（每轮）**：语音只报「第 x 轮，猜猜看是哪个方向」。屏幕只显示距离词（还远 / 近了 / 很近了 / 到了附近，停稳），**不显示箭头、不显示方向名**。慢慢转头找：距离带只在变化时才报一次，不重复刷屏。
4. **找到**：头离秘密方向 ≤12° 且停稳 0.8 秒，语音「猜对了，是向左」（或下、右、上），+1。提前松开不算，停稳计时从零重来。
5. **没猜中**：20 秒内没找到，语音「时间到，是向左」（揭晓答案），+0。
6. **回正**：每轮结束（找到或没猜中）都要回正到中间（偏航角与俯仰角都 <10°），下一轮才报；4 秒没回正语音提醒「请回正」，不回正绝不出下一轮。
7. **完成**：5 轮结束，完成屏报出猜对几轮（「猜对 x / 5」），点「再来一局」重新校准中心与上下左右、再猜 5 轮。秘密顺序固定（左、下、右、上、右），轮与轮之间都回正，所以顺序本身不会带出转圈。

## 技术诚实说明

- **无眼动追踪**：平台没有眼动 API；头部方向只来自 `AbsoluteOrientationSensor`。
- **头部手势事件官方文档只写了 `'nod'`**：不声称转头、摇头、倾斜等手势事件；方向判定全部来自传感器四元数。
- **阈值**：秘密方向为沿自身轴 27°（25–30° 带）；距离带为 ≤12°「到了附近，停稳」/ ≤25°「很近了」/ ≤45°「近了」/ >45°「还远」；停稳 0.8 秒（离带即清零）；每轮 20 秒超时；回正带偏航角与俯仰角都 <10°，4 秒未回正语音提醒且下一轮绝不提前报出；距离公式为 sqrt(偏航差² + 俯仰差²)，只用相对校准中心的差值（俯仰角 `asin(2*(w*x − y*z))`，偏航角 `atan2(2*(w*z + x*y), 1 − 2*(y*y + z*z))`）。
- **上下左右符号是学习的，不是假设的**：开局两句「请低一下头」「请向左转一下」，玩家实际动过去的方向即被记为下、左，因此宿主符号即使反了也不会算错方向。剩余注意事项：校准默认玩家按提示真的低头、左转——若反向做，符号会学反；但校准期间不计数，任何重开都会重新校准。真机验收必须确认：两句校准提示出现且真动作能完成校准、之后真低头计为下而非上、真左转计为左而非右、秘密方向在轮结束前绝不显示或报出、距离带只随移动变化且只在变化时报一次、轮间回正是硬门（4 秒未回正只提醒不进下一轮）。
- **传感器缺失 = SKIP / 演示，绝不假装通过**：网页预览没有方向传感器，屏幕明示 SKIP，演示按钮只走标注的演示路径（校准四步 + 每轮一按即猜对，共 5 轮演示），完成屏写「演示猜对」；真机有传感器时没有演示路径。
- **零持久化**：不调任何存储 API；中心、学到的上下左右符号、轮次与猜对数只活在页面内存里。

## 提审资料 (Review Submission)

### Feature Description

> Guess the hidden direction on Rokid glasses — no arrow, no name, only distance. Tap start: two prompts (look down, turn left) teach the agent down and left, then play 5 rounds. Each round hides one direction; voice reports only how far away it is — far, close, very near, near. Slowly turn toward it and hold steady 0.8 seconds within 12 degrees to find it; 20 seconds without a find is a miss, revealed only at the round's end. Return to center before the next round. Never a circle.

> ## 猜方向
>
> 坐稳，头摆正，点一下开始：我先请你低一下头、向左转一下，记住哪边是下、哪边是左，然后玩 **5 轮——每轮藏一个方向，不显示、不报名字，只报远近**：还远、近了、很近了、到了附近。
>
> 慢慢转头找，听到「到了附近，停稳」就停住 0.8 秒，报「猜对了」才算找到；20 秒没找到算没猜中，语音才会揭晓答案。每轮结束都要回正到中间，下一轮才报。绝不转圈，不快速甩动。痛、晕、麻、恶心，立刻停下来。本游戏是日常活动娱乐，不是医疗建议。
