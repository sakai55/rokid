## 1. 世界观

### 1.1 一句话

现实世界之上叠着一层看不见的「字界」：每个地方被人看过、走过、用过，就会慢慢积出文字——一段描述、一个名字、一段记忆。戴上眼镜的人能读到这层世界，也能往里写。玩家就是这样的「读界人」。

### 1.2 基底规则（世界观即玩法规则，不许违背）

1. **地方先有，字后到。** 字界里没有预先写好的地图：一间房只在一个真实地点被读界人亲手拍下、写下之后才存在。所以每个玩家的世界图都不一样，都是自己走出来的。——对应核心机制：拍照建房。
2. **物久成灵。** 被人长期使用的物（长椅、邮筒、贩卖机、老树）会在字界里生出「物灵」：有名字、有脾气、记得发生过的事。物灵只从物生，从不从真人生成（同时是安全红线，见架构 §11）。——对应 NPC 系统。
3. **字会褪，影会生。** 无人到访、无人记述的地方，文字会慢慢褪掉，褪字的角落生出「蚀影」——没有名字、只会抹掉描述的敌对存在。蚀影不是恶魔，是「被遗忘」本身。——对应战斗系统与主线动力：玩家出门拍照，就是在给世界补字。
4. **方向是真的。** 字界的东南西北与现实严丝合缝：你面朝哪边拍，出口就开在哪边；两个地方在现实里隔多远，在字界里就隔多远。——对应走 / 动玩法与 GPS 规则。
5. **话能通灵。** 对物灵说话，它会应答，也会记住你说过什么、答应过什么。——对应说玩法与 NPC 记忆。

### 1.3 主线脉络（章节按世界规模解锁，不按日历）

- **序章 · 第一间房**：玩家拍下自己的第一间房，遇见第一个物灵，学会看 / 走 / 摆 / 动 / 说五件事。（= 阶段 1 的 5 步样板主线链）
- **第一章 · 褪字的街角**：家附近出现第一处褪字角落与第一只蚀影；打完学会战斗与回房休整。
- **第二章 · 物灵的委托网**：多个物灵之间互相认识，任务开始跨房连锁（一家的钥匙在另一家手里）。
- **第三章 · 远行**：世界图扩到 30 间房以上，出现需要专程前往的地标房与守关蚀影（Boss）。
- **第四章 · 别人的字**（阶段 3）：第一次读到其他读界人写下的共享房——同一地点，两种描述。
- **终章方向 · 大褪字**（阶段 4）：多人共同补写一处大型公共场所（车站 / 公园），异步接力 + 同地回合制收尾。终章细节等阶段 3 数据回来再定，不在本版写死。

### 1.4 基调与文案口径

- 温暖、好奇、略带旧纸味；不恐怖、不血腥、不末世。蚀影的描写走「空、淡、没写完」，不走惊吓。
- 房间描述 60–120 字，一段成文，有物、有光、有声响，不堆形容词；NPC 台词短句，一次不超过 3 句。
- 全部生成文案过两条线：不出现真实人名地名之外的隐私信息；不给出现实行动指令（「去某地」类目标只指向玩家自建房间，架构 §11）。

## 2. 核心循环

```
出门/在家 → 拍一间新房（看） → 房里遇物灵、接任务（说）
→ 按任务走/摆/动完成验证 → 回报结算（经验+界尘+道具）
→ 偶遇蚀影打一场（战斗） → 回「家房」休整、整理背包、逛物灵商店
→ 世界图变大 → 解锁新章、新物灵、新任务链
```

单次游玩节律按真实生活走：一次打开 3–10 分钟办一两件事，不设计长在线；没有每日签到、没有限时消失奖励、没有连续登录惩罚（架构 §11 第 7 条）。

## 4. 交互系统（专章，眼镜侧的命门）

三通道分工写死，任何页面都按此执行，不许一页一个发明：

| 通道 | 负责什么 | 不负责什么 |
|---|---|---|
| 镜腿手势 | 单击 = 确认 / 选中；双击 = 返回 / 打断播报回上层；滑动 = 在选项、出口、背包格之间移动焦点；长按（单指）只唤醒系统助手，不占游戏功能 | 不做连续操作（翻页流靠滑动逐项） |
| 头部动作 | 转头 = 把焦点指向方向性选项（出口四向、战斗目标方位）；头稳 0.8 秒 = 高亮锁定；点头 = 确认方向性选择与判定结果 | 点头不代替一切确认——花钱、删档、弃任务这类重操作必须镜腿单击二次确认 |
| 语音 | 说 = 对 NPC 自由说话、口令选战斗行动（「攻击」「逃跑」）、口述手动录入房间（判定兜底） | ASR 连续失败 2 次自动切预置台词 / 手势选择，不让玩家对着空气反复喊 |

页面通则：一屏一个决策点；正文（房间描述、NPC 台词）TTS 自动播报一段、屏显同文分页；所有可选项编号呈现（滑动按编号顺序走焦点）；每页底部一行固定格式状态条：`房名 · ♥HP · 界尘数 · 当前任务一句话`。手势映射表随每台 README 发布（SOP 既有规则）。

概念图就是按本章口径画的（见配套 10 张概念图），阶段 1 开发时页面结构以概念图为起点，但图是概念稿不是实现截图，冲突时以本章文字为准。

## 5. 角色成长系统

- **等级**：经验来源只有四种（建房、任务、战斗、首次到达锚点房——架构 §4.5）。等级阈值初版：累计经验 0 / 30 / 80 / 160 / 280 / 450 …（阶段 1 只做 1–5 级）。
- **五维**（与五种玩法一一对应，玩什么涨什么）：
  - 洞察（看）：拍照判定与找物；
  - 脚力（走）：步行任务与移动；
  - 巧手（摆）：手势与精细操作；
  - 身法（动）：转头、闪避与先手；
  - 亲和（说）：对话与物灵好感。
  每维 1–10，靠对应玩法积累熟练度升级，与等级分开计。
- **技能**：每维 2 个，共 10 个，阶段 2 上线；阶段 1 只在角色页展示五维与熟练度条。例：洞察 3 级解锁「细看」——看任务判定时多给一条提示行；亲和 3 级解锁「记性好」——NPC 记忆 facts 上限 12→18。
- **称号**：里程碑授予（首房、十房、首次击败守关、首个满好感物灵…），纯展示，可佩戴一个显示在角色页与（阶段 3 起）共享房署名处。
- **失败与死亡**：没有真死亡。战斗 HP 归零 = 「字迹散乱」，自动回到家房，损失随身界尘的 10%（不扣任务物、不扣经验、不掉装备），HP 回满需要家房休整或消耗品。

## 6. 货币与经济系统

只有游戏内货币，没有充值、没有真钱、没有任何付费点（AIUI 无支付通道，世界观也不设）。

| 货币 | 来源 | 消耗（回收口） | 阶段 |
|---|---|---|---|
| **界尘**（主货币） | 任务奖励（主）、战斗胜利、首次建房、图鉴登记 | NPC 商店买消耗品；休整加速；房间改名（10 尘）；判定「请物灵帮看」辅助（5 尘，换一条提示，不代判）；家房仓库扩容 | 1 |
| **回响**（联机货币） | 自己的共享房被别人完成任务、异步协作分成 | 兑换他人共享房的独有道具、给共享房题字 | 3 |

经济纪律：①来源与消耗都写进数值表，一次任务的界尘收入 ≈ 一件普通消耗品价格的 1–1.5 倍，保证「做任务 → 买得起补给 → 再出门」的循环转得动；②大额消耗口只有扩容与改名这类可选事项，永不设「不花钱就玩不下去」的卡点；③货币数值归核心层结算，LLM 不经手（架构设计原则 1）；④阶段 1 数值表：样板任务 20 尘、战斗胜利 8–15 尘、建房 10 尘；消耗品：回 10 HP 的「墨糕」25 尘、判定提示 5 尘、改名 10 尘。

## 7. 背包、道具与装备

- 背包 20 格初版：同类消耗品堆叠上限 9，任务物不占格、不可丢弃，普通物可丢弃（丢弃 = 在当前房间放下，重访可见，形成轻量「布置」乐趣，阶段 2）。
- 道具四类：消耗品（回 HP、判定提示券）、任务物、材料（蚀影掉落的「残页」，商店回收换界尘）、纪念品（不可卖、图鉴登记）。
- 装备阶段 2：三个部位——镜（洞察向）、扣（脚力 / 身法向）、符（亲和向），来源是物灵赠予与商店高价位，不刷随机词条，只固定小加成（+1 维相关判定容错等），避免数值膨胀。

## 8. 任务系统

- **五类模板**（与五种玩法同构）：寻物（看）、送信 / 抵达（走）、开锁 / 摆置（摆）、巡界（动：转头环视确认若干方向）、问答 / 交还（说）。阶段 1 每类 1 个样板串成序章链；阶段 2 每类 ≥4 个模板，参数（目标房、目标物、给予者）从玩家世界里抽真实房间与实体填充——模板是骨，玩家的世界是肉。
- **任务状态机**：offered → active → verifying → done / failed（架构 §4.4）。failed 不惩罚、可重接；同时进行上限 5 个。
- **委托链**（阶段 2）：物灵 A 的任务奖励是物灵 B 任务的钥匙物，链长 2–4 环，链信息在任务页以「A → B → C」呈现。
- **重访任务**：老房间会冒出新任务（物灵想起新事、褪字角落刷新），让玩家的旧图常玩常新——这是本游戏区别于「打卡地图」的关键，阶段 2 起按「距上次到访天数 + 随机」触发，触发只在玩家打开 Agent 时计算（不能后台常驻，不假装推送）。

## 9. NPC 物灵系统

- **生成**：建房判定时从场景的物里选 0–2 个生成物灵（不是每房必有；没有合适物的房间就是安静的房间）。人设三件套：来历（这件物被人用过的痕迹）、脾气（一句话）、心事（一个小心愿，是它的任务种子）。
- **记忆**：summary + facts ≤12 条（架构 §4.3）；好感度 0–5 心，靠完成它的任务与对话涨，满好感给纪念品与一段专属往事（成套写好的人设内容集，阶段 2）。
- **商店**：有「摊位类」物灵（贩卖机、邮筒、书店柜台等）开商店，卖消耗品、收材料；价格全服同表（§6），不做动态定价。
- **对话**：自由 ASR 对话由 LLM 以人设 + 记忆即兴，但任务推进只认状态（交物品查背包、答应与否查选项），台词说得再好听也不跳过验证（架构 §6）。

## 10. 战斗系统

- **遭遇**：蚀影只出现在「褪字角落」——重访老房间时按概率刷出，或主线指定房守关；在新房与家房不刷。遭遇前有预警一行（「这里的字有点淡…」），玩家可绕行。
- **回合**：玩家行动四选（攻击 / 防御 / 技能 / 道具）+ 逃跑；滑动或语音选，单击 / 点头定。伤害公式初版：攻击 = 5 + 身法或洞察（按武器向） + 随机 0–3，防御减半下回合伤害；蚀影 HP 按房龄与玩家等级派生。数值全归核心层，LLM 每回合只写一句战况。
- **属性相性**：蚀影分三型——「空白」（无相性）、「错字」（怕洞察技）、「重影」（怕身法技），角色页与图鉴给出识别提示，鼓励换打法而不是堆数值。
- **守关（Boss）**：章节末地标房一只，HP 与招式成套设计（阶段 2 起每章一只），败了回 家房休整再来，不设「打不过就卡死主线」——守关可绕行，主线给替代路径，只是奖励差一档。

## 11. 地图、家房与图鉴

- **地图页**：文字图（节点 = 房间，连线 = 出口方向）+ 列表二选一视图；走任务进行时地图页置顶目标房的 cardinal 方位与距离。
- **家房**：玩家的第一间房自动为家房（可改设任意自建房为家房）；家房功能：休整回 HP、仓库（阶段 2）、图鉴墙入口、存档状态查看。
- **图鉴**（阶段 2）：房间图鉴（去过的地方）、物灵图鉴（说过话的灵）、道具图鉴、蚀影图鉴；登记自动发生，图鉴只记文字与判定摘要，不存照片（与存档纪律一致）。

## 12. 联机系统（阶段 3 / 4，规划先行、实现后置）

- 共享房：玩家选一间自建房提交共享，过审后别人能在同一地点读到它（架构 §9、§11）。共享的是文字与任务，不共享精确坐标与照片。
- 异步协作：别人在你的共享房完成任务，你得回响；留言板是「题字」——一句短评，过审可见。
- 同地回合制：两个玩家站在同一地点、都打开 Agent，服务端定序打同一只守关蚀影，一人一回合，慢的一方不被实时催促（对方界面显示「等对方落子」）。
- 明确不做：异地实时对战、公会、排行榜攀比（最多阶段 4 评估「补字里程」个人榜，只记自己）。
