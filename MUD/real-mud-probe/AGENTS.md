# 真境探针 Real MUD Probe — Design Contract

v1.0.3 信号自动探测版（首版 v1.0.0）：真境漫游（RealMUD）阶段 1 的前置合并探针。目的只有一个：把正式版开工前说不准的四组数测出来——存储配额、开掌手势 LLM 定格判定认对率、头部朝向误差与头稳耗时、拍照建房判定分段耗时。探针不占正式游戏本体、不进根 README 清单、**不提审**（内部真机验证用）。

## Design contract

- 7 页：首页（四站入口 + 进度摘要；v1.0.2 起首页有 KEY / GES 两行原始事件显示——每个 keydown/keyup 的 code/key/keyCode 与头部手势的 gesture/type 原样印出并经 logq 以 key/ges 步名上报，探头只记录、不判断、不拦截，与选择处理并存；v1.0.3 起首页另有信号自动探测序列，见下条）、存储、手势、朝向、判定耗时、结果单、设置/自检。app.json 页数 = 7，实数对齐。
- **信号自动探测序列（首页，v1.0.3）**：待机态大字提示「点头开始逐个探测信号」；收到 nod 即开始（触发的 nod 本身记为第 1 项证据），进页约 5 秒无 nod 自动开始。五项固定序（点头 / 下滑 / 上滑 / 单击 / 双击），每项全屏大字提示 + 6 秒窗口 + 约 1 秒过渡屏；窗口内每个 keydown/keyup/头部手势事件按探头格式全量记录（类型 + code/key/kc + 窗口内相对时刻），收到期望类别信号不提前结束、重复投递记全。序列中菜单选择停用，输入全归序列。走完自动停汇总屏约 10 秒（逐项 ✓ 附首事件 / ✗ 无信号 / 出错裸码），再自动进「结果图」逐帧循环（每项一帧列全该项全部事件、装不下拆帧，帧标 `结果图 N/M · 第X项 名称 · v1.0.3`，每帧约 10 秒，点头暂停/继续，双击走宿主默认退出）。汇总落盘 results.diag（逐项 ok / 首事件 / 全部事件 / 时间），待机屏显示「上次信号探测：…」一行；汇总态点头再跑一轮。每步硬超时 + 全局看门狗（总时长 + 余量未到汇总则强制收尾、缺项记未完成），内部出错记 E9001 跳下一项——全程自动，不停下等用户确认。
- **执行纪律（GO 定，全探针）**：原子功能测试必须单独跑、按顺序跑、屏显跑的状态、一步步跑——① 隔离：每项开始前清空本项缓冲与计时、上一项计时停干净、捕获闸门（`_accepting`）只在本项窗口内打开，逐项独立落盘，一项崩坏不污染其他项；② 串行：严格顺序、任何时刻只有一个测试在跑，绝不并发，回传 flush 等当前项窗口结束后再发（log() 只入本地队列，flushLog() 只在每项结束与汇总时调用）；③ 屏显状态：运行中屏幕固定状态区实时显示当前项序/名称/状态（等待中 / 记录中·剩余秒数 / 已完成✓ / 无信号✗ / 出错+裸码）与已完成项结果列表（随跑随长）；④ 一步步：上一项未结束（完成/超时/出错跳过）绝不启动下一项，项间约 1 秒过渡屏。信号序列已按此实现；四站内部逐项串行（存储逐档、朝向逐向、判定逐次）与此一致。
- 结果统一落 `mud.probe.results.v1`（wx 存储），键结构：`storage` / `gesture.trials[]` / `heading{trials[], nods, calibrated}` / `timing.runs[]` / `diag{at, items[]}`（信号序列逐项结果）。每站完成即落盘，关掉重开不丢；设置页可整体清除重测。
- **存储站**：localStorage 与 wx 存储各测——单值 1/10/50/100KB 写+读回校验（长度 + checksum）、累计 10KB 一块堆到失败或 500KB 上限、样本房间块 JSON（约 2.4KB）往返逐字比对、时间戳标记（进页先读旧标记再被本轮覆盖，结果单显示上轮标记在/不在）。测完清测试键。
- **手势站**：开掌静态判定 10 次，管线 = 拍照（default）→ 缩图宽 480（失败回退原图并标注）→ `arrayBuffer` + 分块 `btoa` 转 data URL → `LanguageModel` 图片输入，只收结构化 JSON `{gesture: open_palm|other|none, confidence, recognized[]}`，枚举外/把握非数按 E6011 失败处理、不占次数。对错由测试者标真值（对/错），LLM 的答案永远不自任真值。认对 <5/10 时阶段 1 手势开门按探针门降级自评——判定在本探针之外由数据说话。
- **朝向站**：`AbsoluteOrientationSensor` 四元数 → yaw（舰队既有公式）。首读 null 是正常态不当错误；启动 5 秒无读数才报 E7008；构造/出错 E7001；`enableWorldAwareness` 失败 E7006。校准 = 以当前朝向为中心（相对北 0°），四向（东 90/南 180/西 270/北 0）依次测：进入 ±10° 窗口连续 800ms 记到达，记误差度数与从出题到锁定的总耗时。点头在本站只计数（`onHeadGesture` 通道单测），不触发任何操作。中心角度不跨会话保存（磁北会漂），`calibrated` 只记曾校准过，进页必须重校。
- **耗时站**：default 拍照建房判定 3 次，分段 = 拍照（开流+takePhoto）/ 编码（缩图+data URL）/ LLM 往返 / 总。判定走架构 §5 的房间 JSON 结构（recognized / sceneSummary / confidence / uncertain / facesPresent / privateOrDanger / gesture）。每次并行发起一次非阻塞定位：成功补记精度米数，失败记 E7002/E7003（权限拒绝时经 fail 落 lastError），永不阻塞判定、不计入总耗时。LLM 45 秒超时熔断 E6003。
- **结果单**：四站大字汇总（存储各档 ✓/✗ 与累计 KB、手势认对 x/10 与平均把握、朝向平均误差与点头数、判定总耗时中位数与平均把握）+ 逐次明细。进页同时经 logq 上报一条汇总（配了才发）。结果单共 5 屏（汇总 + 存储逐项 / 手势逐次 / 朝向逐向 / 判定逐次四段明细，每段逐项列全落盘原始数、屏顶标屏序与段名），网络日志回传不可用时逐屏截屏即可独立带回全部结果，不依赖网络与钥匙。明细只取 results 落盘字段，不现算假数。
- **错误码**：单点定义在 `err.js`，裸码，`fail()` 三处同码（屏显行 / lastError / 可选 TTS 只读码）。本台可出码：E1001 E1002 E1003 E1007 E1009 E2013 E5001 E5002 E6001 E6002 E6003 E6005（data URL 形状自检）E6009 E6011 E7001 E7002 E7003 E7006 E7008 E8001 E9001。业务代码不散写码字面量（EVT 调试行除外，与舰队惯例一致）。
- **日志回传**：`logq.js` 照 AV11 v1.2.0 形态（本地队列上限 100、按 session 分批 ≤50、fire-and-forget、失败留队）。配置在 `config.js` 一处：`BASE_URL` + `CHANNEL_KEY` 两件齐才启用，缺一即完全 no-op 静默。仓库只存占位符，真钥只在 Studio 就地填、永不回推。flush 时机：各站完成、进结果单、下次启动；信号序列另有全量回传——每事件逐条以 `diag-ev` 入队（项号 + 相对时刻 + 原文），逐项判定 `diag-1`…`diag-5`、最终汇总 `diag-summary`，flush 只在每项窗口结束与序列结束时触发（执行纪律②）。
- 手势映射（全页）：滑动 = 切焦点（ArrowUp/Down）；单击 = 执行焦点（Enter）；双击 = 返回（Backspace，页面 onKeyDown 自接，不依赖 bindtap）；点头 = 执行焦点（朝向页例外：只计数；首页例外：点头 = 开始信号自动探测序列，汇总态点头再跑一轮，结果图态点头暂停/继续）。每页都接 onKeyDown——bindtap-only 在真机不可触发的教训。按键判定一律以 `event.code` 为准、缺失才回退 `event.key`，Enter 与 GlobalHook 同义——真机 `event.key` 不可靠且会遮蔽 code，先读 key 会让滑动/单击全灭（v1.0.0 实测教训，v1.0.1 已改）。焦点项按钮必须实心高亮（data 的 cls 驱动），与底部 focusLine 双保险。每页页脚 flex row，右下角固定显示版本号。

## Technical honesty

- Web 预览里：存储站可真跑（浏览器存储宽松，全过 + 撞 500KB 人为上限——只证明逻辑，不证明眼镜配额）；相机/LLM/传感器/定位在预览里不可用或不真实，相关站会以裸码如实失败（如朝向页预览出 E7001），不模拟结果。全部四站的真实数字只能来自真机一轮。
- 照片与 data URL 永不落盘、永不进日志；存档只留数字、判定摘要与一句场景概括。
- 朝向的「北」是校准相对角，不是磁北真值——探针测的是相对转头的误差与稳定性，不宣称绝对指向精度。

## Permissions

- `CAMERA` — 手势站与耗时站的定格拍照判定。
- `GEOLOCATION` — 耗时站的非阻塞定位读取（精度记录）。
- 不用 ASR，不声明 `RECORD_AUDIO`。与 app.json 声明一致。
