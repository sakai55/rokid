# story-look

Rokid 眼镜绘本共读智能体（AIUI Agent）。

## 身份

一个运行在 Rokid 眼镜上的「亲子绘本共读」助手，解决给孩子讲
绘本没互动的问题——照着书一页页念，孩子听着听着就走神了。
它的做法是：绘本在你手里、孩子在你身边，你看着这一页，用
一句话说说这页画了什么，眼镜把你的话变成一段适合读给
3–6 岁孩子的讲解词，再附上一个问孩子的问题——你问一句、
孩子答一句，一页就活了。它从头到尾看不见绘本：这一页是
什么，全靠你说。

## 能力

- 看（LOOK）：看着绘本这一页点 LOOK，用
  `ImageCapture.takePhoto({mode:'default'})` 拍下整页
  （不可用时回退 wx.media CameraContext，同 #01）。照片只作
  记录——锚定「讲到哪一页了」，界面只显示字节数，拍完立即
  停掉全部媒体轨道。它不会被读取：运行时没有 OCR；而把
  照片发给大模型是本 Agent 刻意不走的路——平台其实支持
  照片经 data: URL 作为图片输入送入大模型（档案 §2.9 的
  官方读字路径），本 Agent 只把文字发给模型，这是产品
  选择，不是平台限制。眼镜看不见这一页，这一页讲什么
  100% 由你说出来。
- 说（SAY）：这一页靠你说。先按文档方式用
  `getUserMedia({audio:{captureSource:'microphone',
  microphoneMode:'wearer'}})` 做佩戴者模式麦克风可用性
  检查（开 wearer 模式流、读回 settings 后立即停流——这
  只是检查，检查流不参与识别），再用宿主
  SpeechRecognition（zh-CN）在它自己的麦克风上一次性识
  别。wearer 模式管不到宿主识别器（档案 §2.4 / §2.8），
  所以本 Agent 不承诺「只收家长、孩子插话不会被收进描
  述」——孩子在旁边说话可能被听成描述的一部分，防线是
  你核对屏幕上原样显示的那句话。听到的一句话**原样**保存并显示
  （同 #21 / #36 的逐字纪律），整个故事就建立在这句话上，
  听错了就再 SAY 一次；主机没有识别能力时如实 SKIP，改走
  内置样例描述轮换，绝不假装在听。
- 讲（TELL）：把这一页的描述，连同**前面所有页的描述**
  （按故事顺序、纯文本）一起发给主机 LanguageModel 大
  模型：要它只围绕你描述的内容，返回两段——2–3 句适合
  读给 3–6 岁孩子的温暖讲解 + 一个问孩子的问题，标注
  来源 LLM。大模型不可用时回退 **OFFLINE ECHO**：讲解词
  就是你自己的描述**原样**（你的话还给你，不冒充生成的
  故事），问题从内置题库（10 个温和的问题）按页轮换，
  标注 OFFLINE ECHO。
- 读（READ）：讲解词生成后**不自动朗读**——它先摆在屏幕
  上等你看完，你点了 READ 才用 speechSynthesis 慢速（0.85
  倍速，主机是否采纳未验证）读给孩子听；问题大字显示，
  由你亲口问孩子。为什么
  不自动：生成文本先过家长的眼睛，再进孩子的耳朵，这是
  本 Agent 的刻意选择，不是缺失的功能。
- 翻页存档（NEXT / READ ALL）：点头（头部稳定时）或 NEXT
  把这一页 {页码， 你的描述， 讲解词， 问题， 来源} 存入
  wx 同步存储（key `storyLook`，只保留最近一个故事，最多
  20 页）；READ ALL 按顺序把存好的讲解词整篇重播。页面
  卸载时同样落盘。
- DEMO：内存里播入《小兔子》两页（第 1 页已存档、第 2 页
  已讲好停在问题视图），全部 OFFLINE ECHO 且标注 DEMO
  路径，不用相机、不用麦克风、不写真实存储；CLEAR 退出
  后恢复你真实的故事。

## 行为边界

- **它看不见绘本**：没有 OCR，且本 Agent 选择不把照片发
  给大模型（平台支持照片经 data: URL 送入模型，本 Agent
  不用这条路径）——「这一页画了什么」只能由你说出来。你没说到的角色、情节，它
  不应该有；给大模型的提示词里明确要求只围绕你的描述
  展开、只加温和的连接、不发明新角色新情节，但生成文本
  仍可能有出入，这正是朗读前必须由你预览的原因。
- **生成内容先过家长、再到孩子**：没有自动朗读这回事。
  LLM 的讲解词是机器生成的文本，适不适合你家孩子、跟你
  手里的书对不对得上，只有你看过才算数；OFFLINE ECHO
  模式读的则是你自己的原话，来源在界面上分得清清楚楚。
- **问题是用来问的，不是考的**：题库和大模型的问题都是
  开放式的闲聊引导（「你猜，接下来会发生什么？」），没有
  标准答案，不给孩子的回答打分、不纠错。
- 麦克风/相机只在用户点 SAY / LOOK 时启动，用完立即停
  掉全部媒体轨道；不录音、不保存照片（只取字节数显示）；
  故事只存本机 wx 同步存储，不上传。发给大模型的只有
  描述文字（你说过的话），没有照片。
- 声明权限：CAMERA（拍绘本页留档）与 RECORD_AUDIO
  （佩戴者模式麦克风检查 + 描述的一次性识别）；朗读走
  系统 TTS，不占权限。
