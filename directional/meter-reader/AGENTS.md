# meter-reader

Rokid 眼镜抄表助手智能体（AIUI Agent）。

## 身份

一个运行在 Rokid 眼镜上的「抄表记忆」助手，解决水表、电表、
燃气表的数字又小、位置又高、光线又差，每次抄完写在纸上回头
就丢、更没人帮你算「这个月用了多少、比上个月多多少」的问题。
眼镜就在你脸上：抬头看着表盘长焦拍一张留底，嘴里把数字逐位
报出来，它解析成数值大字给你核对，点 SAVE 才入账；下个月再
抄，它自动算出本期用量，和上期一比，波动超过 ±50% 就亮出
「用量异常」提醒你去查漏水、漏电、漏气。

## 能力

- 选表（METER）：水表（吨）/ 电表（度）/ 燃气表（立方米）
  三块表轮换，方向键同样换表；换表会清掉待确认读数，防止
  把水表的数记到电表头上。
- 拍照留底（只作记录）：LOOK 用 `getUserMedia` 取流后以
  `ImageCapture.takePhoto({mode:'telephoto'})` 长焦拍下表盘
  留作你自己的视觉副本（不可用时回退 wx.media
  CameraContext），界面只显示字节数并标注 record only。
  运行时没有 OCR，照片永远不会被读取，表盘上的字一个也不会
  被识别出来——历史里的读数只来自你亲口报的数。
- 报读数（READ，一次性 ASR + 解析 + 人工核对）：先按文档
  方式用 `getUserMedia({audio:{captureSource:'microphone',
  microphoneMode:'wearer'}})` 做佩戴者模式麦克风检查（4 麦
  优先收你自己的声音，检查完立即停轨道），再用
  SpeechRecognition（zh-CN）听你报数。两种报法都认：逐位报
  （「一二三四五」「12345」「幺二三四五」「一零二三」逐字
  拼接）与成数报（「八千三百二十一」「九万九千九百九十九」
  = 99999），带小数尾（「…点五」）也可。解析结果大字显示
  在 READ 行等你亲眼核对——**读数永不自动保存**。解析失败
  如实显示听到的原文与「parse FAIL」请重报；主机没有识别
  能力时如实 SKIP，不假装在听。
- 微调（FINE −1 / +1 / +10）：解析差一位时（如最后一位
  听错）不用重报，FINE 三键把待确认读数修正到正确值再
  保存。没有待确认读数时 FINE 会如实拒绝。
- 入账（SAVE，显式确认为唯一入口 + 倒退拦截）：SAVE 按钮
  或 Enter 把 {表， 读数， 日期， 时间} 存入 wx 同步存储
  （key `meterReadings`，总上限 36 条，超出丢最旧的）。
  点头只把待确认读数/用量汇总朗读出来给你核对，**绝不触发
  保存**。**读数倒退会被拦截**：新读数比该表上次读数小时
  SAVE 直接拒绝并提示「听错了？换表点 NEW METER」——表盘
  不会倒转，小的数要么是听错、要么是换了表；真换表时先点
  NEW METER 武装一次，下一笔以「换表基线」存入，不与旧表
  算用量。
- 用量与异常（USAGE）：按存储顺序取同一块表的相邻读数对
  算每期用量；换表基线是新表的一段的起点，入基线的一对不算、
  比较也从不跨换表断点（只比同一块物理表未断链的相邻两期）；
  最新一期与上一期比，
  波动**超过** ±50%（恰好 50% 不算）且上期用量为正时亮
  「! 用量异常： 比上期多/少 XX% — 查漏水/漏电/待机耗电/
  漏气（按表给）」。这是「去看一眼」的提醒，不是漏损诊断。
  SPEAK 朗读用量汇总：「电表本期用量 270 度。上期 230 度。
  用量平稳。」
- DEMO：用运行时 Date 的**一次快照**以纯字符串推导三个月
  的日期，播种电表 8120 → 8350 → 8620（用量 230 → 270，
  +17%，平稳）与水表 320 → 340 → 384（用量 20 → 44，
  +120%，异常），直接切到 USAGE 并选水表，异常行在预览里
  就是真算出来的。重入 DEMO 会先清掉旧 DEMO 记录再播种，
  不重复堆积（预览主机的 Date 是虚拟化且多次采样会漂移，
  一次快照是 DI25/DI26 的教训）。

## 行为边界

- **眼镜从不读表盘**：没有 OCR，照片只作记录、不参与任何
  判断；读数是 ASR 转写 + 解析，你没在 SAVE 前亲眼核对，
  听错的数字就会一本正经地记错——核对环节与倒退拦截就是
  为此存在的双保险。解析器覆盖逐位报数与万以内的成数报法，
  方言说法、含糊读法不在保证范围内，解析失败会如实 FAIL，
  不会猜一个数给你。
- **异常提醒不是诊断**：用量波动可能来自住人变化、季节、
  出差回家等正常原因；Agent 只报「比上期多/少百分之几」，
  查不查、怎么查由你决定。燃气表异常请先注意安全：闻到
  燃气味不要用本 Agent 慢慢核对，直接关阀开窗、联系燃气
  公司。
- 麦克风只在用户点 READ 时启动：佩戴者检查的音频流读完
  设置立即停掉全部轨道，一次性识别结束即 abort；相机只
  在点 LOOK 时启动，拍完立即停轨道；页面隐藏/卸载时同样
  清理。
- 不录音、不上传：识别由系统识别服务处理，本 Agent 只
  保存你确认过的读数与时间；记录只存本机 wx 同步存储。
- 读数与日期全部来自本机时钟与你的口述；设备时钟不对，
  抄表日期就会跟着不对，Agent 不做校正也不编造。
- 声明权限：CAMERA（表盘长焦拍照留底）、RECORD_AUDIO
  （报读数的麦克风检查与语音识别）。
