# memory-anchor

Rokid 眼镜记忆锚点智能体（AIUI Agent）。

## 身份

一个运行在 Rokid 眼镜上的「方向备忘」助手，解决「刚才那个想法/待办
转头就忘」的问题：站在洗手台前想起要买牙膏，走到门口就忘了；看着
药瓶想起晚上要吃药，转身就没影。手机备忘录要掏手机、打字，还和
「当时你在看哪件东西」毫无关系。本 Agent 把备忘挂在你的朝向上：
看着相关物品说出备忘，眼镜把「分类 + 备忘原文 + 你当时的头部
朝向 + 时间」绑成一个锚点存下来；之后只要本 Agent 开着，你再次
转头朝向那个方向并停稳 2 秒，锚点卡片自己弹出来，备忘出声念
一遍——不用你想起「我好像记过什么」，是方向先找到你。

## 能力

- 朝向读取：AbsoluteOrientationSensor（约 5Hz）四元数算 yaw
  朝向角，界面如实标注来源 SENSOR / DEMO / NONE；无传感器时
  不编造朝向，SAVE 会拒绝并说明原因（同 DI07 / DI26）。
- 记备忘（NOTE）：点 NOTE 后先做一次佩戴者模式麦克风**可用性
  检查**——按文档方式用 `getUserMedia({audio:{captureSource:
  'microphone', microphoneMode:'wearer'}})` 开流、读回
  `track.getSettings()` 后**立即停掉全部轨道**。这条检查流只
  验证模式能打开，**不是识别的输入，也不改变识别听到什么**；
  真正的口述由宿主 `SpeechRecognition`（zh-CN）在它自己的
  麦克风通路上完成，界面上检查结果单独占一行 `MIC CHECK:`，
  聆听状态行写明 `(host ASR)`。识别结果**原样**显示在 MEMO 行
  等你核对；主机没有识别能力时 NOTE 如实显示 SKIP，并改为轮换
  五个预置备忘（记得把发票拍照存档 / 出门前给花浇水 / 周五前
  交水电费 / 把伞放回玄关 / 睡前吃一片药）。分类用 CAT 在六个
  内置分类（钥匙 / 文件 / 药 / 工具 / 食材 / 其他）间轮换。
- 保存（SAVE）：只有「已口述、正 verbatim 显示在屏幕上」的
  备忘才能被锚定——点 SAVE，或头部稳定时点头确认。没有待保存
  备忘时，点头/SAVE 一律拒绝，**绝不凭空保存一条备忘**（点头
  在无待保存备忘时改为朗读选中锚点）。记录 {分类， 备忘原文，
  朝向°， 日期， 时间} 存入 wx 同步存储（key `memoryAnchors`，
  最多 10 条，onLoad 载入、onUnload 落盘）；**超过 10 条时最旧
  的一条被丢弃，且状态行会明说丢了哪条**，不静默丢弃。
- 朝向提醒（REMIND，本 Agent 开着时才工作）：提醒引擎每 500 ms
  一拍（用拍数累计计时，不反复采样 Date，避免预览主机虚拟时钟
  漂移扭曲计时）：当前朝向进入某锚点 ±15° 锥内并**连续停留
  2 秒**，该锚点卡片以大字弹出「ANCHOR： 分类 · 备忘 · noted
  时间」，并用 TTS 把备忘念**一遍**（同一次面对只念一遍）；
  朝向离开锥外满 5 秒才重新布防，短暂瞥回不会重复轰炸。
  多个锚点同时在锥内时，取相对角最小的那个触发。
- 列表与指引（LIST）：锚点列表常驻显示（分类 · 备忘 · 朝向 ·
  日期时间）；SEL 轮换选中锚点，相对角 = 锚点朝向 − 当前朝向
  （归一化 −180°…180°，+ 为右），显示 8 向箭头与「TURN: …」
  提示，|相对角| ≤ 15° 时高亮「FACING IT」。SPEAK 朗读选中
  锚点的备忘与登记信息。DONE 两步删除：第一次点只布防并显示
  将删哪条，第二次点才真正删除（防误删）。
- DEMO：用一次时钟快照（同一快照以纯字符串推导全部日期与
  时间——预览主机的 Date 是虚拟化的、多次采样会漂移，DI25
  的教训）登记 2 个标注 DEMO 的锚点（药 @45°「睡前吃一片
  降压药」/ 钥匙 @200°「备用钥匙放在鞋柜里」）；之后每点一次
  DEMO 朝向 +45°，转到 45° 停留 2 秒即触发药锚点的提醒卡片
  与朗读，预览可完整演示。重入 DEMO 先清掉旧 DEMO 锚点。
- 凝视/点头：开启世界感知（enableWorldAwareness）显示头部稳定
  状态；有待保存备忘且头部稳定时点头 = SAVE，无待保存备忘时
  点头 = SPEAK。手势只用文档化的 `nod`。

## 行为边界

- **锚点绑的是方向，不是物品本身**：眼镜没有物品识别，记住的
  是「你记备忘时面朝的方向」。物品被挪走后，方向仍指向你当时
  看着的旧位置——界面常驻行、README 与本文件都如实写明
  「binds direction, not the thing」。
- **提醒只在本 Agent 打开时发生**：朝向流只在页面活着时跑，
  没有后台常驻，关掉 Agent 就没有任何提醒；绝不声称后台/关机
  提醒。回到家附近、站在当初登记位置一带转头，锥角才对得上；
  站在别处朝向同一罗盘角，触发的是「那个方向」，不是「那件
  东西在不在那儿」。
- **备忘文字是宿主 ASR 转写**：原样显示就是让你在 SAVE 之前
  亲眼核对——听错的备忘存进去，提醒时就按错的念。识别不可用
  时如实 SKIP 走预置备忘，不伪造识别结果。
- **麦克风模式不塑造识别**（2026-10-24 能力边界审计口径）：
  wearer 检查流读完设置立即停轨，对宿主 SpeechRecognition 的
  识别没有任何影响；文档与界面都不声称「wearer 模式让识别
  更准/优先收佩戴者声音」之类效果。
- TTS 从不设置 `utterance.lang`（宿主不采纳该属性）；朗读的是
  备忘原文与登记信息，不做任何改写或补全。没有相机、没有
  LLM、没有定位：本 Agent 只用 RECORD_AUDIO 一个权限（朝向
  传感器在 AIUI 里不需要单独权限声明）。
- 麦克风只在用户点 NOTE 时启动：检查流停轨后才开始一次性
  识别，识别结束即 abort；页面隐藏/卸载时停识别器、停传感器、
  清定时器、落盘锚点。记录只存本机 wx 同步存储，不录音、
  不上传。
