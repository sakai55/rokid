# 指向性（directional/）

[中文](README.md) | [English](README.en.md) | 日本語
中国語版（2026-10-29 時点）の翻訳。

指向性シリーズ。DI01–DI50、全50件。視線の向きや頭の向きといった指向性の仕組みを使って、日常の課題を解く。

- DI01 [gaze-translate](gaze-translate/) — 外国語の文を見て頭を止め、望遠で撮って翻訳し、読み上げる
- DI02 [shelf-compare](shelf-compare/) — 棚のバーコードを読み取って表にし、価格を比較。うなずきでリストに追加する
- DI03 [expiry-check](expiry-check/) — 包装の日付を読んで残り日数を計算。期限が近づくと音声で警告する
- DI04 [plant-doctor](plant-doctor/) — 写真で植物の状態を判定し、手入れの手順を音声で案内する
- DI05 [manual-lens](manual-lens/) — 銘板の故障コードを読み、次の操作手順を示す
- DI06 [head-nav](head-nav/) — ナビの矢印が頭の動きに追従。方向が合ってから進む
- DI07 [find-my-thing](find-my-thing/) — 物を見ながら音声で登録。置いた場所と向きをあとで呼び出せる
- DI08 [meet-point](meet-point/) — 位置情報を共有し、頭を向けるだけではぐれた友人の方角が分かる
- DI09 [parking-return](parking-return/) — 駐車位置と向きを保存し、帰りに車まで案内する
- DI10 [exit-radar](exit-radar/) — 見回して出口の方向を登録。緊急時に最寄りの出口を読み上げる
- DI11 [cook-along](cook-along/) — レシピが目の前に浮かぶ。うなずきで手順を進め、油煙の中では音声だけを聞く
- DI12 [repair-buddy](repair-buddy/) — 故障箇所を撮ると手順ごとに指導。1ステップごとにうなずいて確認する
- DI13 [assemble-guide](assemble-guide/) — 図面と部品を見比べて、手順どおりの組み立てを案内し、間違いを指摘する
- DI14 [garden-hands](garden-hands/) — 植物を見ながら剪定と水やりの指示。ハンズフリー
- DI15 [baby-care-hands](baby-care-hands/) — 赤ちゃんを抱いたまま、ハンズフリーで音声Q&A。写真で赤ちゃんの様子も聞ける
- DI16 [sound-compass](sound-compass/) — 頭を回して音源の方向を探り、音がどちら側かを知らせる
- DI17 [far-ear](far-ear/) — 遠くの音声を拾ってリアルタイムで字幕化。遠くの人の声が聞き取りやすくなる
- DI18 [cry-watch](cry-watch/) — 赤ちゃんの部屋の音を見守り、泣き声ですぐ音声で知らせる
- DI19 [name-call](name-call/) — 誰が呼んでいるかを聞き分け、内容と方向を一緒に知らせる
- DI20 [ambient-captions](ambient-captions/) — 全方向の音を拾ってリアルタイム字幕。向いた相手の声を強調する
- DI21 [market-radar](market-radar/) — 向きごとに屋台の値段を登録。振り向くと価格が光り、比べられる
- DI22 [allergen-guard](allergen-guard/) — 原材料表示を読んで、避けたい成分が入っていないか確認。当てはまれば即警告する
- DI23 [fresh-pick](fresh-pick/) — 写真で果物・野菜の熟れ具合と鮮度を判定。選び方をアドバイスする
- DI24 [outfit-check](outfit-check/) — 写真で服装の組み合わせと場面への合い具合を評価。鏡の前で着用姿も評価する
- DI25 [receipt-keeper](receipt-keeper/) — レシートを一目見て記録。月ごとの集計を音声で読み上げる
- DI26 [home-find](home-find/) — しまうときに場所を登録。探すときは方角の手がかりを出す
- DI27 [meter-reader](meter-reader/) — 望遠で水道・電気のメーターを読み、自動で記録して異常値と照合する
- DI28 [home-patrol](home-patrol/) — 出かける前にドア・窓・ガスを点検。1つずつ目で確認してから出発する
- DI29 [parcel-sort](parcel-sort/) — 宅配伝票のバーコードを読み取り、急ぎ具合で音声仕分けする
- DI30 [clean-check](clean-check/) — 見回して掃除した範囲を登録。掃除漏れの隅を知らせる
- DI31 [med-look](med-look/) — 薬瓶のラベルを読み服薬表と照合。用量を知らせ、服用を記録する
- DI32 [posture-guard](posture-guard/) — うつむいている時間を測り、長すぎると音声でそっと知らせる
- DI33 [fall-guard](fall-guard/) — 転倒して応答がない場合、事前に登録した緊急連絡先へ連絡する
- DI34 [cross-street](cross-street/) — 渡る前に左右へ頭を向けて止め、二重に確認してから「渡れる」と知らせる
- DI35 [food-safe](food-safe/) — 残り物の見た目と登録日から、リスクを段階で表示する
- DI36 [word-look](word-look/) — 知らない単語を見て声に出すと、意味と発音が単語帳に入る
- DI37 [story-look](story-look/) — 絵本のページを撮って解説と質問を生成。ページをめくって続きを語る
- DI38 [memory-anchor](memory-anchor/) — 「さっきの考え・用事」が振り向いた瞬間に消える
- DI39 [board-capture](board-capture/) — 授業や会議の黒板・ホワイトボードの字が遠く、すぐ消される
- DI40 [homework-lens](homework-lens/) — 子どもの問題が解けず、親も手順をうまく説明できない
- DI41 [sign-reader](sign-reader/) — 停留所・搭乗口・メニューの表示が遠い・小さいで読めない
- DI42 [transit-direction](transit-direction/) — 駅を出たら頭を向けて方角を確認。ずれれば音声で直す
- DI43 [hotel-checkin](hotel-checkin/) — 8つのチェックポイントを1つずつ見てチェック。見落としは方角付きで案内し直す
- DI44 [photo-level](photo-level/) — 構図に三分割グリッドと水準器を重ね、うなずきでシャッターを切る
- DI45 [queue-sense](queue-sense/) — 目で人数を数えて進み具合を測り、いちばん早い列を見積もる
- DI46 [speaker-focus](speaker-focus/) — 大人数の会議で誰が話しているか追えないときに。議事録には向きで発言者を付ける
- DI47 [badge-reader](badge-reader/) — 名札が読めず名前も忘れた？ 望遠で読んでこっそり教える
- DI48 [teleprompter-gaze](teleprompter-gaze/) — スピーチや動画撮影で言葉を忘れる。下を向いて原稿を見るのは不自然
- DI49 [site-patrol](site-patrol/) — 現場や倉庫の巡回で、項目ごとに目視と記録。両手は道具で塞がっている
- DI50 [elder-day](elder-day/) — 独居高齢者の1日のチェックリスト：服薬・水分・外出を項目ごとに確認する

全リストはルートの [README](../README.md) 末尾にある Agent リストを参照。
