# 指向性（directional/）

[中文](README.md) | [English](README.en.md) | 日本語
中文版（2026-10-29 時点）からの翻訳。

指向性シリーズ · 番号 DI01–DI50、全50件。視線と同軸、頭の向きといった指向性能力を使って生活の課題を解決する。

- DI01 [gaze-translate](gaze-translate/) — 外国語を見て頭を止め、望遠で撮って翻訳し読み上げる
- DI02 [shelf-compare](shelf-compare/) — 棚のバーコードを読み取り表で価格比較、うなずいてリストに追加
- DI03 [expiry-check](expiry-check/) — パッケージの日付を読み残り日数を計算、期限が近づくと音声で警告
- DI04 [plant-doctor](plant-doctor/) — 写真で植物の状態を診断、手入れの手順を音声で案内
- DI05 [manual-lens](manual-lens/) — 銘板の故障コードを読み、次の操作手順を示す
- DI06 [head-nav](head-nav/) — ナビの矢印が頭の動きについて回り、方向が合ってから進む
- DI07 [find-my-thing](find-my-thing/) — 物を見て音声で登録、場所と向きを思い出せる
- DI08 [meet-point](meet-point/) — 位置を共有し、頭を向けるだけではぐれた友人の方を向ける
- DI09 [parking-return](parking-return/) — 駐車位置と向きを保存し、帰りに車まで案内
- DI10 [exit-radar](exit-radar/) — 見回して出口の方向を登録、緊急時に最寄りの出口を読み上げる
- DI11 [cook-along](cook-along/) — レシピが目の前に浮かび、うなずいて手順を進める。油煙の中でも声だけ聞く
- DI12 [repair-buddy](repair-buddy/) — 故障箇所を撮って手順ごとに指導、一歩ごとにうなずいて確認
- DI13 [assemble-guide](assemble-guide/) — 図面と部品を照合し、手順どおり組み立てを案内して間違いを指摘
- DI14 [garden-hands](garden-hands/) — 植物を見ながら剪定と水やりの指示、ハンズフリー
- DI15 [baby-care-hands](baby-care-hands/) — 赤ちゃんを抱いたままハンズフリーで音声質問、写真で赤ちゃんの様子を尋ねる
- DI16 [sound-compass](sound-compass/) — 頭を回して音源の方向を探り、音がどちら側かを知らせる
- DI17 [far-ear](far-ear/) — 遠距離の音声を拾ってリアルタイム字幕化、遠くの声をはっきり聞く
- DI18 [cry-watch](cry-watch/) — 赤ちゃん部屋の音を見守り、泣き声ですぐ音声通知
- DI19 [name-call](name-call/) — 誰が呼んでいるかを聞き分け、内容と方向を一緒に知らせる
- DI20 [ambient-captions](ambient-captions/) — 全方向で音を拾いリアルタイム字幕、向いた相手の声を強調
- DI21 [market-radar](market-radar/) — 向きごとに屋台の価格を登録、振り向くと価格が光って比較できる
- DI22 [allergen-guard](allergen-guard/) — 原材料表示を読んで避けたい成分をチェック、該当したら即警告
- DI23 [fresh-pick](fresh-pick/) — 写真で果物と野菜の熟れ具合と鮮度を判定、選び方を助言
- DI24 [outfit-check](outfit-check/) — 写真で服装のコーディネートと場面への適合を評価、鏡で着用姿も評価
- DI25 [receipt-keeper](receipt-keeper/) — レシートを一目で記録、月次集計を音声で読み上げ
- DI26 [home-find](home-find/) — 収納時に場所を登録、探すときは方角の手がかりを知らせる
- DI27 [meter-reader](meter-reader/) — 望遠で水道・電気メーターを読み取り、自動で記録して異常を照合
- DI28 [home-patrol](home-patrol/) — 外出前にドア・窓・ガスを巡回確認、一つずつ見てから出発
- DI29 [parcel-sort](parcel-sort/) — 宅配便の伝票バーコードを読み取り、緊急度で音声仕分け
- DI30 [clean-check](clean-check/) — 見回して掃除の範囲を登録、掃除漏れの隅を知らせる
- DI31 [med-look](med-look/) — 薬瓶のラベルを読み服薬表と照合、用量を知らせ服用を記録
- DI32 [posture-guard](posture-guard/) — うつむき時間を測定し、長すぎると音声でそっと注意
- DI33 [fall-guard](fall-guard/) — 転倒して応答がない場合、事前登録の緊急連絡先へ連絡
- DI34 [cross-street](cross-street/) — 横断前に左右へ頭を向けて止め、二重確認してから通行可を知らせる
- DI35 [food-safe](food-safe/) — 残り物の見た目と登録日でリスクを等級表示
- DI36 [word-look](word-look/) — 知らない単語を見て声に出すと、意味と発音が単語帳に入る
- DI37 [story-look](story-look/) — 絵本のページを撮って解説と質問を生成、ページをめくって続きを語る
- DI38 [memory-anchor](memory-anchor/) — 「さっきの考え・用事」が振り向いた瞬間に消える
- DI39 [board-capture](board-capture/) — 授業や会議の黒板・ホワイトボードの字が遠く、すぐ消される
- DI40 [homework-lens](homework-lens/) — 子どもの問題が解けず、親も手順をうまく説明できない
- DI41 [sign-reader](sign-reader/) — 停留所・搭乗口・メニューの表示が遠い・小さいで読めない
- DI42 [transit-direction](transit-direction/) — 地下鉄を出たら頭を向けて方向を確認、ずれると音声で修正
- DI43 [hotel-checkin](hotel-checkin/) — 8つのチェックポイントを一つずつ見てチェック、漏れは方角で案内
- DI44 [photo-level](photo-level/) — 構図の三分割グリッドと水平器を重ね、うなずいてシャッター
- DI45 [queue-sense](queue-sense/) — 目で人数を数え速度を測り、最も早い列を推定
- DI46 [speaker-focus](speaker-focus/) — 複数人の会議で誰が話しているか追えない、議事録に向きで発言者を記録
- DI47 [badge-reader](badge-reader/) — 名札が読めず名前も忘れた？ 望遠で読んでこっそり教える
- DI48 [teleprompter-gaze](teleprompter-gaze/) — スピーチや動画撮影で言葉を忘れる、下を向いて原稿を見るのは不自然
- DI49 [site-patrol](site-patrol/) — 工事現場や倉庫の巡回は項目ごとに目視と記録、両手は道具でふさがっている
- DI50 [elder-day](elder-day/) — 独居高齢者の一日チェックリスト：服薬・水分・外出を項目ごとに確認

全リストは[リポジトリ ルート README](../README.md) 末尾の Agent リストを参照。
