# med-look

Rokid 眼镜看药助手智能体（AIUI Agent）。

## 身份

一个运行在 Rokid 眼镜上的「服药记忆与登记」助手，解决老人药瓶
字小、多瓶药吃法记混的问题。服药表由你（或家人、医生）照着
处方预先建好；到了服药的时候，你拿起一瓶药，眼镜把这一瓶的
规则用大字摆出来、用语音念出来 —「降压药，早饭后，1 片」，
你亲眼把手里的瓶子和条目对上，点一下头就登记已服。今天哪
几样服了、哪几样还没服，一眼、一耳都清楚。它是记忆与记录
工具，不是医疗器械，不做任何用药判断。

## 能力

- 建表（SETUP 模式）：NAME 说药名 — 先按文档方式用
  `getUserMedia({audio:{captureSource:'microphone',
  microphoneMode:'wearer'}})` 做佩戴者模式麦克风检查，再用
  SpeechRecognition（zh-CN）一次性识别，听到的名字**原样**
  保存并显示在屏幕上等你核对（同 DI21 market-radar 的纪律）；
  主机没有识别能力时如实显示 SKIP，改为轮换四个通用类别名
  预置（降压药 / 降糖药 / 钙片 / 维生素D — 是类别称呼，
  不是真实药品品牌）。DOSE 轮换剂量（1 片 / 2 片 / 1 粒 /
  半片），WHEN 轮换时段（早上空腹 / 早饭后 / 午饭后 /
  晚饭后 / 睡前），ADD 把 {药名， 剂量， 时段} 存入 wx
  同步存储（key `medTable`，最多 6 条）。同一药名 + 同一
  时段不能重复添加；一种药一天服两次，就建成两条不同
  时段的条目。
- 今日清单（TODAY 模式，默认）：服药表按时段排序逐条列出，
  每条显示近似时段时刻与状态 — 已登记服用的显示
  「✓ 已服 + 实际时间」；时段已过、还没登记的标记
  「! 待服（未服）」；没到时段的显示「未到时间」。时段
  时刻是声明在界面上的近似锚点（空腹 ~7:00、早饭后
  ~8:00、午饭后 ~13:00、晚饭后 ~19:00、睡前 ~22:00），
  是吃饭节奏的粗略对应，不是医学上的服药时刻建议。
- 对照与登记（看瓶 → 对条目 → 点头）：拿起一瓶药，LOOK
  用 `ImageCapture.takePhoto({mode:'telephoto'})` 长焦拍
  下它的标签留作记录（不可用时回退 wx.media
  CameraContext，界面只显示字节数并标注 record only）；
  MED 轮换选到你手里这瓶对应的条目，大字行显示它的规则
  「降压药 — 早饭后 · 1 片」；TAKE（或头部稳定时点头、
  Enter）把 {药名， 时段， 日期， 时间} 追加进已服日志
  （key `medTaken`，最多 60 条）。同一种药同一时段今天
  已经登记过，TAKE 会拒绝并报出上次登记时间 — 防重复服、
  防重复记正是本 Agent 存在的理由。时段没到就提前服了，
  照实登记并在状态行标注「提前」。
- 朗读：SPEAK 用中文朗读今天还没服的清单，如「今天还要服
  2个：早饭后的降压药，1片，现在待服。晚饭后的降糖药，
  1片。」；都登记完了则报「今天表上的药都已经登记服过了。」
- DEMO：从一次 Date 快照取当天日期（纯字符串），播入
  3 条演示服药表（维生素D 早上空腹 1 粒 / 降压药 早饭后
  1 片 / 降糖药 晚饭后 1 片）与一条今晨已服记录
  （维生素D 06:58），并把演示时钟定在 09:30 — 屏幕上
  如实标注「DEMO clock (simulated)」。于是在演示时刻，
  早饭后的降压药时段（8:00）已过且未登记，正好有一条
  「待服」亮出来；选中的正是这一条。重入 DEMO 先清旧的
  演示行再播，不重复堆积。真实模式永远用真实时钟。

## 行为边界

- **它从不核对你手里的瓶子**：AIUI 运行时没有 OCR，
  长焦照片只作记录，永远不会被读取；「这瓶是降压药」
  这个判断只能由你的眼睛（或家人）做出。拿错瓶子登记，
  它抓不到你。界面、代码注释与 README 全程标注
  「agent cannot read the label」。
- **它从不给用药建议**：剂量与时段全部来自你建表时输入
  的处方信息，它只是照表提醒、照表记录。服药表必须来自
  处方（或医生/药师的说明），不要照着本 Agent 的预置
  类别名猜着建表。
- **漏服只显示「未服」，绝不建议补服或加倍**：错过时段
  的条目就如实挂着「待服（未服）」；补不补、怎么补，
  问医生或药师 — Agent 在界面、文档里都不提供这类建议。
- 这不是医疗器械，没有任何医疗认证；它不能替代药盒
  分装、家人提醒或医嘱本身。
- 相机/麦克风只在用户点 LOOK / NAME 时启动，用完立即
  停掉全部媒体轨道；大模型不参与本 Agent（没有判断
  需要它）；页面隐藏/卸载时同样清理并落盘。
- 记录只存本机 wx 同步存储，不上传、不联网；时间来自
  本机时钟，设备时钟不对，待服判断就会跟着不对，
  Agent 不做校正也不编造。
