# market-radar

Rokid 眼镜菜场雷达智能体（AIUI Agent）。

## 身份

一个运行在 Rokid 眼镜上的「摊位价格雷达」助手，解决菜市场几十个
摊位像迷宫、问过的价格转头就忘、想回头找那家便宜的摊位又找不
到的问题。手机备忘录记不了方向，眼镜可以：你站到摊位前看着它，
选好品类，用嘴说出价格，眼镜把「品类 + 价格备注 + 你当时的头部
朝向 + 时间」一起存下来。之后慢慢转头，正对某个已登记摊位时
它就亮出来，带着它当时报的价格。

## 能力

- 朝向读取：AbsoluteOrientationSensor（约 5Hz）四元数算 yaw 朝向角，
  界面如实标注来源 SENSOR / DEMO / NONE；无传感器时不编造朝向，
  REG 会拒绝并说明原因（同 #07 find-my-thing / #10 exit-radar）。
- 登记（REG 模式，默认）：CAT 轮换品类（蔬菜 / 水果 / 肉类 /
  海鲜 / 干货调料）；NOTE 用一次性 SpeechRecognition（zh-CN）记
  备注——先按文档方式用 `getUserMedia({audio:{captureSource:
  'microphone', microphoneMode:'wearer'}})` 做佩戴者模式麦克风
  可用性检查（只验证模式可用：读回设置后立即停轨道；识别由
  宿主 SpeechRecognition 以其自有麦克风完成，检查用的佩戴者
  模式不会给识别降噪），识别结果**原样**显示在 NOTE 行等你
  核对，确认后点
  REG（或头部稳定时点头、Enter）把 {品类， 备注， 朝向°， 时间
  HH:MM} 存入 wx 同步存储（key `marketStalls`，最多 8 条，
  onLoad 载入、onUnload 落盘）。**同一品类可以登记两次**——
  两家西红柿的价格都留着，比价正是本 Agent 的用途。登记成功
  后自动切到 RADAR。
- 备注的诚实回退：主机没有 SpeechRecognition 时 NOTE 如实显示
  SKIP，并改为轮换三个预置标签（便宜 / 一般 / 贵）当备注，
  绝不假装在听。
- 雷达（RADAR 模式）：对每个已登记摊位算相对角 = 摊位朝向 −
  当前头部朝向，归一化 −180°…180°，取 |相对角| 最小者；
  |相对角| ≤ 60°（正前方的锥形范围）时大字高亮
  「FACING: 水果 · 苹果5块一斤 · 10:02」并给登记详情
  「reg 180° · rel +15° · RIGHT-FRONT」与 8 向箭头；超出范围
  时显示最近摊位的方向让你继续转。SPEAK 朗读正对摊位的备注
  （「你正对着水果摊。备注：苹果五块一斤。」），没对上时朗读
  最近摊位的方向与备注。
- 列表（LIST 模式）：全部摊位以「品类 · 备注 · 朝向 · 时间」
  逐行显示，一眼比价；SPEAK 逐条朗读所有备注
  （「一共登记了三家摊位。蔬菜，西红柿三块一斤。……」）。
- DEMO：点 DEMO 在 60° / 180° / 300° 登记 3 个标注 DEMO 的
  摊位（蔬菜 西红柿3块一斤 / 水果 苹果5块一斤 / 海鲜
  虾25块一斤）并切到 RADAR；之后每点一次 DEMO 当前朝向
  +45°，朝向转到 45° 时 60° 的蔬菜摊相对角 +15°，进入
  FACING 高亮态，预览可完整演示。重入 DEMO 会先清掉旧的
  DEMO 记录再登记，不重复堆积。
- 凝视/点头：开启世界感知（enableWorldAwareness）显示头部稳定
  状态；REG 模式下头部稳定时点头 = REG，RADAR / LIST 模式下
  点头 = SPEAK。

## 行为边界

- **朝向只对你登记时站的位置成立**（同 #07 / #10 的几何边界）：
  登记的是「从我站的地方看向这个摊位」的方向，你走到市场
  另一头再转头，角度就对不上了。找摊位时要回到当初登记的
  摊位附近区域，再慢慢转头让它亮起来。市场没动，动的是你
  的位置。
- **备注是 ASR 转写，价格数字最容易听错**：NOTE 把听到的
  原文原样显示，就是为了让你在按 REG 之前亲眼核对——
  「三块」听成「十三块」这种错误，眼镜不会替你纠正，
  你看错了存进去，雷达就会一本正经地报错价。登记前请
  务必看一眼 NOTE 行。识别不可用时如实 SKIP 走预置标签，
  不伪造识别结果。
- 麦克风只在用户点 NOTE 时启动：佩戴者检查的音频流读完
  设置立即停掉全部轨道，一次性识别结束即 abort；页面
  隐藏/卸载时同样停识别器、停传感器、清定时器。
- 不录音、不上传音频：识别由系统识别服务处理，本 Agent 只
  保存你确认过的备注文本；记录只存本机 wx 同步存储。
- 声明权限只有 RECORD_AUDIO；朝向传感器在 AIUI 里不需要
  单独的权限声明；不用相机、不用定位。
