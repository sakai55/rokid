# 指向性（directional/）

指向性系列 · 编号 DI01–DI50，共 50 个。利用视线同轴、头部朝向等指向性能力解决生活问题。

- DI01 [gaze-translate](gaze-translate/) — 看着外文稳头，长焦拍下翻译并朗读
- DI02 [shelf-compare](shelf-compare/) — 扫货架条码入表比价，点头加入清单
- DI03 [expiry-check](expiry-check/) — 读包装日期算剩余天数，临期语音警告
- DI04 [plant-doctor](plant-doctor/) — 拍照识植物状态，养护步骤语音领做
- DI05 [manual-lens](manual-lens/) — 读铭牌故障码，给出下一步操作指引
- DI06 [head-nav](head-nav/) — 导航箭头跟着头转，对准方向才走
- DI07 [find-my-thing](find-my-thing/) — 看向物品语音登记，回忆位置与朝向
- DI08 [meet-point](meet-point/) — 共享定位，转头就能对准走散的朋友
- DI09 [parking-return](parking-return/) — 存车位定位朝向，回程引导找车
- DI10 [exit-radar](exit-radar/) — 环视登记出口方向，紧急时播报最近出口
- DI11 [cook-along](cook-along/) — 菜谱悬在眼前，点头翻步，油烟里只听你
- DI12 [repair-buddy](repair-buddy/) — 拍故障部位分步指导，点头确认每步
- DI13 [assemble-guide](assemble-guide/) — 对照图纸零件，按步引导组装纠错
- DI14 [garden-hands](garden-hands/) — 看着植物给修剪浇水指示，免手操作
- DI15 [baby-care-hands](baby-care-hands/) — 抱娃免手语音问答，拍照问宝宝状态
- DI16 [sound-compass](sound-compass/) — 转头扫描声源方向，报出声音在哪边
- DI17 [far-ear](far-ear/) — 远场收音转实时字幕，听清远处人声
- DI18 [cry-watch](cry-watch/) — 守听婴儿房动静，哭声立刻语音提醒

- DI24 [outfit-check](outfit-check/) — 拍照评衣物搭配与场合，照镜再评上身
- DI25 [receipt-keeper](receipt-keeper/) — 看一眼小票入账，月度汇总语音播报
- DI26 [home-find](home-find/) — 收纳时登记位置，找东西报方位线索
