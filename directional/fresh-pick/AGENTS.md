# fresh-pick

Rokid 眼镜生鲜挑手智能体（AIUI Agent）。

## 身份

一个运行在 Rokid 眼镜上的「挑水果向导」助手，解决不会挑水果、
买回家切开才发现没熟或已经坏了的问题。眼镜看不见、闻不到、
摸不着水果——它做的是把老手的挑选方法拆成四步摆在你眼前：
你看着、手里拿着的那颗，逐项用你自己的眼睛、耳朵、手和鼻子
检查，把观察到的结果报给它，它负责打分、给结论、指出最弱的
一项，还能给第二颗打分，两颗比一比。

## 能力

- 选水果（FRUIT）：5 种内置水果（西瓜 / 牛油果 / 芒果 /
  香蕉 / 桃子），每种四个真检查，按老手顺序排——如西瓜
  「纹路 → 敲声 → 瓜蒂 → 重量」、牛油果「表皮色 → 轻捏
  回弹 → 蒂头下颜色 → 晃动核声」。FRUIT 或方向键切换
  （只在首页，挑到一半不许换，防串账）。
- 手中物拍照（只作记录）：LOOK 用 `getUserMedia` 取流后以
  `ImageCapture.takePhoto({mode:'default'})` 拍下你手里
  正挑的这颗留作记录（不可用时回退 wx.media
  CameraContext），界面只显示字节数并标注 record only。
  照片不被读取、不做任何识别。
- 逐项核查（CHECK）：一次一项，大字提示（如「轻敲瓜身 —
  听是什么声」），你点自己真正观察到的那一项（每项三档：
  好 +2 / 中 +1 / 差 0），再按 NEXT 或 Enter 确认记入；
  点头（`onHeadGesture` nod，头部稳定后）只「确认已选的
  那一项」——绝不替你选、更不会自动选最好的那档。没选就
  确认会被拦下并提示先选。四项合计 /8 分。
- 结论（自动朗读）：≥7 分 **PICK IT — 熟度正好，买它**；
  4–6 分 **OK — 能买**（每种水果各有说法，如牛油果
  「再放 1–2 天」、香蕉「再放半天到一天」、西瓜不后熟
  只写「熟度中等」）；≤3 分 **SKIP IT — 放下，换一个**。
  结论都附一句「为什么」：点名四项里得分最低的那项
  （如「最弱一项：敲声『闷声』（+1）」）——那正是老手
  在下一颗上会先看的地方。SPEAK 可重读。
- 对比第二个（SECOND）：有结论后点 SECOND，把另一颗拿
  在手里再走一遍同样四项（最多比 2 颗）。第二个出分后
  给对比行「第 1 个 7 分 > 第 2 个 3 分 — 买第 1 个」
  并朗读；同分则报「一样好，拿顺手的那个」。
- DEMO：西瓜第一颗报好观察（2/2/2/1 = 7 分 → PICK IT）、
  第二颗报弱观察（1/1/0/1 = 3 分 → SKIP IT），直接走到
  带对比行的结论页，方便在没有相机的预览环境里看到
  完整的打分与对比态。

## 行为边界

- **眼镜不感测水果，感测的是你**：AIUI 运行时没有把照片
  变成成熟度结论的链路（本 Agent 不把照片送 LLM、不使用
  LLM——产品选择；平台本身支持照片经 data: URL 送入
  模型——也没有图像分类）。每一分都来自佩戴者亲眼、
  亲手、亲耳、亲鼻报的
  观察；你报错了（比如把闷声听成好声），它抓不到你。
  它是「结构化的挑选知识清单 + 计分器」，不是传感器。
  界面、代码注释与 README 全程如实标注
  「every score comes from YOUR observations」。
- 分数是经验规则，不是检测结果：检查项与打分按常见挑选
  经验写死在内置表里，品种、产地、季节都会影响判断
  （比如某些西瓜品种纹路天生浅）。结论供参考，买回家
  切开不对版，不说明流程出错——挑水果本来就没有百分百。
- 本 Agent 不判断食品安全：过熟与腐坏只按外观/气味的
  经验项打分；已经发霉、异味冲鼻的东西不要因为分数
  犹豫，直接别买。孕妇、婴幼儿等特殊人群的生鲜选择
  请遵医嘱或问专业人士。
- 相机只在用户点 LOOK 或点头时启动，拍完立即停掉全部
  媒体轨道；页面卸载时同样清理。核对流程本身不依赖
  相机，没有照片也能走完四项。
- 不上传照片，不保存拍摄内容；照片只取字节数用于状态
  显示；分数与结论只在内存里，关掉页面即消失，不落盘。
- 主机没有相机时 LOOK 显示 FAIL 并写明原因，不伪造照片。
