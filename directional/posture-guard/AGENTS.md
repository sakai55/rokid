# posture-guard

Rokid 眼镜姿势守卫智能体（AIUI Agent）。

## 身份

一个运行在 Rokid 眼镜上的「低头计时提醒」助手，解决低头看
手机、看电脑久了脖子僵的问题——你不是不知道要抬头，你是
根本没意识到这一低头就是四十分钟。它先让你看正前方校准
一次「你的平视」，之后持续监测你的头部俯仰：头低过平视
25° 就开始给这一段低头计时，超限时轻轻出声提醒一次
「抬头休息一下」，其余时间安安静静，只把本次累计低头、
最长一段和提醒次数摆在眼前。

## 能力

- 俯仰读取：`AbsoluteOrientationSensor`（约 5Hz）四元数算
  头部俯仰读数。低头是绕眼镜横轴（镜腿到镜腿的轴线）的
  转动，对应 ZYX 欧拉分解里的
  `atan2(2(wx+yz), 1−2(x²+y²))`——用合成四元数在 Node 里
  验证过：平视佩戴姿态约 +90°、低头 30° 约 +60°、抬头
  20° 约 +110°，且不随朝向（yaw）变化。界面如实标注
  来源 SENSOR / DEMO / NONE；读数本身没有意义，永远只用
  它和校准值的差（DROOP = 离你的平视低了多少度）。
- 校准（CAL，一次性）：舒适地看正前方点 CAL，当前读数
  存为平视基准，与提醒上限一起存入 wx 同步存储（key
  `postureGuard`，`{neutralPitch, limitMin}`，onLoad 载入、
  onUnload 落盘）。没有读数时 CAL 直接拒绝，绝不编造
  基准（同 #07 / #30 的规则）。
- 低头计时状态机（每 250ms 推进，本 Agent 的核心）：
  DROOP > 25° 算 DOWN，这一段低头（stretch）开始累计；
  抬头（DROOP ≤ 25°）不到 10 秒只算**暂停**——扭头看一
  眼门不算休息，计时挂起不清零；抬头满 10 秒这一段才
  **清零**并重新武装提醒。累计达到上限时提醒恰好触发
  **一次**（同一段内再低多久都不重复提醒）：
  大字「抬头休息一下」+ TTS「你已经低头二十分钟了，抬头
  看看远处，活动一下脖子。」（分钟数随上限变）。传感器
  读数缺失时一切暂停，不累计也不清零。
- 上限（LIMIT）：5 / 10 / 20 分钟轮换，默认 20 分钟
  （PLAN 定的口径）。
- 本次统计（会话内）：累计低头时长、最长一段连续低头、
  提醒次数，常驻列表显示；SPEAK 随时用中文朗读统计；
  RESET 开新会话（清统计、保留校准），CLEAR 清除校准。
- DEMO：内存里模拟一位监测中的佩戴者（不写存储、不覆盖
  真实校准）：平视 90°、当前低头 34°、进行中的一段已
  累计到 18:24 / 20:00，本次统计为纯常数（最长一段
  24:12 + 当前段 18:24 = 累计 42:36，此前已提醒过 1 次）。
  演示时钟 60 倍速，进入几秒后这一段就跨过上限、提醒
  真实触发；再点 DEMO 在「低头 34° / 抬头 −6°」之间切换
  模拟头部。DEMO 中点 CLEAR 退出演示并恢复真实校准。

## 行为边界

- **它量的是头低的角度，不是你的脖子**：眼镜只能测头部
  相对你校准平视的俯仰，测不到颈椎、肩背的受力，更不知
  道你在看什么——桌上摊一本书读，低头角度和玩手机一模
  一样，照样计时（这是提醒逻辑，不是监视逻辑）。把它当
  「休息闹钟」，不要当「体态检测仪」。
- **不是医疗建议**：提醒只是建议你抬头活动一下。脖子
  持续疼痛、头晕手麻，请去看医生，不要靠一个提醒
  Agent 扛。
- 阈值 25° 与「抬头 10 秒才清零」都是明示的经验规则，
  界面上写清；短暂抬头只暂停不清零，是为了防「抬一下
  头就骗到一段新计时」。
- 校准只对校准时的坐姿/站姿成立：换了姿势（比如从坐着
  变躺着）平视基准就偏了，重新 CAL 即可；Agent 不假装
  能自动跟随。
- 不需要任何权限：不用相机、不用麦克风、不用定位；朝向
  传感器不需要单独权限声明，故 app.json 无 permissions
  字段（同 #07 / #15 / #28 / #30）。统计只在本次会话内存
  里，校准与上限只存本机 wx 同步存储，不上传；DEMO
  数据只在内存里，永不落盘覆盖真实校准。
