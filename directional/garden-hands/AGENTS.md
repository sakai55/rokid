# garden-hands

Rokid 眼镜园艺手记智能体（AIUI Agent）。

## 身份

一个运行在 Rokid 眼镜上的「苗床方位手记」助手，解决戴着手套、
手上全是泥时没法记「哪块畦什么时候浇过水」的问题 — 结果不是
重复浇就是漏浇。站在园子里看着一块畦登记一下，眼镜记下「畦名 +
你当时的头部朝向 + 这块畦的浇水间隔」；浇完水点一下头就记上
今天浇过；哪块到期了它按逾期程度排给你看、念给你听；想找某块
畦，慢慢转头，转到正对它登记时的朝向，它就亮出来。

## 能力

- 朝向读取：AbsoluteOrientationSensor（约 5Hz）四元数算 yaw 朝向角，
  界面如实标注来源 SENSOR / DEMO / NONE；无传感器时不编造朝向，
  REG 会拒绝并说明原因（同 DI07 find-my-thing）。
- 登记（REGISTER 模式，默认）：BED 轮换内置畦名（番茄畦 /
  黄瓜架 / 香草盆 / 月季丛 / 草莓畦，各带内置浇水间隔：番茄 2 天、
  黄瓜 2 天、香草 1 天、月季 3 天、草莓 2 天）；REG（或头部稳定
  时点头）把 {畦名， 朝向°, 间隔天数， 上次浇水日期， 上次动作}
  存入 wx 同步存储（key `gardenBeds`，最多 5 块）。同一块畦重新
  登记只更新朝向与间隔，保留它的浇水历史。CLEAR 清空全部。
- 记录（LOG）：ACT 轮换刚做完的动作（浇水 / 施肥 / 修剪 /
  除虫），LOG 给选中的畦打上今天的日期戳（日期取自本机 Date）；
  动作是浇水时同时更新上次浇水日期、重置它的浇水时钟。戴着
  手套时头部稳定点头 = LOG，不用腾手。
- 到期视图（DUE 模式）：按「今天距上次浇水的天数（从没浇过算
  最逾期）− 间隔天数」排序，最逾期的排最前，到期的行打
  「! DUE」标记；顶部常驻一行最紧急的那块。SPEAK 用中文朗读
  到期汇总，如「草莓畦5天没浇了，今天该浇。番茄畦3天没浇了，
  今天该浇。」
- 找畦（FIND 模式，并常驻计算）：对每块已登记畦算相对角 =
  登记朝向 − 当前头部朝向，取角度上最近的一块显示 8 向箭头；
  |相对角| ≤ 15° 时高亮「FACING 番茄畦」，并结合到期状态
  提示是该浇了还是只是看看。
- 看畦拍照（只作记录）：LOOK 看着畦用 `getUserMedia` +
  `ImageCapture.takePhoto({mode:'default'})` 拍一张当此刻的
  生长记录（不可用时回退 wx CameraContext），界面只显示字节数
  并标注「record only」：照片不被本 Agent 保存（只取字节数），
  生长对比靠你自己在眼镜/手机相册里留的照片，本 Agent 不识别
  植物、不判断长势。
- DEMO：用运行时 Date 实时算出 3 块标注 DEMO 的畦并登记
  （番茄畦 30°、3 天前浇过 → 到期；黄瓜架 150°、1 天前浇过 →
  未到期；草莓畦 270°、5 天前浇过 → 最逾期），切到 DUE 视图；
  之后每点一次 DEMO 当前朝向 +45°，FACING 随之改变，预览可
  完整演示到期排序与找畦。

## 行为边界

- 这是「方位 + 日期手记」，不是植物监测：眼镜不测土壤湿度、
  不识别植物、不判断长势；浇水间隔是内置的经验值（按畦名查表），
  天数由你登记/记录的日期算出，没浇过水的畦如实显示「从没浇过」。
- 朝向缺失（SRC NONE 且非 DEMO）时拒绝登记，绝不编造朝向。
- 照片只在用户点 LOOK 时拍，拍完立即停掉全部媒体轨道，且不落盘
  保存；页面隐藏/卸载时停传感器、清定时器、停媒体轨道。
- 记录只存本机 wx 同步存储，不上传。
