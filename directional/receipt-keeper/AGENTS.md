# receipt-keeper

Rokid 眼镜小票账本智能体（AIUI Agent）。

## 身份

一个运行在 Rokid 眼镜上的「随手记账」助手，解决小票随手一丢、
月底不知道钱花到哪儿去了的问题。手机记账要掏手机、解锁、开
App、敲数字，一套下来小票早扔了。眼镜就在你脸上：结账时看
一眼小票拍张留底，嘴里报出总价，眼珠一扫核对金额，一点
SAVE 就入账；月底点 MONTH，本月各类别花了多少，它算好、
念给你听。

## 能力

- 拍照留底（只作记录）：LOOK 用 `getUserMedia` 取流后以
  `ImageCapture.takePhoto({mode:'telephoto'})` 长焦拍下小票
  留作你自己的视觉副本（不可用时回退 wx.media CameraContext），
  界面只显示字节数并标注 record only。运行时没有 OCR，
  照片永远不会被读取，小票上的字一个也不会被识别出来——
  账本里的金额只来自你亲口报的数。
- 报金额（AMT，一次性 ASR + 解析 + 人工核对）：先按文档方式
  用 `getUserMedia({audio:{captureSource:'microphone',
  microphoneMode:'wearer'}})` 做佩戴者模式麦克风检查（4 麦
  优先收你自己的声音，检查完立即停轨道），再用
  SpeechRecognition（zh-CN）听你报总价，如「一百二十三块五」。
  识别文本由内置解析器转成数字：同时支持阿拉伯数字
  （"123.5"、"123块5"）与中文数字（一百二十三块五 = 123.5、
  三十五 = 35、十二块八 = 12.8、九块九 = 9.9、二百 = 200、
  两千零五十 = 2050）。解析结果以大字显示在 AMT 行等你亲眼
  核对——**金额永不自动保存**。解析失败时如实显示听到的原文
  与「parse FAIL」，请重报；主机没有识别能力时如实 SKIP，
  不假装在听。
- 微调（FINE −1 / +1 / +10）：解析差一点时（如 133 听成了
  123 的近误）不用重报，用 FINE 三个键把待确认金额修正到
  正确值，再保存。没有待确认金额时 FINE 会如实拒绝。
- 入账（SAVE，显式确认为唯一入口）：CAT 轮换类别（餐饮 /
  交通 / 购物 / 家居 / 娱乐 / 其他）；SAVE 按钮或 Enter 把
  {金额， 类别， 日期（本机 Date）, 时间} 存入 wx 同步存储
  （key `receiptLedger`，最多 100 条，超出丢最旧的）。点头
  只把待确认金额朗读出来给你核对，**绝不触发保存**——防止
  听错的数字免手滑进账本。
- 月度汇总（MONTH）：按条目日期的真实年月聚合——本月各
  类别合计、总笔数、今日合计，常驻显示在汇总框；MONTH
  视图逐行列出各类别金额。往月条目仍保留在存储里（直到
  100 条上限把它们挤出），但不计入本月汇总。SPEAK 朗读
  汇总：「本月共花 419 元。餐饮 83.5 元，交通 12 元，购物
  123.5 元，家居 200 元。今天花了 47.5 元。」
- DEMO：用运行时 Date 实时算出本月内的 5 条标注 DEMO 的
  条目（今天餐饮 35.5、今天交通 12、2 天前购物 123.5、
  5 天前家居 200、10 天前餐饮 48；月初时日期钳制到本月 1 号，
  保证月度数学在预览里也是真的），直接切到 MONTH 视图看
  汇总。重入 DEMO 会先清掉旧的 DEMO 条目再播种，不重复堆积。

## 行为边界

- **眼镜从不读小票**：没有 OCR，照片只作记录、不参与任何
  判断；金额是 ASR 转写 + 解析，你没在 SAVE 前亲眼核对，
  听错的数字就会一本正经地记错账——核对环节就是为此存在
  的。解析器只覆盖常见口语形式（到万位、块/毛/角/分），
  方言说法、含糊读法（「幺」等）不在保证范围内，解析失败
  会如实 FAIL，不会猜一个数给你。
- 麦克风只在用户点 AMT 时启动：佩戴者检查的音频流读完设置
  立即停掉全部轨道，一次性识别结束即 abort；相机只在点
  LOOK 时启动，拍完立即停轨道；页面隐藏/卸载时同样清理。
- 不录音、不上传：识别由系统识别服务处理，本 Agent 只
  保存你确认过的金额、类别与时间；记录只存本机 wx 同步
  存储。
- 金额与日期全部来自本机时钟与你的口述；设备时钟不对，
  月度归属就会跟着不对，Agent 不做校正也不编造。
- 声明权限：CAMERA（小票拍照留底）、RECORD_AUDIO（报金额
  的麦克风检查与语音识别）。
