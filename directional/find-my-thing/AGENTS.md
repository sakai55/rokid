# find-my-thing

Rokid 眼镜寻物方位智能体（AIUI Agent）。

## 身份

一个运行在 Rokid 眼镜上的「方位记忆」助手，解决眼镜盒、钥匙、遥控器、
钱包放下就忘在哪的问题。放下东西时看着它登记一下，眼镜记下
「物品 + 房间 + 你当时的头部朝向 + 时间」；找的时候选中物品，
慢慢转头，转到你现在的朝向和当时登记的朝向对上，就是你当时
站在那看它的方向 — 顺着这个方向在附近找。

## 能力

- 朝向读取：AbsoluteOrientationSensor（约 5Hz）四元数算 yaw 朝向角，
  界面如实标注来源 SENSOR / DEMO / NONE；无传感器时不编造朝向，
  SAVE 会拒绝并说明原因。
- 登记（REGISTER 模式）：ITEM 轮换物品（眼镜盒 / 钥匙 / 遥控器 /
  钱包 / 药瓶 / 耳机），ROOM 轮换房间（客厅 / 卧室 / 书房 / 厨房 /
  玄关）；SAVE（或头部稳定时点头）把 {物品， 房间， 朝向°,
  时间 HH:MM} 存入 wx 同步存储（key `findMyThing`，最多 8 条，
  同一物品重新登记会覆盖旧记录）。CLEAR 清空全部。
- 寻物（FIND 模式）：PICK 轮换已登记物品；相对角 = 登记朝向 −
  当前朝向，归一化到 −180°…180°，显示 8 向大箭头与
  「TURN: LEFT-FRONT 40°」式提示；|相对角| ≤ 15° 时高亮
  「FACING IT — look around there」，并显示记忆行
  「遥控器 · 客厅 · 朝向 140° · 14:20 登记」。SPEAK 用中文朗读
  记忆行 + 相对方向。
- BLE 检查（可选）：BLE 按钮只查 navigator.bluetooth 可用性
  （getAvailability），提示可另行配对追踪器；不测距、不报 RSSI。
- DEMO：登记一条标注 DEMO 的样例记录（遥控器 · 客厅 · 朝向 140°）
  并切到 FIND；之后每点一次 DEMO 朝向 +45°，箭头随之旋转，
  转到 135° 时相对角 5° 进入 FACING IT 状态，预览可完整演示。
- 凝视/点头：开启世界感知（enableWorldAwareness）显示头部稳定
  状态；REGISTER 模式下头部稳定时点头 = SAVE，FIND 模式下
  点头 = SPEAK。

## 行为边界

- 这是「方位记忆」，不是物品追踪：眼镜记住的是你当时看向哪，
  不是物品现在在哪；物品被人移动过，朝向指引到的是你上次
  看见它的地方。README 与界面文案都如实说明。
- 记录只存本机 wx 同步存储，不上传；朝向缺失（SRC NONE 且非
  DEMO）时拒绝登记，绝不编造朝向或记录。
- BLE 只做能力检查：已文档化的 API 没有距离/RSSI，不假装有
  接近感应数值。
- 页面隐藏/卸载时停传感器、清定时器，并在卸载时把记录落盘。
