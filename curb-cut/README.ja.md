# カーブカット（curb-cut/）

[中文](README.md) | [English](README.en.md) | 日本語
中国語版（2026-10-29 時点）の翻訳。

カーブカットシリーズ。CC01–CC20（このディレクトリには現在17件）。まず特定の困りごとを抱える人の具体的な課題を1つ解き、そこから、状況次第で同じ困りごとを抱える一般の人へも広げていく。

- CC01 [drop-search](drop-search/) — 落とした小物を足元6区域で1つずつ手探りし、探し終えてから「見つからない」と報告
- CC02 [my-bus-watch](my-bus-watch/) — 登録したバス1系統だけを見守り、路線番号を照合して乗れるか告げる
- CC03 [step-count-down](step-count-down/) — 階段を1段ずつ数え下げ、残り3段から読み上げ
- CC04 [color-order-check](color-order-check/) — 配線の色名を1本ずつ読み上げ、順序を照合して誤接続を防ぐ
- CC05 [greet-name-hold](greet-name-hold/) — 挨拶中に名前を拾い、視界の隅で保持する
- CC06 [alarm-triage-visual](alarm-triage-visual/) — 聴覚障がいのある人の家で、音を視覚バナーに変えて振り分ける
- CC07 [last-sentence](last-sentence/) — グループ会話についていけないとき、直前の一文を止めて再生
- CC08 [curb-ramp-scout](curb-ramp-scout/) — 車椅子の人が交差点でスロープが左右どちらか先に知る
- CC09 [high-shelf-ask](high-shelf-ask/) — 高い棚に手が届かないとき、商品を特定して店員に取ってもらう
- CC10 [freeze-step-cue](freeze-step-cue/) — 玄関で足が出ないとき、拍ごとに一歩ずつ歩き出す
- CC11 [left-home-proof](left-home-proof/) — 外出後にガスや鍵が不安なら、記録の再生で不安を断つ
- CC12 [retrace-steps](retrace-steps/) — 来た道を忘れたら：自分の足跡を逆順にたどって戻る
- CC13 [task-anchor](task-anchor/) — 注意力のアンカー：唯一のタスクを常駐させ、区切りで軽く知らせる
- CC14 [quiet-corner](quiet-corner/) — 感覚過負荷のとき、最も静かな方向を一言で示す
- CC15 [line-by-line](line-by-line/) — 読みの障がい支援：一行を大きく表示し、うなずきで次の行へ
- CC16 [say-by-looking](say-by-looking/) — 失語の代弁：候補4文をうなずきで選び、TTSが代わりに話す
- CC17 [first-sentence](first-sentence/) — 吃音の第一声：最初の一文を単語ごとに定速表示

全リストはルートの [README](../README.md) 末尾にある Agent リストを参照。
