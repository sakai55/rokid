# 路缘坡（curb-cut/）

中文 | [English](README.en.md) | [日本語](README.ja.md)

路缘坡系列 · 编号 CC01–CC20（本目录现有 20 个）。先为一类特殊人群解决一个具体难题，再溢出到情境性障碍中的普通人。

- CC04 [color-order-check](color-order-check/) — 逐根报线材颜色名，顺序核对防接错

- CC06 [alarm-triage-visual](alarm-triage-visual/) — 听障者家中响声变视觉横幅分诊
- CC07 [last-sentence](last-sentence/) — 群聊没跟上时上一句定格回放
- CC08 [curb-ramp-scout](curb-ramp-scout/) — 轮椅者路口先知坡在左还是右
- CC09 [high-shelf-ask](high-shelf-ask/) — 够不着高货架，锁定商品请店员取
