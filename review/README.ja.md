# 再生型 REVIEW（review/）

[中文](README.md) | [English](README.en.md) | 日本語
中国語版（2026-10-29 時点）の翻訳。

注意力アドオンシリーズ。RE01–RE05、全5件。「さっき何だっけ」に答える。

- RE01 [day-lookback](day-lookback/) — 日中の視線を時刻と向きで並べ直し、夜にその順でたどって振り返る
- RE02 [talk-replay](talk-replay/) — 会話の字幕を話者の向き付きで記録。再生では約束・数字・期限だけを並べる
- RE03 [shop-replay](shop-replay/) — 迷った商品を店の向き付きで保存。再生時に価格を比べて、最安をピン留めする
- RE04 [route-replay](route-replay/) — 歩いた道で危険な地点を登録しておき、翌日の出がけに順番に予告する
- RE05 [attention-diary](attention-diary/) — 1日の注意力が誰に持っていかれたか、明細1枚で明らかにする

全リストはルートの [README](../README.md) 末尾にある Agent リストを参照。
