# 提示型 CUE（cue/）

注意力外挂系列 · 编号 CU01–CU05，共 5 个。提醒要在对的场景才响。

- CU01 [cue-door](cue-door/) — 看向大门触发清单，逐项确认全过才放行
- CU02 [cue-fridge](cue-fridge/) — 看向冰箱触发清单，拿一样勾一样关门报漏拿
- CU03 [cue-desk](cue-desk/) — 看向书桌亮今日三件事，起身按未完成给续接句
- CU04 [cue-bag](cue-bag/) — 看向要背的包触发清单，逐项看向格层确认装入
- CU05 [cue-mirror](cue-mirror/) — 看向镜子亮三行，逐行确认已读，提前结束报未读

完整清单见 [仓库根 README](../README.md) 文末的 Agent 清单。
