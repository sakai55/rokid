# キュー型 CUE（cue/）

[中文](README.md) | [English](README.en.md) | 日本語
中文版（2026-10-29 時点）からの翻訳。

注意力アドオンシリーズ · 番号 CU01–CU05、全5件。リマインドは正しい場面でのみ鳴る。

- CU01 [cue-door](cue-door/) — ドアを見るとリストが発動、項目を全て確認してから出発
- CU02 [cue-fridge](cue-fridge/) — 冷蔵庫を見るとリストが発動、取るたびにチェックし、閉めると取り忘れを報告
- CU03 [cue-desk](cue-desk/) — 机を見ると今日の3件が光り、立ち上がると未完了分に再開の一文を出す
- CU04 [cue-bag](cue-bag/) — 背負うバッグを見るとリストが発動、仕切りを一つずつ見て確認しながら詰める
- CU05 [cue-mirror](cue-mirror/) — 鏡を見ると3行が光り、一行ずつ読み終えたことを確認、早く終えると未読分を報告

全リストは[リポジトリ ルート README](../README.md) 末尾の Agent リストを参照。
