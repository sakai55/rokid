# キュー型 CUE（cue/）

[中文](README.md) | [English](README.en.md) | 日本語
中国語版（2026-10-29 時点）の翻訳。

注意力アドオンシリーズ。CU01–CU05、全5件。リマインダは、出すべき場面でだけ出す。

- CU01 [cue-door](cue-door/) — 玄関ドアを見るとリストが起動し、項目をすべて確認して初めて出られる
- CU02 [cue-fridge](cue-fridge/) — 冷蔵庫を見るとリストが起動。取るたびにチェックし、ドアを閉めると取り忘れを報告する
- CU03 [cue-desk](cue-desk/) — 机を見ると今日の3件が光る。席を立つと、未完了分には続きの一文を出す
- CU04 [cue-bag](cue-bag/) — 背負うバッグを見るとリストが起動。仕切りを1つずつ見て、入れたかどうか確認する
- CU05 [cue-mirror](cue-mirror/) — 鏡を見ると3行が光る。1行ずつ読み終えたか確認し、早く切り上げると未読分を報告する

全リストはルートの [README](../README.md) 末尾にある Agent リストを参照。
