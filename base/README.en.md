# Basics (base/)

[中文](README.md) | English | [日本語](README.ja.md)
Translated from the Chinese version (as of 2026-10-29).

Belonging to no series: my-agent is the official scaffolding sample, glasses-benchmark is a full-function benchmark self-check, stream-probe is a continuous video stream probe, and dabiaoge is the glasses-side client of a general-purpose message channel.

- [my-agent](my-agent/) — Official scaffolding sample; tap to switch greetings between Chinese and English
- [glasses-benchmark](glasses-benchmark/) — Full-function glasses self-check; 21 items run in one go with results
- [stream-probe](stream-probe/) — Continuous video-stream probe; measures stream frame-grab rate, recording data rate and frame-capture LLM latency
- [dabiaoge](dabiaoge/) — Dabiaoge: the glasses client of a general-purpose message tunnel; ask by voice, answers appear on screen

For the full list, see the Agent list at the end of the [repository root README](../README.md).
