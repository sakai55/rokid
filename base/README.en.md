# Base (base/)

[中文](README.md) | English | [日本語](README.ja.md)
Translated from the Chinese version (as of 2026-10-29).

Agents that belong to no series: my-agent is the official scaffold sample, glasses-benchmark is a full-function self-check of the glasses, stream-probe probes the continuous video stream, and dabiaoge is the glasses-side client for a general-purpose message tunnel.

- [my-agent](my-agent/) — The official scaffold sample; tap to toggle the greeting between Chinese and English
- [glasses-benchmark](glasses-benchmark/) — Full self-check of the glasses; runs 21 checks in one pass and reports the results
- [stream-probe](stream-probe/) — Continuous video-stream probe; measures frame-grab rate, recording bitrate, and frame-to-LLM latency
- [dabiaoge](dabiaoge/) — Dabiaoge: the glasses client for a general-purpose message tunnel; ask out loud, read the answer on screen

For the full list, see the Agent index at the end of the [root README](../README.md).
