# 基本項目（base/）

[中文](README.md) | [English](README.en.md) | 日本語
中文版（2026-10-29 時点）からの翻訳。

どのシリーズにも属さない：my-agent は公式スキャフォールドのサンプル、glasses-benchmark は全機能ベンチマークの自己点検、stream-probe は連続動画ストリームのプローブ、dabiaoge は汎用メッセージチャネルのグラス側クライアント。

- [my-agent](my-agent/) — 公式スキャフォールドのサンプル、タップで中国語と英語の挨拶を切り替え
- [glasses-benchmark](glasses-benchmark/) — グラスの全機能自己点検、21項目を一括で実行して結果を出す
- [stream-probe](stream-probe/) — 連続動画ストリームのプローブ、ストリームのフレーム取得率・録画データ率・フレーム取得の大規模モデル遅延を測定
- [dabiaoge](dabiaoge/) — dabiaoge：汎用メッセージトンネルのグラス側クライアント、声で質問すると画面に答えが出る

全リストは[リポジトリ ルート README](../README.md) 末尾の Agent リストを参照。
