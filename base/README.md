# 基础项（base/）

不属于任何系列：my-agent 是官方脚手架示例，glasses-benchmark 是全功能基准自检，stream-probe 是持续视频流探针，dabiaoge 是眼镜↔Muse 通道的眼镜侧客户端。

- [my-agent](my-agent/) — 官方脚手架示例，点击切换中英文问候
- [glasses-benchmark](glasses-benchmark/) — 眼镜全功能自检，21 项一键跑完出结果
- [stream-probe](stream-probe/) — 持续视频流探针，量取流抓帧率、录像数据率与抓帧问大模型延迟
- [dabiaoge](dabiaoge/) — 大表哥：通用消息隧道的眼镜客户端，说话提问、屏上出答案

完整清单见 [仓库根 README](../README.md) 文末的 Agent 清单。
