# manual-lens

Rokid 眼镜说明书眼智能体（AIUI Agent）。

## 身份

一个运行在 Rokid 眼镜上的家电故障排查向导，解决「家电跳出故障
代码、说明书早丢了、一只手还扶着机器没法翻手机」的问题。看着
铭牌/故障显示屏用长焦拍一张（只作记录），用选择器亲手确认电器
和代码，眼镜在视线内一步一步给排查计划，语音念一步你做一步，
点头进下一步——双手全程留在机器上。

## 能力

- 凝视确认：开启世界感知（enableWorldAwareness），头部稳定
  （onOrientationStabilityChange stable）后显示「HEAD STEADY」；
  点头（onHeadGesture nod）：没有计划时触发 LOOK 拍照，计划
  进行中则推进一步——用点头代替腾手点按钮。
- 看向长焦拍照（只作记录）：getUserMedia({video:true}) 取流后
  用 ImageCapture.takePhoto({mode:'telephoto'}) 拍下铭牌/显示
  屏的小字（铭牌常在机器背面/侧面，字小又远），界面显示照片
  字节数；ImageCapture 不可用时回退 wx.media CameraContext。
  照片不参与识别，故障代码由用户确认，界面如实标注。
- 电器与代码选择：DEVICE 在 5 类家电间切换（洗衣机 / 空调 /
  热水器 / 洗碗机 / 烤箱），CODE 在该类电器的常见代码间切换
  （每类 3-4 个，含简短含义）；ArrowUp / ArrowDown 切换当前
  聚焦的选择器（点 DEVICE 聚焦电器、点 CODE 聚焦代码）。
- 排查计划：FIX 先尝试 LanguageModel 按「电器 + 代码」生成
  简短计划（解析成功才采用，标注来源 LLM，并要求第 1 步为
  安全动作）；不可用或解析失败时用内置常见原因表（每代码：
  含义一句 + 4 个具体步骤），标注来源 built-in guide。NEXT /
  点头逐步推进，最后一步后显示收尾语（如「Still showing E2?
  Book a technician — quote code E2」）。
- 安全设计：内置表中凡涉水/涉电的电器，每个代码的第 1 步都是
  安全动作（先断电；洗衣机/热水器/洗碗机还包括关进水阀）；
  热水器 E4（漏电）明确要求保持断电、不要自行复位。
- 朗读：SPEAK 用 speechSynthesis.speak 朗读当前步骤（无计划
  时朗读所选电器 + 代码的含义）。
- DEMO：直接载入「洗衣机 + E2（排水问题）」的内置计划进入
  步骤视图，方便在没有相机/大模型的预览环境里看到运行态。

## 行为边界

- 本 Agent 给的是「常见原因排查指引」，不是维修结论，不替代
  专业维修：拆机、换件、加氟、电路检修一概不在步骤内，计划
  收尾统一引导用户带代码报修。
- **燃气类器具不在范围内**：燃气热水器、燃气灶等不在电器表
  内；涉及燃气泄漏风险的故障不要用本 Agent 排查，应关阀
  通风并联系燃气公司/专业人员。
- 绝不声称 OCR：运行时没有可用的文字识别链路把照片变成
  代码，故障代码一律由用户看显示屏后用选择器确认；界面、
  代码注释与 README 都如实标注「photo = record only,
  code confirmed by user」。
- 相机只在用户点 LOOK、点头或按 Enter 时启动，拍完立即停掉
  全部媒体轨道；大模型会话用完即 destroy；页面卸载时同样清理。
- 主机没有相机时 LOOK 显示 FAIL 并写明原因，不伪造照片；
  大模型不可用时如实回退内置表并标注来源。
- 不上传照片，不保存拍摄内容；照片只取字节数用于状态显示。
