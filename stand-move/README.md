# Stand Move（起身活动）

**Studio 导入地址**（复制到 Global AIUI Studio 的 Import Project 输入框）：

```
https://github.com/sakai55/rokid/tree/agent-stand-move
```

注意力外挂系列 B04（BODY 身体型，本组第四个，系列第 44 个）。久坐一上午，腰背僵了才惊觉没起过身。本 Agent 把「察觉久坐」外包出去：头部活动量 + 静止时长监测，静止满阈值提醒起身，环视一圈当作活动确认，结束给小结（提醒几次、起身几次、最长静止多久）。

## 解决的问题

久坐的注意力是事后才到的：腰背僵了才惊觉没起过身，中间几个小时全靠意志力记。本 Agent 管四件事：监测（头部活动量 + 静止时长，头动清零静止计时）、提醒（静止满 45 / 60 分钟横幅 + 一次语音「该起身活动了」，提醒未确认不再重复出声）、确认（环视一圈——偏航角左右各过阈值，或 SWEEP 按键兜底——即确认一次起身，计时重置）、小结（提醒几次、起身几次、最长静止多久，确认后清空）。

## 注意力外挂设计（BODY 身体型）

- **它测不出你是不是真的站起来了，环视只是头部转动代理**：本 Agent 没有身体传感器，不知道你是不是真的站起来、走动或伸展。所谓「起身几次」的意思是「环视确认了几次」。这一点 UI 与本 README 如实写明。
- **头动清零静止计时**：监测中任何头部方向变化都算活动，静止计时清零、最长静止保留。阈值是静止时长阈值，不是墙上时间阈值——这正是它和 water-watch 的区别（water-watch 的间隔是墙上时间，头动不停表）。
- **提醒只出声一次**：跨过阈值时横幅 + 一次语音；提醒未确认时后续计时只亮横幅、不再重复出声，免得骚扰。
- **点头不是起身**：点头只在待机开始监测、在小结页确认清空；监测中与提醒中的点头一律忽略并说明。把点头算成一次起身，等于谎报你站起来了，代码拒绝这样做；确认只能环视或 SWEEP。
- **偏航环视是防御性实现**：若宿主不投递偏航事件，SWEEP 按键就是确认——不假装偏航事件在所有真机上都可用。
- **阈值是固定档位，不是按你身体状态调整的**：只有 45 与 60 分钟两档，待机时 MODE 切换，监测进行中拒绝换档——进行中的监测不会被悄悄重定时。
- **纠错便宜，销毁需确认**：监测页返回键回待机（本轮保留，START 恢复同一轮）；小结页返回键回监测前的状态（提醒还在就不删东西，小结重建）；确认（小结页点 END 或头稳点头）才清空本轮计数；没有 DEL 键。
- **只记本次会话，关掉即清**：静止分钟、起身次数、提醒次数与小结只存会话内存，关掉 Agent 即清——上一轮的久坐记录对下一轮没有任何意义，存下来才是误导。
- **不是医疗建议**：本 Agent 不诊断腰背问题、不承诺任何活动效果、不设定医疗日程——两档阈值只是 plain 的计时预设。严重不适请寻求专业帮助，头晕立即停下。
- **为什么胸前设备做不了**：久坐提醒是「头部活动量 + 静止时长 + 视线内提醒 + 环视确认」——胸前设备既看不到你的头部活动，也没办法把提醒钉在你视线里，更没法用环视当确认。监测、提醒、确认三条都只有头戴设备成立。

## 与邻近 Agent 的分工

- 注意力系列 `eye-rest`（B01）：近视持续计时——头稳才计、头动暂停，满 20 分钟远眺提醒，抬头看远自动确认。本 Agent 不计近视：它计静止时长，头动清零，确认是环视一圈。
- 注意力系列 `water-watch`（B02）：水杯方向登记 + 距上次喝水墙上时间计时 + 喝完凝视确认。本 Agent 不登记方向、不数习惯：它的唯一输入是头部活动，唯一输出是起身提醒与小结；且它的间隔是静止时长（头动清零），不是墙上时间。
- 注意力系列 `breath-pace`（B03）：视线内吸-停-呼节拍光点——按固定拍子走，输出节拍与时长小结。本 Agent 不走节拍：它监测不动，输出提醒与活动确认。

## 功能流程

1. **选阈值（MODE）**：待机时点 MODE 在 45 与 60 分钟间切换；监测进行中 MODE 会拒绝并说明先停下。
2. **监测（START）**：点 START 开始，静止计时走；头动清零计时；静止满阈值横幅 + 一次语音提醒起身。
3. **确认（环视 / SWEEP）**：提醒后左右环视一圈（偏航角左右各过 20°）即确认一次起身，计时重置；宿主不投递偏航事件时点 SWEEP 同样确认。
4. **结束与小结（END）**：监测中或提醒中点 END 出小结（提醒几次、起身几次、最长静止多久）；返回键回监测前的状态（不删东西），小结页点 END 或头稳点头确认后清空本轮计数。

## 权限

- 无权限（`permissions: []`）：方向传感器 + 计时 + 提醒不需要任何权限。不拍照、不录音、不定位。

## 手势映射

- 点按（tap / Enter）：待机 START 开始监测；提醒中 Enter 环视确认；小结页 END 确认清空；监测中 Enter 忽略（头动自会清零计时，无需点按）。
- 双击（double-tap / Backspace）：返回上一态（监测/提醒→待机保留本轮；小结→监测前的状态不删东西）。
- 滑动（swipe / ArrowUp-Down）：在三行信息（当前静止 / 起身确认 / 最长静止）间切换焦点。
- 头稳 + 点头（head-steady + nod）：待机开始监测；小结页确认清空；监测中与提醒中的点头一律忽略（点头不是起身）。
- 单指长按：唤出 AI 语音助手（系统默认）；双指长按：AI 快捷指令（固定文本，零 ASR 启动）。
