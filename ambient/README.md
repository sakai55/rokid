# 环境型 AMBIENT（ambient/）

中文 | [English](README.en.md) | [日本語](README.ja.md)

注意力外挂系列 · 编号 AM01–AM05，共 5 个。环境一直在变，它替你留意。

- AM01 [light-change](light-change/) — 相机定时测光，光线暗了提醒开灯
- AM02 [sky-watch](sky-watch/) — 登记晾晒区，定时回看天空云变预警
- AM03 [noise-map](noise-map/) — 转头扫 8 方向，报最安静的朝向
- AM04 [trail-back](trail-back/) — 沿途登记路口面包屑，返程反向逐点领回
- AM05 [tomorrow-stage](tomorrow-stage/) — 睡前登记明早要用的物品，出门逐项确认带齐

完整清单见 [仓库根 README](../README.md) 文末的 Agent 清单。
