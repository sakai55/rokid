# 環境型 AMBIENT（ambient/）

[中文](README.md) | [English](README.en.md) | 日本語
中文版（2026-10-29 時点）からの翻訳。

注意力アドオンシリーズ · 番号 AM01–AM05、全5件。環境は常に変わるので、代わりに気を配る。

- AM01 [light-change](light-change/) — カメラで定時に光量を測り、暗くなったら照明をつけるよう促す
- AM02 [sky-watch](sky-watch/) — 洗濯物を干す場所を登録し、定時に空を見直して雲の変化を予告
- AM03 [noise-map](noise-map/) — 頭を回して8方向を走査し、最も静かな方角を知らせる
- AM04 [trail-back](trail-back/) — 途中の交差点をパンくずとして登録し、帰りは逆順に一つずつ案内
- AM05 [tomorrow-stage](tomorrow-stage/) — 就寝前に明日の朝使う物を登録し、外出時に項目ごとに持ち物を確認
