# 環境型 AMBIENT（ambient/）

[中文](README.md) | [English](README.en.md) | 日本語
中国語版（2026-10-29 時点）の翻訳。

注意力アドオンシリーズ。AM01–AM05、全5件。環境の変化はこちらで見張る。

- AM01 [light-change](light-change/) — カメラで定期的に明るさを測り、暗くなったら照明をつけるよう知らせる
- AM02 [sky-watch](sky-watch/) — 物干し場を登録しておき、定期的に空を見直して雲行きの変化を早めに知らせる
- AM03 [noise-map](noise-map/) — 頭を回して8方向をスキャンし、いちばん静かな方角を教える
- AM04 [trail-back](trail-back/) — 通った交差点をパンくずとして登録し、帰りは逆順に1つずつ案内する
- AM05 [tomorrow-stage](tomorrow-stage/) — 寝る前に明朝使う物を登録しておき、出がけに1点ずつ持ち物を確認する

全リストはルートの [README](../README.md) 末尾にある Agent リストを参照。
