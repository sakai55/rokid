# speaker-focus

Rokid 眼镜发言聚焦智能体（AIUI Agent）。

## 身份

一个运行在 Rokid 眼镜上的「会议纪要按朝向标注」助手，解决多人
会议里谁在说话跟不上、纪要记不全的问题。它的办法是眼镜独有的：
会前把每个座位绑在你的头部朝向上，会中你转头对准正在说话的
人，它把宿主识别到的每句话按「你当时面对的座位」打上标签。它
标注的永远是你面对的方向，不是说话人的身份——这一点写在界面
常驻行、朗读开场和提审文案里，从不含糊。

## 能力

- 座位登记（SEAT，上限 6）：看着某个座位点 SEAT，把当前头部
  朝向（`AbsoluteOrientationSensor` 四元数 yaw）与这个座位绑
  定，再口述姓名：先按文档方式做佩戴者模式麦克风**可用性
  检查**（开流、读回 settings、立即停轨，结果单独记在
  `MIC CHECK:` 行；检查流不是识别的输入），再用宿主
  SpeechRecognition（zh-CN）一次性识别，姓名**原样**存下。
  主机没有识别能力或识别报错时如实改走标注过的预置名牌轮换
  （座位1..6 / 主持人 / 客户，滑动轮换、单击确认，来源记
  `chip`）。没有朝向读数时 SEAT 直接拒绝，绝不编造方向。
  座位只存 {姓名， 朝向， 来源} 文本，进 wx 存储 `speakerSeats`。
- 朝向→座位（FACING）：实时把当前朝向换算成最近的登记座位
  （±30° 锥内、|相对角| 最小者胜、并列取先登记者），大字显
  示 `FACING: 某某`；锥外显示「—」并写明原因。相对角约定同
  兄弟 Agent：目标朝向 − 当前朝向，+ 为右。
- 聆听轮（LISTEN）：先做 far-field **检查**——以
  `microphoneMode: 'far-field'` 开 getUserMedia 流、读回实际
  模式、用 Web Audio AnalyserNode 显示约 0.6 秒会议室电平，
  然后**停掉全部轨道**（设备不支持该模式报
  OverconstrainedError 时回退默认麦克风并如实标注）；检查之
  后才启动宿主 SpeechRecognition 连续识别。每句定稿按**那一
  刻**的朝向打标签：锥内记座位名、锥外记「朝向未登记」。纪要
  上限 30 段，超出丢最旧并在事件行注明。
- 纪要（LIST / SPEAK）：LIST 显示最近 4 段（时间 + 标签 +
  原文），滑动可前后翻窗；SPEAK 按标签首次出现顺序分组朗
  读，开场先声明「标注的只是你当时面对的方向，不是声音识
  别」，每组念「你当时看着 X 的方向时，记下：……」——从不
  念成「X 说」。纪要只存 {日期， 时间， 标签， 原文} 文本到
  wx 存储 `speakerMinutes`，从不存音频。CLEAR 两段确认只清
  纪要，座位保留。
- 手势优先（档案 §3.2.1 触控板手势）：单击（Enter）= 开/停
  聆听轮（命名中 = 确认预置名牌 / 退出语音命名改走名牌）；滑
  动（ArrowUp/Down）= 翻纪要窗（命名名牌模式时 = 轮换名
  牌）；双击（Backspace）= 返回，由宿主处理；头部稳定时点
  头（nod）= 空闲时开一轮聆听。点头从不登记座位、从不清纪
  要。屏幕保留 6 个按钮（SEAT / LISTEN / LIST / SPEAK /
  CLEAR / DEMO），README「手势映射」逐个说明。
- DEMO：内存里播入一张演示桌——王工 @−40° / 李经理 @0° /
  客户赵总 @+45° 与 3 段已打标签的纪要（一段特意标「朝向未
  登记」）；之后每点一次 DEMO 演示朝向 +45°，FACING 随之变
  化，转满一圈退出并恢复真实记录；DEMO 中 LISTEN 播入标注
  DEMO 的示例句、按演示朝向打标签。演示全程不写任何存储。

## 行为边界

- **标注是朝向，不是身份**：本 Agent 没有、也不声称有声纹 /
  说话人识别。两个人换座、你转头慢了一拍、两个人同时开口，
  标签就会错——所以朗读与文案永远说「你当时看着 X 的方向」，
  分享纪要前请自己核对。两个人坐在同一方向（前后排）时，
  朝向本来就分不开他们，界面不会假装能分。
- **麦克风模式不塑造识别**（2026-10-24 能力边界审计口径）：
  far-field 只作用于检查用的 getUserMedia 流（可用性检查 +
  电平显示），检查流停轨之后宿主 SpeechRecognition 才在它自
  己的麦克风上开始识别；模式对识别结果没有任何影响，文档与
  界面都不声称 far-field 让转写更准。佩戴者模式同理，只用
  于登记姓名前的可用性检查。
- **没有音频留存**：本 Agent 全程不录音、不存音频——检查流
  的电平读数用完即弃，纪要只有宿主识别出的文字。识别错了就
  是错的纪要，朗读正是让你核对的一环。
- 朝向只对你登记时站/坐的位置成立（同 #07/#28 的几何边
  界）：换座位、换会议室，座位朝向必须重新登记。
- 提醒只在 Agent 打开时存在：没有后台监听，关掉页面就没有
  人在记纪要——界面与文案不声称后台记录。
- TTS 从不设置 `utterance.lang`（宿主不采纳该属性，档案
  §2.6）。麦克风只在用户点 SEAT（命名检查）/ LISTEN（检查
  流 + 宿主识别）时启动，检查流用完立即停轨；声明权限只有
  RECORD_AUDIO（麦克风可用性检查、姓名口述与发言识别）。
