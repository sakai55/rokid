# Breath Pace（呼吸节拍）

**Studio 导入地址**（复制到 Global AIUI Studio 的 Import Project 输入框）：

```
https://github.com/sakai55/rokid/tree/agent-breath-pace
```

注意力外挂系列 B03（BODY 身体型，本组第三个，系列第 43 个）。紧张/焦虑时呼吸乱成一团，自己数拍子反而更慌。本 Agent 把数拍子外包出去：视线内呼吸节拍光点（吸-停-呼），跟着看就行，拍子由它数，结束给时长小结（跟了几轮、本次多长）。

## 解决的问题

紧张时呼吸的注意力是反噬的：自己数拍子要分心去数，数着数着更慌。本 Agent 管四件事：节拍（视线内吸-停-呼光点循环，拍档 4-2-6 / 4-4-6，待机时 MODE 切换）、跟看（用户只需看着光点跟，不用自己数）、相位提示（相位切换时报一次相位名，MUTE 关掉语音只看光点）、小结（跟了几轮、本次多长，确认后清空）。

## 注意力外挂设计（BODY 身体型）

- **它测不出你的呼吸，只是一个节拍器**：本 Agent 没有呼吸传感器，不知道你是不是真的跟着吸呼。所谓「跟了几轮」的意思是「节拍器走完了几圈」。这一点 UI 与本 README 如实写明。
- **拍长是固定档位，不是按你实时状态调整的**：只有 4-2-6 与 4-4-6 两档，待机时 MODE 切换，节拍进行中拒绝换档——进行中的节拍不会被悄悄重定时。
- **相位名只报一次，MUTE 后只看光点**：每次进入新相位报一次相位名（吸/停/呼）；点 MUTE 后相位切换不出声，节拍变成纯视觉；SPEAK 主动点才会把当前相位读出来。
- **点头不是呼吸**：点头只在待机开始节拍、在小结页确认清空；节拍中的点头一律忽略并说明。把点头算成一次呼吸，等于谎报你跟了一拍，代码拒绝这样做；暂停只能点 PAUSE。
- **纠错便宜，销毁需确认**：节拍页返回键回待机（本轮保留，START 恢复同一轮）；小结页返回键回节拍（不删东西，小结重建）；确认（小结页点 END 或头稳点头）才清空本轮计数；没有 DEL 键。
- **只记本次会话，关掉即清**：相位、轮数、总秒数与小结只存会话内存，关掉 Agent 即清——上一轮的呼吸记录对下一轮没有任何意义，存下来才是误导。
- **不是医疗建议**：本 Agent 不治疗焦虑、不承诺任何平复效果、不设定医疗日程——两档拍子只是 plain 的计时节拍。严重不适请寻求专业帮助，头晕立即停下。
- **为什么胸前设备做不了**：呼吸节拍是「视线里常驻的光点 + 相位切换的报时」——胸前设备没有办法把节拍钉在你视线里，掏手机看节拍等于又多一次分心。光点、报时、跟看三条都只有头戴设备成立。

## 与邻近 Agent 的分工

- 注意力系列 `eye-rest`（B01）：近视持续计时——头稳才计、头动暂停，满 20 分钟远眺提醒，抬头看远自动确认。本 Agent 不计近视：它按固定拍子走吸-停-呼，输出的是节拍与时长小结。
- 注意力系列 `water-watch`（B02）：水杯方向登记 + 距上次喝水墙上时间计时 + 喝完凝视确认。本 Agent 不登记方向、不数习惯：它的唯一输入是 START / PAUSE / MODE / MUTE，唯一输出是节拍。
- 注意力系列 `standup-echo`（S04）：站会模块关键词门——命中成关联笔记，非命中成一行截取摘要，会后 REVIEW。本 Agent 没有关键词、没有笔记：它只走节拍。

## 功能流程

1. **选拍档（MODE）**：待机时点 MODE 在 4-2-6 与 4-4-6 间切换；节拍进行中 MODE 会拒绝并说明先停下。
2. **跟节拍（START）**：点 START 开始，视线内光点按吸-停-呼循环；相位切换报一次相位名；每走完一圈轮数 +1；真机一秒一跳，DEMO 用步进演示。
3. **暂停与静音（PAUSE / MUTE）**：PAUSE 暂停/继续节拍，暂停时计时停住；MUTE 关掉相位语音，只看光点。
4. **结束与小结（END）**：节拍中点 END 出小结（跟了几轮、本次多长、拍档）；返回键回节拍（不删东西），小结页点 END 或头稳点头确认后清空本轮计数。

## 权限

- 无权限（`permissions: []`）：节拍光点 + 计时 + TTS 相位报不需要任何权限。不拍照、不录音、不定位。

## 手势映射

- 点按（tap / Enter）：待机 START 开始节拍；节拍中 Enter 暂停/继续；小结页 END 确认清空。
- 双击（double-tap / Backspace）：返回上一态（节拍→待机保留本轮；小结→节拍不删东西）。
- 滑动（swipe / ArrowUp-Down）：在三行信息（当前相位 / 已跟轮数 / 本次时长）间切换焦点。
- 头稳 + 点头（head-steady + nod）：待机开始节拍；小结页确认清空；节拍中的点头一律忽略（点头不是呼吸）。
- 单指长按：唤出 AI 语音助手（系统默认）；双指长按：AI 快捷指令（固定文本，零 ASR 启动）。
