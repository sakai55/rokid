中文 | [English](README.en.md) | [日本語](README.ja.md)

注意力外挂系列 · 编号 CO01–CO05，共 5 个。它证明「都看过了」。

- CO01 [last-glance](last-glance/) — 离开前环视存档最后画面，焦虑时按区回放
- CO02 [room-sweep](room-sweep/) — 睡前逐项巡房确认打勾，漏项按方位提醒补看
- CO03 [proof-sweep](proof-sweep/) — 逐行指读记进度，跳行漏段当场提醒给覆盖率
- CO04 [pack-sweep](pack-sweep/) — 清单逐件看向登记，出门前点名没装的那几件
- CO05 [shelf-sweep](shelf-sweep/) — 货架分层分段记已扫格，没扫的格点名提醒
