# カバー型 COVER（cover/）

[中文](README.md) | [English](README.en.md) | 日本語
中文版（2026-10-29 時点）からの翻訳。

注意力アドオンシリーズ · 番号 CO01–CO05、全5件。「全部見た」ことを証明する。

- CO01 [last-glance](last-glance/) — 出かける前に見回して最後の光景を保存、不安なときはエリアごとに再生
- CO02 [room-sweep](room-sweep/) — 就寝前に部屋を項目ごとに確認してチェック、漏れた項目は方角で知らせて見直しを促す
- CO03 [proof-sweep](proof-sweep/) — 行を指で追って読み進捗を記録、飛ばした行や段落をその場で知らせ、カバー率を出す
- CO04 [pack-sweep](pack-sweep/) — リストの品を一つずつ見て登録、出発前にまだ入っていない品を名指しする
- CO05 [shelf-sweep](shelf-sweep/) — 棚を層と区画ごとに走査済みとして記録、まだ走査していない区画を名指しで知らせる

全リストは[リポジトリ ルート README](../README.md) 末尾の Agent リストを参照。
