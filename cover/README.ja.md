# カバー型 COVER（cover/）

[中文](README.md) | [English](README.en.md) | 日本語
中国語版（2026-10-29 時点）の翻訳。

注意力アドオンシリーズ。CO01–CO05、全5件。「全部見た」を裏付ける。

- CO01 [last-glance](last-glance/) — 出かける前に見回して最後の様子を保存。不安なときはエリアごとに再生できる
- CO02 [room-sweep](room-sweep/) — 就寝前に部屋を項目ごとに確認してチェック。漏れた項目は方角で知らせて見直してもらう
- CO03 [proof-sweep](proof-sweep/) — 指で行を追いながら読み、進み具合を記録。飛ばした行や段落はその場で知らせ、カバー率を出す
- CO04 [pack-sweep](pack-sweep/) — リストの品を1つずつ見て登録。出がけに、まだ入っていない物を名指しする
- CO05 [shelf-sweep](shelf-sweep/) — 棚を段・区画ごとにスキャン済みとして記録し、まだ見ていない区画を名指しで知らせる

全リストはルートの [README](../README.md) 末尾にある Agent リストを参照。
